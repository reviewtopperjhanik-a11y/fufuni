## Outbound Webhooks
Outbound webhooks are used to notify third-party services of specific events occurring within the Fufuni e-commerce framework. This reference will cover how webhook payloads are secured, the retry mechanism, and how developers can register new webhook events and view logs in the Admin UI.

### Webhook Payload Security
Webhook payloads are secured using the following headers:

* `X-Fufuni-Signature`: an HMAC-SHA256 hex signature of the payload, generated using a secret key.
* `X-Fufuni-Timestamp`: a Unix timestamp of when the webhook was sent.
* `X-Fufuni-Delivery-Id`: a unique delivery ID for the webhook.
* `User-Agent`: set to `Fufuni-Webhook/1.0`.

The `X-Fufuni-Signature` header is generated using the `signPayload` function, which takes the payload and secret key as input:
```typescript
async function signPayload(payload: string, secret: string): Promise<string> {
  const encoder = new TextEncoder();
  const key = await crypto.subtle.importKey(
    'raw',
    encoder.encode(secret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign']
  );
  const signature = await crypto.subtle.sign('HMAC', key, encoder.encode(payload));
  return Array.from(new Uint8Array(signature))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('');
}
```
The secret key is generated using the `generateWebhookSecret` function, which produces a `whsec_` prefixed 64-character lowercase hex string:
```typescript
export function generateWebhookSecret(): string {
  const bytes = new Uint8Array(32);
  crypto.getRandomValues(bytes);
  return (
    'whsec_' +
    Array.from(bytes)
      .map((b) => b.toString(16).padStart(2, '0'))
      .join('')
  );
}
```
### Retry Mechanism
The retry mechanism is implemented using Cloudflare cron and the `webhook_deliveries` table. The `dispatchWebhooks` function is responsible for sending webhooks and tracking deliveries:
```typescript
export async function dispatchWebhooks(
  stub: DOStub,
  ctx: ExecutionContext,
  eventType: WebhookEventType,
  data: Record<string, unknown>
): Promise<void> {
  // ...
}
```
The `MAX_ATTEMPTS` constant is set to 3, with an exponential backoff of 2^attempt × 1000 ms. Retries are attempted on network errors, 5xx, and 429 status codes, but not on other 4xx status codes.

The `webhook_deliveries` table has the following columns:

* `id`: a unique delivery ID.
* `webhook_id`: the ID of the webhook being delivered to.
* `event_type`: the type of event being delivered.
* `payload`: the JSON payload of the webhook.
* `status`: the status of the delivery (pending, success, or failed).
* `attempts`: the number of attempts made to deliver the webhook.
* `response_code`: the HTTP response code of the delivery.
* `response_body`: the HTTP response body of the delivery.
* `created_at`: the timestamp when the delivery was created.
* `last_attempt_at`: the timestamp when the last delivery attempt was made.

### Registering New Webhook Events and Viewing Logs
Developers can register new webhook events by creating a new webhook in the Admin UI (/admin/webhooks). The Admin UI also allows developers to view delivery logs, including the status and response code of each delivery attempt.

The following built-in event types are available:

* `order.created`: triggered when a new order is placed.
* `order.updated`: triggered when an order status changes.
* `order.shipped`: triggered when an order is marked as shipped.
* `order.refunded`: triggered when an order is refunded.
* `inventory.low`: triggered when the available stock of a product falls below the `LOW_INVENTORY_THRESHOLD` (5).

Developers can also view and rotate the secret key for each webhook in the Admin UI.

### Example Code
To create a new webhook, developers can use the following code:
```typescript
const webhook = {
  url: 'https://example.com/webhook',
  events: ['order.created', 'order.updated'],
  secret: generateWebhookSecret(),
};

const response = await postJson('/webhooks', webhook);
```
To view delivery logs for a webhook, developers can use the following code:
```typescript
const webhookId = 'WEBHOOK_ID';
const response = await getJson(`/webhooks/${webhookId}/deliveries`);
```
To rotate the secret key for a webhook, developers can use the following code:
```typescript
const webhookId = 'WEBHOOK_ID';
const newSecret = generateWebhookSecret();
const response = await putJson(`/webhooks/${webhookId}/secret`, { secret: newSecret });
```
