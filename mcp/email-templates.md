## Email Templates and Dispatch
The Fufuni e-commerce framework provides a robust email templating and dispatching system. This system allows for customizable email templates, variable interpolation, and reliable dispatching of emails to customers.

### 1. Email Template Storage and Editing
Email templates are stored in the database (`order_email_settings` table) and can be edited from `/admin/email-templates`. The table stores separate rows for each event type (e.g., `pending`, `paid`, `shipped`, etc.) and a "global" fallback row.

### 2. Variable Interpolation
Variables are interpolated into email templates using the `lib/order-email.ts` module. The available variables are injected into the template strings using the `{{variable}}` syntax. The following variables are supported:

* `{{storeName}}`
* `{{orderNumber}}`
* `{{orderUrl}}`
* `{{status}}`
* `{{total}}`
* `{{customerName}}`
* `{{trackingNumber}}`
* `{{trackingUrl}}`

These variables are replaced with actual values from the order data when the email is dispatched.

### 3. Troubleshooting
If emails do not send as expected, here are some common issues to check:

* **Absent `MAILGUN_API_KEY`**: If the `MAILGUN_API_KEY` environment variable is not set, email sending will be silently ignored. Always check logs if emails do not send.
* **Template syntax errors**: Verify that template variables are correctly formatted and match the supported variables.
* **Database issues**: Ensure that the `order_email_settings` table is properly populated and that the database connection is stable.

## Code Examples
The following code examples demonstrate how email templates are rendered and dispatched:

### Rendering an Order Confirmation Email
```typescript
import { buildOrderConfirmationEmail } from './email-templates';
import { sendOrderConfirmationEmail } from './order-email';

const order = {
  id: 'ord-123',
  customer_email: 'customer@example.com',
  number: 'ORD-123',
  total_cents: 1000,
  currency: 'USD',
};

const email = buildOrderConfirmationEmail({
  orderNumber: order.number,
  orderUrl: 'https://example.com/order/123',
  STORE_NAME: 'Example Store',
  totalcents: order.total_cents,
  currency: order.currency,
});

sendOrderConfirmationEmail({
  to: order.customer_email,
  subject: email.subject,
  html: email.html,
  text: email.text,
});
```

### Editing Email Templates
To edit email templates, navigate to `/admin/email-templates` and modify the template strings for each event type. For example, to update the subject line for the `paid` event:

```sql
UPDATE order_email_settings
SET subject = 'Your payment has been confirmed!'
WHERE event = 'paid';
```
