## Email Templates and Dispatch

Email templates in the Fufuni e-commerce framework are stored in the database, specifically in the `order_email_settings` table. These templates can be edited from the administration interface at `/admin/email-templates`. Both HTML and plain text versions of the templates are stored, allowing for flexible rendering of emails in various clients.

### Variable Interpolation

Template variables are interpolated using the `lib/order-email.ts` module. This module replaces placeholders such as `{{order_id}}`, `{{customer_name}}`, etc., with actual values. The available variables are defined in the `OrderEmailVars` interface and include:

* `storeName`: The display name of the store.
* `orderNumber`: A human-readable order number.
* `orderUrl`: The full URL to the order status page.
* `status`: The current status of the order.
* `total`: The total cost of the order.
* `customerName`: The name of the customer.
* `trackingNumber`: The tracking number for the order, if applicable.
* `trackingUrl`: The URL to track the order, if applicable.

These variables can be used in both the HTML and text body of the email templates.

### Troubleshooting

When troubleshooting email dispatch issues, it's essential to check the logs for errors. One common issue is the absence of the `MAILGUN_API_KEY` environment variable. Without this key, email sending is silently ignored, and no error messages are displayed. Always verify that this key is set correctly in your environment to ensure that emails are sent successfully.

Additionally, ensure that the email templates are correctly configured and that the variables are properly interpolated. If emails are not being received, check the spam folder and verify that the email addresses are correct.

### Example Usage

To send an order confirmation email, you can use the `buildOrderConfirmationEmail` function from `lib/email-templates.ts`. This function takes an object with the required parameters, such as `orderNumber`, `orderUrl`, `STORE_NAME`, `totalcents`, and `currency`, and returns an object with the subject, HTML body, and text body of the email.

```typescript
import { buildOrderConfirmationEmail } from '../lib/email-templates';

const params = {
  orderNumber: 'ORD-12345',
  orderUrl: 'https://example.com/order/ORD-12345',
  STORE_NAME: 'Example Store',
  totalcents: 10000,
  currency: 'USD',
};

const email = buildOrderConfirmationEmail(params);
console.log(email.subject); // Output: Order Confirmation ORD-12345 — Example Store
console.log(email.html); // Output: HTML body of the email
console.log(email.text); // Output: Text body of the email
```
