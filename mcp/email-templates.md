## Email Templates and Dispatch
The email templating and dispatching system is a crucial component of the Fufuni e-commerce framework. Email templates are used to generate transactional emails, such as order confirmations and status updates, which are sent to customers via Mailgun.

### Email Template Storage and Editing
Email templates are stored in the database in the `order_email_settings` table. Each template has a corresponding HTML and text version, which can be edited from the `/admin/email-templates` administration interface. The available variables that can be used in the templates, such as `{{order_id}}` and `{{customer_name}}`, are injected by the `lib/order-email.ts` module.

### Variable Interpolation
The `lib/order-email.ts` module is responsible for interpolating variables in the email templates. It uses a templating engine to replace placeholders in the template with actual values. The available variables that can be used in the templates are defined in the `OrderEmailVars` interface, which includes fields such as `storeName`, `orderNumber`, `orderUrl`, `status`, `total`, `customerName`, `trackingNumber`, and `trackingUrl`.

### Example of Variable Interpolation
For example, in an email template, you might have a placeholder for the order number: `{{orderNumber}}`. When the email is generated, the `lib/order-email.ts` module will replace this placeholder with the actual order number, using the `renderTemplate` function:
```typescript
function renderTemplate(template: string, vars: OrderEmailVars): string {
  return template

```
### Troubleshooting
If emails are not being sent, there are several things to check:

*   **MAILGUN_API_KEY**: Make sure that the `MAILGUN_API_KEY` environment variable is set. If it is not set, email sending will be silently ignored. Check the logs for any error messages related to Mailgun.
*   **Mailgun Configuration**: Verify that the Mailgun configuration is correct, including the API key, domain, and from address.
*   **Email Template Configuration**: Check that the email templates are configured correctly, including the HTML and text versions, and that the variables are being interpolated correctly.

By following these troubleshooting steps, you should be able to identify and resolve any issues with email templating and dispatching in the Fufuni e-commerce framework.
