## Email Templates and Dispatch

Email templates are a crucial component of the Fufuni e-commerce framework, enabling customized transactional emails to be sent to customers. This reference guide outlines where email templates are stored, how variables are interpolated, and troubleshooting tips.

### Email Template Storage and Editing

Email templates are stored in the `order_email_settings` table in the database. These templates can be edited from the `/admin/email-templates` route, which provides a user-friendly interface for modifying the HTML and text bodies of the email templates.

```typescript
// Example of fetching and updating an email template
import { getDb } from '../db';
import { EmailSettingSchema } from '../routes/order-email-settings';

const db = getDb();
const emailSettings = await db.orderEmailSettings.findFirst({
  where: { event: 'pending' },
});

if (emailSettings) {
  const updatedSettings: UpsertEmailSettingBody = {
    enabled: true,
    subject: 'New Subject',
    html_body: '<h1>New HTML Body</h1>',
    text_body: 'New Text Body',
  };

  await db.orderEmailSettings.update({
    where: { id: emailSettings.id },
    data: updatedSettings,
  });
}
```

### Variable Interpolation

Variables in email templates are interpolated using the `lib/order-email.ts` module. This module replaces placeholders like `{{order_id}}` and `{{customer_name}}` with actual values.

```typescript
// Example of interpolating variables in an email template
import { renderTemplate } from './order-email';

const template = 'Hello {{customer_name}}, your order {{order_id}} has been processed.';
const vars: OrderEmailVars = {
  storeName: 'Fufuni Store',
  orderNumber: 'ORD-12345',
  orderUrl: 'https://example.com/orders/ORD-12345',
  status: 'pending',
  total: '$100.00',
  customerName: 'John Doe',
  trackingNumber: 'ABC123',
  trackingUrl: 'https://example.com/tracking/ABC123',
};

const interpolatedTemplate = renderTemplate(template, vars);
console.log(interpolatedTemplate);
// Output: Hello John Doe, your order ORD-12345 has been processed.
```

### Troubleshooting

When troubleshooting email dispatch issues, it's essential to check the logs for any errors. A common issue is a missing `MAILGUN_API_KEY`, which can cause email sending to be silently ignored.

```bash
# Check environment variables for MAILGUN_API_KEY
echo $MAILGUN_API_KEY

# If MAILGUN_API_KEY is not set, set it as an environment variable
export MAILGUN_API_KEY=your_mailgun_api_key_here
```

To verify if emails are being sent successfully, you can check the Mailgun logs or use the `/send` route in the `mails.ts` module to send a test email.

```typescript
// Example of sending a test email
import { sendMailgunEmail } from '../mailgun';

const testEmail = {
  to: 'test@example.com',
  from: 'from@example.com',
  subject: 'Test Email',
  text: 'This is a test email.',
};

sendMailgunEmail(testEmail)
  .then((response) => console.log(response))
  .catch((error) => console.error(error));
```
