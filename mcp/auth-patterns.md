## Authentication Patterns
The Fufuni e-commerce framework uses a combination of Auth0 JWTs, database API keys, and OAuth tokens to manage authentication and authorization. This reference will cover both backend middleware and frontend guards to help developers understand how to implement authentication patterns in their applications.

### Token Types
The following token types are accepted by the `authMiddleware`:

1. **Auth0 JWT**: A three-part Bearer token that must include the permission set in the `ADMIN_STORE_PERMISSION` environment variable (default "admin:store").
2. **sk_ database API key**: A hashed lookup in the `api_keys` table.
3. **64-char lowercase hex OAuth token**: A lookup in the `oauth_tokens` table.

### AuthRole Values
The `AuthRole` type has the following values:

* "public"
* "admin"
* "oauth"
* "authadmin"
* "databaseadmin"
* "aiadmin"
* "mail"
* "customer"

The role is stored in `c.var.auth.role` after the `authMiddleware` runs.

### Backend RBAC Guards
The following RBAC guards are available:

| Guard | Role | Typical Use Case |
| --- | --- | --- |
| `adminOnly` | "admin" | Protecting admin-only routes |
| `superAdminOnly` | "authadmin" | Protecting super admin-only routes, such as the Auth0 Management API token endpoint |
| `databaseAdminOnly` | "databaseadmin" | Protecting database admin-only routes |
| `aiAccessOnly` | "aiadmin" | Protecting AI admin-only routes |
| `mailAccessOnly` | "mail" | Protecting mail admin-only routes |
| `validJwtAuthOnly` | Any valid Auth0 JWT | Protecting routes that require a valid Auth0 JWT, but no specific permission |
| `requireScope(...scopes)` | OAuth token with specific scopes | Protecting OAuth-scoped routes |

### Backend Code Examples
#### Protecting a route with `authMiddleware` and `adminOnly`
```typescript
import { Hono } from 'hono';
import { authMiddleware, adminOnly } from '../middleware/auth';

const app = new Hono();

app.get('/admin-only-route', [
  authMiddleware,
  adminOnly,
  (c) => {
    // Only admins can access this route
    return c.text('Hello, admin!');
  },
]);
```

#### `superAdminOnly` and the `/v1/__auth0/token` Management API endpoint
```typescript
import { Hono } from 'hono';
import { authMiddleware, superAdminOnly } from '../middleware/auth';

const app = new Hono();

app.get('/v1/__auth0/token', [
  authMiddleware,
  superAdminOnly,
  (c) => {
    // Only super admins can access the Auth0 Management API token endpoint
    return c.text('Auth0 Management API token');
  },
]);
```

#### `customerAuthMiddleware` for customer-scoped routes
```typescript
import { Hono } from 'hono';
import { customerAuthMiddleware } from '../middleware/customer-auth';

const app = new Hono();

app.get('/v1/me', [
  customerAuthMiddleware,
  (c) => {
    // Customer-scoped route, no specific permission required
    return c.text('Hello, customer!');
  },
]);
```

### Frontend Authentication
#### AuthenticationGuard
Use `AuthenticationGuard` to protect a whole page and redirect to login if not authenticated.
```typescript
import { AuthenticationGuard } from '../components/AuthenticationGuard';

const MyComponent = () => {
  // ...
};

const App = () => {
  return (
    <AuthenticationGuard component={MyComponent} />
  );
};
```

#### AuthenticationGuardWithPermission
Use `AuthenticationGuardWithPermission` to conditionally show UI based on a specific Auth0 permission.
```typescript
import { AuthenticationGuardWithPermission } from '../components/AuthenticationGuardWithPermission';

const MyComponent = () => {
  // ...
};

const App = () => {
  return (
    <AuthenticationGuardWithPermission
      permission="admin:store"
      children={<MyComponent />}
      fallback={<div>You do not have permission to access this page.</div>}
    />
  );
};
```

#### hasPermission() and isAuthenticated
Use `hasPermission(permission)` from `useSecuredApi()` to check asynchronously whether the current user's access token contains a specific Auth0 permission string.
```typescript
import { useSecuredApi } from '../hooks/useSecuredApi';

const MyComponent = () => {
  const { hasPermission } = useSecuredApi();

  const isAdmin = hasPermission('admin:store');

  // ...
};
```

Use `isAuthenticated` from `useAuth()` to check synchronously whether the user is logged in.
```typescript
import { useAuth } from '../hooks/useAuth';

const MyComponent = () => {
  const { isAuthenticated } = useAuth();

  if (!isAuthenticated) {
    // ...
  }
};
```

### UsersAndPermissionsPage
The `UsersAndPermissionsPage` allows admins to manage Auth0 user permissions from the storefront UI without going to the Auth0 dashboard.

### LoginLogoutLink and LoginButton
Use `LoginLogoutLink` or `LoginButton` instead of redirecting to Auth0 when you want to provide a login or logout link/button in your application.

### requireScope(...scopes) factory
Use the `requireScope(...scopes)` factory to protect OAuth-scoped routes.
```typescript
import { requireScope } from '../middleware/auth';

const app = new Hono();

app.get('/oauth-scoped-route', [
  authMiddleware,
  requireScope('scope1', 'scope2'),
  (c) => {
    // Only OAuth tokens with scope1 and scope2 can access this route
    return c.text('Hello, OAuth!');
  },
]);
```
