## Framework Overview

Fufuni is a zero-cost, open-source e-commerce stack that runs a full-featured store on Cloudflare’s free tier.  
One Durable Object (SQLite) holds all data; a React 19 storefront talks to it via typed REST endpoints.  
No servers, no cold starts, no external DB—push to GitHub and both backend and frontend deploy automatically.

### Stack

| Layer | Technology | Notes |
|-------|------------|-------|
| Runtime | Cloudflare Workers | 100 k req/day free |
| Database | Durable Object SQLite | Single isolate, no latency |
| Backend | Hono + Zod-OpenAPI | Auto-generated Swagger docs |
| Frontend | React 19 + Vite + HeroUI v3 | Themes: `classic`, `luxury` |
| Auth | Auth0 | RBAC via token permissions |
| Storage | Cloudflare R2 | Product images, 10 GB/mo free |
| Cache | Cloudflare KV | Public routes cached by `pk_` key |
| Email | Mailgun | 3 000 emails/mo free |
| CI/CD | GitHub Actions | Three workflows: Worker, Pages, demo reset |

### Monorepo structure

```
apps/
├── client/          # React SPA, HeroUI, Vite
├── merchant/        # Hono Worker + Durable Object (MerchantDO)
└── cloudflare-worker/  # Legacy, ignore
packages/            # Shared types, utils (empty today)
.github/workflows/   # deploy-cloudflare-worker.yaml, pages.yaml, reset-demo.yaml
```

Key merchant folders:

* `src/routes/` – OpenAPI route files (catalog, orders, webhooks …)  
* `src/do.ts` – Durable Object class, SCHEMA, migrations runner  
* `migrations/` – Numbered `.sql` files applied on start  
* `wrangler.jsonc` – Env vars, Durable Object binding name `MERCHANT`

### Request lifecycle

1. Browser hits `https://<worker>.workers.dev/v1/products`  
2. Worker `index.ts` adds CORS, attaches `MERCHANT` stub to `c.var.db`  
3. `kvCacheMiddleware` checks KV for a public `pk_` key hit; if found, returns cached JSON  
4. Route handler (e.g. `catalog.ts`) calls `c.var.db.fetch('/internal/products', …)`  
5. Durable Object `do.ts` executes SQL inside the isolate, returns rows  
6. Response streamed back to Worker, optionally cached in KV with 5-minute TTL  
7. Frontend receives typed JSON; React hydrates UI

### Key conventions

* **Keys**: Public `pk_*`, secret `sk_*`, never expose the latter  
* **Auth**: Auth0 JWT only; permissions in token, not DB  
* **Errors**: Throw `ApiError(code, message, status, details?)`; global handler formats JSON  
* **Migrations**: Update `SCHEMA`, `ensureInitialized()`, and create `migrations/N.sql` simultaneously  
* **i18n**: Product/category fields accept plain string or JSON `{ "en":"Shoes", "fr":"Chaussures" }`  
* **Rate-limit**: 100 req/min per IP on `/v1/*`  
* **KV cache**: Purges on POST/PUT/DELETE via `kvInvalidateMiddleware` prefixes  
* **Env vars**: Defined in `wrangler.jsonc` and `apps/client/.env` (GitHub Secrets for CI)
