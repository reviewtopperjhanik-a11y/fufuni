## Introduction to Fufuni
Fufuni is an open-source e-commerce platform designed to run on Cloudflare Workers and Durable Objects, leveraging a SQLite database for data storage. It provides a headless commerce solution with a React-based frontend, utilizing HeroUI for styling. The platform is built with a focus on scalability, security, and ease of use, allowing developers to create custom e-commerce applications with minimal setup and cost.

## Stack
| Layer | Technology | Notes |
| --- | --- | --- |
| Frontend | React 19, HeroUI v3 | Client-side rendering with dynamic theming |
| Backend | Cloudflare Workers, Hono, Zod-OpenAPI | Serverless API with automatic documentation |
| Database | Durable Object SQLite | Single database instance for entire store state |
| Authentication | Auth0 | Identity and access management with RBAC |
| Storage | Cloudflare R2 | Object storage for product images and other assets |
| Caching | Cloudflare KV | Key-value store for caching frequently accessed data |
| Deployment | Cloudflare Workers, GitHub Actions | Automated deployment and rollback capabilities |

## Monorepo Structure
The Fufuni monorepo is organized into three main workspaces:
* `apps/client`: React SPA frontend application
* `apps/merchant`: Hono Worker and Durable Object backend application
* `apps/mcp`: MCP server application
Each workspace contains its own set of directories and files, with a focus on modularity and reusability.

## Request Lifecycle
A request to the Fufuni platform typically flows as follows:
1. Client (React SPA) sends a request to the Cloudflare Worker
2. Cloudflare Worker (Hono) handles the request and routes it to the Durable Object
3. Durable Object (MerchantDO) executes the request, interacting with the SQLite database as needed
4. SQLite database stores and retrieves data, providing a single source of truth for the application
5. Durable Object returns a response to the Cloudflare Worker
6. Cloudflare Worker returns a response to the client (React SPA)
