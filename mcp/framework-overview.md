## Framework Overview
The Fufuni e-commerce framework is an open-source, Cloudflare-native headless commerce platform that enables businesses to host their stores for free. It leverages Cloudflare Workers, Durable Objects, and SQLite to provide a highly performant and scalable solution.

## Stack
| Layer | Technology | Notes |
| --- | --- | --- |
| Frontend | React 19 + HeroUI v3 + Vite 8 | Single-page application (SPA) with hot reloading |
| Backend | Hono + Zod-OpenAPI | Cloudflare Worker with API routing and OpenAPI documentation |
| Database | Durable Object SQLite | Single Durable Object with SQLite database for entire store state |
| Caching | Cloudflare KV | Caching layer with variable TTL and bypass rules for admin tokens |
| Authentication | Auth0 | Sole identity provider with RBAC managed via Auth0 permissions |
| Image Storage | Cloudflare R2 | Product image storage with free tier (10 GB/month) |
| Transactional Email | Mailgun | Email service with free tier (3000 emails/month) |

## Monorepo Structure
The Fufuni monorepo consists of three main workspaces:

* `apps/client`: React SPA (storefront + admin)
* `apps/merchant`: Hono Worker + Durable Object (backend API)
* `apps/mcp`: MCP server

The monorepo uses Turborepo for task orchestration, and the `npm run ddev:env` command injects the `.env` file and launches the full stack locally with hot reloading.

## Request Lifecycle
Here's an overview of how a request flows from client to CF Worker to Durable Object to SQLite:

1. Client (React SPA) sends a request to the Cloudflare Worker (Hono).
2. The Cloudflare Worker (Hono) receives the request and sets the `db` variable to a Durable Object stub.
3. The request is then routed to the corresponding API endpoint, which interacts with the Durable Object (MerchantDO).
4. The Durable Object (MerchantDO) executes the request against the SQLite database.

## Key Conventions

* **Naming conventions**: Public API keys are prefixed with `pk_`, while admin/secret keys are prefixed with `sk_`. Never expose `sk_` keys to the frontend.
* **Error handling**: API errors are returned in JSON format with a standardized error code and message.
* **Authentication**: Auth0 is the sole identity provider, and RBAC is managed via Auth0 permissions on the access token.
* **Internationalization (i18n)**: The framework supports multiple locales, and translations are stored in JSON files.

By following these conventions and leveraging the Cloudflare ecosystem, Fufuni provides a highly scalable and performant e-commerce platform that can be hosted for free.
