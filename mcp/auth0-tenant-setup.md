## Auth0 Tenant Setup & Permissions Overview
The `scripts/auth0/deploy-tenant-resources.ts` script provisions all necessary Auth0 resources, including a Single-Page Application (SPA), an API resource server, permission scopes, a post-login Action, and a Machine-to-Machine (M2M) client for the Management API. To run the script, execute `npx tsx scripts/auth0/deploy-tenant-resources.ts -- --env-file=<path>` and follow the prompts to fill in the required environment variables.

### Provisioned Resources
The script provisions the following resources:
- SPA app
- API resource server
- Permission scopes
- Post-login Action
- M2M client for Management API

## Auth0 Permissions
The following Auth0 permissions are used by Fufuni:
| Permission | Description | Role |
| --- | --- | --- |
| `admin:store` | General admin | `admin` |
| `auth0:admin:api` | Management API proxy | `authadmin` |
| `ai:api` | AI features | `aiadmin` |
| `mail:api` | Email sending | `mail` |
| `admin:database` | Direct DB access | `databaseadmin` |

These permissions can be managed using the UsersAndPermissionsPage (`/admin/users-and-permissions`), which requires the `auth0:admin:api` permission.

## Post-Login Action
The post-login Action injects `user_metadata` into the access token as a custom claim. This makes wishlist and preferences available in the JWT without extra API calls.

```typescript
// Example of post-login Action code
export function addUserInfoToAccessToken(user, context, callback) {
  const namespace = 'https://example.com/';
  const userMetadata = user.user_metadata;
  const accessToken = context.accessToken;

  accessToken[namespace + 'wishlist'] = userMetadata.wishlist;
  accessToken[namespace + 'preferences'] = userMetadata.preferences;

  callback(null, user, context);
}
```

## M2M Token Caching
The M2M token for the Management API is cached in KV (key: `auth0_management_token`) for ~23 hours to avoid exhausting the monthly M2M token quota.

```typescript
// Example of M2M token caching
const cache = await getCache();
const token = await cache.get('auth0_management_token');

if (!token) {
  token = await getValidMgmtToken(auth0Domain, managementClientId, managementClientSecret);
  await cache.put('auth0_management_token', token, { expirationTtl: 23 * 60 * 60 });
}
```

## Adding a New Permission
To add a new permission, follow these steps:

1. Add the permission to `deploy-tenant-resources.ts`
2. Re-run the script to provision the new permission
3. Add a backend RBAC guard to restrict access to the new permission
4. Gate the frontend with `AuthenticationGuardWithPermission` to require the new permission

```typescript
// Example of adding a new permission
export function addNewPermission() {
  const newPermission = 'example:api';

  // Add new permission to deploy script
  // ...

  // Re-run deploy script
  // ...

  // Add backend RBAC guard
  import { RBACGuard } from './RBACGuard';

  export function exampleApi() {
    const permission = newPermission;

    if (!RBACGuard(permission)) {
      return <div>Unauthorized</div>;
    }

    // Render API content
  }

  // Gate frontend with AuthenticationGuardWithPermission
  import { AuthenticationGuardWithPermission } from './AuthenticationGuardWithPermission';

  export function examplePage() {
    const permission = newPermission;

    // Render page content
  }
}
```
