## Introduction to Localized Content Patterns
Localized content is essential for supporting multiple languages in your application. In Fufuni, we use a JSON storage format to store localized text fields in the database.

### The JSON Storage Format
The JSON storage format for localized text fields is as follows:
```json
{
  "en-US": "My product",
  "fr-FR": "Mon produit",
  "es-ES": "Mi producto"
}
```
This format allows you to store translations for different locales in a single JSON object.

### Reading and Writing Localized Text
To read localized text, you can use the `getLocalizedText()` function, which takes the JSON object, the desired locale, and a fallback value as arguments:
```typescript
import { getLocalizedText } from '@/utils/description';

const localizedText = {
  "en-US": "My product",
  "fr-FR": "Mon produit",
};

const locale = "fr-FR";
const fallback = "Unknown";

const text = getLocalizedText(localizedText, locale, fallback);
console.log(text); // Output: "Mon produit"
```
To write localized text, you can use the `mergeLocale()` function, which merges a new translation into the existing JSON object:
```typescript
import { mergeLocale } from '@/utils/description';

const localizedText = {
  "en-US": "My product",
};

const locale = "fr-FR";
const text = "Mon produit";

const updatedLocalizedText = mergeLocale(JSON.stringify(localizedText), locale, text);
console.log(updatedLocalizedText);
// Output: {"en-US":"My product","fr-FR":"Mon produit"}
```
### Helper Functions
The following helper functions are available to work with localized text:

* `isLocalizedJson()`: Checks if a given string is a valid localized JSON object.
* `migrateToLocalizedJson()`: Migrates a plain text string to a localized JSON object.

### useLocalizedTextInput Hook
The `useLocalizedTextInput` hook manages a multilingual text field in an admin form. It tracks the current locale, provides `onChange` handlers, integrates AI auto-translation, and detects RTL.

The hook takes the following props:

* `fieldName`: The name of the field.
* `initialValue`: The initial value of the field.
* `options`: An object containing additional options, such as the `parseFn`, `mergeFn`, and `getFn` functions.

The hook returns an object containing the following values:

* `inputValue`: The current value of the input field.
* `isTranslating`: A boolean indicating whether the AI translation is in progress.
* `canUseAi`: A boolean indicating whether the user has the AI permission.
* `isRTL`: A boolean indicating whether the current locale is RTL.
* `handleInputChange`: A function to handle input changes.
* `handleAiTranslate`: A function to trigger AI translation.

### RTL Handling
The `useLocalizedTextInput` hook automatically detects RTL locales and sets the `dir` attribute of the input element to `"rtl"` for Arabic and Hebrew locales.

### Adding a Localized Field to an Admin Form
To add a localized field to an admin form, you can use the `useLocalizedTextInput` hook as follows:

```tsx
          {isTranslating ? 'Translating...' : 'Translate'}
        </button>
      )}
    </div>
  );
};
```
### Common Pitfall
When saving a localized field to the backend, always serialize the full JSON object using `JSON.stringify(allValues)`. Never pass the current-locale string alone, as this can cause data loss.

For example:
```typescript
const allValues = {
  "en-US": "My product",
  "fr-FR": "Mon produit",
};

// Correct way to save the localized field
const serializedValues = JSON.stringify(allValues);
// ...

// Incorrect way to save the localized field
const currentLocale = "fr-FR";
const currentValue = allValues[currentLocale];
// ...
```
