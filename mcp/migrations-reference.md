## Migrations Reference

### Conceptual overview

Every Fufuni merchant is backed by a single Durable Object that owns an embedded SQLite database.  
Because Cloudflare may recreate the DO at any time (upgrade, eviction, migration), the schema must be rebuilt from scratch on first boot, while already-running merchants need to be upgraded in place.  
We therefore keep two artefacts in the codebase:

1. A linear sequence of numbered migration scripts (001 … 033) that describe how to evolve *existing* databases.
2. A single `SCHEMA` constant that describes the *final* state for *new* databases.

When the DO starts, `ensureInitialized()` checks the internal `__meta__` table.  
If it does not exist, the object is brand-new and the entire `SCHEMA` is executed in one shot.  
If it exists, the highest applied version is read and every missing migration is run in order.  
This guarantees zero-downtime upgrades and reproducible fresh installs without duplicating SQL.

### The non-negotiable 3-step process

Adding column `foo` to table `bar` for merchant 034 looks like this:

#### Step 1 – evolve existing databases inside `ensureInitialized()`

```typescript
// apps/merchant/src/do.ts
if (version < 34) {
  sql.exec(/*sql*/ `
    ALTER TABLE bar ADD COLUMN foo TEXT NOT NULL DEFAULT '';
  `);
  version = 34;
}
```

#### Step 2 – update the canonical `SCHEMA` constant

```typescript
// apps/merchant/src/do.ts
export const SCHEMA = /*sql*/ `
  CREATE TABLE bar (
    id   INTEGER PRIMARY KEY,
    foo  TEXT NOT NULL DEFAULT ''
  );
  -- … rest of schema …
`;
```

#### Step 3 – create the human-readable migration file

```sql
-- apps/merchant/migrations/034_add_foo_to_bar.sql
ALTER TABLE bar ADD COLUMN foo TEXT NOT NULL DEFAULT '';
```

All three steps *must* be present in the same PR; CI will reject any deviation.

### Automatic execution on DO startup

The DO’s `constructor` immediately calls `ensureInitialized()`:

```typescript
// apps/merchant/src/do.ts
export class MerchantDO {
  constructor(state: DurableObjectState) {
    this.state = state;
    this.sql = state.storage.sql;
    this.ensureInitialized();
  }

  private ensureInitialized(): void {
    const sql = this.sql;
    let version = 0;

    const meta = sql.exec("SELECT version FROM __meta__ LIMIT 1").one() as
      | { version: number }
      | undefined;
    if (!meta) {
      // brand-new database
      sql.exec(SCHEMA);
      sql.exec("CREATE TABLE __meta__ (version INTEGER PRIMARY KEY)");
      version = LATEST_VERSION; // 34
    } else {
      version = meta.version;
    }

    // apply missing migrations
    if (version < 34) {
      sql.exec(/*sql*/ `ALTER TABLE bar ADD COLUMN foo TEXT NOT NULL DEFAULT '';`);
      version = 34;
    }

    // persist the new version
    sql.exec("UPDATE __meta__ SET version = ?", version);
  }
}
```

No manual intervention is required: the moment a new Worker code is deployed, every DO instance will run the above logic on its next wakeup, ensuring schema convergence across the fleet.
