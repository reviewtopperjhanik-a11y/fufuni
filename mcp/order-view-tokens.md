## Order View Tokens
Order view tokens (OVTs) are a solution to grant guests access to their order status without requiring an Auth0 account. They are signed HS256 JWTs with a 30-day TTL, generated by the `generateOrderViewToken` function.

### Architecture
The OVT architecture solves the problem of guest access without authentication. When an order is created, an OVT is generated using the `generateOrderViewToken` function and included in the order confirmation email as a query parameter. The guest can then visit the order tracking URL, which includes the raw token, and the frontend will pass it to the backend for verification.

* `orderId`: The UUID of the order in the database
* `secret`: The `ORDER_TOKEN_SECRET` environment variable
* `opts`: Optional token generation options, including `issuedAt` and `ttlSeconds`

The `generateOrderViewToken` function is deterministic, meaning that calling it with the same `orderId` and `secret` will always produce the same token. This allows re-sending confirmation emails without storing the token. The TTL of the token is set to 30 days by default, but can be overridden using the `ttlSeconds` option.

### Full Flow
The full flow of the OVT system is as follows:

1. Order created → `generateOrderViewToken` is called to generate a token
2. Token included in email as a query parameter (`?token=...`)
3. Guest visits order tracking URL (`/order/:orderNumber?token=<raw_token>`)
4. Frontend reads token from URL and passes it to backend
5. Backend verifies token using `verifyOrderViewToken`
6. If token is valid, backend returns order details

### ORDER_VIEW_TOKEN_SECRET Environment Variable
The `ORDER_VIEW_TOKEN_SECRET` environment variable is used as the signing secret for the OVTs. It must be set in Wrangler secrets and in the `.env` file. This secret should be kept secure, as it can be used to generate and verify tokens.

To set the `ORDER_VIEW_TOKEN_SECRET` environment variable, run the following command in your terminal:
```bash
wrangler secret put ORDER_TOKEN_SECRET
```
Then, add the following line to your `.env` file:
```makefile
ORDER_TOKEN_SECRET=your_secret_here
```
