# useSecuredApi() Hook Reference

## 1. Import

```ts
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

## 2. Return Value Table

| Method          | Signature                                                      | When to Use                                                                 |
|-----------------|----------------------------------------------------------------|-----------------------------------------------------------------------------|
| `getJson`       | `(url: string) => Promise<Response>`                          | Authenticated GET that returns JSON                                        |
| `postJson`      | `(url: string, body: any) => Promise<Response>`               | Authenticated POST with a JSON body                                       |
| `putJson`       | `(url: string, body: any) => Promise<Response>`               | Authenticated PUT (full resource replace)                                 |
| `patchJson`     | `(url: string, body: any) => Promise<Response>`               | Authenticated PATCH (partial resource update)                             |
| `deleteJson`    | `(url: string) => Promise<Response>`                          | Authenticated DELETE                                                      |
| `postForm`      | `(url: string, formData: FormData) => Promise<Response>`      | Authenticated multipart/form-data POST (e.g. file uploads)                |
| `hasPermission` | `(permission: string) => Promise<boolean>`                    | Async‑check if the current user holds the given Auth0 permission          |
| `getAuth0ManagementToken` | `() => Promise<string>` | Retrieve a token that can call the Auth0 Management API (requires `authadmin` role) |
| `listAuth0Users` | `() => Promise<Auth0User[]>` | List all users via the Management API (requires `authadmin` role) |
| `getUserPermissions` | `(userId: string) => Promise<Auth0Permission[]>` | Retrieve permissions of a specific user (requires `authadmin` role) |
| `addPermissionToUser` | `(userId: string, permission: string) => Promise<void>` | Assign a permission to a user (requires `authadmin` role) |
| `removePermissionFromUser` | `(userId: string, permission: string) => Promise<void>` | Revoke a permission from a user (requires `authadmin` role) |

> **Note**: All methods except the Auth0 Management helpers automatically add the current user’s JWT Bearer token to the `Authorization` header.

---

## 3. How JWT is Injected

`useSecuredApi()` internally calls `useAuth()` to read the logged‑in user’s access token.  
Every request made with the returned helper automatically includes:

```ts
Authorization: Bearer <access-token>
```

You never need to set this header yourself.

## 4. Usage Examples

### 4.1 GET (list products)

```tsx
import { useEffect, useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";

export function ProductList() {
  const { getJson } = useSecuredApi();
  const [products, setProducts] = useState<any[]>([]);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    getJson("/api/products")
      .then((res) => {
        if (!res.ok) throw new Error("Failed to fetch");
        return res.json();
      })
      .then(setProducts)
      .catch((e) => setError(e.message));
  }, [getJson]);

  if (error) return <div>{error}</div>;

  return (
    <ul>
      {products.map((p) => (
        <li key={p.id}>{p.name}</li>
      ))}
    </ul>
  );
}
```

### 4.2 POST (create a review)

```tsx
import { useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";

export function ReviewForm({ productId }: { productId: string }) {
  const { postJson } = useSecuredApi();
  const [comment, setComment] = useState("");

  const submit = async () => {
    const body = { productId, comment };
    const res = await postJson("/api/reviews", body);
    if (!res.ok) alert("Failed to submit review");
    else alert("Review submitted!");
  };

  return (
    <div>
      <textarea value={comment} onChange={(e) => setComment(e.target.value)} />
      <button onClick={submit}>Send Review</button>
    </div>
  );
}
```

### 4.3 DELETE (remove an order)

## 5. Using `hasPermission()` for UI Guarding

```tsx
import { useState, useEffect } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";

export function AdminPanel() {
  const { hasPermission } = useSecuredApi();
  const [canManage, setCanManage] = useState(false);

  useEffect(() => {
    hasPermission("admin:manage")
      .then(setCanManage)
      .catch(() => setCanManage(false));
  }, [hasPermission]);

  if (!canManage) return null; // User not allowed

  return (
    <div>
      <h2>Admin Settings</h2>
      {/* admin controls here */}
    </div>
  );
}
```

## 6. When NOT to Use `useSecuredApi()`

| Scenario | Why |
|----------|-----|
| Public endpoints (e.g., `/api/products`, `/api/categories`) | No auth token needed; using `fetch()` or a custom hook keeps requests lightweight |
| Calls that must omit the `Authorization` header | `useSecuredApi()` will always include the bearer token |

## 7. Auth0 Management Helpers (Admin Only)

| Helper | Use‑Case |
|--------|----------|
| `getAuth0ManagementToken()` | Obtain a token to call the Auth0 Management API (requires `authadmin` role). |
| `listAuth0Users()` | Fetch all users for an admin dashboard. |
| `getUserPermissions(userId)` | Show or edit a user’s permissions. |
| `addPermissionToUser(userId, permission)` | Grant a permission during onboarding. |
| `removePermissionFromUser(userId, permission)` | Revoke a permission after role change. |

> **Tip**: Only call these helpers from components that run on pages accessible by users with the `authadmin` role; otherwise the request will fail with a 403.
