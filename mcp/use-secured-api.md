## useSecuredApi() Hook Reference

The `useSecuredApi` hook is the primary interface for frontend developers to interact with the Fufuni backend (Hono + SQLite). It abstracts the complexities of Auth0 token management, ensuring that every request is automatically signed with a valid JWT Bearer token. This hook is built on top of the framework's internal `useAuth()` provider and provides a consistent, promise-based API for JSON and form-data operations.

In the Fufuni architecture, the backend routes are often protected by middleware that validates these tokens. By using this hook, you eliminate the need to manually fetch tokens from the Auth0 SDK or manage header injection.

### Import Path

To use this hook in your React components, use the following absolute path:

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

## Hook API and Methods

The `useSecuredApi` hook returns an object containing methods for various HTTP actions and utility functions for permission checking.

| Method | Signature | When to use |
| :--- | :--- | :--- |
| `getJson` | `(url: string) => Promise<T>` | Authenticated GET requests that return a JSON response. |
| `postJson` | `(url: string, body: any) => Promise<T>` | Authenticated POST requests with a JSON body. |
| `putJson` | `(url: string, body: any) => Promise<T>` | Authenticated PUT requests for full resource replacement. |
| `patchJson` | `(url: string, body: any) => Promise<T>` | Authenticated PATCH requests for partial resource updates. |
| `deleteJson` | `(url: string) => Promise<T>` | Authenticated DELETE requests. |
| `postForm` | `(url: string, body: FormData) => Promise<T>` | Authenticated `multipart/form-data` uploads (e.g., images). |
| `hasPermission` | `(permission: string) => Promise<boolean>` | To check if the current user has a specific Auth0 scope/permission. |

### Automatic JWT Injection

One of the most critical features of `useSecuredApi` is the automatic injection of the `Authorization` header. When you call any of the request methods (like `getJson` or `postJson`), the hook internally:

1.  Retrieves the current Access Token from the Auth0 session.
2.  Checks if the token is valid or needs refreshing.
3.  Attaches the token as a Bearer string: `Authorization: Bearer <token>`.
4.  Sets the `Content-Type` to `application/json` (except for `postForm`).

This ensures that your request successfully passes through the `auth` middleware on the Cloudflare Workers backend.

## CRUD Usage Examples

Below are functional examples demonstrating how to use the hook within HeroUI-based React components.

### 1. Fetching Data (GET)
This example demonstrates fetching a list of user-specific orders from the backend.

```typescript
import { useEffect, useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Spinner, Table, TableHeader, TableColumn, TableBody, TableRow, TableCell } from "@heroui/react";

interface Order {
  id: string;
  amount: number;
  status: string;
}

export const UserOrders = () => {
  const { getJson } = useSecuredApi();
  const [orders, setOrders] = useState<Order[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchOrders = async () => {
      try {
        const data = await getJson<Order[]>("/v1/orders/me");
        setOrders(data);
      } catch (error) {
        console.error("Failed to fetch orders", error);
      } finally {
        setLoading(false);
      }
    };
    fetchOrders();
  }, [getJson]);

  if (loading) return <Spinner />;

  return (
    <Table aria-label="Your recent orders">
      <TableHeader>
        <TableColumn>ORDER ID</TableColumn>
        <TableColumn>AMOUNT</TableColumn>
        <TableColumn>STATUS</TableColumn>
      </TableHeader>
      <TableBody>
        {orders.map((order) => (
          <TableRow key={order.id}>
            <TableCell>{order.id}</TableCell>
            <TableCell>${order.amount}</TableCell>
            <TableCell>{order.status}</TableCell>
          </TableRow>
        ))}
      </TableBody>
    </Table>
  );
};
```

### 2. Creating Resources (POST)
This example shows how to submit a JSON payload to create a new product review.

```typescript
import { useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button, Textarea, Input } from "@heroui/react";

export const ReviewForm = ({ productId }: { productId: string }) => {
  const { postJson } = useSecuredApi();
  const [comment, setComment] = useState("");
  const [rating, setRating] = useState(5);
  const [isSubmitting, setIsSubmitting] = useState(false);

  const handleSubmit = async () => {
    setIsSubmitting(true);
    try {
      await postJson(`/v1/products/${productId}/reviews`, {
        comment,
        rating,
      });
      alert("Review submitted successfully!");
    } catch (err) {
      console.error("Submission failed", err);
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <div className="flex flex-col gap-4 max-w-md">
      <Input 
        type="number" 
        label="Rating" 
        value={rating.toString()} 
        onChange={(e) => setRating(Number(e.target.value))} 
      />
      <Textarea 
        label="Your Review" 
        value={comment} 
        onChange={(e) => setComment(e.target.value)} 
      />
      <Button 
        color="primary" 
        isLoading={isSubmitting} 
        onPress={handleSubmit}
      >
        Submit Review
      </Button>
    </div>
  );
};
```

### 3. Deleting Resources (DELETE)
In this scenario, we use `deleteJson` to remove an item from a wishlist.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button } from "@heroui/react";
import { TrashIcon } from "lucide-react";

export const DeleteWishlistItem = ({ itemId, onDeleted }: { itemId: string, onDeleted: () => void }) => {
  const { deleteJson } = useSecuredApi();

  const handleDelete = async () => {
    if (!confirm("Are you sure?")) return;
    
    try {
      await deleteJson(`/v1/wishlist/${itemId}`);
      onDeleted();
    } catch (error) {
      alert("Could not delete item");
    }
  };

  return (
    <Button 
      isIconOnly 
      color="danger" 
      variant="flat" 
      onPress={handleDelete}
    >
      <TrashIcon size={18} />
    </Button>
  );
};
```

## Permission-Based UI Guarding

The `hasPermission` method is an asynchronous check against the user's Auth0 scopes. This is essential for hiding administrative controls from regular users.

### hasPermission() Example
The following component only shows the "Admin Dashboard" button if the user has the `read:admin_panel` permission.

```typescript
import { useEffect, useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button, Link } from "@heroui/react";

export const AdminToolbar = () => {
  const { hasPermission } = useSecuredApi();
  const [isAdmin, setIsAdmin] = useState(false);

  useEffect(() => {
    const checkAdmin = async () => {
      const allowed = await hasPermission("read:admin_panel");
      setIsAdmin(allowed);
    };
    checkAdmin();
  }, [hasPermission]);

  if (!isAdmin) return null;

  return (
    <div className="p-4 bg-warning-50 border-b border-warning-200">
      <p className="text-sm font-bold mb-2">Administrator Tools</p>
      <Button 
        as={Link} 
        href="/admin" 
        color="warning" 
        size="sm"
      >
        Go to Admin Dashboard
      </Button>
    </div>
  );
};
```

## When NOT to use useSecuredApi()

While `useSecuredApi()` is powerful, it is specifically designed for **private routes**.

1.  **Public Endpoints:** If you are fetching a public product list or site metadata that does not require login, do not use `useSecuredApi()`. Using it will trigger unnecessary Auth0 redirect flows or throw errors if the user is not logged in. Use the standard browser `fetch()` or a specialized `useQuery` hook for public routes.
2.  **External Third-Party APIs:** Do not use this hook to call external APIs (like Stripe or Google Maps) directly, as it will attempt to attach an Auth0 Bearer token that the external service will not recognize.
3.  **AI Services (Direct Browser Calls):** For Fufuni AI features (moderation/translation), first use `getJson` to call `/v1/ai/parameters` on the Fufuni backend to safely retrieve temporary API keys. Then, use the dedicated `ai-client.ts` helpers which use plain fetch to talk to the AI provider, bypassing the Auth0-signed hook.

## Auth0 Management Helpers

The `useSecuredApi` hook exposes specialized methods for interacting with the Auth0 Management API. These methods are primarily used in the User Management section of the admin dashboard and **require the `authadmin` role** (or specifically the `auth0:admin:api` permission).

### Management Methods List
- `getAuth0ManagementToken()`: Obtains a management token via the Worker's backend (cached in KV).
- `listAuth0Users(mgmtToken)`: Returns a list of all users registered in Auth0.
- `getUserPermissions(mgmtToken, userId)`: Fetches the granular permissions of a specific user.
- `addPermissionToUser(mgmtToken, userId, permissionName)`: Assigns a new scope to a user.
- `removePermissionFromUser(mgmtToken, userId, permissionName)`: Revokes a scope.
- `deleteAuth0User(mgmtToken, userId)`: Permanently deletes a user profile from Auth0.
- `getResourceServers(mgmtToken)`: Lists the APIs (Resource Servers) configured in Auth0.
- `updateResourceServerScopes(mgmtToken, id, scopes)`: Syncs backend permissions with Auth0 configuration.

### Example: Listing Users (Admin Only)
```typescript
const { getAuth0ManagementToken, listAuth0Users } = useSecuredApi();

const loadUsers = async () => {
  const tokenResponse = await getAuth0ManagementToken();
  const users = await listAuth0Users(tokenResponse.access_token);
  return users;
};
```

These helpers allow the Fufuni framework to remain self-contained, enabling administrators to manage user access levels without logging into the Auth0 Dashboard.
