## Introduction to useSecuredApi() Hook
The `useSecuredApi()` hook is a powerful tool for frontend developers to handle secured API requests with ease. It automatically attaches the Auth0 Bearer token to every request, eliminating the need for manual token handling.

### Import Path
To use the `useSecuredApi()` hook, import it from the following path:
```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

### Return Values Table
The `useSecuredApi()` hook returns an object with the following methods:

| Method | Signature | When to Use |
| --- | --- | --- |
| `getJson` | `async (url: string): Promise<any>` | For authenticated GET requests that return JSON. |
| `postJson` | `async (url: string, body: any): Promise<any>` | For authenticated POST requests with a JSON body. |
| `putJson` | `async (url: string, body: any): Promise<any>` | For authenticated PUT (full replace) requests. |
| `patchJson` | `async (url: string, body: any): Promise<any>` | For authenticated PATCH (partial update) requests. |
| `deleteJson` | `async (url: string): Promise<any>` | For authenticated DELETE requests. |
| `postForm` | `async (url: string, formData: FormData): Promise<any>` | For authenticated multipart/form-data POST requests (e.g., image upload). |
| `hasPermission` | `async (permissionString: string): Promise<boolean>` | To check whether the current user has a specific Auth0 permission. |

### Automatic JWT Bearer Token Injection
The `useSecuredApi()` hook automatically attaches the Auth0 Bearer token to every request, so you never need to set `Authorization` headers manually.

### Usage Examples
Here are three complete usage examples in React components:

#### GET Request Example
```tsx
import React, { useEffect, useState } from 'react';
import { useSecuredApi } from "@/features/auth/components/auth-components";

const DataView = () => {
  const { getJson } = useSecuredApi();
  const [data, setData] = useState(null);

  useEffect(() => {
    const fetchData = async () => {
      const response = await getJson('https://api.example.com/data');
      setData(response);
    };
    fetchData();
  }, [getJson]);

  return (
    <div>
      {data ? <pre>{JSON.stringify(data, null, 2)}</pre> : <p>Loading...</p>}
    </div>
  );
};
```

#### POST Request Example
```tsx
import React, { useState } from 'react';
import { useSecuredApi } from "@/features/auth/components/auth-components";

const FormView = () => {
  const { postJson } = useSecuredApi();
  const [name, setName] = useState('');
  const [age, setAge] = useState(0);

  const handleSubmit = async (event: React.FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const response = await postJson('https://api.example.com/users', { name, age });
    console.log(response);
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        Name:
        <input type="text" value={name} onChange={(event) => setName(event.target.value)} />
      </label>
      <br />
      <label>
        Age:
        <input type="number" value={age} onChange={(event) => setAge(event.target.valueAsNumber)} />
      </label>
      <br />
      <button type="submit">Submit</button>
    </form>
  );
};
```

#### DELETE Request Example
```tsx
import React from 'react';
import { useSecuredApi } from "@/features/auth/components/auth-components";

const DeleteButton = () => {
  const { deleteJson } = useSecuredApi();

  const handleDelete = async () => {
    await deleteJson('https://api.example.com/users/1');
    console.log('User deleted');
  };

  return (
    <button onClick={handleDelete}>Delete User</button>
  );
};
```

### hasPermission() Example
To guard an admin UI element, use the `hasPermission()` method as follows:
```tsx
import React from 'react';
import { useSecuredApi } from "@/features/auth/components/auth-components";

const AdminPanel = () => {
  const { hasPermission } = useSecuredApi();

  const isAdmin = async () => {
    const result = await hasPermission('admin:access');
    return result;
  };

  return (
    <div>
      {isAdmin() ? <p>Welcome, admin!</p> : <p>Access denied</p>}
    </div>
  );
};
```

### When Not to Use this Hook
Do not use the `useSecuredApi()` hook for unauthenticated public endpoints (e.g., product listing). Instead, use plain `fetch()` or a custom hook with `useQuery` for public routes.

### Auth0 Management Helpers
The `useSecuredApi()` hook also exposes Auth0 Management API helpers, which require the `authadmin` role:

* `getAuth0ManagementToken()`
* `listAuth0Users()`
* `getUserPermissions()`
* `addPermissionToUser()`
* `removePermissionFromUser()`

These helpers can be used for advanced Auth0 management tasks, such as user permission management.
