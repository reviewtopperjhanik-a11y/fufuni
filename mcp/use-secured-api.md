The `useSecuredApi()` hook is the primary interface for frontend developers to interact with the Fufuni backend (Hono/Cloudflare Workers) and the Auth0 Management API. It serves as a hardened wrapper around the authentication layer, ensuring that every outgoing request is automatically signed with a valid JWT Bearer token.

## Import Path

To use the hook in your React components, import it from the auth features directory:

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

## Hook Interface and Methods

The `useSecuredApi()` hook returns a suite of methods designed for authenticated communication. These methods abstract away the complexity of token retrieval, refresh logic, and header management.

### core API Methods

| Method | Signature | When to Use |
| :--- | :--- | :--- |
| `getJson` | `<T>(url: string): Promise<T>` | Use for authenticated **GET** requests. Automatically parses the response as JSON. |
| `postJson` | `<T>(url: string, body: any): Promise<T>` | Use for **POST** requests with a JSON payload (e.g., creating a resource). |
| `putJson` | `<T>(url: string, body: any): Promise<T>` | Use for **PUT** requests to perform a full replacement of a resource. |
| `patchJson` | `<T>(url: string, body: any): Promise<T>` | Use for **PATCH** requests to perform partial updates. |
| `deleteJson` | `<T>(url: string): Promise<T>` | Use for **DELETE** requests to remove a resource. |
| `postForm` | `<T>(url: string, formData: FormData): Promise<T>` | Use for **POST** requests involving file uploads or `multipart/form-data`. |
| `hasPermission` | `(permission: string): Promise<boolean>` | Async check if the current user possesses a specific Auth0 scope/permission. |

### Auth0 Management Helpers

These methods are exposed for administrative dashboards and require the user to have the `auth0:admin:api` permission.

- `getAuth0ManagementToken()`: Retrieves a temporary token for direct Auth0 API calls.
- `listAuth0Users()`: Fetches the list of users from the Auth0 tenant.
- `getUserPermissions(mgmtToken, userId)`: Retrieves permissions assigned to a specific user.
- `addPermissionToUser(mgmtToken, userId, permissionName)`: Assigns a new scope to a user.
- `removePermissionFromUser(mgmtToken, userId, permissionName)`: Revokes a scope.
- `deleteAuth0User(mgmtToken, userId)`: Permanently deletes a user profile.
- `checkResourceServerScopes(mgmtToken, id, targetScopes)`: Synchronizes API definitions with Auth0.

## Automatic JWT Injection

One of the core strengths of `useSecuredApi()` is its silent handling of the `Authorization` header. In a standard Fufuni implementation, you do **not** manually fetch tokens or set headers.

When you call a method like `postJson`, the hook:
1. Intercepts the call.
2. Contacts the internal `useAuth` provider to get a valid Access Token from the cache (or refreshes it if expired).
3. Injects the token into the request: `Authorization: Bearer <JWT_TOKEN>`.
4. Sets the `Content-Type` to `application/json` (except for `postForm`).
5. Executes the fetch and returns the typed result.

### Usage Example: Authenticated GET

This example demonstrates fetching a user's private order history from the SQLite-backed Durable Object via the Hono API.

```typescript
import { useEffect, useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { SiteLoading } from "@/shared/ui/feedback/site-loading";

interface Order {
  id: string;
  total: number;
  status: string;
}

export const OrderHistory = () => {
  const { getJson } = useSecuredApi();
  const [orders, setOrders] = useState<Order[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchOrders = async () => {
      try {
        // The Bearer token is added automatically
        const data = await getJson<Order[]>("/v1/orders/me");
        setOrders(data);
      } catch (error) {
        console.error("Failed to load orders", error);
      } finally {
        setLoading(false);
      }
    };

    fetchOrders();
  }, [getJson]);

  if (loading) return <SiteLoading />;

  return (
    <ul>
      {orders.map((order) => (
        <li key={order.id}>Order {order.id}: ${order.total} ({order.status})</li>
      ))}
    </ul>
  );
};
```

### Usage Example: Authenticated POST

This example shows how to submit a product review. The backend validates the JWT to identify the reviewer, preventing impersonation.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button, Input, Textarea } from "@heroui/react";
import { useState } from "react";

export const ReviewForm = ({ productId }: { productId: string }) => {
  const { postJson } = useSecuredApi();
  const [comment, setComment] = useState("");
  const [rating, setRating] = useState(5);

  const handleSubmit = async () => {
    try {
      await postJson(`/v1/products/${productId}/reviews`, {
        comment,
        rating,
      });
      alert("Review submitted successfully!");
    } catch (e) {
      alert("Could not submit review. Are you logged in?");
    }
  };

  return (
    <div className="flex flex-col gap-4">
      <Input 
        type="number" 
        label="Rating" 
        value={rating.toString()} 
        onChange={(e) => setRating(Number(e.target.value))} 
      />
      <Textarea 
        label="Your Review" 
        value={comment} 
        onChange={(e) => setComment(e.target.value)} 
      />
      <Button onPress={handleSubmit} color="primary">
        Post Review
      </Button>
    </div>
  );
};
```

### Usage Example: Authenticated DELETE

Commonly used in management dashboards or for personal data management (e.g., removing a saved address).

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button } from "@heroui/react";

export const DeleteAddressButton = ({ addressId, onDeleted }: { addressId: string, onDeleted: () => void }) => {
  const { deleteJson } = useSecuredApi();

  const handleDelete = async () => {
    if (!confirm("Are you sure?")) return;
    
    try {
      await deleteJson(`/v1/me/addresses/${addressId}`);
      onDeleted();
    } catch (err) {
      console.error("Delete failed", err);
    }
  };

  return (
    <Button color="danger" variant="flat" onPress={handleDelete}>
      Delete Address
    </Button>
  );
};
```

## Guarding UI with `hasPermission()`

While the backend enforces security, the frontend uses `hasPermission()` to improve User Experience by hiding elements the user cannot interact with. This method checks the `permissions` array inside the user's JWT.

```typescript
import { useEffect, useState } from "react";
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button } from "@heroui/react";

export const AdminTools = () => {
  const { hasPermission } = useSecuredApi();
  const [canManageCatalog, setCanManageCatalog] = useState(false);

  useEffect(() => {
    // hasPermission is asynchronous as it might wait for the token to be available
    hasPermission("catalog:write").then(setCanManageCatalog);
  }, [hasPermission]);

  if (!canManageCatalog) return null;

  return (
    <div className="p-4 border-1 border-warning rounded-lg">
      <p className="text-sm font-bold">Admin Catalog Management</p>
      <Button size="sm" color="warning" className="mt-2">
        Reindex Search Engine
      </Button>
    </div>
  );
};
```

## When NOT to use this Hook

The `useSecuredApi()` hook is specifically for endpoints that require a user session. Using it for public routes introduces unnecessary overhead (checking for tokens, potential login redirects).

**Do NOT use this hook for:**
1. **Public Product Lists:** Use standard `fetch()` or a tanstack-query hook.
2. **SEO Metadata:** Metadata should be handled during SSR or through public-facing edge functions.
3. **Static Assets:** Images and CSS files should be requested via standard URLs.
4. **AI Parameter Retrieval:** As per Fufuni convention, AI moderation parameters are retrieved via GET `/v1/ai/parameters`. While this endpoint *might* be public or secured depending on the config, direct calls to AI providers (like OpenAI or Anthropic) from the browser should use the specific `ai-client.ts` helpers after obtaining the ephemeral API key.

## Auth0 Management Integration

For internal administrative tools, Fufuni provides helpers that talk directly to the Auth0 Management API via the worker. This is essential for managing user roles and permissions without building a custom user database.

```typescript
/**
 * Example: Adding a "moderator" permission to a user via the Admin Dashboard
 */
const promoteUser = async (targetUserId: string) => {
  const { getAuth0ManagementToken, addPermissionToUser } = useSecuredApi();
  
  try {
    // 1. Get the management token (requires 'auth0:admin:api' permission)
    const { access_token } = await getAuth0ManagementToken();
    
    // 2. Assign the permission
    await addPermissionToUser(access_token, targetUserId, "review:moderate");
    
    alert("User promoted to moderator successfully.");
  } catch (error) {
    console.error("Promotion failed", error);
  }
};
```

This workflow ensures that even complex administrative tasks remain typed and secured under the same hook umbrella, maintaining consistency across the Fufuni framework.
