## UseSecuredApi Hook Reference
The `useSecuredApi` hook provides a convenient way to make authenticated API requests in your React components. It automatically attaches the Auth0 Bearer token to every request, so you don't need to set the `Authorization` headers manually.

### Import Path
To use the `useSecuredApi` hook, import it from the following path:
```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

### Return Values
The `useSecuredApi` hook returns an object with the following methods:

| Method | Signature | When to Use |
| --- | --- | --- |
| `getJson` | `(url: string) => Promise<any>` | Authenticated GET requests that return JSON |
| `postJson` | `(url: string, body: any) => Promise<any>` | Authenticated POST requests with a JSON body |
| `putJson` | `(url: string, body: any) => Promise<any>` | Authenticated PUT (full replace) requests |
| `patchJson` | `(url: string, body: any) => Promise<any>` | Authenticated PATCH (partial update) requests |
| `deleteJson` | `(url: string) => Promise<any>` | Authenticated DELETE requests |
| `postForm` | `(url: string, formData: FormData) => Promise<any>` | Authenticated multipart/form-data POST requests (e.g., image upload) |
| `hasPermission` | `(permissionString: string) => Promise<boolean>` | Check if the current user has a specific Auth0 permission |

### Automatic JWT Bearer Token Injection
The `useSecuredApi` hook automatically attaches the Auth0 Bearer token to every request, so you don't need to set the `Authorization` headers manually.

### Usage Examples
Here are three complete usage examples in React components:

```typescript
// GET example
import React from 'react';
import { useSecuredApi } from "@/features/auth/components/auth-components";

const MyComponent = () => {
  const { getJson } = useSecuredApi();
  const [data, setData] = React.useState(null);

  React.useEffect(() => {
    const fetchData = async () => {
      const response = await getJson('/api/data');
      setData(response);
    };
    fetchData();
  }, [getJson]);

  return (
    <div>
      {data ? <div>{JSON.stringify(data)}</div> : <div>Loading...</div>}
    </div>
  );
};

// POST example

import { useSecuredApi } from "@/features/auth/components/auth-components";
```

### hasPermission Example
To guard an admin UI element, you can use the `hasPermission` method:
```typescript
import React from 'react';
import { useSecuredApi } from "@/features/auth/components/auth-components";

const MyComponent = () => {
  const { hasPermission } = useSecuredApi();

  const isAdmin = async () => {
    const result = await hasPermission('admin:access');
    return result;
  };

  return (
    <div>
      {isAdmin() ? <div>Admin UI element</div> : <div></div>}
    </div>
  );
};
```

### When Not to Use this Hook
Do not use the `useSecuredApi` hook for public routes, such as product listings. Instead, use plain `fetch()` or a custom hook with `useQuery`.

### Auth0 Management Helpers
The `useSecuredApi` hook exposes the following Auth0 Management API helpers:

* `getAuth0ManagementToken`
* `listAuth0Users`
* `getUserPermissions`
* `addPermissionToUser`
* `removePermissionFromUser`
* `deleteAuth0User`
* `getResourceServers`
* `updateResourceServerScopes`
* `getResourceServerScopes`
* `checkResourceServerScopes`

These helpers require the `auth0:admin:api` permission and can be used to manage Auth0 users and permissions.
