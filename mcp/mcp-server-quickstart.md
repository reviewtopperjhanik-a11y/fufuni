## Building the Fufuni MCP Server

### What a Remote MCP Server Is and Why It Accelerates AI-Assisted Development

A **Model Context Protocol (MCP) server** exposes your domain knowledge as a set of *tools* that LLMs can call at runtime.  
Instead of pasting 2000-line markdown files into every prompt, the IDE tells Claude/Copilot:  
“Here is a list of tools; if you need to know how Fufuni handles refunds, call `fufuni_refund_policy`.”  
The LLM receives the exact text in milliseconds, keeps the prompt small, and stays up-to-date without manual copying.

Remote MCP servers run on HTTPS and speak JSON-RPC over Server-Sent Events (SSE).  
Because they are just Cloudflare Workers, they scale to zero cost on the free tier and inherit Durable Objects, KV, R2, etc.

### Worker Entry File Skeleton

Create `workers/mcp/index.ts`:

```typescript
import { McpAgent, McpServer } from '@cloudflare/agents';
import { z } from 'zod';

export { McpAgent }; // re-export so wrangler can find the Durable Object

export default {
  async fetch(req: Request, env: Env): Promise<Response> {
    const agentId = 'fufuni-mcp'; // single global agent is enough
    const stub = env.MCP_AGENT.get(env.MCP_AGENT.idFromName(agentId));
    return stub.fetch(req);
  },
};

// ------------------ Durable Object ------------------

interface Env {
  MCP_AGENT: DurableObjectNamespace;
  MCP_KV: KVNamespace;
}

export class McpAgent extends McpServer<Env> {
  private readonly TOOL_PREFIX = 'fufuni_';

  async init(): Promise<void> {
    // Called once when the DO is created
    await this.registerTools();
  }

  private async registerTools(): Promise<void> {
    // Read the manifest once from KV (populated at build time)
    const manifest = await this.env.MCP_KV.get<{ files: string[] }>('mcp_manifest', 'json');
    if (!manifest) return;

    for (const file of manifest.files) {
      const stem = file.replace(/\.md$/, '');
      const toolName = `${this.TOOL_PREFIX}${stem}`;

      const content = await this.env.MCP_KV.get<string>(`mcp:${file}`, 'text');
      if (!content) continue;

      // First H1 line becomes description
      const description = content
        .split('\n')
        .find(l => l.startsWith('# '))
        ?.slice(2)
        .trim() || `${file} documentation`;

      this.tool({
        name: toolName,
        description,
        parameters: z.object({}), // no parameters needed
        execute: async () => ({ content, contentType: 'text/markdown' }),
      });
    }
  }
}
```

### Registering One Tool per Markdown File

The build script (`tools/build-mcp.ts`) runs before `wrangler deploy`:

```typescript
import { readdir, readFile } from 'node:fs/promises';
import { join } from 'node:path';

async function upload() {
  const dir = join(process.cwd(), 'mcp');
  const files = await readdir(dir);

  const manifest = { files };
  await fetch(`${CF_KV_URL}/mcp_manifest`, {
    method: 'PUT',
    headers: { Authorization: `Bearer ${CF_API_TOKEN}` },
    body: JSON.stringify(manifest),
  });

  for (const file of files) {
    const content = await readFile(join(dir, file), 'utf-8');
    await fetch(`${CF_KV_URL}/mcp:${file}`, {
      method: 'PUT',
      body: content,
    });
  }
}
```

Each file becomes a tool named `fufuni_<stem>`; the LLM sees:

```json
{
  "tools": [
    {
      "name": "fufuni_refund_policy",
      "description": "Refund and return policy for Fufuni marketplace"
    }
  ]
}
```

### Serving SSE and HTTP Endpoints

The `@cloudflare/agents` library automatically mounts:

- `GET /sse` – Server-Sent Events stream for bidirectional JSON-RPC.  
- `POST /mcp` – HTTP JSON-RPC endpoint for tools that return large payloads.

No extra routing code is required; the `McpServer` base class handles CORS, preflight, and content-type negotiation.

### Adding KV Caching

The code above already caches the markdown in KV.  
To invalidate after a content change, bump a version key:

```typescript
await this.env.MCP_KV.put('mcp_version', Date.now().toString());
```

The `init()` method can re-register tools when the version changes:

```typescript
const cachedVer = await this.env.MCP_KV.get('mcp_version');
if (cachedVer !== this.lastVersion) {
  this.lastVersion = cachedVer;
  await this.registerTools();
}
```

### Deployment and IDE Connection

Deploy:

```bash
pnpm build:mcp          # uploads markdown to KV
wrangler deploy --config workers/mcp/wrangler.jsonc
```

Obtain the public URL, e.g. `https://mcp.fufuni.shop`.

Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "fufuni": {
      "url": "https://mcp.fufuni.shop/sse",
      "transport": "sse"
    }
  }
}
```


Restart the editors; the AI can now call any `fufuni_*` tool without manual copy-paste.
