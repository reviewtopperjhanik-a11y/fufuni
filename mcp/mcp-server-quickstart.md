## Introduction to Remote MCP Servers
A remote MCP (Model Context Protocol) server is a Cloudflare Workers application that exposes a set of tools and their corresponding documentation to AI models, accelerating AI-assisted development by providing contextual knowledge. Fufuni's MCP server will serve the static Markdown knowledge-base files generated by a build script and stored in the `mcp/` directory.

## Building the Fufuni MCP Server
To create the MCP server, we'll start with the Worker entry file skeleton using `@cloudflare/agents`:
```typescript
import { McpAgent, McpServer } from '@cloudflare/agents';
import { ReadableStream } from 'whatwg-streams';

// Register tools from mcp/ directory
const tools: { [name: string]: { description: string; response: string } } = {};

// Load and register tools
async function loadTools() {
  const files = await glob('mcp/*.md');
  for (const file of files) {
    const stem = file.replace('mcp/', '').replace('.md', '');
    const content = await Deno.readTextFile(file);
    const lines = content.split('\n');
    const description = lines[0].replace('# ', '');
    tools[stem] = { description, response: content };
  }
}

// Create the MCP server
const server = new McpServer();
loadTools().then(() => {
  for (const [name, tool] of Object.entries(tools)) {
    server.registerTool(name, tool.description, async () => {
      return new ReadableStream({
        start(controller) {
          controller.enqueue(tool.response);
          controller.close();
        },
      });
    });
  }
});

// Handle MCP requests
addEventListener('fetch', (event) => {
  const request = event.request;
  const url = new URL(request.url);
  if (url.pathname === '/mcp') {
    server.handleRequest(request).then((response) => event.respondWith(response));
  } else if (url.pathname === '/sse') {
    // Handle SSE requests
  }
});
```

## Wrangler Configuration and KV Caching
To cache the file reads and minimize the number of invocations, we'll use Cloudflare Workers' KV storage. First, we need to configure the wrangler:
```jsonc
{
  "name": "fufuni-mcp",
  "type": "worker",
  "account_id": "your-account-id",
  "workers_dev": true,
  "routes": [
    {"pattern": "fufuni-mcp.your-domain.workers.dev/mcp", "zone_id": "your-zone-id", "zone_name": "your-zone-name"},
    {"pattern": "fufuni-mcp.your-domain.workers.dev/sse", "zone_id": "your-zone-id", "zone_name": "your-zone-name"}
  ],
  "kv_namespaces": [
    {"binding": "MCP_TOOLS", "id": "your-kv-namespace-id"}
  ]
}
```
Then, we'll modify the `loadTools` function to use KV caching:
```typescript
import { KV } from '@cloudflare/workers';

// Create a KV namespace binding
const MCP_TOOLS = await KVNamespace('MCP_TOOLS');

// Load and register tools with KV caching
async function loadTools() {
  const toolsCache = await MCP_TOOLS.get('tools');
  if (toolsCache) {
    tools = JSON.parse(toolsCache);
  } else {
    const files = await glob('mcp/*.md');
    for (const file of files) {
      const stem = file.replace('mcp/', '').replace('.md', '');
      const content = await Deno.readTextFile(file);
      const lines = content.split('\n');
      const description = lines[0].replace('# ', '');
      tools[stem] = { description, response: content };
    }
    await MCP_TOOLS.put('tools', JSON.stringify(tools));
  }
}
```
## Deployment and Connection to Claude Desktop / VS Code Copilot
To deploy the Fufuni MCP server, run the following command:
```bash
wrangler publish
```
Then, connect to Claude Desktop or VS Code Copilot using the `mcp://` protocol with your deployed worker's URL:
```bash
mcp://fufuni-mcp.your-domain.workers.dev/mcp
```
