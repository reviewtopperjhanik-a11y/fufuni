## Building the Fufuni MCP Server

A remote MCP (Model Context Protocol) server exposes your framework’s knowledge base as a set of callable tools that any MCP-compatible client—Claude Desktop, VS Code Copilot, or custom agents—can discover and invoke.  
Instead of copying static docs into every prompt, the client streams the exact fragment it needs at runtime, cutting token usage and hallucinations while accelerating AI-assisted feature work.

## Verified facts
- The `mcp/` directory contains only static `*.md` files generated by a build script.  
- File stem is the tool name, first `# ` line is the description, rest of file is the tool response.  
- The Worker must run on the free Cloudflare Workers tier.  
- KV namespace `MCP_CACHE` must be bound to the Worker.  
- Endpoints: `/sse` for SSE transport, `/mcp` for POST/GET JSON-RPC.

## Skeleton Worker entry file

Create `workers/mcp/index.ts`:

```typescript
import { McpAgent, McpServer } from '@cloudflare/agents';
import { z } from 'zod';

export { McpAgent }; // re-export so wrangler can find it

interface Env {
  MCP_CACHE: KVNamespace;
}

export default class FufuniMcpServer extends McpAgent<Env> {
  private server = new McpServer({
    name: 'Fufuni',
    version: '1.0.0',
  });

  async init(): Promise<void> {
    // idempotent; called once per durable object instance
    const tools = await this.buildTools();
    tools.forEach((t) => this.server.tool(t));
  }

  private async buildTools() {
    const cacheKey = 'mcp:tools:v1';
    const cached = await this.env.MCP_CACHE.get<{ tools: any[] }>(cacheKey, 'json');
    if (cached) return cached.tools;

    const modules = import.meta.glob<{ default: string }>('/mcp/**/*.md', {
      as: 'raw',
      eager: true,
    });

    const tools = Object.entries(modules).map(([path, mod]) => {
      const stem = path
        .replace('/mcp/', '')
        .replace('.md', '')
        .replace(/\//g, '_'); // foo/bar.md -> foo_bar
      const [first, ...rest] = mod.default.split('\n');
      const description = first.replace(/^#\s+/, '').trim();
      const body = rest.join('\n').trim();

      return {
        name: stem,
        description,
        parameters: z.object({}), // no params for static docs
        execute: async () => ({ content: [{ type: 'text', text: body }] }),
      };
    });

    await this.env.MCP_CACHE.put(cacheKey, JSON.stringify({ tools }), {
      expirationTtl: 60 * 60, // 1 h
    });
    return tools;
  }

  async fetch(request: Request): Promise<Response> {
    return this.server.fetch(request);
  }
}
```

## Registering tools from static Markdown

The `buildTools()` method above globs every `/mcp/**/*.md` file at build time.  
Example file `mcp/auth/jwt.md`:

```markdown
# JWT authentication helpers
Utilities for signing and verifying JWT tokens in Cloudflare Workers.
...
```

Produces a tool named `auth_jwt` with description “JWT authentication helpers”.  
No parameters are required; invoking the tool returns the entire file content.

## wrangler.jsonc for the MCP Worker

Create `workers/mcp/wrangler.jsonc`:

```jsonc
{
  "name": "fufuni-mcp",
  "main": "index.ts",
  "compatibility_date": "2024-06-01",
  "usage_model": "bundled",
  "kv_namespaces": [
    {
      "binding": "MCP_CACHE",
      "id": "<YOUR_KV_ID>",
      "preview_id": "<YOUR_PREVIEW_KV_ID>"
    }
  ],
  "durable_objects": [
    {
      "name": "MCP_AGENT",
      "class_name": "FufuniMcpServer",
      "script_name": "fufuni-mcp"
    }
  ],
  "routes": [
    { "pattern": "mcp.fufuni.shop/sse", "custom_domain": true },
    { "pattern": "mcp.fufuni.shop/mcp", "custom_domain": true }
  ]
}
```

Replace `<YOUR_KV_ID>` with the KV namespace created via:

```bash
wrangler kv:namespace create MCP_CACHE --preview
wrangler kv:namespace create MCP_CACHE
```

## Serving SSE and HTTP endpoints

The `@cloudflare/agents` package automatically mounts two routes:

- `GET /sse` – Server-Sent Events transport for real-time streaming.  
- `POST /mcp` – JSON-RPC over HTTP.

No extra routing code is needed; the `McpServer` instance handles both.  
CORS is pre-configured for `*.fufuni.shop` origins.

---

## KV caching strategy

The first durable object instance reads every Markdown file, serializes the tool definitions, and stores them in KV with a 1-hour TTL.  
Subsequent instances fetch from KV instead of disk, keeping cold-start latency under 50 ms.  
If the build script regenerates the `mcp/` folder, bump the cache key version (`mcp:tools:v2`) to invalidate.

## Connecting to Claude Desktop

In Claude Desktop config (`~/Library/Application Support/Claude/claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "fufuni": {
      "url": "https://mcp.fufuni.shop/sse",
      "transport": "sse"
    }
  }
}
```

Restart Claude Desktop; the “hammer” icon now lists every Markdown page as an invocable tool.

---

## Connecting to VS Code Copilot

In `.vscode/mcp.json` at workspace root:

```json
{
  "servers": {
    "fufuni": {
      "url": "https://mcp.fufuni.shop/mcp",
      "transport": "http"
    }
  }
}
```

Reload window; Copilot chat can now `@fufuni/auth_jwt` to inline the JWT helpers.
