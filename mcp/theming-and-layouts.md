## Theming and Layouts
The Fufuni e-commerce framework provides a flexible theming system and multiple layouts to cater to different use cases.

### Layouts

Fufuni offers two primary layouts: `DefaultLayout` and `LuxuryLayout`. While they share some common components, there are key differences between them.

#### Default Layout

The `DefaultLayout` is the standard layout used throughout the application. It features a horizontal navigation bar, a cart drawer, and a theme switcher. The layout is designed to provide a consistent look and feel across the application.

#### Luxury Layout

The `LuxuryLayout` is a full-bleed layout designed for luxury or editorial pages. The main differences between this layout and the `DefaultLayout` are:

* No horizontal padding on the `<main>` element, allowing components to manage their own maximum width.
* Uses a dark `Footer` component instead of the standard one.
* Still includes the `Navbar`, `CartDrawer`, and `ThemeSwitcher` components.

```typescript
// apps/client/src/layouts/luxury.tsx
import { Navbar } from "@/components/navbar";
import { CartDrawer } from "@/components/cart-drawer";
import { ThemeSwitcher } from "@/components/ui/theme-switcher";
import { Footer } from "@/components/footer";

/**
 * LuxuryLayout — full-bleed layout for luxury/editorial pages.
 *
 * Differences from DefaultLayout:
 * - No horizontal padding on <main> (components manage their own max-width)
 * - Uses the dark luxury Footer instead of the standard one
 * - Still includes Navbar, CartDrawer and ThemeSwitcher
 */
export default function LuxuryLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  const [isCartOpen, setIsCartOpen] = useState(false);

  return (
    <div className="relative flex flex-col min-h-screen">
      <Navbar onCartOpen={() => setIsCartOpen(true)} />
      <CartDrawer isOpen={isCartOpen} onClose={setIsCartOpen} />
      <main className="w-full grow pt-16">{children}</main>
      <Footer />
      <ThemeSwitcher />
    </div>
  );
}
```

### Theming

Fufuni uses a custom theme storage system, where themes are stored in the `store_themes` database table and loaded at startup via the API. This allows for easy management of themes without modifying the codebase.

The `StoreThemeProvider` component applies the active theme to the `<html>` element. It uses the `useStoreTheme` hook to read and set the current theme.


### Editable CMS Blocks

Fufuni uses a static CMS content file (`cms-content.ts`) to define editable content blocks, such as hero banners, carousels, and more. This approach eliminates the need for an external CMS database.

The `cms-content.ts` file contains a map of handle to locale to content, allowing for easy management of content across different locales.

```typescript
// apps/client/src/config/cms-content.ts
/**
 * Static CMS page content for all storefront informational pages.
 * Content is defined here per locale to avoid polluting the main i18n JSON files
 * with large multi-paragraph text blocks.
 * Supported locales: en-US, fr-FR, es-ES, ar-SA, zh-CN, he-IL
 */
export type CmsSection = {
  heading: string;
  body: string;
};

export type CmsPageContent = {
  title: string;
  lead: string;
  sections: CmsSection[];
};

/** Map: handle → locale → content */
export const CMS_CONTENT: Record<string, Record<string, CmsPageContent>> = {
  // ...
};
```

By using these features, developers can easily customize the look and feel of their Fufuni application and manage content without requiring extensive technical knowledge.
