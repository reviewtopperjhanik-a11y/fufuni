## Executing the Seed Script

The Fufuni seed script is a standalone TypeScript utility designed to populate a fresh database with a comprehensive set of demo data, including regions, warehouses, categories, products, orders, and reviews. It interacts directly with the backend API using an administrative secret key.

Before running the seed script, ensure your Cloudflare Worker is running locally and that you have initialized the base configuration (currencies and countries) using the `init.ts` script.

```bash
# 1. Start the local development server
npm run dev

# 2. In a separate terminal, run the seed script
# Usage: npx tsx scripts/seed.ts <API_URL> <ADMIN_KEY>
npx tsx scripts/seed.ts http://localhost:8787 sk_test_your_secret_key_here
```

The script is idempotent for many operations, meaning you can rerun it to update existing entries or add missing data without necessarily duplicating every record, although it is primarily intended for a clean slate.

## Extending the Product Catalog

The `PRODUCT_CATALOG` is a unified array of objects that defines the inventory of the demo store. Each product entry must contain localized metadata and a list of variants. Localized fields like `title` and `description` are stored as JSON strings in the database to support Fufuni's multi-language storefront.

### Adding a New Product

## Managing Seed Categories

Categories in Fufuni are hierarchical. The `seedCategories` function orchestrates the creation of parent and child categories using the `createCat` helper. This helper automatically handles image processing (WebP conversion and thumbnail generation).

### Adding a New Category

To add a category, you must define its handle, localized names, and an optional `parent_id`.

```typescript
async function seedCategories() {
  // ... existing code
  
  // Create a new top-level category
  const electronicsCategory = await createCat({
    handle: 'electronics',
    name: JSON.stringify({
      'en-US': 'Electronics',
      'fr-FR': 'Électronique'
    }),
    description: JSON.stringify({
      'en-US': 'Gadgets and hardware.',
      'fr-FR': 'Gadgets et matériel.'
    }),
  }, 'electronics-hero.png');

  // Create a sub-category linked to the above
  const audioCategory = await createCat({
    handle: 'audio',
    name: JSON.stringify({ 'en-US': 'Audio', 'fr-FR': 'Audio' }),
    parent_id: electronicsCategory.id, // Link to parent
  }, 'audio-gear.png');

  return {
    // ... other categories
    electronics: electronicsCategory.id,
    audio: audioCategory.id,
  };
}
```

## Resilient API Communication

The script includes an `apiWithRetry` helper. This is critical because Cloudflare Workers and Durable Objects may enforce rate limits or encounter transient network issues during heavy seeding operations (like uploading dozens of base64 images).

### Using apiWithRetry

The helper implements exponential backoff and specifically listens for `429 Too Many Requests` responses, parsing the `Retry-After` suggestion if provided by the Hono middleware.

```typescript
/**
 * Example: Custom data migration or batch update using retry logic
 */
async function batchUpdateProductStatus(productIds: string[]) {
  for (const id of productIds) {
    try {
      // Use apiWithRetry for operations that might trigger rate limits
      await apiWithRetry(`/v1/products/${id}`, {
        status: 'published',
        published_at: new Date().toISOString()
      });
      console.log(`Successfully updated product ${id}`);
    } catch (error) {
      console.error(`Failed to update ${id} after max retries:`, error);
    }
  }
}
```

## Currency and Price Conversion

Fufuni handles all pricing in **integer cents** to avoid floating-point rounding errors. The seed script uses EUR as the base currency and converts prices for other regions using fixed exchange rates defined at the top of the file.

### Conversion Logic

The `convertCents` function ensures that prices in USD and GBP are rounded integers.

```typescript
const EUR_TO_USD = 1.14;
const EUR_TO_GBP = 0.86;

function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}

// Usage within the variant loop:
const priceEur = 2999; // €29.99
const priceUsd = convertCents(priceEur, EUR_TO_USD); // 3419 cents -> $34.19
```

When seeding variant prices, the script iterates through the `currencyMap` (fetched from the API) and creates a price record for each supported currency.

## Image Processing Pipeline

The framework prioritizes performance by converting all product and category images to **WebP** format during the seed process. This reduces the payload size for the storefront and ensures consistent behavior across browsers.

### The toWebpDataUri Helper

This function performs three main tasks:
1.  **Decoding**: Handles PNG or JPEG inputs from the local `/img` folder or the `image_map.ts` base64 fallback.
2.  **Resizing**: Uses a `nnsResize` (Nearest-Neighbor) algorithm to downscale images if they exceed `maxSide` pixels, ensuring that thumbnails and hero images are optimized.
3.  **Encoding**: Uses `webp-wasm` to generate a WebP buffer, which is then converted into a data URI.

```typescript
// Example of manual usage for a custom asset
const heroBannerDataUri = await toWebpDataUri(
  'summer-sale-banner.jpg', 
  1920, // Max width/height
  85    // Quality
);

if (heroBannerDataUri) {
  await api('/v1/store/settings', { hero_banner_url: heroBannerDataUri });
}
```

The `imageMap` import allows the script to run even if the physical `.png` files are missing from the repository, as critical assets are embedded as base64 strings.

## Creating Custom Seed Helpers

When extending the framework with new modules (e.g., a "Discounts" or "Gift Cards" module), you should follow the functional pattern of the existing script. Create a standalone `seedX` function and register it in the main `seed()` orchestrator.

### Pattern for New Seeders

```typescript
/**
 * Seed promotional discount codes
 */
async function seedDiscounts(regionData: any) {
  console.log('🎟️ Seeding discount codes...');
  
  const discounts = [
    { code: 'WELCOME10', percentage: 10, description: '10% off for new customers' },
    { code: 'FREESHIP', percentage: 0, description: 'Free shipping on orders over €50' },
  ];

  for (const d of discounts) {
    await api('/v1/discounts', {
      code: d.code,
      type: 'percentage',
      value: d.percentage,
      is_active: true,
      starts_at: new Date().toISOString(),
    });
    console.log(`   └─ Created: ${d.code}`);
  }
}

// Inside the main seed() function:
async function seed() {
  const regionData = await seedRegions();
  const categoryData = await seedCategories();
  const productIds = await seedProducts(regionData, categoryData);
  
  // Call your new helper
  await seedDiscounts(regionData);
  
  await seedOrders(regionData);
  // ...
}
```

This modularity ensures that the seeding process remains readable and that dependencies between entities (like requiring `region_id` before creating a `discount`) are respected.
