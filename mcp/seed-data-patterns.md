## Seed Data Script Reference
The seed script is used to populate the Fufuni e-commerce framework with demo data. This reference guide covers the usage and structure of the seed script.

### Running the Seed Script
To run the seed script, use the following command:
```bash
npx tsx scripts/seed.ts <api_url> <admin_key>
```
Replace `<api_url>` with the URL of your API (e.g., `http://localhost:8787`) and `<admin_key>` with your admin API key (e.g., `sk_abc123...`).

### Product Catalog Structure
The `PRODUCT_CATALOG` is an array of product objects, each with the following properties:
* `key`: a short lookup key for the product
* `handle`: the API product handle
* `categories`: an array of category handles
* `title` and `description`: i18n maps for the product title and description
* `variants`: an array of variant objects with `sku`, `price_cents`, `weight_g`, `stock`, and `imageFile` properties

To add a new product, simply push a new object to the `PRODUCT_CATALOG` array:
```typescript
const PRODUCT_CATALOG = [
  // ... existing products ...
  {
    key: 'new-product',
    handle: 'new-product-handle',
    categories: ['new-category'],
    title: { 'en-US': 'New Product', 'fr-FR': 'Nouveau Produit' },
    description: { 'en-US': 'This is a new product', 'fr-FR': 'Ceci est un nouveau produit' },
    variants: [
      { sku: 'NEW-PRD-001', price_cents: 1999, weight_g: 100, stock: 10, imageFile: 'new-product-image.png' },
      // ... more variants ...
    ],
  },
];
```

### apiWithRetry Helper
The `apiWithRetry` helper is used to handle transient failures (e.g., rate limiting) when making API requests. It retries the request up to a specified number of times (default: 5) with exponential backoff. To use `apiWithRetry` for custom seed data, simply call it with the API path and optional request body:
```typescript
const response = await apiWithRetry('/v1/new-endpoint', { /* request body */ });
```
### Currency Conversion
Currency conversion is done using integer cents and rounding to avoid floating-point pricing errors. The `convertCents` function takes a price in EUR cents and an exchange rate multiplier to convert it to the target currency (e.g., USD, GBP):
```typescript
const eurPrice = 1999; // 19.99 EUR
const usdPrice = convertCents(eurPrice, EUR_TO_USD); // approx. 22.79 USD
```
### Image Embedding
Images are embedded using the `toWebpDataUri` helper, which takes a filename or base64-encoded image data, resizes it to a specified maximum side length, and returns a WebP-encoded data URI:
```typescript
const imageDataUri = await toWebpDataUri('image.png', 1200, 80);
```
If the image file is not found or cannot be read, `toWebpDataUri` returns `null`.

### Adding a New Seed Helper Function
To add a new seed helper function, follow the existing pattern:
1. Create a new function with a descriptive name (e.g., `seedNewData`).
2. Use the `api` or `apiWithRetry` helper to make API requests.
3. Handle any errors or edge cases that may arise.
4. Return the result of the API request or a transformed version of it.
5. Update the `seed()` function to call your new helper function.

Example:
```typescript
async function seedNewData() {
  const response = await apiWithRetry('/v1/new-endpoint', { /* request body */ });
  // Transform the response data if needed
  return response;
}

async function seed() {
  // ... existing seed logic ...
  await seedNewData();
  // ... more seed logic ...
}
```
