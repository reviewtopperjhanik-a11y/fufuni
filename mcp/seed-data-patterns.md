## Seed Data Script Reference

### Running the Seed Script

The seed script populates a fresh Fufuni store with demo data including regions, tax rates, categories, products, inventory, orders and reviews. It is idempotent and safe to rerun.

```bash
#!/usr/bin/env bash
# Start the local API first
npm run dev

# Then seed (replace sk_... with the admin key shown in the terminal)
npx tsx apps/merchant/scripts/seed.ts http://localhost:8787 sk_abc123...
```

Required arguments:
- `<api_url>` – full base URL of the running API (e.g. `http://localhost:8787`)
- `<admin_key>` – the secret key printed when the store is initialised

Products are declared as plain objects inside the `PRODUCT_CATALOG` array. Each entry describes a product, its variants, SKUs and pricing.

To add a new product:
1. Append a new object to `PRODUCT_CATALOG`
2. Ensure `categoryKeys` references existing category handles
3. Provide at least one variant and one SKU
4. Use `tax20` or `tax5` for `taxRateTag` (created by `seedTaxes()`)
5. Add image file names under `images` (PNG/JPG in `./img/` or base64 keys in `imageMap`)

### Adding a Seed Category

Categories are created inside `seedCategories()`. Use the helper `createCat()` to upload images and translations in one call.

```typescript
// inside seedCategories()
const mugsCategory = await createCat(
  {
    handle: 'mugs',
    name: JSON.stringify({
      'en-US': 'Mugs',
      'fr-FR': 'Mugs',
      'es-ES': 'Tazas',
      'zh-CN': '马克杯',
      'ar-SA': 'أكواب',
      'he-IL': 'ספלים',
    }),
    description: JSON.stringify({
      'en-US': 'Ceramic mugs, 330 ml',
      'fr-FR': 'Mugs en céramique, 330 ml',
    }),
    parent_id: parentCategory.id, // or omit for root
  },
  'mugs.png' // file in ./img/ or key in imageMap
);
```

`createCat` automatically:
- Converts the source image to WebP at two sizes (1200 px and 300 px)
- Stores the data URIs in `image_url` and `thumbnail_url`
- Returns the created category object (keep the ID for later assignments)

### apiWithRetry Helper

Cloudflare Workers may return `429 Rate limit exceeded` under load. `apiWithRetry` wraps the low-level `api()` function with exponential back-off and automatic retry.

```typescript
// apps/merchant/scripts/seed.ts
await apiWithRetry('/v1/products', { ...productPayload });
```

Why it exists:
- Local development often hits the 50 req/10 s default limit
- Prevents transient failures from breaking the entire seed run
- Extracts the suggested wait time from the error message when available

Use it for any POST/PATCH that may be called in tight loops (products, SKUs, inventory, etc.).

Custom seed data example:

```typescript
async function seedCoupons() {
  console.log('🎫 Creating coupons...');
  await apiWithRetry('/v1/coupons', {
    code: 'WELCOME10',
    type: 'percentage',
    value: 10,
    max_uses: 1000,
  });
}
```

### Currency Conversion

Prices are stored as integer cents in the database. The script keeps EUR as the base currency and converts to USD/GBP using fixed rates:

```typescript
const EUR_TO_USD = 1.14; // 1 € = 1.14 $
const EUR_TO_GBP = 0.86; // 1 € = 0.86 £

function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate); // avoid float rounding errors
}
```

Example usage inside a SKU:

```typescript
prices: [
  { currency: 'eur', amount: 2499, taxRateTag: 'tax20' },
  { currency: 'usd', amount: convertCents(2499, EUR_TO_USD), taxRateTag: 'tax20' },
  { currency: 'gbp', amount: convertCents(2499, EUR_TO_GBP), taxRateTag: 'tax20' },
],
```

### Image Embedding with toWebpDataUri

Product and category images are converted to WebP data URIs so the script has zero runtime dependencies on external CDNs.

```typescript
const webpUri = await toWebpDataUri(
  'hoodies.png',   // filename in ./img/ or key in imageMap
  1200,            // max pixel side
  80               // WebP quality 0-100
);
```

How it works:
1. Reads PNG/JPEG from disk or decodes base64 embedded in `imageMap`
2. Resizes (maintains aspect) when any side exceeds `maxSide`
3. Encodes to WebP using the WASM build of `webp-wasm`
4. Returns a data URI string ready for `image_url` or `thumbnail_url`

Adding a new image:
- Drop the file into `apps/merchant/scripts/img/`
- Reference the filename in `PRODUCT_CATALOG[*].images` or `createCat()`
- Or embed it as base64 in `imageMap.ts` for portability

### Adding a New Seed Helper

Follow the existing pattern:

1. Create an async function with a single responsibility
2. Use `api()` or `apiWithRetry()` for all HTTP calls
3. Log progress with emoji prefixes for consistency
4. Return useful data (IDs, maps) for downstream helpers
5. Add the call to the main `seed()` orchestrator in the correct order

Example: seed shipping zones

```typescript
async function seedShipping() {
  console.log('🚚 Creating shipping zones...');
  const euZone = await api('/v1/shipping-zones', {
    name: 'EU Zone',
    countries: EU_COUNTRIES,
  });
  const usZone = await api('/v1/shipping-zones', {
    name: 'US Zone',
    countries: ['US', 'CA'],
  });
  return { euZone, usZone };
}
```

Then in `seed()`:

```typescript
const { euZone, usZone } = await seedShipping();
```

Keep helpers idempotent where possible (use unique handles or check existence before creating).
