## Seed Script Overview
The seed script is used to populate a Fufuni e-commerce environment with demo data. It is designed to be idempotent, allowing it to be run multiple times without causing issues.

## Running the Seed Script
To run the seed script, use the following command:
```bash
npx tsx scripts/seed.ts <api_url> <admin_key>
```
Replace `<api_url>` with the URL of your Fufuni API (e.g., `http://localhost:8787`) and `<admin_key>` with your administrator key.

## Adding a New Seed Category
To add a new seed category, create a new function that follows the existing pattern. For example:
```typescript
async function seedNewCategory() {
  console.log('📁 Creating new category...');

  // Helper: create a category with WebP image_url and thumbnail_url
  async function createCat(data: Record<string, any>, imageFile: string) {
    const imageUrl = await toWebpDataUri(imageFile, 1200, 80);
    const thumbUrl  = await toWebpDataUri(imageFile, 300, 80);
    return api('/v1/categories', {
      ...data,
      ...(imageUrl ? { image_url: imageUrl } : {}),
      ...(thumbUrl  ? { thumbnail_url: thumbUrl } : {}),
    });
  }

  // Create new category
  const newCategory = await createCat({
    handle: 'new-category',
    name: JSON.stringify({
      'en-US': 'New Category',
      'fr-FR': 'Nouvelle Catégorie',
    }),
    description: JSON.stringify({
      'en-US': 'This is a new category',
      'fr-FR': 'Ceci est une nouvelle catégorie',
    }),
  }, 'new-category.png');

  return newCategory;
}
```
Then, update the `seed()` function to include the new category:
```typescript

  // ...
}
```

## apiWithRetry Helper
The `apiWithRetry` helper is used to handle transient failures like rate limiting when calling the API. It will retry the request up to 5 times with exponential backoff before throwing an error. To use it for custom seed data, simply replace the `api` function with `apiWithRetry`:
```typescript
const response = await apiWithRetry('/v1/products', {
  // product data
});
```
## Currency Conversion
Currency conversion is done using integer cents and rounding to avoid floating-point errors. The `convertCents` function is used to convert EUR cents to USD or GBP cents:
```typescript
const usdPrice = convertCents(1000, EUR_TO_USD); // convert 10 EUR to USD
const gbpPrice = convertCents(1000, EUR_TO_GBP); // convert 10 EUR to GBP
```
## Image Embedding
Images are embedded using the `toWebpDataUri` helper, which converts images to WebP format and returns a data URI. If an image is not found, it will fall back to a base64-encoded version:
```typescript
const imageUrl = await toWebpDataUri('image.jpg', 1200, 80);
```
