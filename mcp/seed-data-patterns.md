## 2. `PRODUCT_CATALOG` – Adding a New Product  

The catalog is a plain TypeScript array of objects. Each product can contain **variants**, **prices**, and **image references**.

```ts
// apps/merchant/scripts/seed-data.ts (excerpt)
export const PRODUCT_CATALOG = [
  {
    // Unique slug used in URLs and API calls
    slug: 'organic-ceramic-mug',
    // Human‑readable name
    name: 'Organic Ceramic Mug',
    // Short description shown on product cards
    shortDescription: 'Hand‑crafted, 350 ml, microwave‑safe.',
    // Full description (Markdown allowed)
    description: `
## Features
- 100 % natural clay
- Lead‑free glaze
- Dishwasher safe
    `,
    // Category slug – must exist in the seeded categories
    category: 'kitchenware',
    // Base price in **EUR cents** (integer)
    basePriceCents: 1299,
    // Optional variant list (e.g., colors, sizes)
    variants: [
      { sku: 'MUG-BLUE', name: 'Blue', priceModifierCents: 0 },
      { sku: 'MUG-GREEN', name: 'Green', priceModifierCents: 0 },
      { sku: 'MUG-RED', name: 'Red', priceModifierCents: 100 }, // +€1.00
    ],
    // Image reference – either a filename in ./img or a base64 entry in imageMap
    image: 'ceramic-mug.png',
  },
  // …more products
];
```

**Adding a product**

1. Append a new object to `PRODUCT_CATALOG`.  
2. Ensure the `category` value matches a seeded category slug.  
3. If you need localized pricing, use `basePriceCents` (EUR) and let the script convert to USD/GBP automatically (see section 5).  
4. Run the seed script again; the `apiWithRetry` wrapper will POST the product to `/v1/products`.

## 4. `apiWithRetry` – Why & How to Use  

### Why it exists
* The Fufuni API enforces rate limits (e.g., 60 req/min).  
* Transient network glitches can cause occasional 5xx responses.  
* `apiWithRetry` automatically retries on **rate‑limit** errors with exponential back‑off, reducing manual boilerplate.

### Signature

```ts
async function apiWithRetry(
  path: string,
  body?: any,
  maxRetries = 5,
): Promise<any>
```

* `path` – endpoint relative to `API_URL` (e.g., `/v1/products`).  
* `body` – JSON payload for POST/PUT; omitted for GET.  
* `maxRetries` – optional cap (default 5).

### Example: Seeding a custom “discount‑code” resource

```ts
// apps/merchant/scripts/custom-seed.ts
import { apiWithRetry } from './seed'; // re‑use the helper

async function seedDiscountCode() {
  const payload = {
    code: 'WELCOME10',
    amountCents: 1000, // €10.00
    expiresAt: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000).toISOString(),
  };

  // The helper will retry if the API returns a rate‑limit error
  const result = await apiWithRetry('/v1/discount-codes', payload);
  console.log('Created discount code:', result.id);
}

// Call from the main orchestrator or run standalone
seedDiscountCode().catch(console.error);
```

**Tip:** Use `apiWithRetry` for any bulk‑insert or time‑sensitive seed step.

## 5. Currency Conversion (EUR → USD / GBP)

All seed prices are stored in **EUR cents** (`basePriceCents`). The script converts them on‑the‑fly for USD and GBP using integer arithmetic to avoid floating‑point rounding errors.

```ts
// Conversion constants (defined in seed.ts)
const EUR_TO_USD = 1.14; // 1 EUR = 1.14 USD
const EUR_TO_GBP = 0.86; // 1 EUR = 0.86 GBP

/**
 * Convert EUR cents → target currency cents.
 *
 * @param cents Price in EUR cents.
 * @param rate  Exchange‑rate multiplier (e.g., EUR_TO_USD).
 * @returns Rounded integer cents for the target currency.
 */
function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}
```

**Usage inside the seeder**

```ts
const usdCents = convertCents(product.basePriceCents, EUR_TO_USD);
const gbpCents = convertCents(product.basePriceCents, EUR_TO_GBP);

// POST payload example
await apiWithRetry('/v1/products', {
  slug: product.slug,
  name: product.name,
  price: {
    eur: product.basePriceCents,
    usd: usdCents,
    gbp: gbpCents,
  },
  // …other fields
});
```

If you add a new currency, simply declare a new conversion constant and reuse `convertCents`.

## 6. Image Embedding – `toWebpDataUri`  

The seed script stores product images as **WebP data URIs** to keep the repo self‑contained.

### How it works
1. **Source** – either a file path (`./img/<filename>`) *or* a base64 string from `imageMap`.  
2. The helper decodes PNG (via `pngjs`) or JPEG (via `jpeg-js`).  
3. It optionally **down‑scales** the image using `nnsResize` to respect `maxSide`.  
4. The raw RGBA buffer is fed to **`webp-wasm`** to produce a WebP binary.  
5. The binary is base64‑encoded and returned as `data:image/webp;base64,...`.

### Example call

```ts
import { toWebpDataUri } from './seed';

async function getMugImageUri() {
  // Option 1: filename in ./img/
  const uri1 = await toWebpDataUri('ceramic-mug.png', 800);

  // Option 2: embedded base64 entry from imageMap
  const uri2 = await toWebpDataUri(imageMap['logo'], 400, 90);

  console.log('WebP URI (file):', uri1);
  console.log('WebP URI (base64):', uri2);
}
```

**Fallback behavior** – If the source file is missing or the base64 string cannot be parsed, the function returns `null`. The seeder will then skip the image field, allowing the product to be created without a picture.

## 7. Adding a New Seed Helper Function  

Follow the existing pattern: a small, pure‑async function that prepares data and calls `apiWithRetry`. Register it in the final `seed()` orchestrator.

### Step‑by‑step template

```ts
/**
 * Example: Seed a collection of “blog posts”.
 *
 * @param posts Array of post definitions.
 */
async function seedBlogPosts(posts: Array<{
  slug: string;
  title: string;
  content: string;
  authorId: string;
}>) {
  for (const post of posts) {
    // Idempotency: try to fetch first; if it exists, skip creation
    try {
      await apiWithRetry(`/v1/blog/${post.slug}`);
      console.log(`✅ Blog post already exists: ${post.slug}`);
    } catch {
      // Not found → create it
      await apiWithRetry('/v1/blog', {
        slug: post.slug,
        title: post.title,
        content: post.content,
        authorId: post.authorId,
      });
      console.log(`🆕 Created blog post: ${post.slug}`);
    }
  }
}
```

### Registering in the orchestrator

```ts
// Near the bottom of seed.ts
async function seed() {
  // …existing steps (categories, products, etc.)

  // 👉 New step: blog posts
  await seedBlogPosts([
    {
      slug: 'welcome-to-fufuni',
      title: 'Welcome to Fufuni',
      content: '...markdown content...',
      authorId: 'admin',
    },
    // more posts …
  ]);

  console.log('🌱 Seed complete!');
}
```

**Best practices**

* Keep the helper **idempotent** (check existence before POST).  
* Use `apiWithRetry` for all network calls.  
* Log concise status messages (`✅`, `🆕`, `⏳`).  
* Keep the function pure – avoid reading/writing files directly; let the orchestrator pass data structures.
