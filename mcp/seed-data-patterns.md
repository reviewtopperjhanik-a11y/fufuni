## Running the Seed Script

The seed script is a standalone TypeScript utility designed to populate a Fufuni instance with realistic demo data, including regions, warehouses, categories, products, and even simulated orders and reviews. It communicates directly with the Hono backend using an Admin API Key.

Before running the script, ensure your Fufuni backend is running and that you have generated a Secret Key (starting with `sk_`).

```bash
# Navigate to the merchant app directory
cd apps/merchant

# Execute the script using npx tsx
# Usage: npx tsx scripts/seed.ts <API_URL> <ADMIN_KEY>
npx tsx scripts/seed.ts http://localhost:8787 sk_live_your_admin_key_here
```

### Script Requirements
- **Initialized Store**: The database must exist. If the store is fresh, ensure you have completed the initial setup via the dashboard or `init.ts` to create the default currencies and countries.
- **Node.js Environment**: The script uses `tsx` to execute TypeScript files directly and requires `node:fs` and `node:path` for image handling.

## Managing the PRODUCT_CATALOG

The `PRODUCT_CATALOG` is the central source of truth for all products created during the seeding process. It is an array of objects where each entry defines localized metadata, category associations, and specific variants.

To add a new product, append an object to the `PRODUCT_CATALOG` constant. Use the following structure:

```typescript
const PRODUCT_CATALOG = [
  // ... existing products
  {
    key: 'tech-backpack', // Unique lookup key for reviews
    file: 'backpack.png', // Default image filename in ./img/ or image_map.ts
    handle: 'pro-tech-backpack', // URL-friendly identifier
    vendor: 'Fufuni',
    categories: ['bags-carry', 'accessories-tech'], // Category handles
    title: {
      'en-US': 'Pro Tech Backpack',
      'fr-FR': 'Sac à dos Pro Tech',
      'zh-CN': '专业科技双肩包',
    },
    description: {
      'en-US': '<p>A premium backpack for developers.</p>',
      'fr-FR': '<p>Un sac à dos premium pour les développeurs.</p>',
      'zh-CN': '<p>专为开发人员打造的高端双肩包。</p>',
    },
    variants: [
      {
        sku: 'BP-TECH-BLK',
        title: 'Matte Black',
        price_cents: 8900, // Price in EUR cents
        weight_g: 1200,
        stock: 25,
        imageFile: 'backpack-black.png', // Optional variant-specific image
      },
    ],
  },
];
```

### Key Rules for Catalog Entries
1. **Integer Cents**: All prices must be in cents (e.g., `8900` for €89.00). The framework never uses floats for currency to avoid rounding errors.
2. **Localization**: `title`, `description`, and `vendor` (within the seeding loop) are stored as JSON strings in the database. Provide at least `en-US`.
3. **Variants**: Every product must have at least one variant. Variants carry the SKU, price, and physical dimensions.

## Adding Seed Categories

Categories are organized hierarchically. The `seedCategories` function handles the creation of the parent category and its children. When adding a new category, you must define its `handle`, localized names, and an optional `parent_id`.

```typescript
async function seedCategories() {
```

The `createCat` helper automatically generates two WebP images for every category: a high-resolution `image_url` (1200px) and a smaller `thumbnail_url` (300px).

## Resilient API Calls with apiWithRetry

Fufuni runs on Cloudflare Workers. When performing bulk operations (like seeding hundreds of variants), you may encounter rate limits or transient network issues. The `apiWithRetry` helper wraps the standard `fetch` call with exponential backoff logic.

It specifically listens for the "Rate limit exceeded" message and parses the "Try again in X seconds" instruction provided by the Fufuni middleware.

```typescript
/**
 * Usage example for a custom seed task
 */
async function syncExternalInventory(sku: string, newStock: number) {
  try {
    // Use apiWithRetry for volatile operations or high-frequency loops
    await apiWithRetry(`/v1/inventory/${encodeURIComponent(sku)}/warehouse-adjust`, {
      warehouse_id: 'wh_12345',
      delta: newStock,
      reason: 'external_sync',
    });
  } catch (error) {
    console.error(`Failed to sync ${sku} after 5 attempts:`, error);
  }
}
```

## Multi-Currency Price Conversion

Fufuni stores prices per currency in a specific `product_variant_prices` table. The seed script calculates USD and GBP prices automatically based on the EUR base price defined in `PRODUCT_CATALOG`.

```typescript
const EUR_TO_USD = 1.14;
const EUR_TO_GBP = 0.86;

/**
 * Ensures currency conversion remains in integer cents
 */
function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}

// Inside seedProducts loop:
if (usdId) {
  await api(`/v1/products/${productId}/variants/${variantId}/prices`, {
    currency_id: usdId,
    price_cents: convertCents(v.price_cents, EUR_TO_USD),
  });
}
```

By using `Math.round()` on the multiplication of cents, the script ensures that $10.99 (1099 cents) converted to another currency doesn't result in fractional cents that SQLite cannot represent as an `INTEGER`.

## Image Processing and Embedding

To ensure the seed script is portable and doesn't require a specific S3 bucket or R2 setup during development, images are converted to WebP and embedded as **Base64 Data URIs**.

The `toWebpDataUri` function performs the following steps:
1. **Source Discovery**: Checks for a local file in `./img/`. If not found, looks up the key in `image_map.ts` (which contains base64 fallbacks).
2. **Decoding**: Uses `pngjs` or `jpeg-js` to get raw RGBA pixels.
3. **Resizing**: If the image exceeds `maxSide`, it uses the `nnsResize` (Nearest-Neighbor) helper to downscale the buffer.
4. **Encoding**: Uses `webp-wasm` to generate a high-efficiency WebP buffer.

```typescript
// Example: Converting a local file to a small thumbnail URI
const thumbUri = await toWebpDataUri('my-product.png', 400, 75);

if (thumbUri) {
  console.log('Generated WebP Data URI length:', thumbUri.length);
  // Result: "data:image/webp;base64,UklGR..."
}
```

## Adding a New Seed Helper

When extending the script with new data types (e.g., Discounts, Gift Cards), follow the established pattern: define the data constant, create an orchestrator function, and update the `seed()` main function.

### Example: Seeding Discounts

```typescript
// 1. Define the data
const SEED_DISCOUNTS = [
  { code: 'WELCOME10', percentage: 10, starts_at: new Date().toISOString() }
];

// 2. Create the helper
async function seedDiscounts() {
  console.log('🎟️ Creating discount codes...');
  for (const d of SEED_DISCOUNTS) {
    await api('/v1/discounts', {
      code: d.code,
      type: 'percentage',
      value: d.percentage,
      is_active: true,
      starts_at: d.starts_at
    });
    console.log(`   └─ ${d.code} (${d.percentage}%)`);
  }
}

// 3. Update the main orchestrator
async function seed() {
  // ... existing steps
  await seedDiscounts();
  console.log('\n✅ Done!');
}
```

This pattern ensures that every step of the seeding process is logged to the console, providing clear feedback to the developer about the progress and any failures. All helpers should be designed to be as **idempotent** as possible, allowing the script to be re-run against an existing database without creating duplicate logic errors.
