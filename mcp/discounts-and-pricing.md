## Discounts and Pricing

### Direct variant price vs regional prices

The `variants` table stores a `price_cents` column, but **never read it directly** in production.  
Fufuni enforces explicit multi-currency pricing via the `variant_prices` table.  
Each row maps a `(variant_id, currency_id)` pair to a `price_cents` value.  
If a price is missing for a requested currency, the framework throws an error rather than falling back to USD.

```typescript
// ❌  Never do this in production
const [variant] = await db.query('SELECT price_cents FROM variants WHERE id = ?', [variantId]);
return variant.price_cents;

// ✅  Always resolve through lib/pricing.ts
import { resolveVariantPrice } from '../lib/pricing';
const price = await resolveVariantPrice(db, variantId, currencyId); // throws if missing
```

The same rule applies to shipping: use `resolveShippingPrice` which reads `shipping_rate_prices`.

### Applying promo codes and discounts

Discounts live in the `discounts` table.  
A discount can be:

| Field | Meaning |
|-------|---------|
| `code` | Optional uppercase coupon string (`"SUMMER20"`). Null = auto-apply. |
| `type` | `"percentage"` or `"fixed_amount"` |
| `value` | Cents when fixed, basis points when percentage |
| `min_purchase_cents` | Cart must reach this subtotal |
| `max_discount_cents` | Caps percentage discounts |
| `usage_limit` | Global redemption ceiling |
| `usage_limit_per_customer` | Per-email ceiling |

Cart and checkout routes call two helpers:

1. `validateDiscount` – enforces time window, usage limits, min-purchase.
2. `calculateDiscount` – returns the **cents** to subtract.

```typescript
import { validateDiscount, calculateDiscount } from '../routes/discounts';

await validateDiscount(db, discount, cartSubtotalCents, customerEmail);

const deduction = calculateDiscount(discount, cartSubtotalCents);
// deduction is guaranteed: 0 ≤ deduction ≤ subtotalCents
```

Example:

```typescript
const discount: Discount = {
  type: 'percentage',
  value: 20,          // 20 %
  max_discount_cents: 500, // $5.00 cap
};

const deduction = calculateDiscount(discount, 3000); // cart subtotal $30.00
// deduction → 500 (capped at $5.00)
```

Usage tracking is persisted in `discount_usage` (inserted after successful payment).

### lib/pricing.ts – single source of truth

All monetary values that reach the customer flow through this module.  
It exports:

| Function | Purpose |
|----------|---------|
| `resolveVariantPrice` | Final variant price in cents for a currency |
| `resolveShippingPrice` | Final shipping rate in cents for a currency |
| `getCurrencyIdForRegion` | UUID of currency bound to a region |
| `getCurrencyCodeForRegion` | ISO-4217 code of currency bound to a region |
| `getCurrencyIdFromCode` | Reverse lookup from `"EUR"` → currency UUID |
| `hasPriceForCurrency` | Boolean check before adding to cart |

Typical checkout price build-up:

```typescript
import {
  resolveVariantPrice,
  resolveShippingPrice,
  getCurrencyIdForRegion,
} from '../lib/pricing';

const currencyId = await getCurrencyIdForRegion(db, regionId);
if (!currencyId) throw ApiError.notFound('Region has no active currency');

let subtotal = 0;
for (const item of cart.items) {
  const price = await resolveVariantPrice(db, item.variant_id, currencyId);
  subtotal += price * item.quantity;
}

let shipping = 0;
if (selectedShippingRateId) {
  shipping = await resolveShippingPrice(db, selectedShippingRateId, currencyId);
}

let discount = 0;
if (appliedDiscount) {
  await validateDiscount(db, appliedDiscount, subtotal, customerEmail);
  discount = calculateDiscount(appliedDiscount, subtotal);
}

const total = subtotal + shipping - discount; // cents
```

No other file in the codebase is allowed to compute prices; this keeps taxation, rounding and currency rules in one place.
