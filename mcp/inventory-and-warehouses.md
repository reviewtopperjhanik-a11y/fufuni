## Inventory and Warehouses Overview
The Fufuni e-commerce framework utilizes a multi-warehouse inventory management system. This system allows for the tracking of stock levels across multiple warehouses, enabling efficient management of inventory.

### Stock Tracking Across Multiple Warehouses
In the Fufuni framework, stock is tracked across multiple warehouses using the `warehouse_inventory` table. This table stores the current stock level for each SKU in each warehouse. The `warehouse_inventory_logs` table tracks every movement of stock in and out of the warehouses, providing a detailed history of inventory changes.

```typescript
// Example of retrieving the current stock level for a SKU across all warehouses
const getStockLevel = async (db: Database, sku: string) => {
  const stockLevels = await db.query<{ on_hand: number; reserved: number }>(
    `SELECT on_hand, reserved FROM warehouse_inventory WHERE sku = ?`,
    [sku]
  );

  const totalOnHand = stockLevels.reduce((sum, level) => sum + level.on_hand, 0);
  const totalReserved = stockLevels.reduce((sum, level) => sum + level.reserved, 0);

  return { totalOnHand, totalReserved };
};
```

## Stock Reservation and Definitive Deduction
The Fufuni framework implements a two-step process for managing inventory: stock reservation and definitive deduction.

### Stock Reservation
Stock reservation occurs when a customer creates an order. At this point, the system reserves the required quantity of the SKU in the warehouse. This ensures that the stock is set aside for the customer's order and prevents other customers from purchasing the same stock.

```typescript
// Example of reserving stock for an order
const reserveStock = async (db: Database, sku: string, quantity: number) => {
  const timestamp = now();
  const result = await db.run(
    `UPDATE warehouse_inventory
     SET reserved = reserved + ?
     WHERE sku = ?
     AND on_hand - reserved >= ?`,
    [quantity, sku, quantity]
  );

  if (result.changes === 0) {
    throw ApiError.insufficientInventory(sku);
  }
};
```

### Definitive Deduction
Definitive deduction occurs when the payment for an order is finalized. At this point, the system deducts the reserved quantity from the warehouse stock level, ensuring that the stock is removed from the available inventory.

```typescript
// Example of deducting stock after payment finalization
const deductStock = async (db: Database, sku: string, quantity: number) => {
  const timestamp = now();
  await db.run(
    `UPDATE warehouse_inventory
     SET on_hand = on_hand - ?
     WHERE sku = ?
     AND reserved >= ?`,
    [quantity, sku, quantity]
  );
};
```

## Error Handling for Insufficient Inventory
In the event of insufficient inventory, the Fufuni framework throws an `ApiError.insufficientInventory()` error. This error is thrown by the handler, not directly by the `lib/inventory.ts` module.

```typescript
// Example of handling insufficient inventory
const handleInsufficientInventory = async (db: Database, sku: string, quantity: number) => {
  try {
    // Attempt to reserve or deduct stock
    await reserveStock(db, sku, quantity);
  } catch (error) {
    if (error instanceof ApiError && error.type === 'insufficientInventory') {
      throw ApiError.insufficientInventory(sku);
    } else {
      throw error;
    }
  }
};
```
