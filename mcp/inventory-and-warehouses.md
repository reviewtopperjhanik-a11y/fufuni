### Stock Tracking Across Multiple Warehouses
In Fufuni, the `warehouse_inventory` table serves as the central repository for tracking actual stock levels. Each entry in this table corresponds to a specific SKU (Stock-Keeping Unit) at a particular warehouse. The `warehouse_inventory_logs` table maintains a record of every stock movement, including the reason for the movement.

If the SKU exists in this table, the system sums up the `on_hand` quantities across all warehouses to obtain the total available stock. If the SKU is not found in `warehouse_inventory`, the system falls back to the legacy `inventory` table.

### Stock Reservation and Definitive Deduction
Stock reservation occurs when a customer places an order, and the system temporarily allocates the required stock for that order. This is done to prevent overselling and ensure that the stock is available when the order is finalized. The `reserved` field in the `warehouse_inventory` table keeps track of the reserved stock.

On the other hand, definitive deduction happens when the order is finalized, and the payment is processed through Stripe. At this stage, the system deducts the sold stock from the `on_hand` quantity in the `warehouse_inventory` table.

Here's an example of how this works:
```typescript
// Initial stock levels
const initialStock = {
  on_hand: 100,
  reserved: 0,
};

// Reserve stock for an order
const reservedStock = {
  on_hand: 100,
  reserved: 20,
};

// Finalize the order and deduct stock
const finalizedStock = {
  on_hand: 80,
  reserved: 0,
};
```
