## Database Schema Reference

The Fufuni e-commerce backend is backed by a single SQLite database that lives inside a Cloudflare Durable Object.  
The DDL is declared once as the constant `SCHEMA` and is applied idempotently by `ensureInitialized()` every time the DO wakes up.  
Because the DO is a singleton, migrations run exactly once per schema change without locks or external tools.

```typescript
export class MerchantDO extends DurableObject {
  private async ensureInitialized(): Promise<void> {
    if (!this._initialized) {
      this.sql.exec(SCHEMA);
      this._initialized = true;
    }
  }
}
```

All tables are created with `IF NOT EXISTS`, so the method is safe to call on every request.  
Foreign-key constraints are enforced by SQLite pragma `foreign_keys = ON` (set globally in the same method).
