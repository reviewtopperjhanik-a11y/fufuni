## How the Durable Object pattern works

Each merchant in Fufuni owns one SQLite database that lives inside a Cloudflare Durable Object (DO).  
The DO class keeps a single multi-line string called `SCHEMA` that contains every `CREATE TABLE` and `CREATE INDEX` statement the framework needs.  
When the DO instance starts (or after a code update) the private method `ensureInitialized()` opens the embedded SQLite instance and executes the whole `SCHEMA` string in one go.  
Because SQLite is transactional, either every object is created or none are; duplicate runs are safe because every statement is idempotent (`IF NOT EXISTS`).  
Migrations are therefore **runtime, not deploy-time**: just change `SCHEMA`, push, and every DO will lazily apply the diff the next time it is awakened.

```typescript
private async ensureInitialized(): Promise<void> {
  if (this.initialized) return;
  const db = this.ctx.storage.sql;
  db.exec(SCHEMA);
  this.initialized = true;
}
```
