## Durable Object SQLite Storage Pattern

Fufuni leverages Cloudflare's Durable Objects with built-in SQLite for persistence. This architecture ensures strong consistency for e-commerce operations like inventory management and order processing. The schema management follows a two-stage initialization pattern within the `MerchantDO` class.

First, a base `SCHEMA` string containing `CREATE TABLE IF NOT EXISTS` statements defines the foundational structure. Second, the `ensureInitialized()` method executes incremental migrations. Unlike many frameworks that store version numbers in metadata, Fufuni tracks migrations within the database itself using a `migrations` table. 

Inside the Durable Object, SQL execution via `this.sql.exec()` is synchronous. However, because the backend Worker communicates with the Durable Object via a binding (typically `c.var.db`), all queries initiated from the Hono API are asynchronous. Fufuni does not use an ORM; developers write raw SQL and type the results using TypeScript interfaces.

```typescript
// Example of interacting with the schema from a Hono route
import { getDb } from '@/lib/db';

app.get('/products/:id', async (c) => {
  const db = getDb(c);
  const productId = c.req.param('id');

  // Queries are raw SQL, results are typed manually
  const products = await db.query<{ title: string; price_cents: number }>(`
    SELECT p.title, v.price_cents 
    FROM products p
    JOIN variants v ON v.product_id = p.id
    WHERE p.id = ? AND v.status = 'active'
    LIMIT 1
  `, [productId]);

  return c.json(products[0]);
});
```

## Maintenance and Constraints

### Indexes and Uniqueness
Fufuni uses indexes strategically for performance and data integrity:
- **`idx_products_handle`**: Unique index on `products(handle)` (Migration 019). SQLite does not allow adding `UNIQUE` via `ALTER TABLE`, so this index enforces the constraint.
- **`idx_orders_viewtoken`**: Unique index ensuring secure guest access to orders.
- **`idx_carts_expires`**: Used by the Durable Object's `cleanupExpiredCarts` method to efficiently release inventory reservations from abandoned sessions.

### Triggers
The schema includes automatic timestamp management for several tables:
- **`trg_saved_carts_updated_at`**: Automatically updates the `updated_at` column whenever a cart is modified.
- **`trg_categories_updated_at`**: Maintains the update trail for the category tree.

```sql
-- Example of Fufuni's trigger pattern
CREATE TRIGGER IF NOT EXISTS trg_store_themes_updated_at
AFTER UPDATE ON store_themes FOR EACH ROW
BEGIN
  UPDATE store_themes SET updated_at = current_timestamp WHERE id = OLD.id;
END;
```
