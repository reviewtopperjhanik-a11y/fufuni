## Durable Object & SQLite Lifecycle

Fufuni leverages the Cloudflare Durable Objects (DO) SQLite storage backend. Unlike traditional relational databases where migrations are managed by external CLI tools, Fufuni manages its schema programmatically within the `MerchantDO` class. 

The lifecycle follows a strict sequence:
1.  **Schema Definition**: A large `SCHEMA` constant contains the base DDL (Data Definition Language).
2.  **Initialization**: The `ensureInitialized()` method is called at the start of every `fetch` or internal query. It splits the `SCHEMA` string and executes statements using `this.sql.exec()`.
3.  **Runtime Migrations**: After the base schema is applied, Fufuni checks the `migrations` table. It iterates through an array of migration objects (containing a name and SQL) and applies them if they haven't been recorded.
4.  **Synchronous Execution**: Within the Durable Object, `this.sql.exec()` is **synchronous**. However, any external communication from the Worker to the DO via `fetch()` remains **asynchronous**.

```typescript
// Example: Accessing SQLite within a MerchantDO method
// Inside apps/merchant/src/do.ts

public getProductWithVariants(handle: string) {
  // ensureInitialized is called internally by query/run helpers
  const product = this.query<any>(
    "SELECT * FROM products WHERE handle = ?", 
    [handle]
  )[0];

  if (!product) return null;

  const variants = this.query<any>(
    "SELECT * FROM variants WHERE product_id = ?", 
    [product.id]
  );

  return { ...product, variants };
}
```

// Example: Verifying an API Key
async function verifyKey(doContext: MerchantDO, rawKey: string) {
  const hash = await doContext.hashKey(rawKey);
  const keyRecord = doContext.query(
    "SELECT role FROM api_keys WHERE key_hash = ?",
