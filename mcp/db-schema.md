## Durable Object Storage and Initialization

The Fufuni framework leverages the **Cloudflare Durable Objects SQLite Storage API**. Unlike traditional Workers KV or external databases, the state is co-located with the Durable Object instance, providing strongly consistent, low-latency SQL operations.

The backend architecture follows a "Synchronous Internal, Asynchronous External" pattern. Inside the `MerchantDO` class, SQL execution via `this.sql.exec()` is synchronous. However, when the Worker communicates with the Durable Object (via the `MERCHANT` binding), the calls are asynchronous RPC (Remote Procedure Call) operations.

### Schema Persistence and Migration Strategy

Fufuni manages schema evolution through an internal `ensureInitialized()` method. This method runs automatically on every request to the Durable Object.

1.  **Base Schema**: The `SCHEMA` constant contains the "Level 0" DDL. It uses `CREATE TABLE IF NOT EXISTS` to ensure the foundation exists without wiping data.
2.  **Migration Tracking**: All structural changes are tracked in a `migrations` table within the SQLite database itself. Fufuni does **not** use `state.storage.put()` for versioning.
3.  **Runtime Application**: The `ensureInitialized()` method iterates through an array of migration objects. It checks the `migrations` table; if a migration name is missing, it executes the SQL and records the success.

```typescript
// Example of how the Durable Object handles internal SQL execution
// apps/merchant/src/do.ts (simplified snippet)

private ensureInitialized(): void {
  if (this.initialized) return;

  // 1. Run core schema
  const statements = SCHEMA.split(';').filter(s => s.trim().length > 0);
  for (const stmt of statements) {
    this.sql.exec(stmt);
  }

  // 2. Check applied migrations
  const applied = new Set(
    this.sql.exec('SELECT name FROM migrations')
      .toArray()
      .map((r: any) => r.name)
  );

  // 3. Define and apply new migrations (e.g., Migration 034)
  const pending = [
    {
      name: '034_enrich_refunds',
      sql: `ALTER TABLE refunds ADD COLUMN reason TEXT CHECK(reason IN ('duplicate', 'fraudulent', 'requested_by_customer'));`
    }
  ];

  for (const m of pending) {
    if (!applied.has(m.name)) {
      this.sql.exec(m.sql);
      this.sql.exec('INSERT INTO migrations (name) VALUES (?)', m.name);
    }
  }
  this.initialized = true;
}
```

## Practical Database Operations

When contributing to the Fufuni backend, you do not interact with the Durable Object directly. Instead, you use the `getDb()` utility which proxies requests via RPC.

### Example: Fetching a Product with Variants

This example demonstrates how to perform a joined query in a Hono route using the standard database proxy.

```typescript
// apps/merchant/src/routes/products.ts
import { Hono } from 'hono';
import { getDb } from '../utils/db';

const app = new Hono();

app.get('/:handle', async (c) => {
  const db = getDb(c.env.MERCHANT);
  const handle = c.req.param('handle');

  const sql = `
    SELECT 
      p.*,
      json_group_array(
        json_object(
          'id', v.id,
          'sku', v.sku,
          'price', v.price_cents
        )
      ) as variants
    FROM products p
    JOIN variants v ON v.product_id = p.id
    WHERE p.handle = ? AND p.status = 'active'
    GROUP BY p.id
  `;

  const results = await db.query(sql, [handle]);
  
  if (results.length === 0) {
    return c.json({ error: 'Not found' }, 404);
  }

  return c.json(results[0]);
});
```

### Example: Updating Stock with Inventory Logs

When modifying inventory, always perform the update and the log entry to ensure an audit trail exists.

```typescript
// apps/merchant/src/services/inventory.ts

export async function restock(db: any, sku: string, warehouseId: string, amount: number) {
  // SQLite in DO supports multiple statements via exec, 
  // but via RPC we typically run them sequentially.
  
  await db.run(
    `UPDATE warehouse_inventory 
     SET on_hand = on_hand + ?, updated_at = datetime('now') 
     WHERE sku = ? AND warehouse_id = ?`,
    [amount, sku, warehouseId]
  );

  await db.run(
    `INSERT INTO warehouse_inventory_logs (id, sku, warehouse_id, delta, reason)
     VALUES (?, ?, ?, ?, 'restock')`,
    [crypto.randomUUID(), sku, warehouseId, amount]
  );
}
```
