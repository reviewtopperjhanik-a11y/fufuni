# Database Schema Reference

Durable Objects are Cloudflare‑native entities that provide isolated, stateful storage per key (e.g. a merchant ID).  
`SCHEMA` contains the full DDL for every SQLite table that the Durable Object owns.  
During the first request, `ensureInitialized()` runs the DDL against the in‑memory SQLite database and applies any pending migrations (recorded in the `migrations` table). This guarantees that every instance of the Durable Object has a consistent schema before any API logic runs.
