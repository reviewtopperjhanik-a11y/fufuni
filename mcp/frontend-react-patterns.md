## Frontend React Patterns

### 1. React Router Setup

The application uses React Router for client-side routing. Routes are declared in `apps/client/src/app.tsx`. 

```typescript
// apps/client/src/app.tsx
import { Route, Routes } from "react-router-dom";

// ...

return (
  <Suspense fallback={<SiteLoading />}>
    <Routes>
      {/* Routes declaration */}
    </Routes>
  </Suspense>
);
```

Protected routes use the `AuthenticationGuard` component:

```typescript
// apps/client/src/app.tsx
import { AuthenticationGuard } from "./authentication";

// ...

<Route
  element={<AuthenticationGuard component={ApiPage} />}
  path="/api"
/>
```

### 2. Adding a New Page

To add a new page, follow these steps:

1. **Create the page component**: Create a new file in `apps/client/src/pages/`, e.g., `NewPage.tsx`.

```typescript
// apps/client/src/pages/NewPage.tsx
import React from "react";

const NewPage = () => {
  return <div>New Page</div>;
};

export default NewPage;
```

2. **Add the page to the router**: Update `apps/client/src/app.tsx` to include the new route.

```typescript
// apps/client/src/app.tsx
import NewPage from "@/pages/NewPage";

// ...

<Route element={<NewPage />} path="/new-page" />
```

3. **Add a nav item (optional)**: If you want to add a navigation item to the navbar, update `apps/client/src/config/site.ts`.

```typescript
// apps/client/src/config/site.ts
import i18next from "../i18n";

export const siteConfig = () => ({
  // ...
  navItems: [
    // ...
    {
      label: i18next.t("new-page"),
      href: "/new-page",
      permissions: [], // or specify permissions if needed
    },
  ],
  // ...
});
```

### 3. Navbar Auto-Showing/Hiding Items based on Auth0 Permissions

The navbar uses `AuthenticationGuardWithPermission` to show/hide items based on Auth0 permissions.

```typescript
// apps/client/src/components/navbar.tsx
import { AuthenticationGuardWithPermission } from "@/authentication";

// ...

<AuthenticationGuardWithPermission permission="admin:store">
  <li>
    <RouterLink to="/admin/new-page">New Page</RouterLink>
  </li>
</AuthenticationGuardWithPermission>
```

The navbar reads `siteConfig().navItems` and shows/hides items based on the `permissions` array.

### 4. HeroUI v3

The application uses HeroUI v3. Key components include:

* **Button**: `<Button>Click me</Button>`
* **Card**: `<Card><Card.Header>Title</Card.Header><Card.Body>Content</Card.Body></Card>`
* **Modal**: `<Modal><Modal.Trigger>Open Modal</Modal.Trigger><Modal.Content>Content</Modal.Content></Modal>`
* **Table**: `<Table><Table.Header>...</Table.Header><Table.Body>...</Table.Body></Table>`
* **Form**: `<Form><Form.Field>...</Form.Field></Form>`

Use the compound component pattern:

```typescript
// Example usage of Dropdown component
import { Dropdown } from "@heroui/react";

// ...

<Dropdown>
  <Dropdown.Trigger>Trigger</Dropdown.Trigger>
  <Dropdown.Popover>
    <Dropdown.Menu>Menu content</Dropdown.Menu>
  </Dropdown.Popover>
</Dropdown>
```

### 5. ThemeSwitch

The `ThemeSwitch` component allows users to switch between light/dark and custom themes. It is already included in the navbar.

```typescript

// ...

<ThemeSwitch />
```

### 6. Feature Folder Structure and Hook Placement Conventions

The application follows a feature-based folder structure:

* `apps/client/src/features/<feature-name>/components/`
* `apps/client/src/features/<feature-name>/hooks/`
* `apps/client/src/features/<feature-name>/index.ts`

New React hooks go in `apps/client/src/hooks/` if they are page-agnostic, or in the feature folder if feature-specific.

### 7. Worked Example: Adding a "Product Tags" Admin Page

**Step 1: Create the page component**

Create a new file in `apps/client/src/pages/admin/`, e.g., `ProductTagsPage.tsx`.

```typescript
// apps/client/src/pages/admin/ProductTagsPage.tsx
import React from "react";

const ProductTagsPage = () => {
  return <div>Product Tags</div>;
};

export default ProductTagsPage;
```

**Step 2: Add the page to the router**

Update `apps/client/src/app.tsx` to include the new route.

```typescript
// apps/client/src/app.tsx
import ProductTagsPage from "@/pages/admin/ProductTagsPage";

// ...

<Route
  element={
    <AuthenticationGuardWithPermission permission="admin:store">
      <ProductTagsPage />
    </AuthenticationGuardWithPermission>
  }
  path="/admin/product-tags"
/>
```

**Step 3: Add a nav item**

Update `apps/client/src/config/site.ts`.

```typescript
// apps/client/src/config/site.ts
import i18next from "../i18n";

export const siteConfig = () => ({
  // ...
  navItems: [
    // ...
    {
      label: i18next.t("product-tags"),
      href: "/admin/product-tags",
      permissions: ["admin:store"],
    },
  ],
  // ...
});
```

The navbar will automatically show/hide the "Product Tags" item based on the user's permissions.
