## The Admin CRUD Pattern

Fufuni follows a strict three-part pattern for all administrative interfaces. This architecture ensures consistency across the dashboard, reduces boilerplate, and centralizes state management for listing, searching, creating, and editing resources.

1.  **`useAdminCrud<T>()` Hook**: Manages the API lifecycle (TanStack Query), modal states, and form validation logic.
2.  **`AdminCrudLayout` Component**: The structural shell that renders the page header, the "Add" button, the data table (using TanStack Table), and the management modal.
3.  **`RowActions` Component**: A standardized utility rendered in the final column of the table to trigger edit and delete operations.

### Pattern Composition Example

```typescript
import { AdminCrudLayout } from "@/shared/ui/admin/admin-crud-layout";
import { RowActions } from "@/shared/ui/admin/row-actions";
import { useAdminCrud } from "@/hooks/use-admin-crud";
import { tagSchema, type Tag } from "@/shared/schemas/tag";

export function TagsAdminPage() {
  const { 
    items, 
    isLoading, 
    create, 
    update, 
    remove, 
    selectedItem, 
    isModalOpen, 
    openModal, 
    closeModal 
  } = useAdminCrud<Tag>({
    queryKey: ["product-tags"],
    listUrl: "/api/v1/admin/tags",
    createUrl: "/api/v1/admin/tags",
    updateUrl: (id) => `/api/v1/admin/tags/${id}`,
    deleteUrl: (id) => `/api/v1/admin/tags/${id}`,
    zodSchema: tagSchema,
  });

  const columns = [
    { accessorKey: "name", header: "Tag Name" },
    { 
      id: "actions",
      cell: ({ row }) => (
        <RowActions 
          onEdit={() => openModal(row.original)} 
          onDelete={() => remove(row.original.id)}
          deleteConfirmMessage="Are you sure you want to delete this tag?"
        />
      )
    }
  ];

  return (
    <AdminCrudLayout
      title="Product Tags"
      addLabel="Add Tag"
      columns={columns}
      data={items}
      isLoading={isLoading}
      onAdd={() => openModal()}
      renderModal={
        <TagModal 
          isOpen={isModalOpen} 
          onClose={closeModal} 
          initialData={selectedItem}
          onSubmit={selectedItem ? update : create}
        />
      }
    />
  );
}
```

## useAdminCrud() Hook

The `useAdminCrud` hook is the engine of the Fufuni admin panel. It abstracts TanStack Query for data fetching and mutations, while managing the UI state for the creation/editing modal.

### Type Parameters
- **`T`**: The entity type (e.g., `Product`, `Category`). It must extend `HasIdAndStatus` (containing at least an `id: string`).

### Options Object
| Field | Type | Description |
| :--- | :--- | :--- |
| `queryKey` | `string[]` | The TanStack Query key for caching. |
| `listUrl` | `string` | API endpoint for the GET list request. |
| `createUrl` | `string` | API endpoint for the POST create request. |
| `updateUrl` | `(id: string) => string` | Function returning the endpoint for PUT/PATCH. |
| `deleteUrl` | `(id: string) => string` | Function returning the endpoint for DELETE. |
| `zodSchema` | `ZodSchema` | The schema used for client-side validation before submission. |

### Return Values
- **`items`**: Array of `T` fetched from the backend.
- **`isLoading`**: Boolean indicating the initial fetch status.
- **`create(data)`**: Function to trigger the creation mutation.
- **`update(data)`**: Function to trigger the update mutation.
- **`remove(id)`**: Function to trigger the deletion.
- **`selectedItem`**: The item currently being edited (null if creating).
- **`isModalOpen`**: Boolean controlling the visibility of the form modal.
- **`openModal(item?)`**: Opens the modal. If an item is passed, sets `selectedItem` (Edit Mode).
- **`closeModal()`**: Closes the modal and resets `selectedItem`.

```typescript
// Example usage with explicit typing
const crud = useAdminCrud<Country>({
  queryKey: ["admin", "countries"],
  listUrl: "/api/v1/countries",
  createUrl: "/api/v1/countries",
  updateUrl: (id) => `/api/v1/countries/${id}`,
  deleteUrl: (id) => `/api/v1/countries/${id}`,
  zodSchema: countrySchema,
});
```

## AdminCrudLayout

The `AdminCrudLayout` component handles the visual presentation of the resource list. It integrates with HeroUI components and provides a standard header with a search bar and an "Add" button.

### Component Props
| Prop | Type | Description |
| :--- | :--- | :--- |
| `title` | `string` | The h1 title of the page. |
| `addLabel` | `string` | Text for the primary "Add" button. |
| `columns` | `ColumnDef<T>[]` | TanStack Table column definitions. |
| `data` | `T[]` | The array of items to display. |
| `isLoading` | `boolean` | Shows a loading skeleton or spinner if true. |
| `renderModal` | `ReactNode` | The JSX for the CRUD modal. |
| `onAdd` | `() => void` | Callback when the "Add" button is clicked. |

### Column Definition Format
Columns are defined using TanStack Table's `ColumnDef`. For the actions column, always use the `RowActions` component.

```typescript
import { createColumnHelper } from "@tanstack/react-table";

const columnHelper = createColumnHelper<Product>();

const columns = [
  columnHelper.accessor("sku", {
    header: "SKU",
    cell: (info) => <span className="font-mono">{info.getValue()}</span>,
  }),
  columnHelper.accessor("name", {
    header: "Product Name",
  }),
  columnHelper.display({
    id: "actions",
    cell: (props) => (
      <RowActions 
        onEdit={() => openModal(props.row.original)}
        onDelete={() => remove(props.row.original.id)}
      />
    ),
  }),
];
```

## RowActions and Deletion

`RowActions` provides a standardized interface for row-level operations. It encapsulates two icon buttons: an edit button and a delete button with a built-in confirmation Popover.

### Props
- **`onEdit`**: Triggered when the edit icon is clicked. Usually wires to `openModal(item)`.
- **`onDelete`**: Triggered only **after** the user confirms deletion in the popover.
- **`deleteConfirmMessage`**: (Optional) Custom text for the confirmation prompt.

```tsx
// Typical wiring in a table cell
<RowActions
  onEdit={() => openModal(row.original)}
  onDelete={() => handleDelete(row.original.id)}
  deleteConfirmMessage="This action cannot be undone. Delete this user?"
/>
```

The confirmation logic uses a **HeroUI Popover** internally. This eliminates the need for external global dialogs or alert boxes, keeping the interaction contextual to the row being modified.

## Modal and Form Pattern

Fufuni uses a single modal component for both "Create" and "Edit" operations. The distinction is made by the presence of `selectedItem`.

### Form Logic with React Hook Form
The form inside the modal should use `react-hook-form` paired with the same Zod schema passed to the hook.

```tsx
interface TagModalProps {
  isOpen: boolean;
  onClose: () => void;
  initialData: Tag | null;
  onSubmit: (data: any) => Promise<void>;
}

export function TagModal({ isOpen, onClose, initialData, onSubmit }: TagModalProps) {
  const { register, handleSubmit, reset, formState: { errors } } = useForm({
    resolver: zodResolver(tagSchema),
    values: initialData ?? { name: "", slug: "" }, // Reset form when initialData changes
  });

  const handleProcess = async (data: any) => {
    await onSubmit(data);
    onClose();
    reset();
  };

  return (
    <Modal isOpen={isOpen} onClose={onClose}>
      <Modal.Content>
        <form onSubmit={handleSubmit(handleProcess)}>
          <Modal.Header>{initialData ? "Edit Tag" : "Create Tag"}</Modal.Header>
          <Modal.Body>
            <TextField>
              <Label>Name</Label>
              <Input {...register("name")} isInvalid={!!errors.name} />
              {errors.name && <p className="text-danger">{errors.name.message}</p>}
            </TextField>
          </Modal.Body>
          <Modal.Footer>
            <Button variant="ghost" onPress={onClose}>Cancel</Button>
            <Button type="submit" variant="primary">Save</Button>
          </Modal.Footer>
        </form>
      </Modal.Content>
    </Modal>
  );
}
```

## Route Protection

All admin pages must be protected using the `AuthenticationGuardWithPermission` component. This should be applied at the routing level in `app.tsx`, not inside the page component itself.

The required permission for general store administration is `admin:store`.

```typescript
// apps/client/src/app.tsx
import { AuthenticationGuardWithPermission } from "@/shared/ui/auth-guard";

const router = createBrowserRouter([
  {
    path: "/admin",
    element: (
      <AuthenticationGuardWithPermission permission="admin:store">
        <AdminLayout />
      </AuthenticationGuardWithPermission>
    ),
    children: [
      { path: "tags", element: <TagsAdminPage /> },
      // ... other admin routes
    ],
  },
]);
```

/**

import { useAdminCrud } from "@/hooks/use-admin-crud";
import { AdminCrudLayout } from "@/shared/ui/admin/admin-crud-layout";
import { RowActions } from "@/shared/ui/admin/row-actions";
import { tagSchema, type Tag } from "@/shared/schemas/tag";
import { TagModal } from "./components/tag-modal"; // Implementation shown in previous section

export default function ProductTagsPage() {

  const {
    items,
