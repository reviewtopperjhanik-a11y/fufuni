## Product Reviews & Moderation Reference
The Fufuni e-commerce framework handles product reviews through a two-step process: review submission and admin moderation. This reference outlines the review submission flow, verified purchase requirement, admin moderation, cursor-based pagination, and inline JWT extraction.

### Review Submission Flow
The review submission flow consists of the following steps:
1. **Eligibility Check**: The customer checks their eligibility to submit a review for a product using the `GET /v1/products/:id/reviews/eligibility` endpoint. This endpoint returns `{ eligible: boolean, reason? }`.
2. **Submit Review**: If the customer is eligible, they can submit a review for the product. The review is initially set to "pending" and is not shown publicly.
3. **Pending Review**: The review remains in "pending" status until an admin approves or rejects it.
4. **Approved Review**: Once an admin approves the review, it is set to "approved" and becomes publicly visible.

### Verified Purchase Requirement
To submit a review, a customer must have a delivered order containing the reviewed product. This is known as the "verified purchase" requirement. The eligibility endpoint checks for this requirement and returns an error if the customer does not meet it.

### Admin Moderation
Admins can moderate reviews using the admin reviews page. The page allows admins to:
* Approve or reject reviews
* View AI recommendations for reviews (requires `ai:api` Auth0 permission)
* Batch moderate reviews

### Cursor-Based Pagination
Reviews use cursor-based pagination by `created_at` ISO string, not by ID. To fetch the next page of reviews, pass the `cursor` query parameter with the value of the last review's `created_at` timestamp.

### Inline JWT Extraction
The `reviews.ts` file uses inline JWT extraction (manual token decode) because Hono sub-app middleware does not propagate the prefix correctly in this context. This is necessary to ensure proper authentication and authorization for review submissions.

const replyRoute = createRoute({
  method: 'post',
  path: '/v1/products/:productId/reviews/:reviewId/reply',
  tags: ['Reviews'],
  summary: 'Add a reply from the merchant to a review',
  request: {
    params: z.object({ productId: z.string().uuid(), reviewId: z.string().uuid() }),
    body: z.object({ reply: z.string() }),
  },
  responses: {
    201: {
      description: 'Reply added successfully',
    },
  },
});

// Use the adminOnly middleware to restrict access to admins only
replyRoute.use(adminOnly);

// Handle the request
replyRoute.post(async (c) => {
  const { productId, reviewId } = c.req.valid('param');
  const { reply } = c.req.valid('body');
  const db = getDb(c.var.db);

  // Update the review with the merchant reply
  await db.run(`UPDATE product_reviews SET merchant_reply = ? WHERE id = ?`, [reply, reviewId]);

  return c.json(201, { message: 'Reply added successfully' });
});
