## Client-Side PDF Architecture

Fufuni adopts a "Zero-Server PDF" architecture. Instead of generating invoices on Cloudflare Workers—which would consume CPU time and require bundling heavy libraries like `puppeteer` or `canvas`—the framework generates PDFs entirely within the user's browser.

This approach offers three primary benefits:
1.  **Privacy**: Sensitive customer data and order details never leave the browser to hit a separate generation microservice.
2.  **Scalability**: The compute cost of rendering documents is offloaded to the client, keeping Worker execution time (and costs) minimal.
3.  **Responsiveness**: Documents are generated instantly without network latency once the order data is available in the React state.

The framework utilizes `jsPDF` for basic document layout and `jspdf-autotable` for complex itemized lists.

```typescript
// Example: Basic integration in a React 19 component
import React from 'react';
import { Button } from '@heroui/react';
import { downloadInvoicePdf, OrderForPdf } from '@/utils/invoice-pdf';

export const OrderActions = ({ order }: { order: OrderForPdf }) => {
  const handleDownload = () => {
    // Triggers client-side generation and immediate download
    downloadInvoicePdf(order, "Fufuni Electronics", "en-US");
  };

  return (
    <Button onPress={handleDownload} color="primary" variant="flat">
      Download Invoice (PDF)
    </Button>
  );
};
```

## Currency and Locale Formatting

The Fufuni framework stores all monetary values as **integers in cents** (e.g., $10.00 is stored as `1000`) to avoid floating-point math errors. The `utils/currency.ts` module provides the standard logic for converting these integers into strings for the PDF.

The formatting logic uses the native `Intl.NumberFormat` API, which is highly optimized in modern browsers. It supports ISO 4217 codes and handles currencies with zero decimals (like JPY) or three decimals (like KWD) automatically.

### Supported Currency Mapping
While `Intl` handles many codes, the framework explicitly maps common symbols for the PDF generator:
- **USD**: $
- **EUR**: €
- **GBP**: £
- **JPY/CNY**: ¥
- **CAD/AUD**: C$/A$

```typescript
import { formatMoney, formatMoneyFixed } from '@/utils/currency';

/**
 * Demonstrating locale-aware cent conversion
 */
const priceCents = 2999; // Represents 29.99

// Standard localization based on browser settings
console.log(formatMoney(priceCents, "EUR", "fr-FR")); // Output: "29,99 €"

// Forced decimals for accounting (Admin view)
console.log(formatMoneyFixed(priceCents, "USD", 2, "en-US")); // Output: "$29.99"

// Handling zero-decimal currencies
const yenCents = 50000; // Represents 50000 Yen
console.log(formatMoney(yenCents, "JPY", "ja-JP")); // Output: "￥50,000"
```

## Manual vs. AutoTable Generation

Fufuni provides two distinct approaches to PDF generation depending on the required level of customization.

### Manual Layout (`generateInvoice`)
Located in `lib/invoice-generator.ts`, this function uses the low-level `jsPDF` API. It allows for pixel-perfect positioning of headers, store addresses, and custom branding. It is ideal for highly stylized invoices but requires manual calculation of `yPosition` to prevent overlapping text.

```typescript
import { generateInvoice } from '@/lib/invoice-generator';

const data = {
  orderNumber: 'ORD-2026-X',
  orderDate: new Date().toISOString(),
  items: [
    { product_title: 'Mechanical Keyboard', quantity: 1, unit_price_cents: 12000, total_price_cents: 12000, currency: 'USD' }
  ],
  subtotal_cents: 12000,
  tax_cents: 1200,
  shipping_cents: 0,
  total_cents: 13200,
  currency: 'USD',
  customerName: 'Alice Smith',
  customerEmail: 'alice@fufuni.dev',
  storeAddress: 'Fufuni HQ, 55 Cloud Lane, SF',
};

// Generates A4 PDF and triggers browser download save dialog
generateInvoice(data);
```

### AutoTable Implementation (`downloadInvoicePdf`)
Located in `utils/invoice-pdf.ts`, this uses `jspdf-autotable`. It is the preferred method for orders with a large number of items. It handles page breaks automatically—ensuring the table header repeats on new pages and text doesn't bleed off the bottom margin.

```typescript
import { downloadInvoicePdf, OrderForPdf } from '@/utils/invoice-pdf';

const order: OrderForPdf = {
  number: "1001",
  created_at: "2026-03-15T10:00:00Z",
  currency: "EUR",
  email: "customer@example.com",
  items: [
    { title: "Standard Plan", qty: 1, unit_price_cents: 4900 },
    { title: "Extra Seat", qty: 2, unit_price_cents: 1000 }
  ],
  subtotal_cents: 6900,
  shipping_cents: 0,
  tax_cents: 1380,
  total_cents: 8280,
  taxes: [{ name: "VAT 20%", amount_cents: 1380, tax_inclusive: false }]
};

// Generates a structured table with blue headers (Tailwind blue-600)
downloadInvoicePdf(order, "Fufuni Pro", "fr-FR");
```

## Payload Delivery Mechanisms

Once the PDF document is generated in the browser's memory, Fufuni uses two main delivery patterns to provide the file to the user.

### Triggering File Downloads
The `doc.save('filename.pdf')` method is used for standard downloads. It generates a temporary blob internally and triggers the browser's download manager.

### Previewing via Blob URLs
For "View Invoice" buttons, the framework uses `doc.output("bloburi")`. This generates a unique `blob:` URL pointing to the PDF data in the browser's memory and opens it in a new browser tab using `window.open()`. This avoids the friction of downloading a file just to view it.

```typescript
/**
 * Logic inside utils/invoice-pdf.ts for previewing
 */
export function openInvoicePdf(order: OrderForPdf): void {
  const doc = new jsPDF();
  
  // ... (add content to doc) ...

  // Generate a Blob URI representing the PDF
  const blobUri = doc.output("bloburi");
  
  // Open the URI in a new tab
  // This is handled by the browser's native PDF viewer
  window.open(blobUri);
}
```

## Data Models for Invoicing

Developers should adhere to the following interface when preparing data for the PDF generators. Note that addresses are passed as pre-formatted strings to allow the PDF generator to use `splitTextToSize` for automatic word wrapping.

```typescript
interface OrderItem {
  product_title: string;
  quantity: number;
  unit_price_cents: number;
  total_price_cents: number;
  currency: string;
}

interface InvoiceData {
  orderNumber: string;
  orderDate: string; // ISO String
  items: OrderItem[];
  subtotal_cents: number;
  tax_cents: number;
  shipping_cents: number;
  total_cents: number;
  currency: string;
  customerName: string;
  customerEmail: string;
  shippingAddress?: string; // Formatted multi-line string
  billingAddress?: string;
  storeAddress?: string;
}
```

When extending the PDF generator, always use the `mm` (millimeter) unit for `jsPDF` initialization to ensure consistency across different screen resolutions and printer settings. For font styling, Fufuni sticks to `helvetica` (built-in to PDF) to avoid the overhead of embedding custom font files into the document payload.
