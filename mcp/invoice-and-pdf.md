## Invoice and PDF Generation

Fufuni generates invoices entirely in the browser.  
No Worker, no Durable Object, no network round-trip — the React front-end receives the order JSON from the existing `/api/orders/:id` endpoint and turns it into a downloadable PDF using jsPDF.  
This keeps sensitive customer data on the device, removes load from the edge, and works offline once the page is cached.

### 100 % client-side architecture

The flow is deliberately thin:

1. User clicks “Download invoice” on the order detail page.  
2. React fetches the order (already cached by React-Query).  
3. One of the two helper modules below is called:  
   - `generateInvoice` (legacy, manual layout)  
   - `downloadInvoicePdf` (recommended, uses `jspdf-autotable`)  
4. jsPDF builds the document in memory.  
5. `doc.save()` triggers the browser download; no bytes leave the client.

```typescript
// apps/client/src/lib/invoice-generator.ts  (legacy)
import jsPDF from "jspdf";

export function generateInvoice(data: InvoiceData): void {
  const doc = new jsPDF({ unit: "mm", format: "a4" });

  doc.text(`Invoice ${data.orderNumber}`, 20, 20);
  /* …manual line-by-line layout… */

  doc.save(`invoice-${data.orderNumber}.pdf`); // <-- browser download
}
```

```typescript
// apps/client/src/utils/invoice-pdf.ts  (current)
import jsPDF from "jspdf";
import autoTable from "jspdf-autotable";

export function downloadInvoicePdf(
  order: OrderForPdf,
  storeName = "Fufuni Store",
  locale = "en-US"
): void {
  const doc = new jsPDF();
  autoTable(doc, { /* … */ });
  doc.save(`invoice-${order.number}.pdf`);
}
```

Both helpers are synchronous and run in the main thread; for very large carts the component can wrap the call in `startTransition` to keep the UI responsive.

### Currency formatting with locale awareness

Prices are stored in the database as integers in the smallest currency unit (cents).  
The cart already knows the shopper’s locale (`navigator.language` or the value saved in `localStorage`) and the order currency (ISO-4217 code returned by the API).  
The utility module `utils/currency.ts` turns the raw cents into a localized string respecting symbol position, decimal rules and rounding.

```typescript
// apps/client/src/utils/currency.ts
export function formatMoney(
  cents: number,
  currency: string = "",
  locale?: string
): string {
  if (!currency) {
    return new Intl.NumberFormat(locale ?? navigator.language, {
      minimumFractionDigits: 2,
      maximumFractionDigits: 2,
    }).format(cents / 100);
  }

  return new Intl.NumberFormat(locale ?? navigator.language, {
    style: "currency",
    currency: currency.toUpperCase(),
    currencyDisplay: "narrowSymbol",
  }).format(cents / 100);
}
```

Usage inside the PDF helper:

```typescript
const unit = formatMoney(item.unit_price_cents, order.currency, locale);
const total = formatMoney(item.qty * item.unit_price_cents, order.currency, locale);
```

Edge cases handled automatically by `Intl.NumberFormat`:
- JPY has 0 decimals — `formatMoney(9800, "JPY")` → `"¥9,800"`  
- EUR in `fr-FR` uses comma — `29,99 €`  
- USD in `en-US` uses dot — `$29.99`  

### Delivering the PDF payload

jsPDF can produce three output types:
- `string` (base-64)  
- `Uint8Array` (raw bytes)  
- `Blob` (convenient for browsers)

The download helpers use the Blob route because it avoids base-64 bloat and integrates cleanly with the `download` attribute.

```typescript
const blob = doc.output("blob");            // application/pdf Blob
const url = URL.createObjectURL(blob);      // blob:https://shop.example/4a3f…
const a = document.createElement("a");
a.href = url;
a.download = `invoice-${order.number}.pdf`;
a.click();
URL.revokeObjectURL(url);                   // free memory
```

The same Blob URL can also be reused to open the PDF in a new tab:

```typescript
export function openInvoicePdf(order: OrderForPdf): void {
  const doc = new jsPDF();
  /* …build document… */
  window.open(doc.output("bloburi"));       // about:blank replaced by PDF
}
```

Memory is released immediately after the download or tab is closed; no leak occurs even if the user generates dozens of invoices.

### Minimal integration example

```tsx
// apps/client/src/components/OrderDetail.tsx
import { downloadInvoicePdf } from "@/utils/invoice-pdf";
import { formatMoney } from "@/utils/currency";

export function OrderDetail({ order }: { order: OrderForPdf }) {
  const handleDownload = () => {
    downloadInvoicePdf(order, "Fufuni Shop", navigator.language);
  };

  return (
    <section>
      <h2>Order #{order.number}</h2>
      <p>Total {formatMoney(order.total_cents, order.currency)}</p>
      <Button onPress={handleDownload}>Download invoice</Button>
    </section>
  );
}
```

No extra environment variables, no API keys, no serverless function—just a single button that turns JSON into a ready-to-print A4 PDF.
