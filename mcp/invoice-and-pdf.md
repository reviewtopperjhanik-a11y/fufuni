## PDF Generation Architecture

Fufuni generates invoices entirely on the client side to minimize server load and ensure privacy. The system utilizes **jsPDF** for document orchestration and **jsPDF-AutoTable** for rendering complex item lists. There is no server-side PDF rendering engine (like Puppeteer or Chromium); the browser's CPU handles the layout and binary blob creation.

### The generateInvoice Function

The core logic resides in `apps/client/src/lib/invoice-generator.ts`. The function returns a `jsPDF` instance, allowing the caller to decide whether to trigger a download or display a preview.

```typescript

import { TFunction } from "i18next";
import { Order, StoreInfo } from "@/types";

/**
 * Generates a PDF document instance for an order.
 * @param order - The order data from the API
 * @param storeInfo - Store settings (name, address, logo)
 * @param t - i18next translation function
 */
export function generateInvoice(
  order: Order,
  storeInfo: StoreInfo,
  t: TFunction
): jsPDF {
  const doc = new jsPDF({ unit: "mm", format: "a4" });
  
  // Implementation uses doc.text() and autoTable()
  // All labels use t('invoice-key-name')
  
  return doc;
}

// Usage in a React component
const handleDownload = () => {
  const doc = generateInvoice(order, store, t);
  doc.save(`invoice-${order.number}.pdf`);

const handlePreview = () => {
  const doc = generateInvoice(order, store, t);
  window.open(doc.output("bloburi"), "_blank");
};
```

## Invoice Content and Layout

The invoice is structured into standard sections to comply with global e-commerce expectations. The generation sequence follows this order:

1.  **Store Header**: Displays the store logo (base64) if available. If missing, the store name is rendered as bold text. Includes the store's physical address.
2.  **Order Metadata**: Invoice/Order number and the localized creation date.
3.  **Customer Info**: Billing and shipping addresses, customer email, and phone number.
4.  **Itemized Table**: 
    *   Columns: Product title, Quantity, Unit Price, Tax Rate/Amount (per line), and Line Total.
5.  **Totals Section**:
    *   Subtotal (excl. tax)
    *   Shipping costs
    *   Detailed tax breakdown (VAT/Sales Tax per rate)
    *   **Grand Total** (bold)
6.  **Footer**: Payment method used and a thank-you note.

## Currency and Formatting

All monetary values in Fufuni are stored as **integers in the smallest unit (cents)** to avoid floating-point errors. The `formatCurrency` utility handles the conversion for display.

### formatCurrency Signature
The utility in `apps/client/src/utils/currency.ts` divides the input by 100 before passing it to the `Intl.NumberFormat` API.

```typescript
/**
 * Formats cents to a localized currency string.
 * @param amountCents - Integer value (e.g., 2999)
 * @param currency - ISO 4217 code (e.g., "EUR")
 * @param locale - BCP 47 tag (e.g., "fr-FR")
 */
export function formatCurrency(
  amountCents: number,
  currency: string,
  locale: string = "en-US"
): string {
  const amount = amountCents / 100;
  
  return new Intl.NumberFormat(locale, {
    style: "currency",
    currency: currency.toUpperCase(),
  }).format(amount);
}
```

## Secure Public Access (Order-View)

Customers often need to download invoices without logging into an account. Fufuni provides a **signed token mechanism** for temporary public access.

### Token Flow
1.  **Generation**: The admin or customer (if logged in) calls `GET /v1/orders/:id/invoice`. 
2.  **Server Response**: The Hono backend generates a short-lived HMAC-signed token.
3.  **TTL**: Tokens are valid for exactly **1 hour**.
4.  **Public URL**: The frontend directs users to `/order-view/:token`.

### Backend Implementation (Hono)
```typescript
// apps/server/src/routes/orders.ts
app.get("/:id/invoice", async (c) => {
  const orderId = c.req.param("id");
  // Logic to generate signed JWT or encrypted token
  const token = await generateOrderViewToken(orderId); 
  
  return c.json({ 
    url: `${c.env.FRONTEND_URL}/order-view/${token}`,
    expires_at: Date.now() + 3600000 
  });
});
```

To add a field (e.g., "Customer VAT Number") to the generated PDF:

1.  **Modify Types**: Update the `Order` interface in `apps/client/src/types/index.ts`.
2.  **Update Generator**: Modify `apps/client/src/lib/invoice-generator.ts` to include the new line.

## Store Logo Handling

The store logo is treated as a high-priority visual element but has a safe fallback.

1.  **Storage**: The logo is saved as a **Base64 data URI** string within the `store_settings` table in SQLite.
2.  **Processing**: When generating the PDF, `jsPDF`'s `addImage` method is used.
3.  **Fallback**: If the `storeInfo.logo` string is null or empty, the generator skips the image block and instead renders the `storeInfo.name` in a large, bold font at the top left to maintain branding consistency.

```typescript
// Logo handling in generator
if (storeInfo.logo && storeInfo.logo.startsWith('data:image')) {
  doc.addImage(storeInfo.logo, 'PNG', margin, margin, 40, 20);
  yPosition += 25;
} else {
  doc.setFontSize(22);
  doc.setFont("helvetica", "bold");
  doc.text(storeInfo.name, margin, margin + 10);
  yPosition += 20;
}
```
