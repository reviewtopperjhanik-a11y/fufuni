## Invoice and PDF Generation Overview
The Fufuni e-commerce framework utilizes a 100% client-side architecture for invoice and PDF generation, leveraging the capabilities of jsPDF and jspdf-autotable. This approach eliminates the need for server-side processing, resulting in a more efficient and scalable solution.

## Client-Side PDF Generation
The `lib/invoice-generator.ts` module exposes the `generateInvoice(data: InvoiceData): void` function, which generates an A4-sized PDF invoice based on the provided `InvoiceData` object. The PDF is then downloaded as `invoice-{orderNumber}.pdf`. This function is responsible for formatting the invoice details, including order information, customer data, and itemized listings.

## Currency Formatting
Currency formatting is handled by the `utils/currency.ts` module, which provides functions for converting cent amounts to locale-aware currency strings. The supported currencies include USD, EUR, GBP, CAD, CHF, AUD, JPY, and CNY. The `formatMoney` function is used to format the currency, taking into account the locale and currency code.

### Example: Currency Formatting
```typescript
import { formatMoney } from "../utils/currency";

const amount = 2999; // 29.99
const currency = "EUR";
const locale = "fr-FR";

const formattedAmount = formatMoney(amount, currency, locale);
console.log(formattedAmount); // Output: "29,99 €"
```

## Delivering the PDF Payload
The `utils/invoice-pdf.ts` module provides two functions for delivering the PDF payload: `downloadInvoicePdf` and `openInvoicePdf`. Both functions accept an `OrderForPdf` object, which contains the necessary data for generating the invoice.

*   `downloadInvoicePdf(order, storeName?, locale?)`: Triggers a browser download of the generated PDF invoice.
*   `openInvoicePdf(order, storeName?, locale?)`: Opens the generated PDF invoice in a new browser tab using a blob URL.

### Example: Downloading the PDF Invoice
```typescript
import { downloadInvoicePdf } from "../utils/invoice-pdf";

const order: OrderForPdf = {
  number: "ORD-12345",
  created_at: "2026-03-22",
  currency: "EUR",
  email: "john@example.com",
  items: [
    {
      title: "Widget",
      qty: 2,
      unit_price_cents: 2999,
    },
  ],
  subtotal_cents: 5998,
  tax_cents: 1140,
  shipping_cents: 798,
  total_cents: 7936,
};

downloadInvoicePdf(order);
```

## Benefits of Client-Side PDF Generation
The client-side approach to PDF generation offers several benefits, including:

*   **Improved performance**: By generating the PDF on the client-side, the server is not burdened with the processing task, resulting in faster response times.
*   **Enhanced security**: Sensitive data, such as order information and customer details, is not transmitted to the server, reducing the risk of data breaches.
*   **Increased scalability**: The client-side approach allows for more efficient handling of large volumes of PDF generation requests, making it an ideal solution for high-traffic e-commerce applications.
