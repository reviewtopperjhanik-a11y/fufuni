## Client-Side PDF Architecture

Fufuni offloads 100% of PDF generation to the client's browser. This architectural decision serves three primary purposes:
1.  **Performance:** Generating PDFs is CPU-intensive. By moving this task to the browser, we preserve Cloudflare Worker CPU cycles for API orchestration and database operations.
2.  **Privacy:** Sensitive customer data (addresses, emails, purchase history) remains in the browser's memory and is never sent to a third-party generation service.
3.  **Cost:** There are no "per-PDF" costs or external API dependencies for invoice creation.

The framework utilizes `jsPDF` for the document structure and `jspdf-autotable` for managing complex item lists that require automatic page breaks and header repetition.

```typescript
// Example of the low-level jsPDF initialization used in Fufuni
import jsPDF from "jspdf";

/**
 * Basic setup for an A4 document in Fufuni
 */
const initInvoiceDoc = () => {
  const doc = new jsPDF({
    orientation: "portrait",
    unit: "mm",
    format: "a4",
  });

  // Set standard metadata for generated documents
  doc.setProperties({
    title: "Invoice",
    subject: "Order Confirmation",
    author: "Fufuni E-commerce",
    creator: "Fufuni Framework"
  });

  return doc;
};
```

## Delivering the PDF Payload

Fufuni provides two distinct delivery methods for invoices via the `utils/invoice-pdf.ts` module: `downloadInvoicePdf` for direct saving and `openInvoicePdf` for browser-based previewing.

### Download vs. Preview

-   **`downloadInvoicePdf`**: Triggers a browser download event. This is the preferred method for the "Download Invoice" button in the User Dashboard.
-   **`openInvoicePdf`**: Generates a `Blob` and creates a temporary URL. This is used when an administrator wants to quickly check an invoice without cluttering their local storage.

```tsx
import React from "react";
import { Button } from "@heroui/react";
import { downloadInvoicePdf, openInvoicePdf, OrderForPdf } from "@/utils/invoice-pdf";

interface InvoiceActionsProps {
  order: OrderForPdf;
}

export const InvoiceActions: React.FC<InvoiceActionsProps> = ({ order }) => {
  const handleDownload = () => {
    // Uses default store name and browser locale
    downloadInvoicePdf(order, "Fufuni Flagship Store");
  };

  const handlePreview = () => {
    // Opens in a new tab using window.open(blobUri)
    openInvoicePdf(order, "Fufuni Flagship Store", "en-US");
  };

  return (
    <div className="flex gap-4">
      <Button color="primary" onPress={handleDownload}>
        Download PDF
      </Button>
      <Button variant="bordered" onPress={handlePreview}>
        Preview in New Tab
      </Button>
    </div>
  );
};
```

## Currency and Locale Logic

Currency formatting is handled by `utils/currency.ts` using the native `Intl.NumberFormat` API. This ensures that symbols, decimal separators, and decimal counts (e.g., 0 decimals for JPY) are strictly compliant with ISO 4217 standards.

### Localization Rules
-   If no locale is provided, the framework falls back to `navigator.language`.
-   Monetary values are divided by 100 before formatting to convert cents to the major currency unit.
-   The `currencyDisplay: "narrowSymbol"` option is used to ensure compact PDF layouts (e.g., "$" instead of "USD").

```typescript
import { formatMoney, formatAmount } from "@/utils/currency";

/**
 * Demonstrating localized currency formatting
 */
const priceCents = 299900; // $2,999.00

// Result: "$2,999.00" (assuming en-US)
const usFormat = formatMoney(priceCents, "USD", "en-US");

// Result: "2.999,00 €" (assuming de-DE)
const euFormat = formatMoney(priceCents, "EUR", "de-DE");

// Result: "¥2,999" (JPY has 0 decimals by default in Intl)
const jpFormat = formatMoney(priceCents, "JPY", "ja-JP");

// Result: "2,999.00" (No symbol, used for raw table data)
const rawAmount = formatAmount(priceCents, "USD", "en-US");
```

## PDF Table Construction

The most complex part of the invoice is the itemized table. Fufuni uses `jspdf-autotable` to handle these dynamic lists. The `startY` coordinate is adjusted based on whether shipping or tracking information is present to prevent overlapping.

### Table Implementation Details
-   **Header Styles:** Uses a fixed blue-600 background (`[37, 99, 235]`) to match the default HeroUI/Tailwind theme.
-   **Pagination:** The `didDrawPage` hook is used to inject a footer on every page, containing the generation date and store branding.
-   **Dynamic Positioning:** The totals section (Subtotal, Tax, Shipping, Total) is calculated based on the `finalY` position of the table, ensuring it always appears exactly 8mm below the last item row.

```typescript
import autoTable from "jspdf-autotable";
import { jsPDF } from "jspdf";

/**
 * Logic found in utils/invoice-pdf.ts for table generation
 */
function drawItemsTable(doc: jsPDF, order: OrderForPdf, startY: number) {
  const tableBody = order.items.map(item => [
    item.title,
    item.qty.toString(),
    formatMoney(item.unit_price_cents, order.currency),
    formatMoney(item.qty * item.unit_price_cents, order.currency)
  ]);

  autoTable(doc, {
    startY,
    head: [["Item", "Qty", "Unit Price", "Total"]],
    body: tableBody,
    headStyles: { fillColor: [37, 99, 235] },
    margin: { left: 14, right: 14 },
    styles: { fontSize: 9, cellPadding: 3 },
    columnStyles: {
      1: { halign: 'center' }, // Quantity
      2: { halign: 'right' },  // Unit Price
      3: { halign: 'right' }   // Line Total
    }
  });
  
  // Return the Y position where the table ended
  return (doc as any).lastAutoTable.finalY;
}
```

## Handling Tax and Discounts

The framework supports both inclusive and exclusive taxes. When generating the totals section, the generator iterates through the `taxes` array.

1.  **Tax Inclusive:** Labeled as "Incl. [Tax Name]". These do not add to the `total_cents` but are shown for transparency.
2.  **Tax Exclusive:** Labeled as "Tax ([Tax Name])". These are added to the subtotal.
3.  **Discounts:** Represented as negative values in the totals breakdown to clearly show the savings applied to the order.

```typescript
/**
 * Logic for the totals section in utils/invoice-pdf.ts
 */
const renderTotals = (doc: jsPDF, order: OrderForPdf, startY: number) => {
  let currentY = startY + 8;
  const rightAlignX = doc.internal.pageSize.getWidth() - 14;

  // Render Subtotal
  doc.text("Subtotal", 14, currentY);
  doc.text(formatMoney(order.subtotal_cents, order.currency), rightAlignX, currentY, { align: "right" });
  
  // Render Discounts if any
  if (order.discount_amount_cents) {
    currentY += 6;
    doc.text("Discount", 14, currentY);
    doc.text(`-${formatMoney(order.discount_amount_cents, order.currency)}`, rightAlignX, currentY, { align: "right" });
  }

  // Render Tax lines
  if (order.taxes && order.taxes.length > 0) {
    order.taxes.forEach(tax => {
      currentY += 6;
      const label = tax.tax_inclusive !== false ? `Incl. ${tax.name}` : `Tax (${tax.name})`;
      doc.text(label, 14, currentY);
      doc.text(formatMoney(tax.amount_cents, order.currency), rightAlignX, currentY, { align: "right" });
    });
  }

  // Final Total
  currentY += 8;
  doc.setFont("helvetica", "bold");
  doc.line(14, currentY - 5, rightAlignX, currentY - 5); // Separation line
  doc.text("TOTAL", 14, currentY);
  doc.text(formatMoney(order.total_cents, order.currency), rightAlignX, currentY, { align: "right" });
};
```

## Security and PDF Blobs

When using `openInvoicePdf`, the system utilizes `doc.output("bloburi")`. This generates a `blob:` URL that points to the data in the browser's memory.

-   **Memory Management:** These URLs are temporary. While the framework relies on the browser to clean them up, developers should be aware that opening hundreds of PDFs in a single session without closing tabs will consume client RAM.
-   **No Persistence:** Because the PDF is generated on the fly, there is no "Permanent Link" to an invoice. To share an invoice, the user must download the file and send the attachment. This prevents unauthorized access to invoices via guessed URLs.

```typescript
/**
 * Implementation of the opening logic
 */
export function openInvoicePdf(order: OrderForPdf): void {
  const doc = generateBasePdf(order); // Internal function to populate doc
  
  // This creates a blob URL like blob:http://localhost:5173/uuid
  const blobUrl = doc.output("bloburi");
  
  // Opens the browser's native PDF viewer
  window.open(blobUrl);
}
```
