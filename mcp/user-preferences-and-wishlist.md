## User Preferences and Metadata Architecture

In the Fufuni framework, we distinguish between **volatile preferences** (like product wishlists or UI themes) and **relational state** (like saved carts). To minimize database overhead and ensure fast access at the edge, Fufuni utilizes Auth0's `user_metadata` for preferences instead of a dedicated SQLite table.

By storing the wishlist in Auth0 `user_metadata`, the list of favorite product IDs is embedded directly into the user's JWT access token. This allows the frontend to read the wishlist immediately upon decoding the token without performing an additional fetch to the Fufuni backend or the SQLite database.

### Multi-tenant Namespacing

Because multiple Fufuni store instances might share a single Auth0 tenant, all data in `user_metadata` is namespaced. This prevents a user's wishlist from "Store A" appearing in "Store B". The system uses the `STORE_URL` environment variable to isolate data.

```typescript
// Example of the namespaced user_metadata structure inside a JWT
{
  "sub": "auth0|12345",
  "extra_user_info/user_metadata": {
    "https://store-alpha.fufuni.com": {
      "wishlist": ["prod_01J2", "prod_09K3"],
      "marketing_consent": true
    },
    "https://store-beta.fufuni.com": {
      "wishlist": ["prod_ZZZ9"]
    }
  }
}
```

## Reading the Wishlist with useWishlist()

The `useWishlist()` hook is the primary interface for managing favorites. It is designed to be "lightweight" by deriving its state from the JWT currently held in memory. It uses `jose` to decode the token client-side, avoiding any round-trip to the server during the initial render or subsequent re-renders.

### Hook Implementation and Token Decoding

The hook relies on `getWishlistFromToken` to parse the `extra_user_info/user_metadata` claim. Note the fallback logic for backward compatibility.

```typescript
import { decodeJwt } from "jose";
import { getStoreMetadata } from "@/lib/store-metadata";

const STORE_URL = import.meta.env.STORE_URL;

/**
 * Extracts wishlist from JWT without a backend call.
 */
export function getWishlistFromToken(token: string | null): string[] {
  if (!token) return [];
  try {
    const payload = decodeJwt(token) as any;
    const userMetadata = payload["extra_user_info/user_metadata"];
    // Isolate data for THIS specific store instance
    const storeMetadata = getStoreMetadata(userMetadata, STORE_URL);

    return Array.isArray(storeMetadata?.wishlist) ? storeMetadata.wishlist : [];
  } catch (error) {
    console.error("Failed to decode wishlist from token", error);
    return [];
  }
}
```

### Usage in Components

The hook provides a `toggle` function and an `isFavorite` helper, making it trivial to implement "Like" buttons.

```tsx
import { useWishlist } from "@/hooks/use-wishlist";
import { Button } from "@heroui/react";
import { HeartIcon } from "@/components/icons";

export const WishlistButton = ({ productId }: { productId: string }) => {
  const { toggle, isFavorite, isLoading } = useWishlist();
  const isFav = isFavorite(productId);

  return (
    <Button
      isIconOnly
      variant="light"
      isLoading={isLoading}
      onPress={() => toggle(productId)}
      aria-label="Toggle Wishlist"
    >
      <HeartIcon fill={isFav ? "red" : "none"} stroke={isFav ? "red" : "currentColor"} />
    </Button>
  );
};
```

## Mutation Flow and Synchronization

When `toggle()` is called, the hook performs a sequence of actions to ensure the UI stays in sync with the Auth0 identity provider.

1.  **API Call:** It sends a `POST` (to add) or `DELETE` (to remove) request to the Fufuni backend.
2.  **Server Persistance:** The backend updates the `user_metadata` via the Auth0 Management API.
3.  **Token Refresh:** The hook calls `refreshToken()`. Since the remote metadata has changed, the new JWT returned by Auth0 will contain the updated wishlist.
4.  **Local State Sync:** The hook updates its internal state and dispatches a `CustomEvent`.

### The WISHLIST_UPDATED_EVENT

To ensure reactivity across different components (e.g., a Navbar counter and a Product card) without the performance cost of a global React Context, we use a standard DOM event: `fufuni:wishlist-updated`.

```typescript
// Inside useWishlist hook toggle function
const newToken = await refreshToken();
const newWishlist = getWishlistFromToken(newToken || null);

// Update local state in useTokenUserData
setWishlist(newWishlist);

// Notify other instances of the hook or external listeners
window.dispatchEvent(
  new CustomEvent("fufuni:wishlist-updated", { detail: newWishlist })
);
```

## Backend Implementation

The Fufuni backend acts as a proxy to the Auth0 Management API. The `PATCH /v1/me/preferences` endpoint allows updating any namespaced metadata field.

### Hono Route for Preferences

The backend validates the payload using Zod and ensures that only the namespaced section of the metadata is modified, protecting the rest of the user profile.

```typescript
// apps/server/src/routes/me/preferences.ts
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import { z } from "zod";

const preferencesSchema = z.object({
  marketing_consent: z.boolean().optional(),
  language: z.string().length(2).optional(),
});

const app = new Hono();

app.patch("/", zValidator("json", preferencesSchema), async (c) => {
  const user = c.get("user"); // Auth middleware provides user ID
  const updates = c.req.valid("json");
  const storeUrl = process.env.STORE_URL;

  // Use Auth0 Management API to update user_metadata
  // Data is nested under [storeUrl]
  await c.get("auth0").users.update(
    { id: user.sub },
    { 
      user_metadata: { 
        [storeUrl]: updates 
      } 
    }
  );

  return c.json({ success: true });
});
```

## Saved Carts: Database vs. Metadata

While the wishlist is stored in Auth0, **Saved Carts** are stored in the Fufuni SQLite database. This is because a "Saved Cart" is a heavy object that requires a foreign key relationship to the `carts` and `cart_items` tables.

| Feature | Storage | Reason |
| :--- | :--- | :--- |
| **Wishlist** | Auth0 `user_metadata` | Small array of IDs, needs to be available in JWT at the edge. |
| **Theme/Language** | Auth0 `user_metadata` | Simple key-value pair, persists across devices via IDP. |
| **Saved Carts** | SQLite `saved_carts` table | Relational data, references specific database rows (PK/FK). |

### SQLite Schema for Saved Carts

```sql
-- apps/server/src/db/schema.sql
CREATE TABLE saved_carts (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    cart_id TEXT NOT NULL,
    name TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (cart_id) REFERENCES carts(id) ON DELETE CASCADE
);
```

## Step-by-Step: Adding a New Preference Field

To add a new user preference (e.g., `preferred_currency`), follow these four steps.

### 1. Update Type Definitions
Define the new field in your shared types or metadata utilities.

```typescript
// apps/client/src/lib/store-metadata.ts
export interface FufuniStoreMetadata {
  wishlist: string[];
  preferred_currency?: string; // New field
}
```

### 2. Update the Hook/Reader
Modify your reading logic to extract the new field from the decoded JWT.

```typescript
// In a new hook useUserPreferences()
export function getPreferencesFromToken(token: string | null) {
  const payload = decodeJwt(token) as any;
  const storeMetadata = getStoreMetadata(payload["extra_user_info/user_metadata"], STORE_URL);
  return {
    currency: storeMetadata?.preferred_currency ?? 'USD'
  };
}
```

### 3. Implement the Update Method
Use `auth.patchJson` to persist the change to the backend endpoint.

```typescript
const updateCurrency = async (currencyCode: string) => {
  await auth.patchJson(`${apiBase}/v1/me/preferences`, {
    preferred_currency: currencyCode
  });
  
  // Always refresh token after updating metadata to get a fresh JWT
  await refreshToken();
  
  // Trigger event for UI reactivity
  window.dispatchEvent(new CustomEvent("fufuni:prefs-updated"));
};
```

### 4. Handle Reactivity
Listen for the custom event in components that need to react to the change without a full page refresh.

```tsx
useEffect(() => {
  const handleUpdate = () => {
    // Re-read from the refreshed token
    const newPrefs = getPreferencesFromToken(auth.accessToken);
    setLocalCurrency(newPrefs.currency);
  };

  window.addEventListener("fufuni:prefs-updated", handleUpdate);
  return () => window.removeEventListener("fufuni:prefs-updated", handleUpdate);
}, [auth.accessToken]);
```
