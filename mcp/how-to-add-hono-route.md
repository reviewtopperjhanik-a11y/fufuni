## How to Add a New API Route
### Step 1: Create a New Route File
Create a new file for your route, e.g., `apps/merchant/src/routes/my-feature.ts`.

### Step 2: Minimal Boilerplate
Here's the minimal boilerplate for a new route file:

```typescript
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';

// Create a public router (no auth required)
const publicApp = new OpenAPIHono<HonoEnv>();

// Create an admin router (auth + adminOnly required)
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);

// Define a route
const myFeatureRoute = createRoute({
  method: 'get',
  path: '/',
  tags: ['My Feature'],
  summary: 'My feature route',
  responses: {
    200: { 
      content: { 'application/json': { schema: z.object({ message: z.string() }) } },
      description: 'Success',
    },
  },
});

publicApp.openapi(myFeatureRoute, async (c) => {
  // Handler implementation
  return c.json({ message: 'Hello, world!' }, 200);
});

export { publicApp as publicMyFeature, adminApp as adminMyFeature };
```

### Step 3: Splitting Public vs Admin Endpoints
- For public endpoints (no auth required), use the `publicApp` instance.
- For admin endpoints (auth + adminOnly required), use the `adminApp` instance.

### Step 4: Using getDb() to Run Queries
To interact with the database, use the `getDb()` function:

```typescript
const db = getDb(c.var.db);
const rows = await db.query<any>('SELECT * FROM my_table');
```

### Step 5: Using ApiError for Error Responses
Use `ApiError` to throw structured HTTP errors:

```typescript
throw ApiError.notFound('Resource not found');
throw ApiError.invalidRequest('Invalid request data', { field: 'error' });
```

### Step 6: Registering the Route in index.ts
- Public routes are registered BEFORE authMiddleware:

```typescript
app.route('/v1/my-feature', publicMyFeature);
```

- Admin routes are registered AFTER authMiddleware:

```typescript
app.route('/v1/my-feature', adminMyFeature);
```

### Step 7: Available RBAC Guards
The following RBAC guards are available:

- `adminOnly`: Requires the `admin:store` permission.
- `superAdminOnly`: Requires super admin privileges.
- `databaseAdminOnly`: Requires database admin privileges.
- `aiAccessOnly`: Requires AI access privileges.
- `mailAccessOnly`: Requires mail access privileges.
- `validJwtAuthOnly`: Requires a valid JWT.

### Step 8: Complete Worked Example
Here's a complete example for a "tags" endpoint with GET / (list, public) + POST / (create, adminOnly):

```typescript
// apps/merchant/src/routes/tags.ts
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';
import { TagResponse, TagListResponse, CreateTagBody } from '../schemas';

const publicApp = new OpenAPIHono<HonoEnv>();
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);

// GET /tags (public)
const listTagsRoute = createRoute({
  method: 'get',
  path: '/',
  tags: ['Tags'],
  summary: 'List all tags',
  responses: {
    200: { 
      content: { 'application/json': { schema: TagListResponse } },
      description: 'List of tags',
    },
  },
});

publicApp.openapi(listTagsRoute, async (c) => {
  const db = getDb(c.var.db);
  try {
    const rows = await db.query<any>('SELECT * FROM tags');
    return c.json({ items: rows }, 200);
  } catch (error) {
    throw ApiError.internalServerError(error instanceof Error ? error.message : 'Failed to fetch tags');
  }
});

// POST /tags (adminOnly)
const createTagRoute = createRoute({
  method: 'post',
  path: '/',
  tags: ['Tags'],
  summary: 'Create a tag (admin)',
  security: [{ bearerAuth: ['admin:store'] }],
  middleware: [adminOnly] as const,
  request: {
    body: {
      content: { 'application/json': { schema: CreateTagBody } },
    },
  },
  responses: {
    201: { 
      content: { 'application/json': { schema: TagResponse } },
      description: 'Tag created',
    },
  },
});

adminApp.openapi(createTagRoute, async (c) => {
  const body = c.req.valid('json');
  const db = getDb(c.var.db);

  try {
    await db.run('INSERT INTO tags (name) VALUES (?)', [body.name]);
    const [row] = await db.query<any>('SELECT * FROM tags WHERE name = ?', [body.name]);
    return c.json(row, 201);
  } catch (error) {
    throw ApiError.internalServerError(error instanceof Error ? error.message : 'Failed to create tag');
  }
});

export { publicApp as publicTags, adminApp as adminTags };
```

In `index.ts`:

```typescript
app.route('/v1/tags', publicTags);
app.route('/v1/tags', adminTags);
```
