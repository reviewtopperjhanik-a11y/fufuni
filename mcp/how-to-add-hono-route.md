## Implementing New API Routes in Fufuni

Fufuni utilizes `hono` and `@hono/zod-openapi` to provide a type-safe, self-documenting REST API. All routes are backed by SQLite via a Cloudflare Durable Object. When adding a new feature, you must follow the dual-app pattern to separate public storefront access from administrative management.

### The Standard Route Boilerplate

Every route file should be located in `apps/merchant/src/routes/` and follow a consistent structure. You define a public app for unauthenticated or public-key (pk_) access and an admin app for authenticated management (sk_ or JWT).

```typescript
// apps/merchant/src/routes/my-feature.ts
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, uuid, now, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';
// Always import schemas from the centralized directory
import { ErrorResponse } from '../schemas';

// 1. PUBLIC ROUTER: Accessible by storefronts/guests
const publicApp = new OpenAPIHono<HonoEnv>();

// 2. ADMIN ROUTER: Protected by authMiddleware
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);

export { publicApp as publicMyFeature, adminApp as adminMyFeature };
```

## Database Operations and Error Handling

Fufuni abstracts the Durable Object's SQLite interface through the `getDb` helper. Never access the Durable Object methods directly; use the `Database` interface which provides `query<T>` for data retrieval and `run` for mutations.

### Performing Queries and Mutations

The `db` instance is retrieved from `c.var.db` (populated via middleware in `index.ts`).

```typescript
// Example of a GET handler
publicApp.openapi(someRouteDefinition, async (c) => {
  const db = getDb(c.var.db);
  try {
    const rows = await db.query<{ name: string }>(
      `SELECT name FROM my_table WHERE status = ?`,
      ['active']
    );
    return c.json({ items: rows }, 200);
  } catch (error) {
    // Standardized internal error wrapping
    throw ApiError.internalServerError(error instanceof Error ? error.message : 'DB Failure');
  }
});

// Example of a POST/PATCH handler
adminApp.openapi(createRouteDefinition, async (c) => {
  const db = getDb(c.var.db);
  const body = c.req.valid('json'); // NEVER use c.req.json()
  
  try {
    const id = uuid();
    await db.run(
      `INSERT INTO my_table (id, name, created_at) VALUES (?, ?, ?)`,
      [id, body.name, now()]
    );
    return c.json({ id, ok: true }, 201);
  } catch (error) {
    if (error instanceof ApiError) throw error;
    throw ApiError.internalServerError('Failed to create record');
  }
});
```

### Structured Error Responses

Always use the `ApiError` class to ensure the frontend receives a consistent JSON envelope: `{ error: { code, message, details } }`.

| Method | Status | Use Case |
| :--- | :--- | :--- |
| `ApiError.notFound(msg)` | 404 | Resource does not exist in DB |
| `ApiError.badRequest(msg)` | 400 | Validation failed or logic error |
| `ApiError.unauthorized()` | 401 | Missing or invalid credentials |
| `ApiError.forbidden()` | 403 | Authenticated but lacks permissions |
| `ApiError.conflict(msg)` | 409 | Duplicate handle, SKU, or email |

## Security and RBAC Guards

Administrative routes are guarded by `authMiddleware`, but specific endpoints often require granular permissions. These guards are applied in the `middleware` array of the `createRoute` configuration.

### Available RBAC Guards

Import these from `../middleware/auth`:

- **`adminOnly`**: Standard merchant admin access. Requires `admin:store` permission.
- **`superAdminOnly`**: Highest level access for system configuration.
- **`databaseAdminOnly`**: Required for raw SQL or database maintenance routes (`admin:database`).
- **`aiAccessOnly`**: Required for AI translation and parameter configuration (`ai:api`).
- **`mailAccessOnly`**: Required for managing transactional email templates (`mail:api`).
- **`validJwtAuthOnly`**: Ensures the request has a valid Auth0 JWT, regardless of specific permissions.

```typescript
const sensitiveRoute = createRoute({
  method: 'post',
  path: '/reindex',
  tags: ['System'],
  security: [{ bearerAuth: ['admin:database'] }],
  middleware: [databaseAdminOnly] as const, // Guard applied here
  responses: {
    200: { description: 'Success', content: { 'application/json': { schema: z.object({ ok: z.boolean() }) } } }
  }
});
```

## Route Registration in index.ts

The order of registration in `apps/merchant/src/index.ts` is critical. Public routes must be mounted **before** global middleware that might intercept them, and before any catch-all admin routers.

```typescript
// apps/merchant/src/index.ts

// 1. Import your apps
import { publicMyFeature, adminMyFeature } from './routes/my-feature';

// ... (CORS and DB setup)

// 2. Register PUBLIC routes BEFORE auth middleware
app.route('/v1/my-feature', publicMyFeature);

// 3. Rate limiting and Cache middleware (optional)
app.use('/v1/my-feature', rateLimitMiddleware());

// 4. Register ADMIN routes AFTER public routes
app.route('/v1/my-feature', adminMyFeature);
```

## Complete Example: Tags API

In this example, we implement a "Tags" feature. This allows public listing of tags used in the store and administrative creation of new tags.

### 1. Route Implementation

```typescript
// apps/merchant/src/routes/tags.ts
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, uuid, now, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';
import { ErrorResponse } from '../schemas';

// Define schemas (In a real app, these would be in ../schemas/tags.ts)
const TagSchema = z.object({
  id: z.string().uuid(),
  name: z.string().min(1),
  slug: z.string(),
  created_at: z.string()
});

const CreateTagBody = z.object({
  name: z.string().min(1).openapi({ example: 'Eco-Friendly' }),
  slug: z.string().min(1).openapi({ example: 'eco-friendly' })
});

const publicApp = new OpenAPIHono<HonoEnv>();
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);

// --- PUBLIC: List Tags ---
const listTagsRoute = createRoute({
  method: 'get',
  path: '/',
  tags: ['Tags'],
  summary: 'List all tags',
  responses: {
    200: {
      description: 'List of tags',
      content: { 'application/json': { schema: z.object({ items: z.array(TagSchema) }) } }
    }
  }
});

publicApp.openapi(listTagsRoute, async (c) => {
  const db = getDb(c.var.db);
  const rows = await db.query<any>(`SELECT * FROM tags ORDER BY name ASC`);
  return c.json({ items: rows }, 200);
});

// --- ADMIN: Create Tag ---
const createTagRoute = createRoute({
  method: 'post',
  path: '/',
  tags: ['Tags'],
  summary: 'Create a new tag',
  security: [{ bearerAuth: ['admin:store'] }],
  middleware: [adminOnly] as const,
  request: {
    body: { content: { 'application/json': { schema: CreateTagBody } } }
  },
  responses: {
    201: {
      description: 'Tag created',
      content: { 'application/json': { schema: TagSchema } }
    },
    409: {
      description: 'Slug already exists',
      content: { 'application/json': { schema: ErrorResponse } }
    }
  }
});

adminApp.openapi(createTagRoute, async (c) => {
  const { name, slug } = c.req.valid('json');
  const db = getDb(c.var.db);

  const [existing] = await db.query(`SELECT id FROM tags WHERE slug = ?`, [slug]);
  if (existing) throw ApiError.conflict(`Tag slug "${slug}" is already taken`);

  const id = uuid();
  const timestamp = now();
  await db.run(
    `INSERT INTO tags (id, name, slug, created_at) VALUES (?, ?, ?, ?)`,
    [id, name, slug, timestamp]
  );

  return c.json({ id, name, slug, created_at: timestamp }, 201);
});

export { publicApp as publicTags, adminApp as adminTags };
```

### 2. Registration

Add the following to `apps/merchant/src/index.ts`:

```typescript
import { publicTags, adminTags } from './routes/tags';

// Mount public side
app.route('/v1/tags', publicTags);

// Mount admin side
app.route('/v1/tags', adminTags);
```

### 3. Database Migration

Since Fufuni uses SQLite inside a Durable Object, ensure the table exists in the `initSchema` method of `apps/merchant/src/do.ts`:

```sql
CREATE TABLE IF NOT EXISTS tags (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  slug TEXT NOT NULL UNIQUE,
  created_at TEXT NOT NULL
);
```

### Key Rules Checklist
- **Naming**: Export `public[Feature]` and `admin[Feature]`.
- **Validation**: Only use `c.req.valid('json')` or `c.req.valid('param')`.
- **OpenAPI**: Always provide `summary`, `tags`, and `responses` in `createRoute`.
- **Zod**: Use `z.string().uuid()` for ID parameters and `z.string().openapi({ param: { name: '...', in: 'path' } })` for path segments.
- **Safety**: Always wrap DB calls in `try/catch` and throw `ApiError`.
