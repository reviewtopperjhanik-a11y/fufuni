## How to Add a Database Migration

### When to Use a Migration vs. Editing the SCHEMA Constant

**Use a migration** when you need to:
- Add new tables, columns, or indexes
- Modify existing table structures
- Add constraints or triggers
- Update production databases

**Edit the SCHEMA constant directly** only when:
- Setting up a fresh development environment
- Adding tables that will never exist in production
- Creating temporary test structures

### Migration Creation Steps

#### Step 1: Create the SQL File

Create a new file in `apps/merchant/migrations/` with the next sequential number:

```sql
-- apps/merchant/migrations/034-add-tags.sql
-- Migration 034: Add product tags functionality
-- 
-- Run locally:  npx wrangler d1 execute merchant --local --file migrations/034-add-tags.sql
-- Run remotely: npx wrangler d1 execute merchant-db --remote --file migrations/034-add-tags.sql

PRAGMA foreign_keys = ON;

CREATE TABLE IF NOT EXISTS tags (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL UNIQUE,
  color TEXT DEFAULT '#3B82F6',
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS product_tags (
  product_id TEXT NOT NULL REFERENCES products(id) ON DELETE CASCADE,
  tag_id TEXT NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (product_id, tag_id)
);

CREATE INDEX IF NOT EXISTS idx_product_tags_tag ON product_tags (tag_id);
CREATE INDEX IF NOT EXISTS idx_product_tags_product ON product_tags (product_id);
```

### Common Pitfalls

#### 1. Missing IF NOT EXISTS
```sql
-- ❌ Wrong - will fail on re-run
CREATE TABLE tags (...);

-- ✅ Correct - idempotent
CREATE TABLE IF NOT EXISTS tags (...);
```

#### 2. Migration Name Mismatch
```typescript
// ❌ Wrong - file name and migration name don't match
// File: 034-tags.sql
this.sql.exec("INSERT INTO migrations (name) VALUES ('034-add-tags')");

// ✅ Correct - exact match
// File: 034-tags.sql
this.sql.exec("INSERT INTO migrations (name) VALUES ('034-tags')");
```

#### 3. Incorrect Column Types
```sql
-- ❌ Wrong - using BOOLEAN
is_active BOOLEAN NOT NULL DEFAULT true,

-- ✅ Correct - use INTEGER for booleans
is_active INTEGER NOT NULL DEFAULT 1,

-- ❌ Wrong - using VARCHAR
id VARCHAR(36) PRIMARY KEY,

-- ✅ Correct - use TEXT for UUIDs
id TEXT PRIMARY KEY,
```

#### 4. Async Operations in ensureInitialized
```typescript
// ❌ Wrong - DO SQL is synchronous
await this.sql.exec("CREATE TABLE ...");

// ✅ Correct - no await
this.sql.exec("CREATE TABLE ...");
```

#### 5. Modifying Existing Migrations
Never change a migration after deployment. Instead, create a new one:

```sql
-- ❌ Never do this - modifying existing migration
-- File: 030-products.sql (already deployed)
ALTER TABLE products ADD COLUMN tags TEXT;

-- ✅ Correct approach - new migration
-- File: 035-add-product-tags.sql
ALTER TABLE products ADD COLUMN tags TEXT;
```
