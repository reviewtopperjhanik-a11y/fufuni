## Internationalisation (i18n) Reference
### Supported Locales

The application supports the following 6 locales:

* en-US (English)
* fr-FR (Français)
* es-ES (Español)
* zh-CN (中文)
* ar-SA (العربية)
* he-IL (עברית)

The locale JSON files are located in the `apps/client/src/locales/base/` directory.

### Adding a New Translation Key

To add a new translation key, follow these steps:

1. **Edit the JSON files**: Open the JSON files for each locale (e.g., `en-US.json`, `fr-FR.json`, etc.) and add the new key-value pair.
2. **JSON structure**: The JSON structure is flat, with keys using kebab-case (e.g., "admin-users-page-title"). The values can contain interpolation syntax using `{{ }}`.

Example:
```json
// en-US.json
{
  "product-tags": "Product Tags",
  "add-tag": "Add Tag",
  "tag-placeholder": "Enter tag name..."
}
```
### Using the Hook in a Component

To use the translation hook in a component, follow these steps:

1. **Import the hook**: `import { useTranslation } from 'react-i18next';`
2. **Use the hook**: `const { t } = useTranslation();`
3. **Translate a key**: `t('key')`
4. **Translate with interpolation**: `t('key', { count: 2 })`

Example:
```typescript
import React from 'react';
import { useTranslation } from 'react-i18next';

const ProductTags = () => {
  const { t } = useTranslation();

  return (
    <div>
      <h2>{t('product-tags')}</h2>
      <input type="text" placeholder={t('tag-placeholder')} />
      <button onClick={() => console.log(t('add-tag'))}>{t('add-tag')}</button>
    </div>
  );
};
```
