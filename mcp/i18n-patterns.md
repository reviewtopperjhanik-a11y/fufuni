## Internationalisation (i18n) Reference
### Supported Locales
The Fufuni e-commerce framework currently supports 6 locales: en-US, fr-FR, es-ES, zh-CN, ar-SA, and he-IL. The locale JSON files live in the `apps/client/src/locales/base` directory, with each file named after its corresponding locale code (e.g., `en-US.json`).

### Adding a New Translation Key
To add a new translation key, edit the following files:
* `apps/client/src/i18n.ts`: add a new object to the `availableLanguages` array with the locale code, native name, and `isRTL` property (if applicable).
* `apps/client/src/locales/base/{localeCode}.json`: add a new key-value pair with the translation key in kebab-case (e.g., "product-tags-title").

JSON structure:
* Use flat keys (no nesting).
* Use interpolation syntax `{{variable}}` to insert dynamic values.

Example:
```json
// en-US.json
{
  "product-tags-title": "Product Tags",
  "product-tags-description": "Discover related products with {{tag}}",
  "product-tags-add": "Add {{tag}} to product"
}
```

### Using the useTranslation Hook
In a component, use the `useTranslation` hook to access the `t` function:
```typescript
import { useTranslation } from 'react-i18next';

const MyComponent = () => {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('product-tags-title')}</h1>
      <p>{t('product-tags-description', { tag: 'example' })}</p>
      <button>{t('product-tags-add', { tag: 'example' })}</button>
    </div>
  );
};
```

### Handling RTL Languages
For RTL languages (ar-SA and he-IL), the framework automatically applies RTL styles to the layout when the language is set. No additional configuration is required.
