## 2. Adding a New Translation Key

### 2.1 Files to Edit

1. **Locale JSON**  
   Add the key to the appropriate language file, e.g. `locales/base/en-US.json`.  
2. **Optional: Base JSON**  
   Keep the base (`en-US`) the source of truth; other locales should mirror its structure.

### 2.2 JSON Structure

```json
// locales/base/en-US.json
{
  "welcome": "Welcome to Fufuni",
  "product.count": "There {{count}} product{{count > 1 ? 's' : ''}}",
  "product.tags.title": "Product Tags",
  "product.tags.more": "Show more tags"
}
```

* Keys are **flat** (no nesting).  
* Interpolation uses `{{variable}}`.  
* Pluralization handled via `{{count}}` in the key and the `count` option.

> **Tip:** Keep the key names short, unique, and descriptive.

## 3. Using `useTranslation()` in a Component

```tsx
import { useTranslation } from "react-i18next";

export default function Header() {
  const { t, i18n } = useTranslation();

  return (
    <header dir={i18n.dir()}>
      <h1>{t("welcome")}</h1>
      <p>{t("product.count", { count: 3 })}</p>
    </header>
  );
}
```

* `t('key')` → plain text.  
* `t('key', { count })` → handles pluralisation.  
* `i18n.dir()` returns `"ltr"` or `"rtl"` based on current language.

## 4. Handling RTL Languages

| Step | Action |
|------|--------|
| **Set `dir` attribute** | `dir={i18n.dir()}` on the root element (see above). |
| **Global CSS** | Add a fallback for RTL: `<html dir="rtl">` automatically flips layout. |
| **Component‑level** | Use `i18n.dir()` inside conditional styles or classes. |
| **Example** | `<div className={i18n.dir() === "rtl" ? "text-right" : "text-left"}>` |

> The `availableLanguages` list flags RTL languages (`isRTL: true`).  
> The `i18next` backend will load the corresponding JSON, so no additional code is needed for language resources.

## 5. Worked Example – Adding “Product Tags”

### 5.1 Create Translation Keys

1. **Edit `locales/base/en-US.json`:**

```json
{
  "product.tags.title": "Product Tags",
  "product.tags.count": "Showing {{count}} tag{{count > 1 ? 's' : ''}}",
  "product.tags.more": "Show more tags"
}
```

2. **Mirror in other locales** (e.g., `fr-FR.json`):

```json
{
  "product.tags.title": "Étiquettes du produit",
  "product.tags.count": "Affichage de {{count}} étiquette{{count > 1 ? 's' : ''}}",
  "product.tags.more": "Afficher plus d'étiquettes"
}
```

### 5.2 React Component

```tsx
import { useTranslation } from "react-i18next";

export default function ProductTags({ tags }: { tags: string[] }) {
  const { t, i18n } = useTranslation();

  const displayedTags = tags.slice(0, 3);
  const remaining = tags.length - displayedTags.length;

  return (
    <section dir={i18n.dir()}>
      <h2>{t("product.tags.title")}</h2>

      <ul>
        {displayedTags.map((tag) => (
          <li key={tag}>{tag}</li>
        ))}
      </ul>

      {remaining > 0 && (
        <p>{t("product.tags.more")}</p>
      )}

      <p>{t("product.tags.count", { count: tags.length })}</p>
    </section>
  );
}
```

* Uses `t("product.tags.count", { count })` for pluralised text.  
* `dir={i18n.dir()}` ensures RTL support for Arabic & Hebrew.  
* Keeps the component language‑agnostic.

### 5.3 Adding a New Language (Optional)

If you want to support a new locale, e.g., `de-DE`:

1. **Add to `availableLanguages`:**

```ts
{ code: "de-DE", nativeName: "Deutsch", isRTL: false },
```

2. **Create `./locales/base/de-DE.json`** mirroring the structure.  
3. **Update `loadPath`** in `i18n.ts` to handle `"de-DE"`.  
4. **Refresh the page** – the new language appears in the Language Switcher.
