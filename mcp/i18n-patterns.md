## Internationalisation (i18n) Reference

The Fufuni e-commerce framework supports internationalisation (i18n) for frontend developers, allowing you to create a multilingual user experience. This reference guide provides information on how to work with i18n in the frontend.

### Supported Locales

The framework currently supports six locales:

* en-US (English - United States)
* fr-FR (French - France)
* es-ES (Spanish - Spain)
* zh-CN (Chinese - China)
* ar-SA (Arabic - Saudi Arabia)
* he-IL (Hebrew - Israel)

The locale JSON files are located in the `apps/client/src/locales/base` directory. For example, the English locale file is `en-US.json`.

### Adding a New Translation Key

To add a new translation key, follow these steps:

a. Edit the following files:
	* `apps/client/src/locales/base/en-US.json` (add the new key to the master language file)
	* `apps/client/src/locales/base/<locale>.json` (add the translated value for each supported locale)
b. JSON structure:
	* Use flat keys (e.g., "product-tags")
	* Use kebab-case for key names (e.g., "admin-users-page-title")
	* Use interpolation syntax for dynamic values (e.g., "product-card-tax-included": "Dont {{name}}")

Example:
```json
// en-US.json
{
  "product-tags": "Product Tags",
  "product-tag-add": "Add Tag",
  "product-tag-remove": "Remove Tag"
}

// fr-FR.json
{
  "product-tags": "Étiquettes de produit",
  "product-tag-add": "Ajouter une étiquette",
  "product-tag-remove": "Supprimer une étiquette"
}
```

### Using the useTranslation() Hook

To use a translation key in a component, import the `useTranslation` hook from `react-i18next`:
```typescript
import { useTranslation } from 'react-i18next';

const MyComponent = () => {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('product-tags')}</h1>
      <button onClick={() => console.log(t('product-tag-add'))}>
        {t('product-tag-add')}
      </button>
    </div>
  );
};
```
You can also use the `t` function with interpolation:
```typescript
const productName = 'Example Product';
return (
  <div>
    <p>{t('product-card-tax-included', { name: productName })}</p>
  </div>
);
```
Note: Always add at least the en-US translation key as the default value, never use the default value parameter of the t() function.

### Handling RTL Languages

For RTL languages (ar-SA and he-IL), the framework automatically applies RTL styles to the layout when the language is set to an RTL language. You don't need to take any additional steps to handle RTL languages.

### Worked Example: Adding a New "Product Tags" Feature

Let's add a new "product tags" feature with three translation keys:

1. "product-tags" (the title of the tags section)
2. "product-tag-add" (the text for the "Add Tag" button)
3. "product-tag-remove" (the text for the "Remove Tag" button)

Add the new keys to the `en-US.json` file:
```json
{
  "product-tags": "Product Tags",
  "product-tag-add": "Add Tag",
  "product-tag-remove": "Remove Tag"
}
```
Add the translated values for each supported locale:
```json
// fr-FR.json
{
  "product-tags": "Étiquettes de produit",
  "product-tag-add": "Ajouter une étiquette",
  "product-tag-remove": "Supprimer une étiquette"
}

// es-ES.json
{
  "product-tags": "Etiquetas de producto",
  "product-tag-add": "Agregar etiqueta",
  "product-tag-remove": "Eliminar etiqueta"
}

// zh-CN.json
{
  "product-tags": "",
  "product-tag-add": "",
  "product-tag-remove": ""
}

// ar-SA.json
{
  "product-tags": "وسوم المنتج",
  "product-tag-add": "إضافة وسوم",
  "product-tag-remove": "إزالة وسوم"
}

// he-IL.json
{
  "product-tags": "תגיות מוצר",
  "product-tag-add": "הוסף תגית",
  "product-tag-remove": "הסר תגית"
}
```
Use the `useTranslation` hook in your component:
```typescript
import { useTranslation } from 'react-i18next';

const ProductTags = () => {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('product-tags')}</h1>
      <button onClick={() => console.log(t('product-tag-add'))}>
        {t('product-tag-add')}
      </button>
      <button onClick={() => console.log(t('product-tag-remove'))}>
        {t('product-tag-remove')}
      </button>
    </div>
  );
};
```
