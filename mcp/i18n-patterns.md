## Internationalisation (i18n) Reference

### Supported Locales & File Locations

Fufuni ships with six locales. Each namespace lives in `apps/client/src/locales/{namespace}/{locale}.json`. The default namespace is `base`, so the full paths are:

```typescript
apps/client/src/locales/base/en-US.json
apps/client/src/locales/base/fr-FR.json
apps/client/src/locales/base/es-ES.json
apps/client/src/locales/base/zh-CN.json
apps/client/src/locales/base/ar-SA.json
apps/client/src/locales/base/he-IL.json
```

The configuration lives in `apps/client/src/i18n.ts` and exports the `availableLanguages` array that drives the `<LanguageSwitch />` component.

### Adding a New Translation Key

1. Open every locale file you want to support (usually all six).
2. Add a flat key–value pair. Nested objects are **not** used in Fufuni to keep the bundle small and the keys grep-able.

```json
// apps/client/src/locales/base/en-US.json
{
  "product.tags.label": "Product tags",
  "product.tags.add": "Add tag",
  "product.tags.remove": "Remove tag"
}
```

Interpolation uses double curly braces:

```json
"cart.items.count": "{{count}} item(s)"
```

3. Save the file. Vite’s dev server hot-reloads the JSON; no restart needed.

### Using the Hook in Components

```typescript
import { useTranslation } from 'react-i18next';

export function ProductTags({ tags }: { tags: string[] }) {
  const { t } = useTranslation(); // default namespace is 'base'

  return (
    <div>
      <h3>{t('product.tags.label')}</h3>
      <button>{t('product.tags.add')}</button>
      <p>{t('cart.items.count', { count: tags.length })}</p>
    </div>
  );
}
```

Pluralisation follows i18next rules:

```typescript
t('cart.items.count', { count: 0 }); // → "0 items" (if defined)
t('cart.items.count', { count: 1 }); // → "1 item"
```

### RTL Language Support

Arabic (`ar-SA`) and Hebrew (`he-IL`) have `isRTL: true` in `availableLanguages`. HeroUI automatically flips the `dir` attribute on `<html>` when the locale changes, so most components adapt automatically. When you need manual control:

```typescript
import { useTranslation } from 'react-i18next';
import { useEffect } from 'react';

export function useDirection() {
  const { i18n } = useTranslation();
  const isRTL = i18n.dir() === 'rtl';
  useEffect(() => {
    document.documentElement.setAttribute('dir', isRTL ? 'rtl' : 'ltr');
  }, [isRTL]);
  return isRTL;
}
```

Then in your layout:

```typescript
const isRTL = useDirection();
<div className={`flex gap-4 ${isRTL ? 'flex-row-reverse' : ''}`}>…</div>
```

### Worked Example: Product Tags Feature

Goal: add three keys for a new “product tags” feature.

1. Add keys to every locale file:

```json
// apps/client/src/locales/base/en-US.json
{
  "product.tags.label": "Product tags",
  "product.tags.add": "Add tag",
  "product.tags.remove": "Remove tag"
}
// apps/client/src/locales/base/fr-FR.json
{
  "product.tags.label": "Étiquettes produit",
  "product.tags.add": "Ajouter une étiquette",
  "product.tags.remove": "Supprimer l’étiquette"
}
// …repeat for es-ES, zh-CN, ar-SA, he-IL
```

2. Create the component:

```typescript
// apps/client/src/components/product-tags.tsx
import { useTranslation } from 'react-i18next';
import { Button, Chip } from '@heroui/react';

export function ProductTags({ tags, onAdd, onRemove }: {
  tags: string[];
  onAdd: () => void;
  onRemove: (index: number) => void;
}) {
  const { t } = useTranslation();
  return (
    <div className="flex flex-wrap items-center gap-2">
      <span className="text-sm font-medium">{t('product.tags.label')}</span>
      {tags.map((t, i) => (
        <Chip key={i} onClose={() => onRemove(i)}>
          {t}
        </Chip>
      ))}
      <Button size="sm" onPress={onAdd}>
        {t('product.tags.add')}
      </Button>
    </div>
  );
}
```

3. Use it anywhere:

```typescript
<ProductTags
  tags={product.tags}
  onAdd={() => setProduct({ ...product, tags: [...product.tags, 'new'] })}
  onRemove={(i) =>
    setProduct({ ...product, tags: product.tags.filter((_, idx) => idx !== i) })
  }
/>
```

4. Verify RTL:

Switch to Arabic or Hebrew in the `<LanguageSwitch />`; the Chip close icon should appear on the left and the layout should mirror automatically.
