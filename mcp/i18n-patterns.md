## Introduction to Internationalisation (i18n) in Fufuni
Fufuni supports six locales: en-US, fr-FR, es-ES, zh-CN, ar-SA, and he-IL. The locale JSON files live in the `apps/client/src/locales/base` directory. Each file contains the translation keys for its respective language.

## Supported Locales and JSON Files
The following locales are supported:
* en-US: `en-US.json`
* fr-FR: `fr-FR.json`
* es-ES: `es-ES.json`
* zh-CN: `zh-CN.json`
* ar-SA: `ar-SA.json`
* he-IL: `he-IL.json`

These JSON files contain flat keys with kebab-case names (e.g., "admin-users-page-title").

## Adding a New Translation Key
To add a new translation key:
a. Edit the `en-US.json` file (master language) and add a new key-value pair.
b. Edit the corresponding JSON files for other languages and add the same key with its translated value.
c. Use the `t()` function in your component to access the translation key.

Example:
```json
// en-US.json
{
  "product-tags": "Product Tags",
  "add-tag": "Add Tag",
  "remove-tag": "Remove Tag"
}

// fr-FR.json
{
  "product-tags": "Étiquettes de produit",
  "add-tag": "Ajouter une étiquette",
  "remove-tag": "Supprimer une étiquette"
}
```

```typescript
// MyComponent.tsx
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h2>{t('product-tags')}</h2>
      <button onClick={() => addTag()}>{t('add-tag')}</button>
      <button onClick={() => removeTag()}>{t('remove-tag')}</button>
    </div>
  );
}
```

## Using the `useTranslation()` Hook
To use the `useTranslation()` hook in a component:
```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('home')}</h1>
      <p>{t('product-card-tax-default', { name: 'VAT' })}</p>
    </div>
  );
}
```

## Handling RTL Languages
For RTL languages (ar-SA and he-IL), the `rtl` styles are automatically applied to the layout when the language is set to an RTL language. You don't need to manually handle RTL logic in your components.

## Adding a New Language
To add a new language:
1. Declare the new language in `i18n.ts` within the `availableLanguages` array.
2. Create a new JSON file in the `apps/client/src/locales/base` directory with the language code (e.g., "pt-BR.json").
3. Add the translation keys to the new JSON file.

Example:
```typescript
// i18n.ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import i18nextHttpBackend, {
  type HttpBackendOptions,
} from "i18next-http-backend";

// ...

const availableLanguages = [
  {
    code: 'en-US',
    nativeName: 'English',
    isRTL: false,
    isDefault: true,
  },
  {
    code: 'fr-FR',
    nativeName: 'French',
    isRTL: false,
  },
  {
    code: 'pt-BR',
    nativeName: 'Portuguese',
    isRTL: false,
  },
  // ...
];
```

// pt-BR.json
{
  "product-tags": "Etiquetas de produto",
  "add-tag": "Adicionar etiqueta",

}
