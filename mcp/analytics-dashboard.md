## Overview of Analytics & Dashboard
The Fufuni e-commerce framework provides a dashboard endpoint for retrieving key analytics metrics. The endpoint is protected by admin-only middleware, requiring the `admin:store` permission.

### Dashboard Endpoint
The dashboard endpoint is available at `GET /v1/analytics/dashboard` and accepts a `period` query parameter with values `"7d"`, `"30d"`, `"90d"`, or `"all"`. The response includes the following metrics:
* `total_revenue_cents`: The total revenue for the specified period.
* `order_count`: The number of orders for the specified period.
* `avg_order_value_cents`: The average order value for the specified period.
* `new_customers_count`: The number of new customers for the specified period.
* `top_products`: The top 5 products by revenue for the specified period.
* `orders_by_status`: A breakdown of orders by status for the specified period.
* `low_stock_items`: A list of items with available quantity less than or equal to `LOW_INVENTORY_THRESHOLD`.

### Revenue Calculation
Revenue is calculated by summing the product of `unit_price_cents` and `quantity` for each order item, joined with orders. Only orders with status not in (`"canceled"`, `"refunded"`) are counted.

```typescript
const revenue = await db.query<{
  total_cents: number;
  order_count: number;
  avg_order_cents: number;
}>(
  `SELECT
     COALESCE(SUM(oi.unit_price_cents * oi.quantity), 0)  AS total_cents,
     COUNT(DISTINCT o.id)                                  AS order_count,
     COALESCE(AVG(oi.unit_price_cents * oi.quantity), 0)  AS avg_order_cents
   FROM orders o
   JOIN order_items oi ON o.id = oi.order_id
   WHERE o.status NOT IN ('canceled', 'refunded')
     AND o.created_at >= ${since}`
);
```

### Low Stock Alerting
Low stock alerting is triggered when the available quantity of an item is less than or equal to `LOW_INVENTORY_THRESHOLD`. The `low_stock_items` field in the dashboard response includes the following fields:
* `product_id`: The ID of the product.
* `product_title`: The title of the product.
* `available_quantity`: The available quantity of the product.

```typescript
const lowStockItems = await db.query<{
  product_id: string;
  product_title: string;
  available_quantity: number;
}>(
  `SELECT
     p.id                            AS product_id,
     p.title                          AS product_title,
     COALESCE(p.available_quantity, 0) AS available_quantity
   FROM products p
   WHERE p.available_quantity <= ${LOW_INVENTORY_THRESHOLD}`
);
```
