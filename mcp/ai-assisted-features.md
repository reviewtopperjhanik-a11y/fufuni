## AI-Assisted Features

### Architecture: Browser-Only Inference

All AI inference in Fufuni happens **exclusively in the browser**.  
The backend never sees the prompt or the model response; its only job is to vend short-lived credentials (`GET /v1/ai/parameters`) that the client uses to call the provider directly.

**Security implications**
- **No prompt injection surface on the server** – the backend cannot be tricked into leaking context or keys through prompt injection.  
- **Provider keys rotate automatically** – the backend returns one random key from a comma-separated pool stored in `AI_API_KEY`.  
- **Zero trust on the client** – the browser must still respect CORS and the provider’s rate limits; Fufuni does not add extra auth layers.  
- **No data retention** – prompts and responses live only in the user’s tab and are never logged by Fufuni.

```typescript
// apps/client/src/hooks/useAiCredentials.ts
import { useQuery } from "@tanstack/react-query";
import { apiClient } from "@/lib/api-client";

export function useAiCredentials() {
  return useQuery({
    queryKey: ["ai", "parameters"],
    queryFn: async () => {
      const { data } = await apiClient.GET("/v1/ai/parameters");
      return data; // { apiKey, model, url }
    },
    staleTime: 5 * 60 * 1000, // 5 min
  });
}
```

### `ai-client.ts`: Central AI Toolkit

Located at `apps/client/src/utils/ai-client.ts` — **never duplicate** this file.  
All new AI helpers must be added here and exported for reuse.

```typescript
export interface AiParams {
  apiKey: string;
  model: string;
  url: string;
  provider?: "openai" | "groq" | "anthropic" | "auto";
}
```

**Provider auto-detection**
- `url.includes("anthropic")` → `anthropic`
- `url.includes("groq")` → `groq`
- anything else → `openai` (covers OpenAI, Ollama, vLLM, etc.)

**Usage Example**
```typescript
import { analyzeReviewWithAi, type AiParams } from "@/utils/ai-client";

async function moderateReview(review: ReviewInput) {
  const { data: creds } = await apiClient.GET("/v1/ai/parameters");
  const result = await analyzeReviewWithAi(review, creds);
  if (result.success) {
    console.log(`Review ${review.id}: ${result.recommendation} – ${result.reason}`);
    return result.recommendation;
  } else {
    console.warn("AI moderation failed", result.error);
    return "approve"; // fail-open
  }
}
```

### Adding a New AI Use-Case (Step-by-Step)

**Goal**: Add `generateSeoDescriptionWithAi()` that produces a 160-char SEO meta description for a product.

1. **Add the helper to `ai-client.ts`**
```typescript
export interface SeoDescriptionResult {
  success: boolean;
  description?: string;
  error?: string;
}

export async function generateSeoDescriptionWithAi(
  productTitle: string,
  productHtml: string,
  aiParams: AiParams,
): Promise<SeoDescriptionResult> {
  const provider = detectProvider(aiParams.url, aiParams.provider);
  const prompt =
    `You are an SEO expert. Create a single 150-160 character meta description for the following product.\n` +
    `Product title: ${productTitle}\n` +
    `Product description (HTML): ${productHtml}\n` +
    `Return ONLY the description, no quotes, no HTML.`;

  // Re-use existing low-level callers
  const res = provider === "anthropic"
    ? await callAnthropicApi(prompt, "en", aiParams, false, { maxTokens: 64 })
    : await callOpenAiCompatibleApi(prompt, "en", aiParams, false, { maxTokens: 64 });

  if (!res.success) return { success: false, error: res.error };
  const desc = res.content?.trim().slice(0, 160);
  return { success: true, description: desc };
}
```

2. **Export the helper**
```typescript
// ai-client.ts
export { generateSeoDescriptionWithAi };
```

3. **Consume in UI**
```typescript
import { useAiCredentials } from "@/hooks/useAiCredentials";
import { generateSeoDescriptionWithAi } from "@/utils/ai-client";

function SeoGenerator({ title, html }: { title: string; html: string }) {
  const { data: creds } = useAiCredentials();
  const [desc, setDesc] = useState<string>();

  const generate = async () => {
    if (!creds) return;
    const res = await generateSeoDescriptionWithAi(title, html, creds);
    if (res.success) setDesc(res.description);
  };

  return (
    <AuthenticationGuardWithPermission permission="ai:api">
      <Button onPress={generate}>Generate SEO</Button>
      {desc && <Textarea value={desc} readOnly />}
    </AuthenticationGuardWithPermission>
  );
}
```

4. **Done** – no backend changes required. The new feature automatically inherits key rotation, provider abstraction, and permission gating.
