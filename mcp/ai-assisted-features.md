## Architecture
The AI-assisted features in our application run entirely in the browser, with no server-side inference. This design decision has significant security implications, as sensitive AI credentials are fetched by the client and used to make direct requests to the AI provider. To mitigate potential risks, we use API key rotation and ensure that all AI-related logic is isolated within the `ai-client.ts` module.

## Backend
The backend provides a single endpoint, `GET /v1/ai/parameters`, which returns the AI configuration parameters. This endpoint requires the `ai:api` Auth0 permission, enforced by the `aiAccessOnly` middleware. The response contains the following properties:
```typescript
{
  "apiKey": "string",
  "model": "string",
  "url": "string"
}
```
The `apiKey` is randomly chosen from a pool of keys provided in the `AI_API_KEY` environment variable. If any of the required environment variables (`AI_API_KEY`, `AI_MODEL`, or `AI_API_URL`) are missing, the endpoint returns a `503` error.

## ai-client.ts
The `ai-client.ts` module is the central location for all AI-related logic. It exports the `AiParams` interface, which defines the structure of the AI configuration parameters:
```typescript
export interface AiParams {
  apiKey: string;
  model: string;
  url: string;
  provider?: "openai" | "groq" | "anthropic" | "auto";
}
```
The `provider` field is auto-detected from the `url` field, with the following logic:
* If the `url` contains "anthropic", the provider is set to "anthropic".
* If the `url` contains "groq", the provider is set to "groq".
* Otherwise, the provider defaults to "openai".

## Gating AI Features
To gate AI features in your UI, use the `AuthenticationGuardWithPermission` component with the `permission="ai:api"` prop, or check the `hasPermission("ai:api")` function from the `useSecuredApi` hook.

## Adding a New AI Use Case
To add a new AI feature, follow these steps:

1. Add a new typed helper function to the `ai-client.ts` module, following the `AiParams` interface.
2. Fetch the AI credentials from the `GET /v1/ai/parameters` endpoint.
3. Pass the credentials to your new helper function.
4. Use the `AiParams` interface to define the input parameters for your function.
5. Implement the logic for your new AI feature, using the `AiParams` object to make requests to the AI provider.

Example:
```typescript
export async function summarizeTextWithAi(
  text: string,
  aiParams: AiParams,
): Promise<SummarizationResult> {
  // Implement summarization logic using AiParams
}

// Usage
const text = "This is a long piece of text.";
const aiParams: AiParams = {
  apiKey: "YOUR_API_KEY",
  model: "YOUR_MODEL",
  url: "https://api.openai.com/v1",
};

const result = await summarizeTextWithAi(text, aiParams);
if (result.success) {
  console.log(`Summarized text: ${result.summary}`);
} else {
  console.error(`Error: ${result.error}`);
}
```
