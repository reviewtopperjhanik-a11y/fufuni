## Architecture: Client-Side AI Inference

Fufuni utilizes a "Proxy-less AI" architecture. Unlike traditional backend-heavy frameworks, Fufuni does not proxy AI requests through the Cloudflare Worker. Instead, the Worker acts as a secure credential vault, and the browser (client-side) performs the actual inference.

This design offers several advantages:
1.  **Worker Efficiency**: Backend subrequest limits and CPU time are preserved for database and business logic.
2.  **Streaming & Timeouts**: Long-running completions or streaming responses are handled directly by the browser, avoiding the 30-second execution limit of standard Workers.
3.  **Cost Control**: The client fetches credentials once per session, and subsequent API calls are billed directly to the provider without intermediate egress costs.

```typescript
// apps/client/src/hooks/use-ai-config.ts
import { useQuery } from '@tanstack/react-query';
import { api } from '@/lib/api';

/**
 * Hook to fetch ephemeral AI credentials for the current session.
 * Requires the 'ai:api' permission.
 */
export function useAiConfig(provider?: string) {
  return useQuery({
    queryKey: ['ai-parameters', provider],
    queryFn: async () => {
      const res = await api.admin.ai.parameters.$get({
        query: { provider }
      });
      if (!res.ok) throw new Error('AI not configured');
      return res.json();
    },
    staleTime: 1000 * 60 * 5, // Cache for 5 minutes
  });
}
```

## Credential Storage and Encryption

AI settings (API keys, model IDs, endpoints) are stored in a highly secure manner. Rather than plain-text environment variables, Fufuni uses an encrypted JSON blob stored in the `KV_CACHE` under the key `ai:config`.

### Encryption Logic
The configuration is encrypted using the `CRYPTOKEN` Wrangler secret. The format is compatible with OpenSSL's AES-256-CBC implementation, using PBKDF2 for key derivation.

```bash
# How to encrypt the configuration for Fufuni
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"YOUR_CRYPTOKEN_SECRET"
```

### The `ai-enc.ts` Library
This utility handles the decryption inside the Worker using the Web Crypto API, ensuring zero dependencies on Node.js-specific modules.

```typescript
// Example of how the backend decrypts config at runtime
import { decryptAiConfig } from '../lib/ai-enc';

const encryptedConfig = await env.KV_CACHE.get('ai:config');
if (encryptedConfig && env.CRYPTOKEN) {
  const config = await decryptAiConfig(encryptedConfig, env.CRYPTOKEN);
  console.log('Available providers:', Object.keys(config.providers));
}
```

## Secure Parameter Retrieval

The endpoint `GET /v1/ai/parameters` is the bridge between the secure vault and the client. It is protected by the `aiAccessOnly` middleware, ensuring only authorized staff can access the keys.

The backend performs several logic steps:
1.  **Priority Selection**: It selects the model with the lowest `priority` value (where 1 is highest).
2.  **Key Rotation**: It randomly selects a non-expired key from the provider's pool for load balancing.
3.  **Fallback**: If no encrypted config is found, it falls back to legacy `AI_API_KEY`, `AI_MODEL`, and `AI_API_URL` environment variables.

### Endpoint Definition
```typescript
// apps/merchant/src/routes/ai.ts
const aiParamsRoute = createRoute({
  method: 'get',
  path: '/parameters',
  summary: 'Retrieve AI configuration for the client',
  security: [{ bearerAuth: ['ai:api'] }],
  middleware: [aiAccessOnly] as const,
  responses: {
    200: {
      content: { 'application/json': { schema: AiParamsResponse } },
      description: 'Decrypted API key, model, and URL',
    },
  },
});
```

## Workflow: Product Auto-Translation

When an admin creates a product, they can fill the base language (usually `en-US`) and use the "Auto-translate" feature to populate other locales.

1.  **Trigger**: Admin clicks the "Translate all" button in the Product Form.
2.  **Credential Fetch**: The UI calls `GET /v1/ai/parameters`.
3.  **Inference**: For every target locale defined in the store settings, `translateWithAi` is called.
4.  **UI Update**: The localized fields (Name, Description) are pre-filled with the AI output.
5.  **Review**: The admin can manually tweak the AI-generated text before saving the product.

### Implementation Example
```typescript
async function handleAutoTranslate(targetLocales: string[]) {
  const { apiKey, model, url } = await fetchAiParams();
  
  for (const locale of targetLocales) {
    const translatedName = await translateWithAi(sourceName, locale, { apiKey, model, url }, false);
    const translatedDesc = await translateWithAi(sourceDesc, locale, { apiKey, model, url }, true);
    
    setLocaleData(locale, {
      name: translatedName.content,
      description: translatedDesc.content
    });
  }
}
```

## Workflow: Review Moderation

The Review Moderation workflow helps admins process large volumes of feedback efficiently.

1.  **Display**: When the admin opens the "Pending Reviews" dashboard, the UI fetches AI parameters.
2.  **Batch Analysis**: The `analyzeReviewsBatchWithAi` function is called with a concurrency limit of 5 to avoid browser rate-limiting.
3.  **Visualization**:
    *   **Approve recommendation**: The "Approve" button is highlighted in green.
    *   **Reject recommendation**: The "Reject" button is highlighted in red, and the AI's reason (e.g., "Contains profanity") is displayed as a tooltip.
4.  **Final Action**: The admin makes the final decision; AI never auto-publishes content.

## Graceful Degradation

Fufuni is designed to function fully without AI. Features degrade gracefully:

| Feature | Behavior when AI is missing/unconfigured |
| :--- | :--- |
| **Product Form** | The "Auto-translate" buttons are hidden or disabled. |
| **Review Moderation** | AI recommendations and reasons are hidden; buttons remain neutral. |
| **Email Templates** | "Translate to all" feature is removed; manual translation is still possible. |
| **API Endpoint** | `GET /parameters` returns a `503 Service Unavailable` with a descriptive error. |

```typescript
// UI Check for AI availability
{aiConfig.isSuccess ? (
  <Button onClick={onTranslate}>Auto-translate with AI</Button>
) : (
  <p className="text-tiny text-default-400">AI translation unavailable</p>
)}
```
