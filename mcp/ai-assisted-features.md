## AI Architecture and Browser-Side Inference

Fufuni adopts a "Client-Side Inference" architecture for all AI-assisted features. Unlike traditional architectures that proxy LLM requests through a backend server, Fufuni workers only serve as a secure credential delivery mechanism. The actual inference—sending prompts to providers like OpenAI, Groq, or Anthropic—happens directly in the user's browser.

This approach offers several advantages:
1.  **Worker Performance**: Keeps Cloudflare Worker execution time low, avoiding timeouts during long LLM generations.
2.  **Scalability**: Offloads the networking and data processing overhead of large LLM responses to the client.
3.  **Cost Control**: Prevents double-billing for bandwidth and reduces server-side compute requirements.

### Security Implications
Because API keys are delivered to the browser, they are technically visible in the Network tab. To mitigate risks, Fufuni uses:
-   **Strict Gating**: Credentials are only accessible to authenticated users with the `ai:api` permission.
-   **Short-Lived Context**: Keys are fetched just-in-time when an AI action is triggered.
-   **Provider-Level Restrictions**: It is strongly recommended to use scoped API keys (restricted to specific models) and set hard usage limits at the provider level.

```typescript
// Example: How the frontend retrieves temporary credentials
import { useSecuredApi } from "@/hooks/use-secured-api";

async function getAiCredentials(provider?: string) {
  const api = useSecuredApi();
  const query = provider ? `?provider=${provider}` : "";
  const response = await api.get<{ apiKey: string; model: string; url: string }>(
    `/v1/ai/parameters${query}`
  );
  return response.data;
}
```

## Backend: The AI Parameters Endpoint

The backend provides a single source of truth for AI configuration via `GET /v1/ai/parameters`. This route is managed in `apps/merchant/src/routes/ai.ts`.

### Logic and Selection
1.  **Permission Check**: The route uses `aiAccessOnly` middleware, requiring the `ai:api` Auth0 permission.
2.  **Config Loading**: It attempts to load an encrypted configuration from Cloudflare KV (`KV_CACHE` key `ai:config`).
3.  **Fallback**: if KV is empty, it falls back to environment variables (`AI_API_KEY`, `AI_MODEL`, `AI_API_URL`).
4.  **Priority Selection**: It uses `selectModels()` from `ai-enc.ts` to find the highest-priority model (Priority `1` is best).
5.  **Key Rotation**: From the selected provider, it filters out keys marked as `expired` and picks one at random for uniform load balancing.

```typescript
// apps/merchant/src/routes/ai.ts snippet
adminApp.openapi(aiParamsRoute, async (c) => {
  const config = await loadConfig(c.env);
  if (config) {
    // Select candidates sorted by priority (1 = highest/best)
    const candidates = selectModels(config, {});
    
    for (const { provider, model } of candidates) {
      const validKeys = provider.keys.filter(k => k.type !== 'expired');
      if (validKeys.length === 0) continue;

      const keyObj = validKeys[Math.floor(Math.random() * validKeys.length)];
      return c.json({
        apiKey: keyObj.key,
        model: model.id,
        url: provider.endpoint,
      }, 200);
    }
  }
  // ... fallback to env vars ...
});
```

## AI Configuration and Encryption

Fufuni uses an encrypted JSON format to store multiple AI providers and keys securely. This allows rotating keys or changing models without redeploying the worker code.

### The ai.json Structure
The source configuration contains providers, their endpoints, model priorities, and key tiers.

```json
{
  "version": 1,
  "providers": {
    "groq": {
      "protocol": "openai",
      "endpoint": "https://api.groq.com/openai/v1",
      "keys": [
        { "key": "gsk_...", "owner": "admin", "type": "paid" },
        { "key": "gsk_old", "type": "expired" }
      ],
      "models": [
        { "id": "llama-3.3-70b-versatile", "priority": 1, "contextWindow": 128000 }
      ]
    },
    "anthropic": {
      "protocol": "anthropic",
      "endpoint": "https://api.anthropic.com/v1",
      "keys": [
        { "key": "sk-ant-...", "type": "premium" }
      ],
      "models": [
        { "id": "claude-3-5-sonnet-20241022", "priority": 2, "contextWindow": 200000 }
      ]
    }
  }
}
```

### Encryption Format
The file is encrypted using OpenSSL-compatible AES-256-CBC with PBKDF2. The `CRYPTOKEN` environment variable serves as the master decryption key.

**Command to encrypt:**
```bash
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"$CRYPTOKEN"
```

The worker decrypts this content in-memory using the Web Crypto API, ensuring keys never touch the persistent disk in plaintext.

## Selection Logic and Metadata (ai-enc.ts)

The `ai-enc.ts` utility library handles the complex logic of finding the right model and managing token budgets.

### Key Tiering
Keys are tagged with a `AiKeyTier`:
-   `expired`: Never selected by the backend.
-   `free`: Subject to lower rate limits.
-   `paid`/`premium`/`unlimited`: Higher priority or higher quota usage.

### Model Discovery Helpers
`ai-enc.ts` provides functions to navigate the config:
-   `findModelById(config, modelId)`: Finds a model implementation across all providers (e.g., searching for "gpt-4o" in both OpenAI and Azure).
-   `getModelBudget(modelId, ...)`: Returns `maxOutputTokens` and `maxSourceCharsTotal`. It uses `KNOWN_MODEL_SPECS` for models like Claude and GPT-4 to calculate how many characters can fit in the context window safely.

```typescript
import { getModelBudget } from '../lib/ai-enc';

// Calculate how much text we can send to Claude 3.5 Sonnet
const budget = getModelBudget('claude-3-5-sonnet-20241022');
console.log(`Max output: ${budget.maxOutputTokens}`);
console.log(`Available source space: ${budget.maxSourceCharsTotal} characters`);
```

## The Client-Side AI Utility (ai-client.ts)

All frontend AI calls must go through `apps/client/src/utils/ai-client.ts`. This module centralizes provider abstraction and prompt engineering.

### Provider Auto-Detection
The client detects the protocol based on the `url` provided by the backend:
-   `anthropic` in URL → Uses Anthropic Messages API.
-   `groq` in URL → Uses OpenAI-compatible API (Chat Completions).
-   Default → OpenAI-compatible.

### Core Functions
1.  **`analyzeReviewWithAi`**: Moderates reviews (approve/reject).
2.  **`analyzeReviewsBatchWithAi`**: Parallel moderation (concurrency limit: 5).
3.  **`translateWithAi`**: Handles HTML or plain text translation while preserving e-commerce tokens (e.g., `TMPLVAR0`).

```typescript
import { translateWithAi, type AiParams } from "@/utils/ai-client";

const params: AiParams = {
  apiKey: "...", 
  model: "gpt-4o",
  url: "https://api.openai.com/v1"
};

const result = await translateWithAi(
  "<h1>Hello World</h1>",
  "French",
  params,
  true // isHtml
);

if (result.success) {
  console.log(result.content); // "<h1>Bonjour le monde</h1>"
}
```

## Updating AI Keys and Models

When a key expires or you want to switch to a cheaper provider:

1.  **Edit `ai.json`**: Update the `keys` array or change `priority` values.
2.  **Encrypt**: Run the encryption command using the current `CRYPTOKEN`.
3.  **Deploy**:
    -   **Production**: Upload the contents of `ai.json.enc` to the Cloudflare KV `KV_CACHE` under the key `ai:config`. This can be done via the Merchant Dashboard AI settings or via `wrangler kv:key put`.
    -   **Development**: If using environment variables, update the `.dev.vars` file or the `wrangler.jsonc` bindings.

### Key Management Best Practices
-   **Always keep an 'expired' tag**: Do not delete old keys immediately; mark them as `type: "expired"` in `ai.json` for auditing.
-   **Priority 1 is King**: The system always tries to fulfill requests using models with priority `1`. Use higher numbers (2, 3) for expensive or slower fallbacks.
-   **Protocol Awareness**: Ensure the `protocol` field (`openai` vs `anthropic`) matches the endpoint, as the client uses different request shapes for each.
