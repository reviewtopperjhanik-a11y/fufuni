## AI-Assisted Features

### Architecture: Browser-Side Inference & Security

All AI inference in Fufuni happens **exclusively in the browser**.  
The backend never sees user prompts or model outputs; it only brokers credentials.

```typescript
// apps/client/src/hooks/useAiCredentials.ts
import { useAuth0 } from '@auth0/auth0-react';
import { AiParams } from '@/utils/ai-client';

export function useAiCredentials(): AiParams | undefined {
  const { getAccessTokenSilently } = useAuth0();

  const [aiParams, setAiParams] = useState<AiParams>();

  useEffect(() => {
    getAccessTokenSilently({
      authorizationParams: { audience: 'https://api.fufuni.com' },
    })
      .then(async (token) => {
        const res = await fetch(`${import.meta.env.VITE_API_URL}/v1/ai/parameters`, {
          headers: { Authorization: `Bearer ${token}` },
        });
        if (!res.ok) throw new Error('AI not configured');
        const json = await res.json();
        setAiParams(json);
      })
      .catch(() => {
        /* silently ignore – UI hides AI buttons */
      });
  }, [getAccessTokenSilently]);

  return aiParams;
}
```

Security implications:
- **No prompt leakage**: sensitive product data never transits the backend.  
- **Rate-limit distribution**: backend rotates keys client-side, so each key is used by many browsers but never exposed in logs.  
- **CSP**: `connect-src` must whitelist the AI provider domains (`api.openai.com`, `api.groq.com`, `api.anthropic.com`).  
- **No server-side billing**: costs are tied to the keys injected at deploy time, not user actions.

### Backend: `GET /v1/ai/parameters`

Route lives in `apps/merchant/src/routes/ai.ts` and is guarded by the `ai:api` Auth0 permission.

```typescript
// apps/merchant/src/routes/ai.ts (excerpt)
app.openapi(aiParamsRoute, async (c) => {
  const rawApiKey = c.env.AI_API_KEY;        // GitHub secret at deploy
  const model = c.env.AI_MODEL;
  const url = c.env.AI_API_URL;

  if (!rawApiKey || !model || !url)
    throw new ApiError('not_configured', 503, 'AI is not configured');

  const apiKeys = rawApiKey.split(',').map(k => k.trim()).filter(Boolean);
  const apiKey = apiKeys[Math.floor(Math.random() * apiKeys.length)];

  return c.json({ apiKey, model, url }, 200);
});
```

Response shape:
```json
{
  "apiKey": "sk-anthropic-...",
  "model": "claude-3-haiku-20240307",
  "url": "https://api.anthropic.com/v1"
}
```

Key rotation is random per request; add more keys (comma-separated) in GitHub secrets to increase quota.

### ai-client.ts: `AiParams` Interface & Provider Auto-Detection

```typescript
// apps/client/src/utils/ai-client.ts
export interface AiParams {
  apiKey: string;
  model: string;
  url: string;
  provider?: "openai" | "groq" | "anthropic" | "auto";
}
```

Auto-detection logic:
```typescript
function detectProvider(url: string, explicit?: string) {
  if (explicit && ["openai", "groq", "anthropic"].includes(explicit))
    return explicit as "openai" | "groq" | "anthropic";
  if (url.includes("anthropic")) return "anthropic";
  if (url.includes("groq")) return "groq";
  return "openai"; // default
}
```

Supported providers:
- **OpenAI** (`https://api.openai.com/v1`)  
- **Groq** (`https://api.groq.com/openai/v1`)  
- **Anthropic** (`https://api.anthropic.com/v1`)

```typescript

  aiParams: AiParams,
): Promise<ReviewAnalysisResult>
```

Usage example:
```typescript
// apps/client/src/components/ReviewModeration.tsx
import { analyzeReviewWithAi } from '@/utils/ai-client';

async function moderate(review: ReviewInput) {
  const aiParams = await fetchAiParams(); // from useAiCredentials()
  const res = await analyzeReviewWithAi(review, aiParams);

  if (res.success) {
    console.log(res.recommendation, res.reason); // "approve" | "reject"
  } else {
    toast.error(res.error);
  }
}
```

```typescript
const html = `<p>Our <strong>premium</strong> cotton T-shirt...</p>`;
```

### Gating AI Features with Auth0 Permission

Wrap UI behind `AuthenticationGuardWithPermission`:

```tsx
// apps/client/src/pages/Reviews.tsx
import { AuthenticationGuardWithPermission } from '@/components/auth';

<AuthenticationGuardWithPermission permission="ai:api">
  <Button onClick={moderateAll}>Moderate with AI</Button>
</AuthenticationGuardWithPermission>
```

Or imperatively:
```typescript
import { hasPermission } from '@/utils/auth';

if (hasPermission(user, 'ai:api')) {
  showAiButton = true;
}
```


2. Fetch credentials in component:
```typescript
const aiParams = useAiCredentials();
if (!aiParams) return null; // AI disabled
```

3. Gate UI:

5. Deploy: add optional env vars to GitHub secrets; missing vars return `503` and UI hides gracefully.
