## Overview of the Checkout and UCP Flow
The Fufuni checkout and UCP (Universal Commerce Protocol) flow is designed to handle the complex process of creating a cart, managing the checkout session, and finalizing the order. This reference will outline the architecture, step-by-step flow, and key differences between guest and authenticated user checkout.

## Architecture: UCP Sessions and Stripe PaymentIntents
The `/ucp/v1/checkout-sessions` endpoint is the primary entry point for checkout. When a request is made to this endpoint, a CartSession and a Stripe PaymentIntent are created. The Stripe PaymentIntent represents the payment process, while the CartSession manages the intermediate state of the checkout.

The relationship between UCP sessions and Stripe PaymentIntents is as follows:
*   A UCP session is created with a unique `session_id`.
*   A Stripe PaymentIntent is created with a unique `payment_intent_id`.
*   The `payment_intent_id` is associated with the UCP session.

```typescript

  apiVersion: '2022-11-15',

    payment_method_types: ['card'],

            name: 'T-shirt',
          },
          unit_amount: 2000,
        },
        quantity: 1,
      },
    ],
    mode: 'payment',
    success_url: 'https://example.com/success',

  // Store the session_id and payment_intent_id in the ucp_checkout_sessions table
```

## Handling the Stripe Webhook (checkout.session.completed)
To handle the `checkout.session.completed` event, you need to set up a Stripe webhook endpoint that listens for this event. When the event is received, the endpoint should finalize the order by updating the order status and sending a confirmation email to the user.

```typescript
// Example of setting up a Stripe webhook endpoint
import Stripe from 'stripe';

const stripe = new Stripe('YOUR_STRIPE_SECRET_KEY', {
  apiVersion: '2022-11-15',
});

const webhookSecret = 'YOUR_STRIPE_WEBHOOK_SECRET';

const handleWebhook = async (req: Request, res: Response) => {
  const sig = req.headers['stripe-signature'];

  let event;

  try {
    event = stripe.webhooks.constructEvent(req.body, sig, webhookSecret);
  } catch (err) {
    return res.status(400).send(`Webhook Error: ${err.message}`);
  }

  if (event.type === 'checkout.session.completed') {
    // Finalize the order
    await finalizeOrder(event);
  }

  res.json({ received: true });
};
```
