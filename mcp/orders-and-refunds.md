## Orders and Refunds

### Order Lifecycle and Statuses

The order lifecycle in Fufuni involves several statuses that an order can go through, from initial creation to completion or cancellation. These statuses are defined in both the frontend and backend codebases. On the frontend, they are mapped to HeroUI Chip color variants in `apps/client/src/config/order-status.ts`, while on the backend, they are established through database migrations.

The 7 defined order statuses are:

1. **Pending**: Indicates that the order has been created but payment has not been confirmed.
2. **Paid**: Signifies that payment for the order has been successfully processed.
3. **Processing**: Shows that the order is being prepared for shipment.
4. **Shipped**: Confirms that the order has been dispatched to the customer.
5. **Delivered**: Marks the order as successfully received by the customer.
6. **Refunded**: Indicates that the order has been fully or partially refunded.
7. **Canceled**: Signifies that the order has been canceled, either by the customer or the merchant.

These statuses are crucial for tracking the progress of orders and for triggering specific actions, such as sending email notifications to customers.

### The Refund Process

Refunds in Fufuni are processed through Stripe, ensuring a secure and reliable transaction flow. The refund process involves the following steps:

1. **Request Refund**: A refund request is initiated through the Fufuni admin interface, specifying the order and amount to be refunded.
2. **Stripe Refund**: The Fufuni backend interacts with the Stripe API to process the refund. This involves creating a refund object in Stripe that corresponds to the payment intent associated with the order.
3. **Update Order Status**: After the refund is successfully processed by Stripe, the Fufuni backend updates the order status in the database to "Refunded" if the refund is full or keeps the current status if it's a partial refund.
4. **Notify Customer**: Optionally, Fufuni can send a notification email to the customer regarding the refund.
