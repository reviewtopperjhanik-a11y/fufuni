## Orders and Refunds Reference

The order lifecycle is a crucial part of any e-commerce platform, and Fufuni is no exception. This reference will cover the order lifecycle, available statuses, and the refund process, including how the backend interacts with Stripe.

### Order Lifecycle and Available Statuses

The order lifecycle in Fufuni consists of the following statuses, which are defined in both the frontend (`apps/client/src/config/order-status.ts`) and backend (`001-add-order-statuses.sql` migration):

* `pending`: Initial status when an order is created, indicating that payment has not been processed yet.
* `paid`: Order has been paid, but no further action has been taken.
* `processing`: Order is being processed, which may include preparing for shipment.
* `shipped`: Order has been shipped to the customer.
* `delivered`: Order has been delivered to the customer.
* `refunded`: Order has been refunded, either partially or fully.
* `canceled`: Order has been canceled.

These statuses are used to track the progress of an order and trigger specific actions or notifications.

### Refund Process

The refund process in Fufuni involves the following steps:

1. **Initiate Refund**: A refund is initiated through the Fufuni backend API, which sends a request to Stripe to refund the order.
2. **Stripe Refund**: Stripe processes the refund and updates the payment status.
3. **Update Order Status**: After a successful refund, the Fufuni backend updates the order status to `refunded` and stores the refund details, including the Stripe refund ID and amount.

**Important**: Never modify the order status in the database directly without going through the Stripe API. This ensures that the refund is properly processed and recorded in both Stripe and Fufuni.

adminApp.openapi(refundOrder, async (c) => {
  const { orderId } = c.req.valid('param');
  const { amount_cents } = c.req.valid('json');

  const stripeSecretKey = c.get('auth').stripeSecretKey;
  if (!stripeSecretKey) throw ApiError.invalidRequest('Stripe not connected');

  const db = getDb(c.var.db);

  const [order] = await db.query<any>(`SELECT * FROM orders WHERE id = ?`, [orderId]);
  if (!order) throw ApiError.notFound('Order not found');
  if (order.status === 'refunded') throw ApiError.conflict('Order already refunded');
  if (!order.stripe_payment_intent_id) {
    throw ApiError.invalidRequest('Cannot refund test orders (no Stripe payment)');
  }

  const stripe = new Stripe(stripeSecretKey);

  try {
    const refund = await stripe.refunds.create({
      payment_intent: order.stripe_payment_intent_id,
      amount: amount_cents,
    });

    await db.run(
      `INSERT INTO refunds (id, order_id, stripe_refund_id, amount_cents, status) VALUES (?, ?, ?, ?, ?)`,
      [uuid(), order.id, refund.id, refund.amount, refund.status ?? 'succeeded']
    );

    if (!amount_cents || amount_cents >= order.total_cents) {
      await db.run(`UPDATE orders SET status = 'refunded' WHERE id = ?`, [orderId]);

      const [refundedOrder] = await db.query<any>(`SELECT * FROM orders WHERE id = ?`, [orderId]);
      const orderItems = await db.query<any>(`SELECT * FROM order_items WHERE order_id = ?`, [orderId]);
      const formattedOrder = formatOrder(refundedOrder, orderItems);

      await dispatchWebhooks(c.var.db, c.executionCtx, 'order.refunded', {
        order: formattedOrder,
        refund: { stripe_refund_id: refund.id, amount_cents: refund.amount },
      });

      c.executionCtx.waitUntil(
        sendOrderStatusEmail(c.env, c.var.db, orderId, 'refunded').catch(() => {}),
      );
    }

    return c.json({ stripe_refund_id: refund.id, status: refund.status ?? 'succeeded' }, 200);
  } catch (e: any) {
    throw ApiError.stripeError(e.message || 'Refund failed');
  }
});
