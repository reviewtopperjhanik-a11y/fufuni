## AI Implementation Architecture

Fufuni adopts a "Secure Key Vault" architecture for AI features. Unlike traditional frameworks that proxy AI requests through the backend, Fufuni executes AI calls directly from the user's browser. The backend's role is strictly limited to managing, rotating, and decrypting credentials.

This approach offers several advantages:
1.  **Worker Efficiency**: Large payloads (like long product descriptions) do not consume Cloudflare Worker execution time or memory.
2.  **Latency**: Removing the middleman reduces request overhead.
3.  **Scalability**: The framework can handle thousands of concurrent AI operations without hitting backend bottlenecks.

```typescript
// Typical workflow in a React component
import { translateWithAi } from "@/utils/ai-client";

async function handleTranslation(content: string) {
  // 1. Fetch short-lived decrypted credentials from Fufuni Backend
  const res = await fetch("/api/v1/ai/parameters", {
    headers: { Authorization: `Bearer ${token}` }
  });
  const aiParams = await res.json();

  // 2. Call the AI Provider (OpenAI/Anthropic/Groq) directly from the browser
  const result = await translateWithAi(content, "fr-FR", aiParams);
  
  if (result.success) {
    console.log("Translated content:", result.content);
  }
}
```

## Credential Storage and Encryption

AI credentials (API keys, models, and endpoints) are never stored in plain text. They are managed via an encrypted configuration file or environment variables. Following the "Verified facts", these are stored in the `ai_settings` table (managed via `ai:config` in KV for the cache layer).

### The Encryption Layer
Fufuni uses `AES-256-CBC` with `PBKDF2` key derivation to protect credentials. The `CRYPTOKEN` (or `ENCRYPTION_KEY`) Wrangler secret is required to decrypt the configuration at runtime.

```typescript
// Example of how the framework decrypts the AI configuration in the Worker
import { decryptAiConfig, type AiConfig } from '../lib/ai-enc';

export async function loadAiConfig(env: any): Promise<AiConfig | null> {
  const encryptedPayload = await env.KV_CACHE.get('ai:config');
  if (!encryptedPayload || !env.CRYPTOKEN) return null;

  try {
    // Uses Web Crypto API internally for high performance
    return await decryptAiConfig(encryptedPayload, env.CRYPTOKEN);
  } catch (err) {
    console.error("AI Decryption failed:", err);
    return null;
  }
}
```

## AI Parameter Retrieval

The `GET /parameters` endpoint is the gateway for the frontend to access AI capabilities. It is restricted to users with `ai:api` permissions.

### Logic and Load Balancing
The endpoint does not just return a static key. It:
1.  Filters candidates based on `priority` (1 is highest).
2.  Excludes keys marked as `expired`.
3.  Performs a random selection (uniform load-balancing) from the available key pool for the chosen model.

```typescript
// apps/merchant/src/routes/ai.ts implementation snippet
adminApp.openapi(aiParamsRoute, async (c) => {
  const config = await loadConfig(c.env);
  if (config) {
    const candidates = selectModels(config);
    for (const { provider, model } of candidates) {
      const validKeys = provider.keys.filter(k => k.type !== 'expired');
      if (validKeys.length === 0) continue;

      const keyObj = validKeys[Math.floor(Math.random() * validKeys.length)];
      return c.json({
        apiKey: keyObj.key,
        model: model.id,
        url: provider.endpoint,
      }, 200);
    }
  }
  throw new ApiError('not_configured', 503, 'AI not available');
});
```

## Review Moderation Workflow

Review moderation allows administrators to quickly filter spam or offensive content. The UI calls `analyzeReviewWithAi` before displaying moderation actions.

### Prompt Engineering
The system uses a strict JSON-only response format to ensure the frontend can parse the recommendation reliably. It evaluates the rating, title, body, and author name collectively.

## Auto-Translation Features

Fufuni uses AI to automate the localization of product catalogs. This workflow typically triggers during product creation or when adding new locales to the store.

### Workflow
1.  **Source Extraction**: The system takes the base language content (e.g., `en-US`).
2.  **Batch Processing**: It iterates through all target locales defined in the store settings.
3.  **Field Mapping**: It translates the `name`, `description`, and `meta_title` fields.
4.  **Placeholder Preservation**: Specifically for email templates, tokens like `TMPLVAR0` are strictly ignored by the AI to prevent breaking the template engine.

```typescript
async function translateProduct(product: any, targetLocales: string[], aiParams: any) {
  for (const locale of targetLocales) {
    const nameTranslation = await translateWithAi(product.name, locale, aiParams, false);
    const descTranslation = await translateWithAi(product.description, locale, aiParams, true);
    
    if (nameTranslation.success && descTranslation.success) {
      await saveTranslation(product.id, locale, {
        name: nameTranslation.content,
        description: descTranslation.content
      });
    }
  }
}
```

## Admin Configuration and Management

Administrators manage AI settings via the Merchant panel. Configuration is uploaded as a raw encrypted file (`ai.json.enc`).

### Updating Configuration
The `POST /v1/ai/config` endpoint allows developers to push a new encrypted config without redeploying the Worker code. This updates the `KV_CACHE` and clears the in-memory `_configCache` across Worker isolates.

## Graceful Degradation

AI features are treated as non-critical enhancements. The framework is designed to function fully even if AI is misconfigured or the provider is down.

| Feature | Behavior when AI is missing/fails |
| :--- | :--- |
| **Review Moderation** | The UI omits the "AI Recommendation" badge; admins moderate manually. |
| **Product Translation** | The "Auto-translate" button is hidden or disabled in the product form. |
| **Email Templates** | Fallback to the base language or manual translation fields. |
| **API Endpoints** | Return `503 Service Unavailable` with a clear `not_configured` error code. |

### Implementation of Degradation check
```typescript
// Client-side check for feature availability
const checkAiAvailability = async () => {
  try {
    const res = await fetch("/api/v1/ai/parameters");
    if (!res.ok) throw new Error();
    setAiEnabled(true);
  } catch {
    setAiEnabled(false); // Gracefully hide AI buttons
  }
};
```
