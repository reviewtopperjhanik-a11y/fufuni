## Execution and CLI Arguments

The Fufuni seed script is a standalone TypeScript utility located in `apps/merchant/scripts/seed.ts`. It interacts directly with the framework's REST API using an administrative API key. Because Fufuni utilizes SQLite via Durable Objects, the seed script is designed to be idempotent; however, it is recommended to run it against a fresh or recently initialized store.

To execute the script, you must provide the API URL (usually your local Cloudflare Worker address) and a valid Secret Key (`sk_...`) generated during the initial store setup.

```bash
# Basic usage targeting a local development server
npx tsx scripts/seed.ts http://localhost:8787 sk_live_your_admin_key_here

# Usage against a production or staging environment
npx tsx scripts/seed.ts https://api.yourstore.com sk_live_your_admin_key_here
```

The script performs a sequence of operations:
1.  **Regions & Taxes**: Configures currencies (EUR, USD, GBP), countries, and VAT rates.
2.  **Categories**: Builds the taxonomy tree.
3.  **Products**: Populates the catalog, generates variants, and sets inventory.
4.  **Orders**: Simulates customer transactions across different regions.
5.  **Reviews**: Seeds product feedback for delivered orders.

## Currency Conversion Logic

Fufuni handles multi-currency pricing at the variant level. The seed script calculates prices for USD and GBP based on a fixed exchange rate defined at the top of the file. This ensures that the demo data looks realistic across different regional storefronts.

The `convertCents` function avoids floating-point issues by rounding to the nearest integer cent.

```typescript
const EUR_TO_USD = 1.14;
const EUR_TO_GBP = 0.86;

/**
 * @param cents Base price in EUR
 * @param rate Exchange rate multiplier
 */
function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}

// Example usage within seedProducts loop:
const priceUsd = convertCents(v.price_cents, EUR_TO_USD);
await api(`/v1/products/${productId}/variants/${variantId}/prices`, {
  currency_id: usdCurrencyId,
  price_cents: priceUsd,
});
```

## Resilient API Communication with apiWithRetry

Since Cloudflare Workers and Durable Objects may impose rate limits (especially during heavy write operations like seeding), the script includes an `apiWithRetry` helper. This function detects "429 Too Many Requests" errors and performs exponential backoff.

### Implementing Custom Seed Logic

If you need to seed custom entities (like blog posts or store settings), use `apiWithRetry` to ensure the script doesn't crash during network congestion.

```typescript
async function seedBlogPosts() {
  console.log('📝 Seeding blog posts...');
  
  const posts = [
    { title: 'The Future of E-commerce', slug: 'future-ecommerce' },
    { title: 'Why SQLite on the Edge?', slug: 'sqlite-edge' }
  ];

  for (const post of posts) {
    try {
      // apiWithRetry(path, body, maxRetries)
      await apiWithRetry('/v1/cms/posts', post, 3);
      console.log(`   ✅ Seeded: ${post.title}`);
    } catch (error) {
      console.error(`   ❌ Failed to seed ${post.title}:`, error);
    }
  }
}
```

## Image Processing and WebP Embedding

To keep the seed script portable, Fufuni uses a sophisticated image pipeline. Images are either read from the `scripts/img` directory or retrieved from a base64 `image_map.ts`. The script then:
1.  Decodes the PNG or JPEG.
2.  Resizes the image using a Nearest-Neighbor algorithm (`nnsResize`) if it exceeds a `maxSide` threshold.
3.  Encodes the result into WebP format using `webp-wasm`.
4.  Uploads the result as a Data URI to the API.

### The toWebpDataUri Helper

This helper is essential for generating both high-resolution product images and low-resolution thumbnails.

```typescript
/**
 * Processes a source image and returns a WebP Data URI.
 */
async function generateProductAssets(fileName: string) {
  // Main product image (max 1200px)
  const imageUrl = await toWebpDataUri(fileName, 1200, 85);
  
  // Catalog thumbnail (max 400px)
  const thumbUrl = await toWebpDataUri(fileName, 400, 70);

  return { imageUrl, thumbUrl };
}
```

## Extending the Orchestrator

The `seed()` function is the main entry point. When adding new features to the framework, follow the pattern of creating a specialized helper (e.g., `seedPromotions`) and invoking it within the main `try-catch` block.

```typescript
async function seed() {
  console.log('🌱 Starting Fufuni Seed Process...');

  const regionData = await seedRegions();
  const categoryData = await seedCategories();
  
  // 1. Seed core catalog
  const productIds = await seedProducts(regionData, categoryData);

  // 2. Add your custom helper here
  await seedDiscounts(productIds);

  // 3. Finalize with orders and reviews
  await seedOrders(regionData);
  await seedReviews(productIds);

  console.log('✅ Seed complete.');
}

async function seedDiscounts(productIds: Record<string, string>) {
  console.log('🎟️ Seeding discount codes...');
  await api('/v1/discounts', {
    code: 'WELCOME20',
    percentage: 20,
    starts_at: new Date().toISOString(),
  });
}
```
