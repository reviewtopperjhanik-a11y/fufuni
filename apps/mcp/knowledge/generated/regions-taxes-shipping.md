## Regions and Geographic Groupings

Regions in Fufuni serve as the foundational configuration for localization, currency, and logic segregation. A region defines a collection of countries (identified by ISO 3166-1 alpha-2 codes) that share the same currency and tax/shipping rules.

### Data Model and Schema
The backend stores regions in the SQLite database managed by the Durable Object. Each region includes:
- `id`: A unique UUID.
- `name`: A descriptive name (e.g., "European Union", "North America").
- `country_codes`: A JSON-serialized array of strings (e.g., `["FR", "DE", "IT"]`).
- `currency`: The ISO 4217 code (e.g., "EUR").
- `is_default`: A boolean indicating if this region should be used when no other matches are found.

### CRUD Implementation
The `adminApp` handles region management. When creating or updating a region, the `country_codes` must be validated against a list of valid ISO codes.

## Tax Rates Management

Tax rates are region-specific and define how the checkout engine calculates the tax component of an order. Fufuni supports both inclusive (VAT-style) and exclusive (US Sales Tax-style) tax logic.

### Data Model
- `region_id`: Links the rate to a specific geographic group.
- `rate`: A decimal value between 0 and 1 (e.g., `0.20` for 20%).
- `label`: The display name used on invoices (e.g., "VAT", "GST", "Sales Tax").
- `is_inclusive`: A boolean. If `true`, the price stored in the product catalog already includes this tax.

## Calculation Logic: lib/tax.ts

The calculation engine differentiates between extracting tax from a gross price and adding tax to a net price. All monetary values are handled in **cents** (integers) to avoid floating-point errors.

### Tax Formulas
1.  **Inclusive Tax:** The price already contains the tax.
    -   `TaxAmount = GrossPrice * (Rate / (1 + Rate))`
2.  **Exclusive Tax:** The price is net; tax is added on top.
    -   `TaxAmount = NetPrice * Rate`

### Implementation
The `lib/tax.ts` file provides utility functions used during the cart calculation and checkout process.

```typescript
// apps/merchant/src/lib/tax.ts
import { ApiError } from '../types';

/**
 * Computes the tax amount for a given price.
 * @param price - Price in cents.
 * @param rate - Tax rate as a decimal (e.g., 0.20).
 * @param inclusive - Whether the tax is already included in the price.
 */
export function computeTax(price: number, rate: number, inclusive: boolean): number {
  if (inclusive) {
    // Formula: Price * Rate / (1 + Rate)
    // Example: 120 EUR total with 20% VAT -> 120 * (0.2 / 1.2) = 20 EUR tax
    return Math.round(price * (rate / (1 + rate)));
  } else {
    // Formula: Price * Rate
    // Example: 100 EUR net with 20% Tax -> 100 * 0.2 = 20 EUR tax
    return Math.round(price * rate);
  }
}

/**
 * Formats a tax amount for display based on currency.
 */
export function formatTaxAmount(amount: number, currency: string): string {
  return new Intl.NumberFormat('en-US', {
    style: 'currency',
    currency: currency,
  }).format(amount / 100);
}
```

## Shipping Zones and Methods

Shipping zones map one or more regions to a set of available shipping methods. This allows merchants to define different carriers and prices for "Domestic" vs. "International" regions.

### Data Model
- **Zone**:
  - `name`: Identifier (e.g., "Europe Standard").
  - `region_ids`: An array of UUIDs linking to the `regions` table.
- **Shipping Method**:
  - `carrier`: The provider (e.g., "FedEx", "DHL").
  - `service`: The service level (e.g., "Overnight", "Ground").
  - `price`: Base cost in cents.
  - `estimated_days`: Delivery timeframe.
  - `free_threshold`: The subtotal (in cents) at which this method becomes free (0 if always paid).

### Configuration Example
```typescript
// Example of an Admin payload for creating a shipping zone
const shippingZonePayload = {
  name: "EU Express",
  region_ids: ["region-uuid-1", "region-uuid-2"],
  methods: [
    {
      carrier: "UPS",
      service: "Express Saver",
      price: 1500, // 15.00 EUR
      estimated_days: 2,
      free_threshold: 10000 // Free shipping over 100.00 EUR
    }
  ]
};
```

## Calculation Logic: lib/shipping.ts

The `getShippingMethods` function is responsible for filtering and pricing methods based on the customer's current cart state.

### Method Resolution
1.  Identify the region associated with the cart.
2.  Find all shipping zones that include that `region_id`.
3.  Retrieve all methods for those zones.
4.  Apply the `free_threshold` logic: if `subtotal >= free_threshold`, set price to 0.
5.  Sort methods by price (cheapest first).

```typescript
// apps/merchant/src/lib/shipping.ts
import { Database } from '../db';

export interface ShippingMethod {
  id: string;
  carrier: string;
  service: string;
  price: number;
  estimated_days: number;
}

/**
 * Resolves eligible shipping methods for a specific region and subtotal.
 */
export async function getShippingMethods(
  db: Database, 
  regionId: string, 
  subtotalCents: number
): Promise<ShippingMethod[]> {
  const query = `
    SELECT sm.* FROM shipping_methods sm
    JOIN shipping_zones sz ON sm.zone_id = sz.id
    JOIN zone_regions zr ON sz.id = zr.zone_id
    WHERE zr.region_id = ?
  `;
  
  const methods = await db.query<any>(query, [regionId]);

  return methods.map(method => {
    const isFree = method.free_threshold > 0 && subtotalCents >= method.free_threshold;
    return {
      id: method.id,
      carrier: method.carrier,
      service: method.service,
      price: isFree ? 0 : method.price,
      estimated_days: method.estimated_days
    };
  }).sort((a, b) => a.price - b.price);
}
```

## Checkout Integration

The checkout process in Fufuni is reactive to the customer's shipping/billing address.

### Region Resolution
The framework determines the active region by looking up the billing address country code. This resolution happens as soon as the customer provides their address in the checkout flow.

1.  **Address Input**: User enters "France" (FR).
2.  **Lookup**: The system queries the `regions` table for a record where `country_codes` contains `"FR"`.
3.  **Fallback**: If no match is found, the region marked `is_default = 1` is selected.

### Auto-Selection of Shipping
To minimize friction, the framework automatically selects the most economical shipping option if the customer has not explicitly chosen one.

```typescript
// checkout.ts logic snippet
async function updateCartWithBestShipping(db: Database, cartId: string, regionId: string, subtotal: number) {
  const availableMethods = await getShippingMethods(db, regionId, subtotal);
  
  if (availableMethods.length > 0) {
    // getShippingMethods already returns them sorted by price ascending
    const cheapest = availableMethods[0];
    
    await db.run(
      'UPDATE carts SET shipping_method_id = ?, shipping_total_cents = ? WHERE id = ?',
      [cheapest.id, cheapest.price, cartId]
    );
  }
}
```
