## Regions and Geographic Mapping

Regions in Fufuni serve as the foundational grouping for localization, tax calculation, and shipping availability. Every cart and order is associated with a specific region, which dictates the currency and the applicable rules for that transaction.

### Data Model and CRUD

A Region represents a group of countries (identified by ISO 3166-1 alpha-2 codes) that share the same currency and tax/shipping logic. The `regions` table is the source of truth for these mappings.

### Country Mapping Logic

When a customer provides a billing address during checkout, Fufuni resolves the region by searching for the country code in the `country_codes` array of all active regions. If no match is found, the system falls back to the region marked `is_default: true`.

```typescript
async function resolveRegionByCountry(db: any, countryCode: string) {
  const regions = await db.query('SELECT * FROM regions');
  
  // Find region where countryCode exists in the JSON array
  let region = regions.find(r => JSON.parse(r.country_codes).includes(countryCode));
  
  // Fallback to default region
  if (!region) {
    region = regions.find(r => r.is_default === 1);
  }
  
  return region;
}
```

## Tax Rates Configuration

Tax rates in Fufuni are region-specific and can be configured as either inclusive (tax already in the price) or exclusive (tax added at checkout).

### Data Model

Each tax rate is linked to a `region_id`. The `rate` is stored as a decimal (e.g., `0.20` for 20% VAT).

- **id**: UUID
- **region_id**: Foreign key to regions
- **rate**: Decimal (0.0 to 1.0)
- **label**: Display string (e.g., "VAT", "Sales Tax")
- **is_inclusive**: Boolean (0 or 1 in SQLite)

### Management Endpoint

Admin users manage tax rates via the `/v1/tax-rates` endpoint.

## Tax Calculation Logic (`lib/tax.ts`)

The tax library handles the mathematical heavy lifting. Because Fufuni stores all prices in the smallest currency unit (cents), calculation must account for floating point precision and the inclusive/exclusive flag.

### Formulas

1.  **Inclusive Tax**: The tax is "backed out" of the gross price.
    *   *Formula*: `GrossPrice * rate / (1 + rate)`
    *   *Example*: A $120 item with 20% inclusive VAT. Tax = $120 * 0.2 / 1.2 = $20.
2.  **Exclusive Tax**: The tax is added on top of the net price.
    *   *Formula*: `NetPrice * rate`
    *   *Example*: A $100 item with 20% exclusive Sales Tax. Tax = $100 * 0.2 = $20.

### Implementation

```typescript
/**
 * Computes tax for a given price in cents.
 * @param priceCents - The price in cents
 * @param rate - The tax rate (e.g., 0.2 for 20%)
 * @param inclusive - Whether the price already includes the tax
 */
export function computeTax(priceCents: number, rate: number, inclusive: boolean): number {
  if (inclusive) {
    // Tax = Total - (Total / (1 + rate))
    return Math.round(priceCents * rate / (1 + rate));
  } else {
    // Tax = Price * rate
    return Math.round(priceCents * rate);
  }
}

/**
 * Formats a cent-based amount for display with its currency.
 */
export function formatTaxAmount(amount: number, currency: string): string {
  return new Intl.NumberFormat('en-US', {
    style: 'currency',
    currency: currency,
  }).format(amount / 100);
}
```

## Shipping Zones and Methods

## Shipping Method Selection (`lib/shipping.ts`)

The `getShippingMethods` function filters available methods based on the cart's region and subtotal. The core feature here is the `free_threshold_cents` logic.

### Free Shipping Logic

If the cart's subtotal is greater than or equal to the `free_threshold_cents` defined for a method, the price for that method is set to `0` for that specific checkout session.

```typescript
export interface ShippingMethod {
  id: string;
  carrier: string;
  service: string;
  price_cents: number;
  estimated_days: number;
}

/**
 * Retrieves eligible shipping methods for a region and subtotal.
 */
export async function getShippingMethods(
  db: any, 
  regionId: string, 
  subtotalCents: number
): Promise<ShippingMethod[]> {
  // Find zones that contain this regionId
  const zones = await db.query('SELECT * FROM shipping_zones');
  const eligibleZones = zones.filter(z => JSON.parse(z.region_ids).includes(regionId));
  
  if (eligibleZones.length === 0) return [];

  const zoneIds = eligibleZones.map(z => z.id);
  const methods = await db.query(
    `SELECT * FROM shipping_methods WHERE zone_id IN (${zoneIds.map(() => '?').join(',')})`,
    zoneIds
  );

  return methods.map(m => {
    let finalPrice = m.price_cents;
    
    // Apply free shipping threshold
    if (m.free_threshold_cents !== null && subtotalCents >= m.free_threshold_cents) {
      finalPrice = 0;
    }

    return {
      id: m.id,
      carrier: m.carrier,
      service: m.service,
      price_cents: finalPrice,
      estimated_days: m.estimated_days
    };
  }).sort((a, b) => a.price_cents - b.price_cents); // Sort by cheapest first
}
```

## Checkout Integration

The checkout process ties regions, taxes, and shipping together in a specific sequence:

### 1. Region Resolution
As soon as the user enters their billing address, the system resolves the `region_id`. This updates the cart's currency and triggers a recalculation of taxes.

### 2. Tax Calculation
The system identifies the tax rates linked to the resolved `region_id`. For each item in the cart, the tax is calculated using `computeTax`.

### 3. Shipping Auto-Selection
When shipping methods are fetched via `getShippingMethods`, the frontend or the backend checkout worker performs an auto-selection logic:
- If the customer has not manually selected a shipping method, the system automatically selects the method with the lowest `price_cents`.
- If a free shipping method is available (due to the subtotal reaching the threshold), it typically becomes the auto-selected default.

### 4. Final Total Calculation
The order total is calculated as:
`Subtotal (Net or Gross) + Shipping Price + Exclusive Tax Amount`. 
Note that Inclusive Tax is already present in the Subtotal and is simply reported as a line item rather than added.

```typescript
// Simplified checkout calculation logic
async function refreshCartTotals(db: any, cartId: string, countryCode: string) {
  const region = await resolveRegionByCountry(db, countryCode);
  const subtotal = await calculateSubtotal(db, cartId);
  
  // Get shipping
  const methods = await getShippingMethods(db, region.id, subtotal);
  const selectedMethod = methods[0]; // Auto-select cheapest
  
  // Get taxes
  const taxRates = await db.query('SELECT * FROM tax_rates WHERE region_id = ?', [region.id]);
  let totalTax = 0;
  
  for (const rate of taxRates) {
    totalTax += computeTax(subtotal, rate.rate, rate.is_inclusive === 1);
  }

  const shippingPrice = selectedMethod?.price_cents ?? 0;
  const total = subtotal + shippingPrice + (taxRates.some(r => r.is_inclusive === 0) ? totalTax : 0);

  return { subtotal, shippingPrice, totalTax, total, currency: region.currency };
}
```
