## Product Model and Image Structure

In the Fufuni framework, the `products` table stores core metadata, while media and variants are managed through a combination of JSON columns and related tables. Every product must have a base name (typically `en-US`), a reference to a category, and a base currency.

The `images` column in the `products` table is a JSON array of objects. This design allows for fast retrieval of product thumbnails without additional joins. The first image object where `isPrimary` is `true` is treated as the main thumbnail.

```typescript
import { z } from '@hono/zod-openapi';

/**
 * Image structure within the product.images JSON array
 */
export const ProductImageSchema = z.object({
  url: z.string().url().openapi({ example: 'https://cdn.fufuni.com/prod/shoe-01.jpg' }),
  alt: z.string().openapi({ example: 'Blue running shoe - side view' }),
  isPrimary: z.boolean().default(false).openapi({ description: 'If true, this is the main thumbnail' }),
});

export const ProductResponse = z.object({
  id: z.string().uuid(),
  category_id: z.string().uuid(),
  name: z.string().openapi({ description: 'Base name (usually en-US)' }),
  description: z.string().nullable(),
  base_currency: z.string().length(3).openapi({ example: 'USD' }),
  images: z.array(ProductImageSchema),
  created_at: z.string().datetime(),
  updated_at: z.string().datetime(),
}).openapi('Product');

export type Product = z.infer<typeof ProductResponse>;
```

## Category Tree and Hierarchy

Categories are structured as a tree using a `parent_id` column. A category with a `null` `parent_id` is a root category. Slugs must be unique within the same level of the hierarchy and are used for SEO-friendly URLs.

To create a nested category, you must provide the UUID of the parent. The frontend components (built with HeroUI) recursively render this structure to provide navigation menus.

```typescript
// Example: Creating a nested "Running Shoes" category under "Footwear"
// POST /v1/categories
const createCategory = async (db: D1Database, name: string, parentId: string | null) => {
  const id = crypto.randomUUID();
  const slug = name.toLowerCase().replace(/\s+/g, '-');
  
  await db.prepare(`
    INSERT INTO categories (id, parent_id, slug, name)
    VALUES (?, ?, ?, ?)
  `).bind(id, parentId, slug, name).run();
  
  return { id, slug };
};
```

## Localization and Fallback Logic

Fufuni uses a "Sidecar Table" strategy for localization. The `product_locales` and `category_locales` tables store translations. When a request is made with a specific `?locale=`, the system attempts to join with the locale table; if no record exists for that specific locale, it defaults to the value stored in the main `products` table (the `en-US` reference).

### Localization SQL Schema
```sql
CREATE TABLE product_locales (
  product_id TEXT NOT NULL,
  locale TEXT NOT NULL, -- e.g., 'fr-FR', 'ja-JP'
  name TEXT NOT NULL,
  description TEXT,
  PRIMARY KEY (product_id, locale),
  FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
);
```

### Fallback Implementation Example
```typescript
async function getLocalizedProduct(db: D1Database, id: string, locale: string) {
  const result = await db.prepare(`
    SELECT 
      p.id,
      COALESCE(pl.name, p.name) as name,
      COALESCE(pl.description, p.description) as description,
      p.base_currency,
      p.images
    FROM products p
    LEFT JOIN product_locales pl ON p.id = pl.product_id AND pl.locale = ?
    WHERE p.id = ?
  `).bind(locale, id).first();
  
  return result;
}
```

## Variant Management

Every product must have at least one variant. A variant represents a specific SKU that can be purchased. Variants handle inventory and specific pricing. The `attributes` column is a JSON object storing key-value pairs like size or color.

```typescript

  }),
});

// Endpoint: POST /v1/products/:id/variants
```

When a product has multiple variants, the frontend typically presents them as options (e.g., a dropdown for Size). If a variant's `stock_quantity` is 0, it should be marked as "Out of Stock" in the UI but remains visible unless explicitly hidden.

## Product Tags and Filtering

Tags enable many-to-many relationships between products and arbitrary labels. Unlike categories, tags are flat and are used primarily for collections or feature-based filtering. The API uses a join table `product_tags` and filters using `OR` logic when multiple tags are provided in the query string.

```typescript
/**
 * Logic for filtering products by multiple tags using OR logic.
 */
function buildTagFilter(tags: string[]): { sql: string; params: string[] } {
  const placeholders = tags.map(() => '?').join(',');
  return {
    sql: `EXISTS (
      SELECT 1 FROM product_tags pt 
      JOIN tags t ON pt.tag_id = t.id 
      WHERE pt.product_id = p.id AND t.slug IN (${placeholders})
    )`,
    params: tags
  };
}
```

## Image Array Management

The product image array is an ordered list. The order of objects in the JSON array determines the display order in the storefront gallery.

### Key Operations:
1.  **Adding an Image:** Append a new object to the `images` array in the `products` table.
2.  **Setting Primary:** Iterate through the array, set all `isPrimary` to `false`, then set the target image's `isPrimary` to `true`.
3.  **Reordering:** The client sends the entire array in the new desired order, and the backend performs a single `UPDATE` on the `images` column.

```typescript
/**
 * Updates the order of images for a product.
 */
async function reorderImages(db: D1Database, productId: string, newImages: any[]) {
  // Validate that all images have the required fields
  const validatedImages = z.array(ProductImageSchema).parse(newImages);
  
  await db.prepare(`
    UPDATE products 
    SET images = ?, updated_at = CURRENT_TIMESTAMP 
    WHERE id = ?
  `)
  .bind(JSON.stringify(validatedImages), productId)
  .run();
}
```

By storing images as JSON, Fufuni avoids the overhead of managing a separate `product_images` table for simple gallery operations, which is highly efficient on SQLite-based Durable Objects. For high-scale assets, the `url` typically points to a Cloudflare R2 bucket or an Image Transformation endpoint.
