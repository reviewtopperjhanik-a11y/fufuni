## What is the MCP Server?

The MCP server is a component within the Fufuni e-commerce framework that provides knowledge-base tools to AI assistants. It operates via Cloudflare Workers for production or stdio mode for local development with Claude Desktop.

## Directory Layout

The knowledge base source files are organized as follows:

- `apps/mcp/src/knowledge/topics/` – Contains one `.ts` file per topic, each exporting a `Topic` object.
- `apps/mcp/src/knowledge/generate.ts` – The generator script that processes topic files.
- `apps/mcp/src/knowledge/base.ts` – Shared types and utilities for topic files.

Generated output is written to `<repo-root>/mcp/` as `.md` files.

## Adding a New Topic

To add a new knowledge topic:

1. Create a new file at `apps/mcp/src/knowledge/topics/<topic-name>.ts`
2. Include the copyright header and implement the `Topic` interface

Example topic file (`apps/mcp/src/knowledge/topics/example.ts`):

```typescript
// Copyright (c) 2026 Ronan LE MEILLAT - SCTG Development / License: AGPL-3.0-or-later

import { Topic } from "../base.js";
import { BASE_SYSTEM, appendFacts } from "../base.js";

export default {
  name: "example",
  description: "Example knowledge topic for demonstration purposes",
  sources: ["packages/core/src/example.ts"],
  systemPrompt: BASE_SYSTEM,
  manualFacts: [],
  buildPrompt: (sources: string) => `
    ${appendFacts()}
    Based on the following sources:
    ${sources}

    Generate concise documentation about the example feature.`,
  maxSourceChars: 10000,
} satisfies Topic;
```

## Topic Interface Fields

Each topic must define these properties:

- `name` – Matches the filename without `.ts`
- `description` – One-sentence summary
- `sources` – Array of file paths from repository root
- `systemPrompt` – Base system instructions (typically `BASE_SYSTEM`)
- `manualFacts` – Array of verified facts to prepend
- `buildPrompt` – Function receiving concatenated source content
- `maxSourceChars` – Maximum source content length to process

## Generate Commands

Available generation commands:

- `npm run mcp:generate` – Dry run using cached responses where possible
- `npm run mcp:generate:force` – Forces regeneration of all topics
- `npm run mcp:auto` – Regenerates only modified topics and publishes (requires `AI_MODEL`, `AI_API_KEY`, `AI_API_URL`)
- `npm run mcp:auto:flash` – Uses Gemini-3 flash with encrypted config (requires `CRYPTOKEN`)

## Publishing Knowledge

The `gen-knowledge.ts` script (`apps/mcp/scripts/gen-knowledge.ts`) processes generated `.md` files from `<repo-root>/mcp/` to create:

- `knowledge.ts` – Runtime knowledge module
- `bm25-index.ts` – Search index
- `chunks.ts` – Content chunks
- `vectors.ts` – Vector embeddings

## Local Development

For Claude Desktop testing, run the MCP server in stdio mode:

```bash
npx tsx apps/mcp/src/stdio.ts
```

## Important Warning

Never edit `apps/mcp/src/knowledge.ts` directly – it is automatically generated from topic files. All knowledge updates must be made by adding or modifying topic files in `apps/mcp/src/knowledge/topics/`.
