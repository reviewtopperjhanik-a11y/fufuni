## MCP Server Overview
The **MCP (Modular Claude Protocol) server** provides structured knowledge-base tools to AI assistants. It runs as:
- A **Cloudflare Worker** (production)
- A **stdio server** (local development, compatible with Claude Desktop)

AI assistants query the MCP server via tool calls to fetch framework-specific documentation, code conventions, or verified facts. Each knowledge topic is a self-contained `.ts` file that defines:
1. **Source files** to analyze (e.g., `apps/backend/src/routes/*.ts`)
2. **System prompt** guiding the LLM’s output format
3. **Manual facts** (authoritative overrides)
4. **Build logic** to generate Markdown documentation

   export default {
     name: "my-new-topic",  // Must match filename (without .ts)
     description: "One-sentence summary of what this topic covers.",
     sources: [
       "apps/backend/src/routes/**/*.ts",  // Glob patterns from repo root

     systemPrompt: BASE_SYSTEM + `

## Topic Interface Fields
| Field          | Type                     | Purpose                                                                 |
|----------------|--------------------------|-------------------------------------------------------------------------|
| `name`         | `string`                 | Topic identifier (matches filename).                                    |
| `description`  | `string`                 | One-sentence summary (used in tool call descriptions).                  |
| `sources`      | `string[]`               | Glob patterns for source files (relative to repo root).                 |
| `systemPrompt` | `string`                 | LLM instructions (appended to `BASE_SYSTEM`).                           |
| `manualFacts`  | `string[]`               | Authoritative facts that override source analysis.                     |
| `buildPrompt`  | `(sources: string) => string` | Function returning the full LLM prompt (receives concatenated sources).|
| `maxSourceChars`| `number`               | Truncate concatenated sources to this length (default: `20000`).       |

**Example `buildPrompt`**:
```typescript
buildPrompt: (sources) => `
  Analyze these route handlers:
  \`\`\`typescript
  ${sources}
  \`\`\`
  Generate a table of all routes with:
  - Method (GET/POST/etc.)
  - Path
  - Zod input schema (if any)
  - Example request/response
`,
```

## Generate Commands
| Command                     | Purpose                                                                 | Example                          |
|-----------------------------|-------------------------------------------------------------------------|----------------------------------|
| `mcp:generate`              | Dry-run (uses cache; skips unchanged topics).                          | `npm run mcp:generate`           |
| `mcp:generate:force`        | Force-regenerate all topics (ignores cache).                           | `npm run mcp:generate:force`     |
| `mcp:auto`                  | Generate + publish modified topics (requires AI env vars).            | `AI_MODEL=gpt-4 npm run mcp:auto` |
| `mcp:auto:flash`            | Use Gemini-3 flash with encrypted config (requires `CRYPTOKEN`).       | `CRYPTOKEN=x npm run mcp:auto:flash` |

**Environment Variables for `mcp:auto`**:
```bash
export AI_MODEL="gpt-4-turbo"       # Model name
export AI_API_KEY="sk-..."           # API key
export AI_API_URL="https://..."      # API endpoint
```

## Publishing Knowledge to Runtime
The **`gen-knowledge.ts`** script (apps/mcp/scripts/) processes generated `.md` files into runtime modules:
1. **Input**: `<repo-root>/mcp/*.md` (one file per topic)
2. **Output**:
   - `apps/mcp/src/knowledge.ts` (auto-generated; exports `KNOWLEDGE_BASE`)
   - `apps/mcp/src/bm25-index.ts` (search index)
   - `apps/mcp/src/chunks.ts` (text chunks for embeddings)
   - `apps/mcp/src/vectors.ts` (vector embeddings)

**Regenerate runtime knowledge**:
```bash
npx tsx apps/mcp/scripts/gen-knowledge.ts
```

## Local Stdio Mode (Claude Desktop)
To test the MCP server locally with Claude Desktop:
1. **Start the stdio server**:
   ```bash
   npx tsx apps/mcp/src/stdio.ts
   ```
2. **Configure Claude Desktop**:
   - Add a new **MCP tool** in Claude’s settings.
   - Set the tool URL to `http://localhost:3000` (default stdio port).
   - Use the same `name` and `description` as defined in your topic files.

**Example stdio output**:
```
[MCP] Listening on stdin/stdout (Ctrl+C to exit)
[MCP] Loaded 42 topics from apps/mcp/knowledge/topics/
[MCP] Ready for tool calls.
```

**⚠️ `apps/mcp/src/knowledge.ts` is auto-generated.**

2. Run `npm run mcp:generate:force`.
