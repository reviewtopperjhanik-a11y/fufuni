## Customer Authentication Flow

The `customerAuthMiddleware` handles JWT validation and customer resolution. It runs on all `/v1/me/*` routes:

### JWT Validation Rules
1. Requires `Authorization: Bearer <token>` header
2. Rejects API keys (tokens starting with `pk_`/`sk_`)
3. Verifies Auth0-issued JWTs using `verifyAuth0Jwt()` with:
   - Domain from `c.env.AUTH0_DOMAIN`
   - Audience from `c.env.AUTH0_AUDIENCE`
4. Extracts claims: `sub`, `email`, `name`, `permissions`

```typescript
// Example middleware usage in routes/me.ts
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', customerAuthMiddleware);
```

### Auth Context Storage
On success, stores in `c.get('auth')`:
```typescript
{
  role: 'customer',
  sub: 'auth0|abc123',       // Auth0 user identifier
  email: 'user@example.com', // May be undefined
  permissions: string[],     // Empty for most customers
  userMetadata: Record<string, any> // From JWT
}
```

## Auto-Creation on First Access

The `resolveCustomer()` function (called by middleware) implements get-or-create logic:

1. **Primary lookup**: Finds customer by `auth_provider_id` (Auth0 sub)
2. **Fallback lookup**: If not found, tries email match (legacy accounts)
3. **Auto-creation**: If neither exists, inserts new customer row

```typescript
// Key parts of resolveCustomer()
async function resolveCustomer(db: any, jwtSub: string, email?: string, name?: string) {
  // 1. Try Auth0 sub lookup
  let customer = await db.query(
    `SELECT * FROM customers WHERE auth_provider_id = ? AND auth_provider = 'auth0' LIMIT 1`,
    [jwtSub]
  );

  // 2. Fallback to email lookup if no sub match
  if (email && customer.length === 0) {
    const emailResult = await db.query(
      `SELECT * FROM customers WHERE email = ? LIMIT 1`,
      [email.toLowerCase()]
    );
    if (emailResult.length > 0) {
      // Link existing customer to Auth0 sub
      await db.run(/* UPDATE query */);
      return emailResult[0];
    }
  }

  // 3. Create new customer if none found
  if (customer.length === 0) {
    const newId = uuid();
    await db.run(
      `INSERT INTO customers (id, email, auth_provider, auth_provider_id, created_at, updated_at)
       VALUES (?, ?, 'auth0', ?, ?, ?)`,
      [newId, email?.toLowerCase(), jwtSub, now(), now()]
    );
    return { id: newId, email: email?.toLowerCase(), /* ... */ };
  }

  return customer[0];
}
```
