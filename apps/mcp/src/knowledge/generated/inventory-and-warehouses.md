## Inventory & Warehouses Reference

### Data Model

**inventory Table** (legacy)
```sql
CREATE TABLE inventory (
  sku TEXT PRIMARY KEY,
  on_hand INTEGER NOT NULL DEFAULT 0,
  reserved INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT
);
```

**warehouse_inventory Table**
```sql
CREATE TABLE warehouse_inventory (
  id TEXT PRIMARY KEY,
  sku TEXT NOT NULL,
  warehouse_id TEXT NOT NULL,
  on_hand INTEGER NOT NULL DEFAULT 0,
  reserved INTEGER NOT NULL DEFAULT 0,
  updated_at TEXT,
  FOREIGN KEY (sku) REFERENCES variants(sku),
  FOREIGN KEY (warehouse_id) REFERENCES warehouses(id)
);
```

**warehouses Table**
```sql
CREATE TABLE warehouses (
  id TEXT PRIMARY KEY,
  display_name TEXT NOT NULL,
  priority INTEGER NOT NULL DEFAULT 0,
  -- Additional address fields
);
```

### Transaction Safety

All inventory mutations are wrapped in Durable Object transactions to prevent race conditions. This ensures atomic operations during high-concurrency scenarios like flash sales.

Example transaction in `reserveInventory`:
```typescript
const result = await db.run(
  `UPDATE warehouse_inventory
   SET reserved = reserved + ?,
       updated_at = ?
   WHERE sku = ?
   AND (on_hand - reserved) >= ?`,
  [qty, timestamp, sku, qty]
);
```

### Core Inventory Functions

**getAvailableQty(db, sku)**
Returns available stock (on_hand - reserved).

```typescript
import { getAvailableQty } from '../lib/inventory';

const available = await getAvailableQty(db, 'PROD-001');
console.log(`Available stock: ${available}`);
```

**reserveInventory(db, sku, qty)**
Reserves stock during checkout. Throws `ApiError.insufficientInventory` if unavailable.

```typescript
try {
  await reserveInventory(db, 'PROD-001', 2);
} catch (error) {
  if (error instanceof ApiError) {
    console.error('Insufficient stock');
  }
}
```

**releaseReservation(db, sku, qty)**
Releases reserved stock on order cancellation.

```typescript
await releaseReservation(db, 'PROD-001', 1);
```

**commitSale(db, sku, qty)**
Deducts stock after successful payment.

```typescript
await commitSale(db, 'PROD-001', 2);
```

### Checkout Flow

1. **Cart Checkout**: Reserve stock
   ```typescript
   await reserveInventory(db, 'PROD-001', 1);
   ```
2. **Payment Success**: Commit sale
   ```typescript
   await commitSale(db, 'PROD-001', 1);
   ```
3. **Payment Failure**: Release reservation
   ```typescript
   await releaseReservation(db, 'PROD-001', 1);
   ```

### Low-Stock Webhook

Triggered when stock drops below configurable threshold (default: 10 units) after `commitSale`.

Event payload:
```typescript
{
  sku: 'PROD-001',
  current_stock: 8,
  threshold: 10,
  warehouse_id: 'WH-1' // Optional for multi-warehouse
}
```

### Multi-Warehouse Logic

Stock is aggregated across warehouses using priority-based allocation:
```sql
SELECT warehouse_id
FROM warehouse_inventory
WHERE sku = 'PROD-001'
ORDER BY (on_hand - reserved) DESC
LIMIT 1
```

The highest-priority warehouse (lowest `priority` value) is used as default for new products.
