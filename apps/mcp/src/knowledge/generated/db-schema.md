## Database Schema Reference

### Durable Object Pattern
Fufuni uses Cloudflare Durable Objects as a per-merchant SQLite database container. The schema is defined in a **static DDL string** (`SCHEMA`) that creates all tables, indexes, and constraints. At runtime:

1. **Initialization**: The `ensureInitialized()` method splits `SCHEMA` by semicolons and executes each statement sequentially.
2. **Migrations**: After applying the base schema, the method checks the `migrations` table for applied migrations. Any unapplied migrations (defined in an inline array) are executed, and their names are recorded in the `migrations` table.
3. **Synchronous Execution**: All SQL operations (`this.sql.exec()`) are synchronous within the Durable Object, but calls from Workers are async RPC via the `MERCHANT` binding.
