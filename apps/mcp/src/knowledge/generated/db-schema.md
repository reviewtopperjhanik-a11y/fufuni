## Durable Object SQLite Architecture

Fufuni leverages Cloudflare Durable Objects with built-in SQLite storage to provide consistent, transactional data management for each merchant. Unlike traditional stateless Workers, the `MerchantDO` maintains a persistent SQLite database file that survives between requests.

### Initialization and Migrations
The database schema is managed through a "Hybrid Idempotent" approach. When the Durable Object starts or receives its first request, it calls `ensureInitialized()`. This method performs two primary actions:
1. **Schema DDL**: It executes a large `SCHEMA` constant containing `CREATE TABLE IF NOT EXISTS` statements. This ensures the foundational structure exists.
2. **Runtime Migrations**: It checks a `migrations` table within the SQLite database to see which incremental updates (e.g., `ALTER TABLE` commands) have been applied. If a migration name is missing from the table, the DO executes the SQL and records the success.

```typescript
// Example of how the framework interacts with the DO via the getDb helper
import { getDb } from '@fufuni/core';

export async function getProductWithVariants(c: Context, productId: string) {
  const db = getDb(c.var.db);
  
  // Queries are raw SQL strings passed to the DO over RPC
  const product = await db.query(`
    SELECT p.*, v.id as variant_id, v.sku, v.price_cents
    FROM products p
    JOIN variants v ON p.id = v.product_id
    WHERE p.id = ?
  `, [productId]);

  return product;
}
```

// Example: Deducting tokens for an AI generation request
async function consumeTokens(c: Context, customerId: string, units: number) {
  const db = getDb(c.var.db);
  
  await db.run(`
    UPDATE ai_token_balances 
    SET balance_units = balance_units - ?, updated_at = datetime('now')
    WHERE customer_id = ? AND balance_units >= ?
  `, [units, customerId, units]);

  await db.run(`
    INSERT INTO ai_token_transactions (id, customer_id, amount, type, note)
    VALUES (?, ?, ?, 'debit', 'AI Generation')
  `, [crypto.randomUUID(), customerId, units]);
}

## Indexing Strategy

Fufuni uses strategic indexing to ensure performance even as the SQLite database grows. Key patterns include:

- **Lookup Indexes**: `idx_variants_sku` and `idx_products_handle` for high-frequency catalog resolution.
- **Status/State Filters**: `idx_orders_status_created` and `idx_carts_expires` to facilitate cleanup tasks and admin dashboard filtering.
- **Foreign Key Support**: Indexes on almost all `_id` columns (e.g., `idx_order_items_order_id`) to speed up join operations.
- **Security Lookups**: `idx_api_keys_hash` and `idx_customers_auth_provider_id` for near-instant authentication of API and JWT-based requests.
