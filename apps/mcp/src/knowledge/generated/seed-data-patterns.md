## Seed Data Script Reference

### How to Run the Seed Script

To populate your local or test environment with demo data, run the seed script with the following command:

```bash
npx tsx scripts/seed.ts <api_url> <admin_key>
```

**Required arguments:**
- `<api_url>`: Base URL of your Fufuni API (e.g., `http://localhost:8787`)
- `<admin_key>`: Admin API key (starts with `sk_`)

**Example:**
```bash
npx tsx scripts/seed.ts http://localhost:8787 sk_test_1234567890abcdef
```

### PRODUCT_CATALOG Structure

The `PRODUCT_CATALOG` array defines all products to be seeded. Each product object requires:

```typescript
interface Product {
  key: string;          // Short lookup key (used by reviews)
  file: string;         // Default image filename
  handle: string;       // API product handle (URL-friendly)
  vendor: string;       // Vendor name
  categories: string[]; // Category handles
  title: Record<string, string>;       // Localized titles
  description: Record<string, string>; // Localized HTML descriptions
  variants: Variant[];  // Product variants
}

interface Variant {
  sku: string;           // Stock keeping unit
  title: string;         // Variant title
  price_cents: number;   // Price in EUR cents
  weight_g: number;      // Weight in grams
  stock: number;         // Initial stock quantity
  imageFile?: string;    // Override image filename
  variant_type?: string; // 'physical' (default) or 'digital'
  requires_shipping?: boolean; // false for digital products
  ai_token_units?: number; // For AI token products
}
```

### apiWithRetry Helper

The `apiWithRetry` function handles transient API failures (like rate limiting) with exponential backoff.

**Usage:**
```typescript
const result = await apiWithRetry('/v1/products', productData, 3); // 3 retries
```

**Key features:**
- Automatically retries on rate limit errors (extracts wait time from response)
- Uses exponential backoff for other errors (2^attempt * 1000ms)
- Throws error after max retries exhausted
- Defaults to 5 retries

**Example with custom retry logic:**
```typescript
try {
  const data = await apiWithRetry('/v1/orders', orderData);
} catch (error) {
  console.error('Failed after retries:', error.message);
}
```

### Currency Conversion

The script converts EUR-based prices to USD and GBP using fixed exchange rates:

```typescript
const EUR_TO_USD = 1.14;
const EUR_TO_GBP = 0.86;

function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}
```

**Usage pattern:**
```typescript
// Set base price in EUR cents
const basePrice = 2999;

// Convert for other currencies
const usdPrice = convertCents(basePrice, EUR_TO_USD); // 2999 * 1.14
const gbpPrice = convertCents(basePrice, EUR_TO_GBP); // 2999 * 0.86
```

### Image Handling

The `toWebpDataUri` function converts images to optimized WebP format:

```typescript
async function toWebpDataUri(
  src: string | null,  // Filename or data URI
  maxSide: number,     // Max dimension (px)
  quality = 80         // WebP quality (0-100)
): Promise<string | null>
```

**Supported sources:**
1. Filesystem path (e.g., `'tee-black.png'` - reads from `./img/` directory)
2. Base64 data URI (from `imageMap`)

**Example usage:**
```typescript
const imageUrl = await toWebpDataUri('tee-black.png', 1200, 80);
const thumbUrl = await toWebpDataUri('tee-black.png', 300, 80);
```

**Fallback behavior:**
- Returns `null` if source is missing/unreadable
- Images are embedded as base64 in the script for portability


2. Add to the main `seed()` orchestrator:
```typescript
async function seed() {
  // ... existing steps
  await seedNewData();
  // ... rest of orchestration
}
```

3. Follow these conventions:
- Use emoji prefixes in console logs (📦, ✅, ⚠️, etc.)
- Make functions idempotent where possible
- Return any IDs needed by other seed functions
- Handle errors with try/catch and meaningful messages
