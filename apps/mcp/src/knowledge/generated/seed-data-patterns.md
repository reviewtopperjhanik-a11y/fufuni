## Seed Data Script Reference

The seed script is a TypeScript utility that populates a Fufuni e-commerce instance with realistic demo data. It's designed to be idempotent and safe to run multiple times.

### Running the Seed Script

To run the seed script, use the following command:

```bash
npx tsx scripts/seed.ts <api_url> <admin_key>
```

Replace `<api_url>` with your API endpoint (e.g., `http://localhost:8787`) and `<admin_key>` with your admin API key.

Example:
```bash
npx tsx scripts/seed.ts http://localhost:8787 sk_abc123...
```

### Adding a New Product to PRODUCT_CATALOG

To add a new product, push a new entry to the `PRODUCT_CATALOG` array. Each product must include:

- `key`: A short lookup key used by reviews and seeds
- `handle`: The API product handle
- `categories`: An array of category handles
- `variants`: Variant rows with SKU, price_cents, stock, etc.

Example of adding a new product:

```typescript
{
  key: 'new-product', file: 'new-product.png', handle: 'new-product', vendor: 'Fufuni',
  categories: ['accessories-tech'],
  title:       { 'en-US': 'New Product', 'fr-FR': 'Nouveau Produit', 'es-ES': 'Nuevo Producto', 'zh-CN': '新产品', 'ar-SA': 'منتج جديد', 'he-IL': 'מוצר חדש' },
  description: { 'en-US': '<p>Description of the new product.</p>', 'fr-FR': '<p>Description du nouveau produit.</p>', 'es-ES': '<p>Descripción del nuevo producto.</p>', 'zh-CN': '<p>新产品的描述。</p>', 'ar-SA': '<p>وصف المنتج الجديد.</p>', 'he-IL': '<p>תיאור של המוצר החדש.</p>' },
  variants: [
    { sku: 'NEW-PROD-S', title: 'Small', price_cents: 1999, weight_g: 200, stock: 50, imageFile: 'new-product-small.png' },
```

### Using the apiWithRetry Helper

The `apiWithRetry` helper is used to make API requests with automatic retry for transient failures like rate limiting. It's particularly useful when seeding large amounts of data.

Example usage:

```typescript
const result = await apiWithRetry('/v1/products', {
  handle: 'new-product',
  title: JSON.stringify({ 'en-US': 'New Product' }),
  description: JSON.stringify({ 'en-US': 'Description of the new product' }),
  vendor: JSON.stringify({ 'en-US': 'Fufuni' }),
});
```

### Currency Conversion

The script converts prices from EUR cents to USD and GBP using fixed exchange rates:

```typescript
const EUR_TO_USD = 1.14;
const EUR_TO_GBP = 0.86;
```

These rates are used in the `convertCents` function to calculate prices in other currencies:

```typescript
function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}
```

### Image Handling

Images are embedded as base64 data in the `imageMap` object, allowing the script to run even after the PNGs are removed. The `toWebpDataUri` helper converts images to WebP format and creates data URIs.

Example usage:

```typescript
const imageUrl = await toWebpDataUri(imageMap['new-product.png'], 1200, 80);
const thumbnailUrl = await toWebpDataUri(imageMap['new-product.png'], 300, 80);
```

### Adding a New Seed Helper Function

1. Create a new function with a descriptive name (e.g., `seedNewEntity`).

3. Ensure the function is idempotent and safe to run multiple times.

Example of adding a new seed helper function:

