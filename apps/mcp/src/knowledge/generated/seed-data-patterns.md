## apiWithRetry Helper

The `apiWithRetry` helper handles transient API failures (like rate limiting):

```typescript
// Basic usage
const data = await apiWithRetry('/v1/products', productData);

// With custom retry settings
const result = await apiWithRetry(
  '/v1/tax-rates',
  taxRateData,
  3 // maxRetries
);
```

This function automatically:
- Detects rate limit errors from response messages
- Implements exponential backoff for retries
- Throws the final error if all retries fail

## Currency Conversion

Prices are stored in EUR cents and converted to other currencies:

```typescript
// Conversion rates (defined in script)
const EUR_TO_USD = 1.14;
const EUR_TO_GBP = 0.86;

// Convert EUR cents to another currency
function convertCents(cents: number, rate: number): number {
  return Math.round(cents * rate);
}

// Usage example:
const usdPrice = convertCents(2999, EUR_TO_USD); // 2999 EUR cents → USD
```

## Image Embedding

Product images are handled by `toWebpDataUri`:

```typescript
// From filesystem path
const imageUrl = await toWebpDataUri('products/tee-black.png', 1200);

// From base64 data (embedded in imageMap)
const thumbUrl = await toWebpDataUri(imageMap['tee-black.png'], 300);

// With quality setting
const highQualUrl = await toWebpDataUri('product.jpg', 800, 90);
```

The function automatically:
- Detects PNG/JPEG format
- Resizes images if exceeding maxSide
- Converts to WebP format
- Returns data URI string

To add a new seed function:

```typescript

```

2. Update the main `seed()` orchestrator:
```typescript
async function seed() {
  // ... existing steps ...
  await seedNewFeature();
  // ... rest of flow ...

```

