## Architecture of a Fufuni Route

Fufuni utilizes `hono/zod-openapi` to ensure that every endpoint is strictly typed and automatically documented in the Swagger/OpenAPI registry. A standard route file follows a specific pattern: it exports two distinct `OpenAPIHono` instances—one for public consumption and one for administrative tasks.

The framework runs on Cloudflare Durable Objects. When a request hits the Worker, the `index.ts` entry point assigns a Durable Object stub to the Hono context (`c.var.db`). Your route handlers use this stub via the `getDb` helper to execute SQL queries directly against the SQLite database embedded in the DO.

### File structure and boilerplate

New routes must be created in `apps/merchant/src/routes/`. The file should begin with necessary imports, including the environment types and the database helper.

```typescript
// apps/merchant/src/routes/my-feature.ts
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, uuid, now, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';
// Import pre-defined schemas from the central schema directory
import { ErrorResponse } from '../schemas';

// 1. Initialize the Public App (No Auth required)
const publicApp = new OpenAPIHono<HonoEnv>();

// 2. Initialize the Admin App (Auth required)
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);

export { publicApp as publicFeature, adminApp as adminFeature };
```

## Defining Endpoints with OpenAPIHono

In Fufuni, you never use raw Hono methods like `app.get()` if you want OpenAPI documentation. Instead, you use `createRoute()` to define the contract (params, query, body, and responses) and `app.openapi()` to implement the logic.

### Creating a Public Read Endpoint

Public endpoints are accessible by the storefront or third-party integrations using a Public Key (`pk_...`).

```typescript
// Example: Fetching a single resource by slug
import { MyResourceSchema, MyResourceParam } from '../schemas';

const getResourceRoute = createRoute({
  method: 'get',
  path: '/:slug',
  tags: ['My Feature'],
  summary: 'Get resource by slug',
  request: {
    params: MyResourceParam,
  },
  responses: {
    200: {
      content: { 'application/json': { schema: MyResourceSchema } },
      description: 'Successful retrieval',
    },
    404: {
      content: { 'application/json': { schema: ErrorResponse } },
      description: 'Resource not found',
    },
  },
});

publicApp.openapi(getResourceRoute, async (c) => {
  const { slug } = c.req.valid('param');
  const db = getDb(c.var.db);

  const [row] = await db.query<any>(
    'SELECT * FROM my_table WHERE slug = ? AND status = ?',
    [slug, 'active']
  );

  if (!row) {
    throw ApiError.notFound(`Resource with slug ${slug} not found`);
  }

  return c.json(row, 200);
});
```

### Creating an Admin Mutation Endpoint

Admin endpoints require a Secret Key (`sk_...`) or a valid Auth0 JWT. You must enforce RBAC guards using middleware defined in the route configuration.

```typescript
// Example: Creating a new resource
import { CreateResourceBody } from '../schemas';

const createResourceRoute = createRoute({
  method: 'post',
  path: '/',
  tags: ['My Feature'],
  summary: 'Create a new resource (Admin)',
  security: [{ bearerAuth: [] }],
  middleware: [adminOnly] as const, // RBAC Guard
  request: {
    body: {
      content: { 'application/json': { schema: CreateResourceBody } },
    },
  },
  responses: {
    201: {
      content: { 'application/json': { schema: MyResourceSchema } },
      description: 'Created successfully',
    },
  },
});

adminApp.openapi(createResourceRoute, async (c) => {
  const body = c.req.valid('json'); // Validated by Zod
  const db = getDb(c.var.db);
  const id = uuid();

  await db.run(
    'INSERT INTO my_table (id, name, created_at) VALUES (?, ?, ?)',
    [id, body.name, now()]
  );

  return c.json({ id, ...body, created_at: now() }, 201);
});
```

## Database Interaction and Error Handling

The Fufuni framework uses a simplified SQLite interface provided by the Durable Object.

### SQL Methods

1.  **`db.query<T>(sql, params)`**: Used for `SELECT` statements. It returns an array of objects. Always destructure if you expect a single row: `const [item] = await db.query(...)`.
2.  **`db.run(sql, params)`**: Used for `INSERT`, `UPDATE`, and `DELETE`. It returns an object containing `{ changes: number }`.

### Using ApiError

Never throw raw `Error` objects. Use the `ApiError` class to ensure the frontend receives a standardized JSON error envelope and the correct HTTP status code.

```typescript
// Common ApiError usage patterns
if (duplicate) throw ApiError.conflict('Slug already exists');
if (!item) throw ApiError.notFound('Item not found');
if (invalid) throw ApiError.badRequest('Invalid configuration', { field: 'theme_color' });

// Internal errors should include the original message for debugging
try {
    await db.run(...);
} catch (e) {
    throw ApiError.internalServerError(e instanceof Error ? e.message : 'DB Failure');
}
```

## Registering Routes in index.ts

Routing order is critical in `apps/merchant/src/index.ts`. Public routes must be registered before the global authentication and rate-limiting middlewares to avoid blocking guest access.

```typescript
// apps/merchant/src/index.ts

import { publicFeature, adminFeature } from './routes/my-feature';

// ... existing imports ...

// 1. Mount Public Routes (No auth)
app.route('/v1/my-feature', publicFeature);

// 2. Middlewares (Auth, Rate Limit)
app.use('/v1/*', rateLimitMiddleware());

// 3. Mount Admin Routes (Requires Auth)
app.route('/v1/my-feature', adminFeature);
```

### KV Cache Invalidation

If your new resource is high-traffic (like products or categories), you should add it to the `kvCacheMiddleware` in `index.ts`. The Fufuni framework automatically invalidates the cache for `v1/categories/*` and `v1/products/*` when a `POST`, `PATCH`, or `DELETE` request is successful on those paths. For new custom paths, you may need to register them in the `kvInvalidateMiddleware` section.

## Available RBAC Guards

Fufuni uses specialized middleware to restrict access based on the token's scope or the user's Auth0 permissions. These are imported from `../middleware/auth`.

| Guard | Use Case |
| :--- | :--- |
| `adminOnly` | Standard store management (Catalog, Orders, Customers). |
| `superAdminOnly` | Sensitive operations like deleting the entire store. |
| `databaseAdminOnly` | Raw SQL access or database migrations. |
| `aiAccessOnly` | Accessing AI configuration or translation endpoints. |
| `mailAccessOnly` | Sending transactional emails or checking logs. |
| `validJwtAuthOnly` | Any valid user (Customer or Admin) with a JWT. |

## Worked Example: Product Tags API

This example demonstrates a complete implementation of a "Tags" feature, providing a public list of tags used in the store and an admin-only creation endpoint.

### 1. Implementation (`apps/merchant/src/routes/tags.ts`)

```typescript
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, uuid, now, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';

// Define schemas (In a real app, move these to apps/merchant/src/schemas/tags.ts)
const TagSchema = z.object({
  id: z.string().uuid(),
  name: z.string().min(1),
  slug: z.string().min(1),
}).openapi('Tag');

const CreateTagSchema = z.object({
  name: z.string().min(1),
  slug: z.string().min(1),
}).openapi('CreateTag');

const publicApp = new OpenAPIHono<HonoEnv>();
const adminApp = new OpenAPIHono<HonoEnv>();

// PUBLIC: List Tags
const listTagsRoute = createRoute({
  method: 'get',
  path: '/',
  tags: ['Tags'],
  responses: {
    200: {
      content: { 'application/json': { schema: z.array(TagSchema) } },
      description: 'List of all product tags',
    },
  },
});

publicApp.openapi(listTagsRoute, async (c) => {
  const db = getDb(c.var.db);
  const tags = await db.query<any>('SELECT id, name, slug FROM tags ORDER BY name ASC');
  return c.json(tags, 200);
});

// ADMIN: Create Tag
adminApp.use('*', authMiddleware);
const createTagRoute = createRoute({
  method: 'post',
  path: '/',
  tags: ['Tags'],
  security: [{ bearerAuth: [] }],
  middleware: [adminOnly] as const,
  request: {
    body: { content: { 'application/json': { schema: CreateTagSchema } } },
  },
  responses: {
    201: {
      content: { 'application/json': { schema: TagSchema } },
      description: 'Tag created',
    },
    409: {
      content: { 'application/json': { schema: z.object({ error: z.string() }) } },
      description: 'Slug already exists',
    },
  },
});

adminApp.openapi(createTagRoute, async (c) => {
  const { name, slug } = c.req.valid('json');
  const db = getDb(c.var.db);

  const [existing] = await db.query('SELECT id FROM tags WHERE slug = ?', [slug]);
  if (existing) throw ApiError.conflict('Tag slug already exists');

  const id = uuid();
  await db.run('INSERT INTO tags (id, name, slug, created_at) VALUES (?, ?, ?, ?)', 
    [id, name, slug, now()]
  );

  return c.json({ id, name, slug }, 201);
});

export { publicApp as publicTags, adminApp as adminTags };
```

### 2. Registration (`apps/merchant/src/index.ts`)

```typescript
import { publicTags, adminTags } from './routes/tags';

// ... 

// Public routes registered first
app.route('/v1/tags', publicTags);

// ... Auth middleware is usually here ...

// Admin routes registered last
app.route('/v1/tags', adminTags);
```

Ensure your Durable Object migrations include the necessary tables. Durable Objects in Fufuni use SQLite, so your `do.ts` or migration script should include:

  name TEXT NOT NULL,
