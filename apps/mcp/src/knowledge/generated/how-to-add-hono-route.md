## How to Add a New API Route

### 1. File to Create
Create a new file at:
```bash
apps/merchant/src/routes/my-feature.ts
```
Follow the existing naming convention (e.g., `categories.ts`, `products.ts`).

---

### 2. Minimal Boilerplate
Start with these imports and the basic router structure:

```typescript
// apps/merchant/src/routes/my-feature.ts
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';
import { MyFeatureResponse, ErrorResponse } from '../schemas';

// Public router (no auth)
const publicApp = new OpenAPIHono<HonoEnv>();

// Admin router (auth + adminOnly)
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);
```

---

### 3. Splitting Public vs Admin Endpoints
Export **two named routers** following the pattern:
```typescript
export { publicApp as publicMyFeature, adminApp as adminMyFeature };
```
- **Public routes**: No auth middleware. Use for read-only endpoints (e.g., listing products, fetching categories).
- **Admin routes**: Apply `authMiddleware` and RBAC guards (e.g., `adminOnly`). Use for mutations (e.g., creating/updating/deleting).

---

### 4. Using `getDb()` for Queries
- **Read operations**: Use `db.query<T>()` for `SELECT` statements.
- **Write operations**: Use `db.run()` for `INSERT`/`UPDATE`/`DELETE`.

Example:
```typescript
const db = getDb(c.var.db);
const rows = await db.query<MyFeatureType[]>(`SELECT * FROM my_table WHERE status = 'active'`);
await db.run(`INSERT INTO my_table (id, name) VALUES (?, ?)`, [uuid(), 'New Item']);
```

---

### 5. Error Handling with `ApiError`
Throw structured errors using the `ApiError` class. Hono’s global error handler converts these to JSON responses.

```typescript
if (!item) throw ApiError.notFound('Item not found');
if (conflict) throw ApiError.conflict('Handle already exists');
throw ApiError.internalServerError('Database error');
```

---

### 6. Registering the Route in `index.ts`
- **Public routes**: Mount **before** `authMiddleware` (e.g., `app.route('/v1/my-feature', publicMyFeature)`).
- **Admin routes**: Mount **after** `authMiddleware` (e.g., `app.route('/v1/my-feature', adminMyFeature)`).

Example placement:
```typescript
// In index.ts:
app.route('/v1/my-feature', publicMyFeature);  // Public (no auth)
app.use('/v1/*', rateLimitMiddleware());       // Auth middleware starts here
app.route('/v1/my-feature', adminMyFeature);   // Admin (auth required)
```

### 7. RBAC Guards and When to Use Them
Import from `../middleware/auth` and apply as middleware in `createRoute`:

| Guard                | Usage                                                                 |
|----------------------|-----------------------------------------------------------------------|
| `adminOnly`          | Requires `admin:store` permission (e.g., product management).         |
| `superAdminOnly`     | Requires `admin:database` (e.g., schema migrations).                  |
| `databaseAdminOnly`  | Alias for `superAdminOnly`.                                           |
| `aiAccessOnly`       | Requires `ai:api` permission (e.g., AI translation endpoints).       |
| `mailAccessOnly`     | Requires `mail:api` permission (e.g., sending transactional emails).  |
| `validJwtAuthOnly`   | Requires any valid JWT (no specific permission).                     |

Example:
```typescript
middleware: [adminOnly] as const,  // Admin-only route
```

### 8. Complete Example: Tags Endpoint
Here’s a full implementation for a `tags` resource with:
- Public `GET /v1/tags` (list all tags).
- Admin `POST /v1/tags` (create a tag).

#### File: `apps/merchant/src/routes/tags.ts`
```typescript
import { OpenAPIHono, createRoute } from '@hono/zod-openapi';
import { z } from 'zod';
import { ApiError, uuid, now, type HonoEnv } from '../types';
import { getDb } from '../db';
import { authMiddleware, adminOnly } from '../middleware/auth';
import { TagResponse, TagListResponse, CreateTagBody, ErrorResponse } from '../schemas';

// Public router
const publicApp = new OpenAPIHono<HonoEnv>();

// Admin router
const adminApp = new OpenAPIHono<HonoEnv>();
adminApp.use('*', authMiddleware);

// Public: List all tags
const listTagsRoute = createRoute({
  method: 'get',
  path: '/',
  tags: ['Tags'],
  summary: 'List all tags',
  responses: {
    200: {
      content: { 'application/json': { schema: TagListResponse } },
      description: 'List of tags',
    },
    500: {
      content: { 'application/json': { schema: ErrorResponse } },
      description: 'Server error',
    },
  },
});

publicApp.openapi(listTagsRoute, async (c) => {
  const db = getDb(c.var.db);
  try {
    const tags = await db.query<{ id: string; name: string; slug: string }[]>(
      `SELECT id, name, slug FROM tags ORDER BY name ASC`
    );
    return c.json({ items: tags }, 200);
  } catch (error) {
    throw ApiError.internalServerError(error instanceof Error ? error.message : 'Failed to fetch tags');
  }
});

// Admin: Create a tag
const createTagRoute = createRoute({
  method: 'post',
  path: '/',
  tags: ['Tags'],
  summary: 'Create a tag (admin)',
  security: [{ bearerAuth: ['admin:store'] }],
  middleware: [adminOnly] as const,
  request: {
    body: {
      content: { 'application/json': { schema: CreateTagBody } },
    },
  },
  responses: {
    201: {
      content: { 'application/json': { schema: TagResponse } },
      description: 'Tag created',
    },
    400: {
      content: { 'application/json': { schema: ErrorResponse } },
      description: 'Invalid input',
    },
    409: {
      content: { 'application/json': { schema: ErrorResponse } },
      description: 'Slug already exists',
    },
  },
});

adminApp.openapi(createTagRoute, async (c) => {
  const body = c.req.valid('json');
  const db = getDb(c.var.db);

  try {
    // Check for duplicate slug
    const [existing] = await db.query<{ id: string }>(
      `SELECT id FROM tags WHERE slug = ?`,
      [body.slug]
    );
    if (existing) throw ApiError.conflict(`Slug "${body.slug}" already exists`);

    // Insert new tag
    const id = uuid();
    await db.run(
      `INSERT INTO tags (id, name, slug, created_at, updated_at)
       VALUES (?, ?, ?, ?, ?)`,
      [id, body.name, body.slug, now(), now()]
    );

    // Return the created tag
    const [tag] = await db.query<{
      id: string;
      name: string;
      slug: string;
      created_at: string;
      updated_at: string;
    }>(`SELECT * FROM tags WHERE id = ?`, [id]);

    return c.json(tag, 201);
  } catch (error) {
    if (error instanceof ApiError) throw error;
    throw ApiError.internalServerError(error instanceof Error ? error.message : 'Failed to create tag');
  }
});

export { publicApp as publicTags, adminApp as adminTags };
```

#### Register in `index.ts`
```typescript
// Add to imports:
import { publicTags, adminTags } from './routes/tags';

// Mount public routes BEFORE auth middleware:
app.route('/v1/tags', publicTags);

// Mount admin routes AFTER auth middleware:
app.route('/v1/tags', adminTags);
```

#### Required Schema Definitions
Add these to `apps/merchant/src/schemas/index.ts`:

```typescript
export const TagResponse = z.object({
  id: z.string().uuid(),
  name: z.string(),
  slug: z.string(),
  created_at: z.string().datetime(),
  updated_at: z.string().datetime(),
});

export const TagListResponse = z.object({
  items: z.array(TagResponse),
});

export const CreateTagBody = z.object({
  name: z.string().min(1).max(100),
  slug: z.string().min(1).max(100).regex(/^[a-z0-9-]+$/),
});
```

### Key Takeaways
1. **Always** use `c.req.valid('json')` (never `c.req.json()`).
2. **Split routes** into `publicApp` (no auth) and `adminApp` (with `authMiddleware`).
3. **Declare schemas** in `schemas/` and import them—never inline.
4. **Register public routes first**, admin routes after `authMiddleware` in `index.ts`.
5. **Use `getDb()`** for all SQL operations (`query` for reads, `run` for writes).
6. **Throw `ApiError`** for structured error responses.
