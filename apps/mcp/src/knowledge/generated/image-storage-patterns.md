## Image Storage Patterns

Fufuni supports three image storage methods with automatic selection based on file size and manual overrides:

### Storage Methods

1. **base64**: Images <1MB stored as data URIs directly in SQLite columns
2. **r2**: Images ≥1MB uploaded to Cloudflare R2 bucket via API
3. **url**: External URLs stored as-is (Cloudinary, etc.)

### Automatic Storage Selection

The `uploadImageFile()` utility automatically chooses storage based on WebP-converted size:
- Base64 for files <1MB (`BASE64_SIZE_LIMIT`)
- R2 for files ≥1MB (or when `forceR2=true`)
- 5MB maximum upload size (`FILE_SIZE_LIMIT`)

```typescript
import { uploadImageFile } from '@/utils/image-upload';

const result = await uploadImageFile(
  file,
  'https://api.yourstore.com',
  useSecuredApi().postForm,
  true // forceR2
);
```

### WebP Conversion Rules

All uploads undergo mandatory WebP conversion:
- Maximum dimension: 1200px
- Quality: 0.8 (80%)
- Thumbnails generated separately at 300px

### ImageUploadInput Component

The canonical admin UI component with these props:

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| value | string \| null | Yes | - | Current image URL/data URI |
| onChange | (url: string \| null) => void | Yes | - | Update handler |
| onThumbnailChange | (url: string \| null) => void | No | - | Thumbnail update handler |
| apiBaseUrl | string | Yes | - | API base URL |
| forceR2 | boolean | No | false | Force R2 storage |
| disabled | boolean | No | false | Disable controls |

Complete usage example:

```typescript
import { ImageUploadInput } from '@/components/image-upload-input';

function ProductForm() {
  const [imageUrl, setImageUrl] = useState<string | null>(null);

  return (
    <ImageUploadInput
      value={imageUrl}
      onChange={setImageUrl}
      apiBaseUrl="https://api.yourstore.com"
      forceR2={false}
    />
  );
}
```

### URL Validation Security

Always validate user-provided URLs with `isValidImageUrl()`:

```typescript
import { isValidImageUrl } from '@/utils/image-upload';

if (isValidImageUrl(userInput)) {
  // Safe to use in <img src>
}
```

Accepted protocols:
- `http:` and `https:` for external URLs
- `data:image/` for base64 images

### R2 Backend Endpoints

| Endpoint | Method | Permission | Description |
|----------|--------|------------|-------------|
| `/v1/images` | POST | `admin:store` | Upload image to R2 |
| `/v1/images/:key` | DELETE | `admin:store` | Delete from R2 + purge CDN |

All R2-served images pass through Cloudflare's KV CDN cache. Purge the cache whenever:
- An image is updated
- An image is deleted
- Immediate consistency is required

```typescript
// Purge example
await fetch('https://api.yourstore.com/v1/images/abc123', {
  method: 'DELETE',
  headers: { 'Authorization': 'Bearer ADMIN_TOKEN' }
});
```
