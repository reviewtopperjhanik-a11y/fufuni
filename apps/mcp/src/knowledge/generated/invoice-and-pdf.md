The Fufuni e-commerce framework handles invoice generation entirely client-side using the jsPDF library for PDF creation and formatting. This approach ensures that no sensitive order data is transmitted to external servers during the PDF generation process.

## PDF Generation

Invoice PDFs are generated using the `generateInvoice()` function from `invoice-generator.ts`, which leverages the [jsPDF](https://parall.ax/products/jspdf) library and [jsPDF-AutoTable](https://github.com/simonbengtsson/jsPDF-AutoTable) plugin for table rendering.

The function signature is:
```typescript
function generateInvoice(data: InvoiceData): jsPDF;
```

**Key characteristics:**
- Returns a `jsPDF` document instance for further manipulation
- All processing occurs in the browser with zero server calls
- Supports both download and preview workflows

To trigger a browser download:
```typescript
const doc = generateInvoice(invoiceData);
doc.save(`order-${orderNumber}.pdf`);
```

To open the PDF in a new tab:
```typescript
const doc = generateInvoice(invoiceData);
window.open(doc.output("bloburl"), "_blank");
```

## Invoice Content Structure

Invoice PDFs follow this standardized layout:

1. **Store Header**
   - Store logo (if available as base64 data URI)
   - Store name and address
   - "INVOICE" title

2. **Order Metadata**
   - Order number and date
   - Customer email and billing info

3. **Itemized Products Table**
   - Columns: Product, Quantity, Unit Price, Total
   - Automatic pagination for long item lists

4. **Financial Summary**
   - Subtotal
   - Tax breakdown (per jurisdiction if applicable)
   - Shipping costs
   - Grand total (bolded)

5. **Footer**
   - Store contact information
   - Generation timestamp

The `InvoiceData` interface defines all required fields:
```typescript
interface InvoiceData {
  orderNumber: string;
  orderDate: string;
  items: {
    product_title: string;
    quantity: number;
    unit_price_cents: number;
    total_price_cents: number;
    currency: string;
  }[];
  // ... additional fields
}
```

## Currency Formatting

Monetary values use the `formatCurrency()` utility from `utils/currency.ts` with this signature:
```typescript
function formatCurrency(
  cents: number,
  currency: string,
  locale?: string
): string;
```

**Key behaviors:**
- Accepts amounts in smallest currency unit (e.g., cents)
- Automatically divides by 100 before formatting
- Supports ISO 4217 currency codes ("USD", "EUR", "JPY", etc.)
- Uses browser's `Intl.NumberFormat` for locale-aware formatting

Example usage:
```typescript
formatCurrency(2999, "EUR", "fr-FR"); // "29,99 €"
formatCurrency(2999, "USD", "en-US"); // "$29.99"
formatCurrency(9800, "JPY", "ja-JP"); // "¥9,800" (JPY uses 0 decimals)
```

## Order View Token System

Public invoice access uses time-limited tokens:

1. **Token Generation**
   - Endpoint: `GET /v1/orders/:id/invoice`
   - Returns: Signed token (valid for 1 hour)

2. **Token Usage**
   - Public route: `/order-view/:token`
   - Data fetch: `GET /v1/orders/view/:token`

Example token flow:
```typescript
// Server-side token generation
const { token } = await fetch(`/v1/orders/${orderId}/invoice`);

// Client-side access
const orderData = await fetch(`/v1/orders/view/${token}`);
```

## Adding New Invoice Fields

To extend invoice data:

1. **Update Data Interfaces**
   Modify `InvoiceData` in `invoice-generator.ts` and `OrderForPdf` in `invoice-pdf.ts`

2. **Server Integration**
   - Extend the order API response (`/v1/orders/view/:token`)
   - Add field mapping in the frontend data transformer

3. **PDF Layout**
   - Add field to the PDF generation logic in both:
     - `generateInvoice()` for basic layout
     - `downloadInvoicePdf()` for AutoTable version

Example field addition:
```typescript
// 1. Extend interface
interface InvoiceData {
  // ... existing fields
  paymentMethod: string;
}

// 2. Add to PDF generation
doc.text(`Payment: ${data.paymentMethod}`, margin, yPosition);
```

1. **Translation Function**

## Store Logo Handling

Store logos are managed as follows:

1. **Storage**
   - Base64 data URI in `store_settings` table
   - Recommended dimensions: 200x60px

2. **Fallback Behavior**
   When no logo is available:
   - Displays store name as text header
   - Uses default typography styling

3. **Implementation**
   ```typescript
   if (storeLogo) {
     doc.addImage(storeLogo, "JPEG", margin, yPosition, 40, 20);
   } else {
     doc.setFontSize(16);
     doc.text(storeName, margin, yPosition);
   }
   ```

## Complete Example

This demonstrates a full invoice generation flow:

```typescript
import { generateInvoice } from "@/lib/invoice-generator";
import { useTranslation } from "react-i18next";

function InvoiceDownloadButton({ orderId }: { orderId: string }) {
  const { t } = useTranslation();
  const [isLoading, setIsLoading] = useState(false);

  const handleDownload = async () => {
    setIsLoading(true);
    try {
      // 1. Fetch order data using token
      const tokenResponse = await fetch(`/v1/orders/${orderId}/invoice`);
      const { token } = await tokenResponse.json();

      const orderResponse = await fetch(`/v1/orders/view/${token}`);
      const orderData = await orderResponse.json();

      // 2. Generate PDF
      const pdf = generateInvoice(
        {
          orderNumber: orderData.number,
          orderDate: orderData.created_at,
          items: orderData.items.map(item => ({
            product_title: item.title,
            quantity: item.qty,
            unit_price_cents: item.unit_price_cents,
            total_price_cents: item.qty * item.unit_price_cents,
            currency: orderData.currency
          })),
          // ... other required fields
        },
        t // Pass translation function
      );

      // 3. Trigger download
      pdf.save(`invoice-${orderData.number}.pdf`);
    } finally {
      setIsLoading(false);
    }
  };

  return (
    <button onClick={handleDownload} disabled={isLoading}>
      {t("invoice-downloadButton")}
    </button>
  );
}
```
