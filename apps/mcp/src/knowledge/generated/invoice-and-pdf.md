## Invoice & PDF Generation Reference

### 1. PDF Generation
Fufuni uses **jsPDF** (with **jspdf-autotable** plugin) for client-side PDF generation. No server-side rendering occurs.

#### Key Functions
```typescript
// Manual layout (legacy)
import { generateInvoice } from "@/lib/invoice-generator";
generateInvoice(invoiceData: InvoiceData): void;

// AutoTable-based (preferred)
import { downloadInvoicePdf, openInvoicePdf } from "@/utils/invoice-pdf";
downloadInvoicePdf(order: OrderForPdf, storeName?: string, locale?: string): void;
openInvoicePdf(order: OrderForPdf, storeName?: string, locale?: string): void;
```

#### Saving vs. Opening
```typescript
// Trigger browser download
downloadInvoicePdf(order, "My Store", "fr-FR");

// Open in new tab
openInvoicePdf(order, "My Store", "fr-FR");
```

### 2. Invoice Content Structure
All invoices follow this **fixed order** of sections:

1. **Header**
   - Store logo (if available) or store name
   - "INVOICE" label (right-aligned)

2. **Order Metadata**
   - Order number + date
   - Customer email
   - Shipping address (if physical goods)

3. **Items Table**
   - Columns: Product Title | Qty | Unit Price | Total
   - Auto-wrapped text for long product names

4. **Totals Breakdown**
   - Subtotal
   - Discount (if applicable)
   - Shipping
   - Taxes (per line if multiple rates)
   - **TOTAL** (bold, larger font)

5. **Footer**
   - Generation timestamp
   - Store name

#### Example Table Structure
```typescript
const tableBody = order.items.map(item => [
  item.title,
  item.qty.toString(),
  formatCurrency(item.unit_price_cents, order.currency),
  formatCurrency(item.qty * item.unit_price_cents, order.currency)
]);
```

### 3. Currency Formatting
All monetary values are stored as **cents** (integer) and converted to display format via:

```typescript
import { formatMoney, formatMoneyFixed } from "@/utils/currency";

// Standard formatting (respects JPY 0-decimal convention)
formatMoney(2999, "EUR", "fr-FR"); // "29,99 €"

// Force 2 decimals (for accounting displays)
formatMoneyFixed(2999, "JPY", 2, "ja-JP"); // "¥29.99" (instead of "¥30")
```

#### Key Rules
- **Always pass cents** (never pre-divide by 100)
- Currency codes must be **ISO 4217** uppercase (`"EUR"`, `"USD"`)
- Locale defaults to browser setting if omitted

### 6. Adding a New Invoice Field
Modify these files in order:

1. **Type Definition**
   Extend `OrderForPdf` in `invoice-pdf.ts`:
   ```typescript
   interface OrderForPdf {
     // ...existing fields
     new_field?: string;
   }
   ```

2. **API Response**
   Ensure the field is included in `/v1/orders/view/:token` response.

3. **PDF Layout**
   Add rendering logic in `downloadInvoicePdf`:
   ```typescript
   if (order.new_field) {
     doc.text(`New Field: ${order.new_field}`, 14, currentY);
     currentY += 6;
   }
   ```

4. **Translation** (if needed)
   Add keys to `public/locales/en/invoice.json` with `invoice-` prefix:
   ```json
   {
     "invoice-new-field": "Custom Field"
   }
   ```

### 7. i18n in PDFs
Translation uses **react-i18next**’s `t()` function:

```typescript
// Pass t() to the generator
generateInvoice({
  // ...data
  t: (key: string) => i18n.t(key)
});

// Translation keys MUST use "invoice-" prefix
doc.text(t("invoice-subtotal"), 14, currentY);
```

#### Key Conventions
- Prefix: All invoice keys start with `invoice-`
- Fallback: Missing keys show the key name (e.g., `invoice-tax` → "tax")

### 8. Store Logo Handling
- **Storage**: Base64 data URI in `store_settings.logo_data_uri`
- **Fallback**: If missing, the PDF renders the store name in **20pt bold Helvetica**
- **Implementation**:
  ```typescript
  if (storeSettings.logo_data_uri) {
    doc.addImage(storeSettings.logo_data_uri, "PNG", 14, 10, 40, 12);
  } else {
    doc.setFontSize(20);
    doc.text(storeName, 14, 20);
  }
  ```
