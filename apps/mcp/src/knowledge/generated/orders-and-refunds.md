## Orders & Refunds Reference

### Order Status Machine

```
pending → paid → processing → shipped → delivered
   \_________________________/
                     |
                   canceled
                     |
                   refunded
```

Valid transitions:
- `pending` → `paid` (after successful payment)
- `paid` → `processing` (manual or automatic)
- `processing` → `shipped` (with tracking info)
- `shipped` → `delivered` (manual confirmation)
- Any post-paid status → `canceled` (admin action)
- Any post-paid status → `refunded` (via refund endpoint)

### Order Endpoints

| Method | Path | Auth Requirement | Description |
|--------|------|------------------|-------------|
| GET | `/v1/orders` | `admin:store` | List all orders with pagination |
| GET | `/v1/me/orders` | Customer JWT | List authenticated user's orders |
| GET | `/v1/orders/:id` | `admin:store` | Get order details by ID |
| PATCH | `/v1/orders/:id/status` | `admin:store` | Update order status |
| POST | `/v1/orders/:id/refund` | `admin:store` | Process refund |
| PATCH | `/v1/orders/:id/cancel` | `admin:store` | Cancel order |
| GET | `/v1/orders/:id/invoice` | `admin:store` | Get invoice URL |
| GET | `/v1/orders?export=csv` | `admin:store` | Export orders as CSV |

### Refund Flow

Refunds are processed via the dedicated endpoint:

```typescript
// apps/merchant/src/routes/orders.ts
const refundOrder = createRoute({
  method: 'post',
  path: '/{orderId}/refund',
  // ...
});
```

Example refund request:
```typescript
fetch(`/v1/orders/${orderId}/refund`, {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer sk_admin_...',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount_cents: 1000, // Partial refund of 10.00 EUR
    reason: 'requested_by_customer',
    notes: 'Customer returned one item'
  })
});
```

Refund process:
1. Validates order exists and is refundable
2. Creates Stripe refund:
   ```typescript
   const refund = await stripe.refunds.create({
     payment_intent: order.stripe_payment_intent_id,
     amount: amount_cents,
     reason: reason as Stripe.RefundCreateParams.Reason,
   });
   ```
3. Records refund in database:
   ```typescript
   await db.run(
     `INSERT INTO refunds (...) VALUES (...)`,
     [refundId, order.id, refund.id, refund.amount, ...]
   );
   ```
4. Updates order status to `refunded` (full) or `partially_refunded`

### Order Cancellation

Cancel an order via:

Cancellation effects:
- Sets order status to `canceled`

### Order Item Immutability

Order items capture product details at purchase time and remain unchanged:

```typescript
// Database schema for order_items
{
  id: string,
  order_id: string,
  sku: string,
  title: string,  // Product title at time of purchase
  qty: number,
  unit_price_cents: number,  // Price at time of purchase
  // ... other fields
}
```

This ensures:
- Price changes after purchase don't affect historical orders
- Product title updates don't rewrite order history
- Tax rates and currency are preserved as they were at checkout

Example from order creation:
```typescript
const orderItems = items.map(item => ({
  sku: item.sku,
  title: variant.title,  // Captured at this moment
  qty: item.qty,
  unit_price_cents: resolvedPrice,  // Captured at this moment
}));
```
