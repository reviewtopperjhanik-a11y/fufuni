## Authentication Patterns

### Token Types

The Fufuni authentication system accepts three token types:

1. **Auth0 JWT**: Three-part Bearer token (header.payload.signature) verified against Auth0's JWKS. Must include the permission specified in `ADMIN_STORE_PERMISSION` (default: `admin:store`).

2. **Admin API key**: Database-stored key with `sk_` prefix. Hashed and looked up in the `api_keys` table.

3. **OAuth token**: 64-character lowercase hex string. Looked up in the `oauth_tokens` table with scope validation.

### AuthRole Values

The `AuthRole` type defines the possible roles assigned after authentication:

| Role | Description |
|------|-------------|
| `public` | Unauthenticated or public-key request |
| `admin` | Admin API key or Auth0 token with `admin:store` permission |
| `oauth` | OAuth API key with specific scopes |
| `authadmin` | Token with `auth0:admin:api` permission |
| `databaseadmin` | Token with `admin:database` permission |
| `aiadmin` | Token with AI permission (from `AI_PERMISSION` env var) |
| `mail` | Token with `mail:api` permission |
| `customer` | Auth0 token with no specific admin permission |

### Backend RBAC Guards

The following middleware guards are available in `apps/merchant/src/middleware/auth.ts`:

| Guard | Checks For | Typical Use Case |
|-------|------------|------------------|
| `adminOnly` | `admin` role | General admin endpoints |
| `superAdminOnly` | `authadmin` role | Auth0 Management API token endpoint |
| `databaseAdminOnly` | `databaseadmin` role | Database administration routes |
| `aiAccessOnly` | `aiadmin` role | AI configuration and operations |
| `mailAccessOnly` | `mail` role | Email sending and management |
| `validJwtAuthOnly` | Any valid Auth0 JWT | Customer-facing endpoints without permission checks |
| `requireScope(...scopes)` | OAuth token with specified scopes | Third-party API access with scope validation |

### Backend Code Examples

#### Protecting a Route with authMiddleware + adminOnly

```typescript
import { Hono } from 'hono';
import { authMiddleware, adminOnly } from '../middleware/auth';
import { getDb } from '../db';

const app = new Hono();

app.use('/admin/*', authMiddleware);
app.use('/admin/products*', adminOnly);

app.get('/admin/products', async (c) => {
  const db = getDb(c.var.db);
  const products = await db.query('SELECT * FROM products');
  return c.json(products);
});
```

#### superAdminOnly and the /v1/__auth0/token Endpoint

```typescript
import { Hono } from 'hono';
import { superAdminOnly } from '../middleware/auth';

const app = new Hono();

app.get('/v1/__auth0/token', superAdminOnly, async (c) => {
  // Returns cached Auth0 Management API token
  const token = await getManagementToken(c.env);
  return c.json({ access_token: token });

```

#### Customer-scoped Routes with customerAuthMiddleware

```typescript
import { Hono } from 'hono';
import { customerAuthMiddleware } from '../middleware/customer-auth';

const app = new Hono();

app.use('/v1/me/*', customerAuthMiddleware);

app.get('/v1/me', async (c) => {
  const auth = c.get('auth');
  // auth.role is 'customer'
  // auth.sub contains Auth0 user identifier
  return c.json({
    email: auth.email,
    permissions: auth.permissions
  });
});
```

#### OAuth-scoped Routes with requireScope

```typescript
import { Hono } from 'hono';
import { authMiddleware, requireScope } from '../middleware/auth';

const app = new Hono();

app.use('/api/oauth/*', authMiddleware);
app.use('/api/oauth/products', requireScope('read:products'));

app.get('/api/oauth/products', async (c) => {
  // Only accessible with OAuth tokens having 'read:products' scope
  const db = getDb(c.var.db);
  const products = await db.query('SELECT * FROM products');
  return c.json(products);
});
```

### Frontend Authentication Components

#### AuthenticationGuard

Protects entire pages by redirecting unauthenticated users to the login page:

```tsx
import { AuthenticationGuard } from '@fufuni/ui';

function AdminDashboard() {
  return <div>Admin content here</div>;
}

export default function WrappedAdminDashboard() {
  return <AuthenticationGuard component={AdminDashboard} />;
}
```

#### AuthenticationGuardWithPermission

Conditionally renders UI based on specific Auth0 permissions:

```tsx
import { AuthenticationGuardWithPermission } from '@fufuni/ui';

function AdminPanel() {
  return <div>Sensitive admin controls</div>;
}

export default function ProtectedAdminPanel() {
  return (
    <AuthenticationGuardWithPermission
      permission="admin:store"
      fallback={<div>Access denied</div>}
    >
      <AdminPanel />
    </AuthenticationGuardWithPermission>
  );
}
```

#### Permission Checks with useSecuredApi

```tsx
import { useSecuredApi } from '@fufuni/ui';

function AdminFeature() {
  const { hasPermission } = useSecuredApi();

  return (
    <button
      onClick={async () => {
        if (await hasPermission('database:admin')) {
          // Proceed with database operation
        }
      }}
    >
      Perform Database Action
    </button>
  );
}
```

#### Authentication State with useAuth

```tsx
import { useAuth } from '@fufuni/ui';

function UserGreeting() {
  const { isAuthenticated } = useAuth();

  return isAuthenticated
    ? <div>Welcome back!</div>
    : <div>Please log in</div>;
}
```

#### LoginLogoutLink vs LoginButton

Use `LoginLogoutLink` for navigation elements that should show login/logout state:

```tsx
import { LoginLogoutLink } from '@fufuni/ui';

function NavBar() {
  return (
    <nav>
      <LoginLogoutLink />
    </nav>
  );
}
```

Use `LoginButton` when you need a clickable button with custom styling:

```tsx
import { LoginButton } from '@fufuni/ui';

function LoginPage() {
  return (
    <div>
      <LoginButton className="bg-blue-500 hover:bg-blue-700" />
    </div>
  );
}
```

#### UsersAndPermissionsPage

The `/admin/users-and-permissions` page allows administrators to manage Auth0 user permissions from the storefront UI without accessing the Auth0 dashboard directly. This is particularly useful for non-technical administrators.

To use this page, you must have the `auth0:admin:api` permission assigned in Auth0.

```tsx
import { UsersAndPermissionsPage } from '@fufuni/ui';

function AdminRoutes() {
  return (
    <Routes>
      <Route path="/admin/users-and-permissions" element={<UsersAndPermissionsPage />} />
    </Routes>
  );
}
```

### Permission Management

All RBAC permissions are managed exclusively through the Auth0 dashboard. The `deploy-tenant-resources` script provisions the required Auth0 resources:

```bash
npx tsx scripts/auth0/deploy-tenant-resources.ts
```

This script creates:
- Auth0 applications
- API definitions
- Required permissions
- Actions and flows

For local development, ensure your `.dev.vars` includes the required Auth0 configuration:

```bash
AUTH0_DOMAIN=your-tenant.auth0.com
AUTH0_AUDIENCE=https://your-api-audience
```
