# AI Token Integration Guide

## Product Setup

AI token packages are catalog variants with specific fields:

```typescript
// Example variant for 100 AI tokens
{
  id: 'variant_123',
  sku: 'AI_100',
  title: '100 AI Tokens',
  variant_type: 'ai_tokens', // Required
  ai_token_units: 100,       // Units granted per purchase
  requires_shipping: 0,      // Always 0 for AI tokens
  status: 'active',
  product_id: 'product_456'
}
```

Key requirements:
- `variant_type` must be `"ai_tokens"`
- `ai_token_units` must be a positive integer
- `requires_shipping` must be `0`
- No inventory rows are created or checked

## Checkout Behavior

Carts containing only AI token variants bypass normal checkout constraints:

```typescript
// checkout.ts - inventory reservation logic
for (const item of items) {
  const [v] = await db.query<any>(`SELECT variant_type FROM variants WHERE sku = ?`, [item.sku]);
  if (!v || v.variant_type === 'physical') { // Skip for non-physical
    await reserveInventory(db, item.sku, item.qty);
  }
}
```

Digital-only carts skip shipping entirely:
- `getAvailableShippingRates()` returns `{ items: [], cart_total_weight_g: 0 }`
- Frontend proceeds directly to Stripe payment

## Post-Purchase Flow

After successful Stripe payment, the webhook handler processes AI token purchases:

```typescript
// webhooks.ts - Stripe checkout.session.completed handler
const aiTokenItems = await db.query<any>(
  `SELECT oi.qty, v.ai_token_units
   FROM order_items oi
   JOIN variants v ON v.sku = oi.sku
   WHERE oi.order_id = ? AND v.variant_type = 'ai_tokens'`,
  [orderId]
);

for (const aiItem of aiTokenItems) {
  if (aiItem.ai_token_units) {
    await creditAiTokens(
      db,
      customerId,
      orderId,
      aiItem.ai_token_units * aiItem.qty,
      c.var.db,
      c.executionCtx
    );
  }
}
```

## API Key Auto-Generation

Keys follow the `fufkey_` format with 40 random alphanumeric characters:

```typescript
// ai-tokens.ts - generateFufKey()
function generateFufKey(): string {
  const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789';
  const buf = new Uint8Array(40);
  crypto.getRandomValues(buf);
  return 'fufkey_' + Array.from(buf, (v) => chars[v % chars.length]).join('');
}
```

Key storage and generation timing:
1. **Storage**: Persisted in `customers.metadata.ai_proxy_api_key`
2. **Generation**: Automatically created during `creditAiTokens()` if missing
3. **Timing**: Fires on first AI token purchase or manual linking

## Outbound Webhooks

Two event types are dispatched:

```typescript
// creditAiTokens() - webhook dispatch
const eventType = keyIsNew ? 'ai_tokens.key_created' : 'ai_tokens.credited';
ctx.waitUntil(
  dispatchWebhooks(stub, ctx, eventType, {
    customer_id: customerId,
    order_id: orderId,
    api_key: apiKey,
    credited_units: units,
    balance_units: newBalance,
  })
);
```

**ai_tokens.key_created** (new key):
- Sent when auto-generating a key
- Proxy should register the new key

**ai_tokens.credited** (existing key):
- Sent when adding to an existing balance
- Proxy should update the existing key's balance

## ai-proxy-cloudflare Integration

Environment variables:
```bash
# wrangler.toml
FUFUNI_MERCHANT_URL = "https://your-store.fufuni.com"
AI_BALANCE_SHARED_SECRET = "your_shared_secret_here"
```

Balance enforcement flow:
```typescript
// ai-proxy-cloudflare logic
async function checkBalance(apiKey: string, env: Env) {
  if (!env.FUFUNI_MERCHANT_URL) return; // Standalone mode

  const res = await fetch(`${env.FUFUNI_MERCHANT_URL}/v1/ai-tokens/proxy/balance/${apiKey}`, {
    headers: { Authorization: `Bearer ${env.AI_BALANCE_SHARED_SECRET}` }
  });

  if (res.ok && (await res.json()).balance_units <= 0) {
    return new Response('Insufficient AI token balance', { status: 402 });
  }
}
```

## Security Considerations

1. **Timing-safe comparison** for proxy authentication:
```typescript
function timingSafeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return diff === 0;
}
```

2. **Key masking** in admin interfaces:
```typescript
function maskApiKey(key: string): string {
  return key.length > 8 ? key.slice(0, 8) + '…' : key.slice(0, 4) + '…';
}
```

3. **Never expose full keys** except to authenticated owners via `/me/ai-tokens/balance`
