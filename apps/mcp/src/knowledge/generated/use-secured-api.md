## useSecuredApi() Hook Reference

### Import Path
```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

### Return Values Table

| Method               | Signature                                                                 | When to Use                                                                 |
|----------------------|---------------------------------------------------------------------------|-----------------------------------------------------------------------------|
| **getJson**          | `(url: string) => Promise<any>`                                           | Authenticated GET requests expecting JSON responses                         |
| **postJson**         | `(url: string, body: Record<string, unknown>) => Promise<any>`            | Authenticated POST requests with JSON body                                  |
| **putJson**          | `(url: string, body: Record<string, unknown>) => Promise<any>`            | Authenticated PUT requests (full resource replacement)                     |
| **patchJson**        | `(url: string, body: Record<string, unknown>) => Promise<any>`            | Authenticated PATCH requests (partial resource update)                     |
| **deleteJson**       | `(url: string) => Promise<any>`                                          | Authenticated DELETE requests                                               |
| **postForm**         | `(url: string, formData: FormData) => Promise<any>`                      | Authenticated multipart/form-data uploads (e.g. images)                     |
| **hasPermission**     | `(permissionString: string) => Promise<boolean>`                         | Check if current user has a specific Auth0 permission before rendering UI   |

### JWT Bearer Token Injection
The hook automatically attaches the current user's Auth0 JWT as an `Authorization: Bearer` header to every request. You **never** set headers manually:

```typescript
// ✅ Automatic (correct)
const { getJson } = useSecuredApi();
const data = await getJson("/v1/protected/endpoint");

// ❌ Manual (incorrect - will fail)
const data = await fetch("/v1/protected/endpoint", {
  headers: { Authorization: `Bearer ${token}` } // ❌ Never do this
});
```

### Usage Examples

#### 1. GET Request (Fetch User Profile)
```tsx
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { useEffect, useState } from "react";

export function UserProfile() {
  const { getJson } = useSecuredApi();
  const [profile, setProfile] = useState(null);

  useEffect(() => {
    const fetchProfile = async () => {
      const data = await getJson("/v1/users/me");
      setProfile(data);
    };
    fetchProfile();
  }, []);

  return (
    <div>
      <h2>{profile?.name}</h2>
      <p>{profile?.email}</p>
    </div>
  );
}
```

```tsx
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

### Permission Check Example
Guard an admin UI element using `hasPermission()`:

```tsx
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { useEffect, useState } from "react";

export function AdminDashboard() {
  const { hasPermission } = useSecuredApi();
  const [isAdmin, setIsAdmin] = useState(false);

  useEffect(() => {
    const checkAdmin = async () => {
      const hasAdminAccess = await hasPermission("admin:dashboard:access");
      setIsAdmin(hasAdminAccess);
    };
    checkAdmin();
  }, []);

  if (!isAdmin) return <p>Access denied</p>;

  return (
    <div className="p-4">
      <h1>Admin Dashboard</h1>
      {/* Admin-only content */}
    </div>
  );
}
```

### When NOT to Use This Hook
**Avoid** `useSecuredApi()` for:
- Public routes (e.g. product listings, marketing pages)
- Unauthenticated API calls (use plain `fetch()` or `useQuery` instead)
- Static content (use Vite's `import` for assets)

```typescript
// ✅ Correct for public data
const products = await fetch("/v1/products").then(res => res.json());

// ❌ Incorrect (unnecessary auth)
const { getJson } = useSecuredApi();
const products = await getJson("/v1/products"); // ❌ Overkill
```

### Auth0 Management Helpers
For **admin users** with `auth0:admin:api` permission, the hook exposes:

| Helper Method                     | Use Case                                                                 |
|-----------------------------------|--------------------------------------------------------------------------|
| `getAuth0ManagementToken()`       | Get a temporary Auth0 Management API token (cached in KV)               |
| `listAuth0Users()`                | List all Auth0 users (paginated)                                        |
| `getUserPermissions(userId)`      | Check permissions for a specific user                                  |
| `addPermissionToUser()`           | Grant a permission to a user                                            |
| `removePermissionFromUser()`      | Revoke a permission from a user                                         |
| `deleteAuth0User(userId)`        | Permanently delete a user from Auth0                                    |
| `getResourceServers()`            | List all Auth0 API resource servers                                     |
| `updateResourceServerScopes()`    | Modify permissions (scopes) for an API                                 |

Example: List all users with admin privileges:
```tsx
const { getAuth0ManagementToken, listAuth0Users, getUserPermissions } = useSecuredApi();

const fetchAdmins = async () => {
  const token = await getAuth0ManagementToken();
  const users = await listAuth0Users(token.access_token);
  const admins = [];

  for (const user of users) {
    const permissions = await getUserPermissions(token.access_token, user.user_id);
    if (permissions.some(p => p.permission_name.includes("admin"))) {
      admins.push(user);
    }
  }

  return admins;
};
```
