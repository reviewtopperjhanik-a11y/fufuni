## Introduction and Import Path

The `useSecuredApi` hook is the primary interface for React components to communicate with protected routes in the Fufuni backend. It abstracts away the complexity of Auth0 token management, silent refreshes, and header injection.

When using this hook, you do not need to manually fetch the Access Token or set the `Authorization: Bearer <token>` header. The hook internally retrieves the valid JWT from the `useAuth` provider and attaches it to every request.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { useState, useEffect } from "react";
import { Button, Card, CardBody } from "@heroui/react";

/**
 * Basic usage example in a functional component
 */
export const MySecureComponent = () => {
  const { getJson } = useSecuredApi();
  const [data, setData] = useState<any>(null);

  const fetchData = async () => {
    // No headers needed; JWT is injected automatically
    const result = await getJson("/v1/protected/resource");
    setData(result);
  };

  return (
    <Button onPress={fetchData}>Fetch Private Data</Button>
  );
};
```

## Hook Reference Table

The hook returns an object containing several asynchronous methods for HTTP operations and permission checking. All JSON-based methods automatically set the `Content-Type: application/json` header.

| Method | Signature | When to use |
| :--- | :--- | :--- |
| `getJson` | `(url: string) => Promise<T>` | Authenticated GET requests expecting a JSON response. |
| `postJson` | `(url: string, body: any) => Promise<T>` | Authenticated POST requests with a JSON body. |
| `putJson` | `(url: string, body: any) => Promise<T>` | Authenticated PUT requests for full resource replacement. |
| `patchJson` | `(url: string, body: any) => Promise<T>` | Authenticated PATCH requests for partial updates. |
| `deleteJson` | `(url: string) => Promise<T>` | Authenticated DELETE requests. |
| `postForm` | `(url: string, formData: FormData) => Promise<T>` | Authenticated multipart/form-data POST (e.g., file/image uploads). |
| `hasPermission` | `(permission: string) => Promise<boolean>` | Async check if the user possesses a specific Auth0 scope. |

## Automatic JWT Injection

The Fufuni framework utilizes the Auth0 SPA SDK via the `useAuth` provider. When you call a method like `postJson`, the hook performs the following sequence:

1.  Calls `getAccessTokenSilently()` to retrieve a valid JWT from the Auth0 cache or via a hidden iframe.
2.  Constructs a `fetch` request.
3.  Injects the `Authorization: Bearer <token>` header.
4.  Standardizes error handling (throwing errors for non-2xx status codes).

Because this process is asynchronous, these methods always return a `Promise`.

```typescript
// Internal logic simplified representation:
// You don't write this; useSecuredApi does this for you.
const token = await getAccessToken();
const response = await fetch(url, {
  headers: {
    Authorization: `Bearer ${token}`,
    "Content-Type": "application/json"
  },
  ...options
});
```

## CRUD Usage Examples

Below are three complete examples demonstrating the most common operations using HeroUI v3 components.

### 1. Fetching Data (GET)
This example demonstrates fetching a list of private "Orders" and rendering them in a HeroUI table.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Table, TableHeader, TableColumn, TableBody, TableRow, TableCell, Spinner } from "@heroui/react";
import { useEffect, useState } from "react";

interface Order {
  id: string;
  amount: number;
  status: string;
}

export const OrderHistory = () => {
  const { getJson } = useSecuredApi();
  const [orders, setOrders] = useState<Order[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    getJson("/v1/orders/me")
      .then((data) => setOrders(data as Order[]))
      .catch(console.error)
      .finally(() => setLoading(false));
  }, [getJson]);

  if (loading) return <Spinner />;

  return (
    <Table aria-label="My Orders">
      <TableHeader>
        <TableColumn>ID</TableColumn>
        <TableColumn>STATUS</TableColumn>
        <TableColumn>AMOUNT</TableColumn>
      </TableHeader>
      <TableBody>
        {orders.map((order) => (
          <TableRow key={order.id}>
            <TableCell>{order.id}</TableCell>
            <TableCell>{order.status}</TableCell>
            <TableCell>${order.amount}</TableCell>
          </TableRow>
        ))}
      </TableBody>
    </Table>
  );
};
```

### 2. Creating a Resource (POST)
This example shows how to send a JSON payload to the backend to create a new support ticket.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button, Input, Textarea } from "@heroui/react";
import { useState } from "react";

export const CreateTicket = () => {
  const { postJson } = useSecuredApi();
  const [subject, setSubject] = useState("");
  const [message, setMessage] = useState("");
  const [isSubmitting, setIsSubmitting] = useState(false);

  const handleSubmit = async () => {
    setIsSubmitting(true);
    try {
      await postJson("/v1/support/tickets", { subject, message });
      alert("Ticket created successfully!");
      setSubject("");
      setMessage("");
    } catch (err) {
      alert("Failed to create ticket");
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <div className="flex flex-col gap-4 max-w-md">
      <Input 
        label="Subject" 
        value={subject} 
        onValueChange={setSubject} 
      />
      <Textarea 
        label="Message" 
        value={message} 
        onValueChange={setMessage} 
      />
      <Button 
        color="primary" 
        isLoading={isSubmitting} 
        onPress={handleSubmit}
      >
        Submit Ticket
      </Button>
    </div>
  );
};
```

### 3. Deleting a Resource (DELETE)
Standard pattern for deleting a resource using the specific HTTP verb.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { Button } from "@heroui/react";

export const DeleteAccountButton = ({ userId }: { userId: string }) => {
  const { deleteJson } = useSecuredApi();

  const handleDelete = async () => {
    const confirmed = window.confirm("Are you sure?");
    if (!confirmed) return;

    try {
      await deleteJson(`/v1/users/${userId}`);
      window.location.href = "/";
    } catch (error) {
      console.error("Deletion failed", error);
    }
  };

  return (
    <Button color="danger" variant="flat" onPress={handleDelete}>
      Terminate Account
    </Button>
  );
};
```

## Guarding UI Elements with `hasPermission()`

The `hasPermission` function allows you to conditionally render UI components based on the user's Auth0 scopes. This is vital for "Admin" or "Moderator" sections. Note that `hasPermission` is asynchronous because it may need to verify the token state.

```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
import { useEffect, useState } from "react";
import { Card, CardHeader, Divider } from "@heroui/react";

export const AdminDashboardPanel = () => {
  const { hasPermission } = useSecuredApi();
  const [isAdmin, setIsAdmin] = useState<boolean>(false);

  useEffect(() => {
    const checkStatus = async () => {
      const allowed = await hasPermission("admin:all");
      setIsAdmin(allowed);
    };
    checkStatus();
  }, [hasPermission]);

  if (!isAdmin) return null; // Hide completely for non-admins

  return (
    <Card className="border-danger">
      <CardHeader className="text-danger font-bold">
        Admin Control Plane
      </CardHeader>
      <Divider />
      {/* Admin specific tools go here */}
    </Card>
  );
};
```

## When NOT to use this Hook

It is important to distinguish between **Public** and **Protected** routes.

1.  **Public Routes:** For endpoints like `GET /v1/products` or `GET /v1/config`, do **NOT** use `useSecuredApi`. Using it on public routes forces an authentication check and will trigger a login redirect or fail if the user is not logged in. Use standard `fetch()` or a library like TanStack Query (`useQuery`) with a basic fetcher.
2.  **External APIs:** Do not use this hook to call 3rd party APIs (like Stripe or SendGrid) directly. Your Auth0 JWT is meant for the Fufuni backend only.
3.  **AI Inference:** Fufuni handles AI parameters differently. You use `getJson` to get credentials from `/v1/ai/parameters`, but then you use the `ai-client.ts` helpers directly to talk to the AI provider from the browser, bypassing the backend for the actual inference stream.

## Auth0 Management API Helpers

The `useSecuredApi` hook also exposes several advanced helpers for interacting with the Auth0 Management API. These are primarily used in the "User Management" or "API Configuration" sections of the admin dashboard.

**Warning:** Most of these methods require the `auth0:admin:api` permission and a backend configured to handle the `/v1/__auth0/token` proxy.

### List of Helpers
- `getAuth0ManagementToken()`: Obtains a Machine-to-Machine token via the Fufuni worker (cached in KV).
- `listAuth0Users(token)`: Returns an array of `Auth0User` objects.
- `getUserPermissions(token, userId)`: Fetches specific scopes assigned to a user.
- `addPermissionToUser(token, userId, permissionName)`: Dynamically assigns a scope.
- `removePermissionFromUser(token, userId, permissionName)`: Revokes a scope.
- `deleteAuth0User(token, userId)`: Completely removes a user from the Auth0 database.
- `getResourceServerScopes(token, id)`: Lists the scopes defined for an API.
- `updateResourceServerScopes(token, id, scopes)`: Synchronizes the backend's Zod-OpenAPI scopes with the Auth0 dashboard.

### Example: Syncing API Scopes
This is typically done by a "Super Admin" when new routes are added to the Hono backend.

```typescript
const syncScopes = async () => {
  const { getAuth0ManagementToken, updateResourceServerScopesWithAudience } = useSecuredApi();
  
  const mgmtToken = await getAuth0ManagementToken();
  const targetScopes = [
    { value: "orders:read", description: "Read personal orders" },
    { value: "admin:all", description: "Global administrator access" }
  ];

  await updateResourceServerScopesWithAudience(
    mgmtToken.access_token,
    "https://api.fufuni.com", 
    targetScopes
  );
};
```
