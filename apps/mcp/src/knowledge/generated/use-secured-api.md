## useSecuredApi() Hook Reference

Import the hook from:
```typescript
import { useSecuredApi } from "@/features/auth/components/auth-components";
```

## Return Values

| Method          | Signature                          | When to Use                                  |
|-----------------|------------------------------------|----------------------------------------------|
| `getJson`       | `(url: string) => Promise<any>`    | Authenticated GET requests returning JSON    |
| `postJson`      | `(url: string, body: object) => Promise<any>` | Authenticated POST with JSON body       |
| `putJson`       | `(url: string, body: object) => Promise<any>` | Authenticated PUT (full replace)        |
| `patchJson`     | `(url: string, body: object) => Promise<any>` | Authenticated PATCH (partial update)    |
| `deleteJson`    | `(url: string) => Promise<any>`    | Authenticated DELETE requests                |
| `postForm`      | `(url: string, formData: FormData) => Promise<any>` | Authenticated multipart/form-data POST (e.g. file uploads) |
| `hasPermission` | `(permission: string) => Promise<boolean>` | Check if user has specific Auth0 permission |

## JWT Bearer Token Handling

The hook automatically injects the Auth0 JWT Bearer token into every request. You never need to manually set `Authorization` headers.

## Usage Examples

### GET Request Example
```tsx
import { useSecuredApi } from "@/features/auth/components/auth-components";

function UserProfile() {
  const { getJson } = useSecuredApi();
  const [profile, setProfile] = React.useState(null);

  React.useEffect(() => {
    getJson("/api/v1/user/profile")
      .then(setProfile)
      .catch(console.error);
  }, []);

  return <div>{profile?.name}</div>;
}
```

      await postJson("/api/v1/products", formData);
      // Handle success

    } finally {

  };

    <form onSubmit={handleSubmit}>

### DELETE Request Example
```tsx
import { useSecuredApi } from "@/features/auth/components/auth-components";

function DeleteProduct({ productId }) {
  const { deleteJson } = useSecuredApi();

  const handleDelete = async () => {
    if (confirm("Are you sure?")) {
      await deleteJson(`/api/v1/products/${productId}`);
      // Refresh product list
    }
  };

  return <button onClick={handleDelete}>Delete</button>;
}
```

## hasPermission() Example

```tsx
import { useSecuredApi } from "@/features/auth/components/auth-components";

function AdminPanel() {
  const { hasPermission } = useSecuredApi();
  const [hasAdminAccess, setHasAdminAccess] = React.useState(false);

  React.useEffect(() => {
    hasPermission("admin:dashboard").then(setHasAdminAccess);
  }, []);

  return (
    <>
      {hasAdminAccess && (
        <div className="admin-controls">
          {/* Admin controls here */}
        </div>
      )}
    </>
  );
}
```

## When NOT to Use This Hook

Do not use `useSecuredApi()` for public routes or unauthenticated endpoints (e.g., product listings). For public data, use standard `fetch()` or a dedicated public API hook.

## Auth0 Management Helpers

The hook exposes additional helpers for Auth0 Management API (requires `auth0:admin:api` permission):

- `getAuth0ManagementToken()`: Obtain a management API token
- `listAuth0Users()`: List all Auth0 users
- `getUserPermissions()`: Get permissions for a specific user
- `addPermissionToUser()`: Grant a permission to a user
- `removePermissionFromUser()`: Revoke a permission from a user
- `deleteAuth0User()`: Delete an Auth0 user
- `getResourceServers()`: List configured resource servers
- `updateResourceServerScopes()`: Update scopes for a resource server

These helpers are primarily used in admin interfaces for user and permission management.
