## Discount Types

Fufuni supports three discount types:

1. `percentage`: Reduces cart subtotal by a percentage (0-100%)
2. `fixed_amount`: Reduces cart subtotal by a fixed amount (currency-specific)
3. `free_shipping`: Waives shipping costs (not shown in code but per verified facts)

Discount fields:
```typescript
interface Discount {
  id: string; // UUID
  code: string | null; // Null for automatic discounts
  type: 'percentage' | 'fixed_amount' | 'free_shipping';
  value: number; // 25 for 25%, or 1000 for $10.00
  min_purchase_cents: number; // Minimum cart value in cents
  max_discount_cents: number | null; // Maximum discount cap
  starts_at: string | null; // ISO 8601 timestamp
  expires_at: string | null; // ISO 8601 timestamp
  usage_limit: number | null; // Maximum redemptions
  usage_limit_per_customer: number | null; // Per-customer limit
  // ... other fields
}
```

## Atomic Use Counting

Each redemption increments `usage_count` atomically:

```sql
-- Inside Durable Object transaction
UPDATE discounts
SET usage_count = usage_count + 1
WHERE id = ? AND status = 'active'
  AND (usage_limit IS NULL OR usage_count < usage_limit)
  AND (expires_at IS NULL OR NOW() <= expires_at);
```

If the update affects 0 rows, the code is rejected.

## Pricing Pipeline

1. **Base Price**: From `variant_prices` table
2. **Tier Pricing**: Volume discounts (not shown in code)
3. **Discounts**: Applied to subtotal
4. **Tax**: Calculated on discounted subtotal

Example calculation:
```typescript
// From discounts.ts
function calculateDiscount(discount: Discount, subtotalCents: number): number {
  switch (discount.type) {
    case 'percentage':
      return Math.min(
        Math.floor((subtotalCents * discount.value) / 100),
        discount.max_discount_cents || Infinity
      );
    case 'fixed_amount':
      return Math.min(discount.value, subtotalCents);
  }
}
```
