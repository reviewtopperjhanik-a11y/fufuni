## Discount Types and Fields

Fufuni supports three discount types, each with specific validation rules:

### 1. Percentage Discount
```typescript
{
  type: 'percentage',
  value: 10,       // 10% (0-100)
  max_discount_cents: 5000, // Optional: cap at $50.00
  currency: 'USD'  // Required for max_discount_cents
}
```

### 2. Fixed Amount Discount
```typescript
{
  type: 'fixed_amount',
  value: 1500,     // $15.00 off
  currency: 'USD'  // Required
}
```

### 3. Free Shipping Discount
```typescript
{
  type: 'free_shipping',
  value: 0,        // Not used
  min_purchase_cents: 10000 // Optional: require $100+ cart
}
```

**Common Fields for All Types:**
```typescript
interface Discount {
  id: string;              // UUID
  code: string | null;     // "SUMMER20" or null for automatic discounts
  status: 'active' | 'inactive';
  starts_at: string | null; // ISO 8601 or null for immediate
  expires_at: string | null;
  usage_limit: number | null;
  usage_limit_per_customer: number | null;
  usage_count: number;     // Tracked atomically
  stripe_coupon_id: string | null;
  stripe_promotion_code_id: string | null;
}
```

## Atomic Use Counting

Fufuni uses Durable Objects to ensure atomic counter increments:

```typescript
// Inside cart checkout transaction:
await db.run(`
  UPDATE discounts
  SET usage_count = usage_count + 1
  WHERE id = ? AND (
    usage_limit IS NULL OR
    usage_count < usage_limit
  )
`, [discountId]);

// Check affected rows:
const [result] = await db.query<{ changes: number }>(
  `SELECT changes() as changes`
);
if (result.changes === 0) {
  throw ApiError.invalidRequest('Discount usage limit reached');
}
```

**Per-Customer Tracking:**
```typescript
// Record usage in separate table
await db.run(`
```

## Pricing Pipeline

Calculations follow this strict 4-step order:

1. **Base Price Resolution**
   ```typescript
   const basePrice = await resolveVariantPrice(db, variantId, currencyId);
   // Throws if no price configured for variant+currency
   ```

2. **Tier Pricing (if applicable)**
   ```typescript
   const tierPrice = await applyTierPricing(db, variantId, quantity);
   // Example: 3 for $50 instead of $60
   ```

3. **Discount Application**
   ```typescript
   const discountAmount = calculateDiscount(discount, subtotalCents);
   const discountedSubtotal = subtotalCents - discountAmount;
   ```

4. **Tax Calculation**
   ```typescript
   const taxAmount = computeTax(discountedSubtotal, taxRate);
   const total = discountedSubtotal + taxAmount;
   ```

**Complete Example:**
```typescript
// 1. Resolve prices for all items
const itemPrices = await Promise.all(
  cart.items.map(item =>
    resolveVariantPrice(db, item.variant_id, currencyId)
  )
);

// 2. Calculate subtotal
const subtotalCents = itemPrices.reduce((sum, price, i) =>
  sum + (price * cart.items[i].quantity), 0);

// 3. Apply discount
const discountAmount = discount ?
  calculateDiscount(discount, subtotalCents) : 0;
const discountedSubtotal = subtotalCents - discountAmount;

// 4. Add tax
const taxRate = await getTaxRate(db, cart.region_id);
const taxCents = Math.round(discountedSubtotal * taxRate);
const totalCents = discountedSubtotal + taxCents;
```

## Currency Handling

### Storage Rules
- **All monetary values** are stored as integers (smallest unit)
  ```typescript
  // $19.99 → 1999 cents
  // €24.50 → 2450 cents
  ```
- **Database schema** uses `INTEGER` for all price fields:
  ```sql
  CREATE TABLE variant_prices (
    variant_id TEXT NOT NULL,
    currency_id TEXT NOT NULL,
    price_cents INTEGER NOT NULL,  -- Never float
    PRIMARY KEY (variant_id, currency_id)
  );
  ```

### Client-Side Formatting
Use `Intl.NumberFormat` with the currency code:

```typescript
function formatPrice(cents: number, currencyCode: string): string {
  return new Intl.NumberFormat(undefined, {
    style: 'currency',
    currency: currencyCode,
    currencyDisplay: 'narrowSymbol'
  }).format(cents / 100);
}

// Usage:
formatPrice(2999, 'USD'); // "$29.99"
formatPrice(2450, 'EUR'); // "€24.50"
formatPrice(3990, 'JPY'); // "¥3,990"
```

### Multi-Currency Example
```typescript
// Backend (TypeScript)
const prices = {
  USD: 2999,  // $29.99
  EUR: 2799,  // €27.99
  GBP: 2499   // £24.99
};

// Frontend (React)
<ul>
  {Object.entries(prices).map(([currency, cents]) => (
    <li key={currency}>
      {formatPrice(cents, currency)}
    </li>
  ))}
</ul>
```
