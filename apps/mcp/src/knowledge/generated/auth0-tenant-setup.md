## Auth0 Tenant Setup Reference

### When to run the deploy script
Run `npm run auth0:deploy` **once per new Auth0 tenant** from the monorepo root. Re-run it only when:
- Adding new permission scopes
- Changing callback URLs
- Reconfiguring social logins
- Recovering from a misconfigured tenant

```bash
# From monorepo root
npx tsx scripts/auth0/deploy-tenant-resources.ts -- --env-file=.env.production
```

### What the script configures
1. **SPA Client**: PKCE-enabled application with allowed origins/callbacks
2. **API Resource Server**: Defines all permission scopes (e.g., `read:messages`)
3. **Social Connections**: Google, GitHub, Microsoft, Apple logins
4. **authadmin Role**: Grants `admin:store` + `auth0:admin:api` permissions
5. **Login Post-Action**: Injects permissions into ID tokens

### Required environment variables
Create a `.env` file with these **5 mandatory** variables:

```ini
# Auth0 tenant domain (e.g., "my-tenant.eu.auth0.com")
AUTH0_DOMAIN=your-tenant.auth0.com

# Management API client (machine-to-machine)
AUTH0_MANAGEMENT_API_CLIENT_ID=your_management_client_id
AUTH0_MANAGEMENT_API_CLIENT_SECRET=your_management_client_secret

# Your API audience (must match backend CORS)
AUTH0_AUDIENCE=https://api.yourdomain.com/

# Store URL (for callback validation)
STORE_URL=https://store.yourdomain.com
```

### Adding a new permission scope
1. **Update the scopes array** in `deploy-tenant-resources.ts`:
   ```typescript
   scopes: [
     // ... existing scopes
     { value: "delete:products", description: "Delete products" }
   ]
   ```

2. **Re-run the deploy script**:
   ```bash
   npm run auth0:deploy -- --env-file=.env.production
   ```

3. **Assign to roles** (if admin-only):
   ```typescript
   // In Auth0 Dashboard > Roles > authadmin
   // Add "delete:products" to the role's permissions
   ```

4. **Use in frontend guards**:
   ```tsx
   // In your React component
   if (!hasPermission("delete:products")) {
     return <PermissionDenied />;
   }
   ```

### The authadmin role
**Permissions granted**:
- `admin:store`: Full access to Fufuni admin endpoints
- `auth0:admin:api`: Can call Auth0 Management API

**Assigning to a user**:
1. Go to Auth0 Dashboard > User Management
2. Select user > "Roles" tab
3. Assign the `authadmin` role

**Verification**:
```typescript
// Backend check (Hono middleware)
app.use("/admin/*", async (c, next) => {
  const user = c.get("user");
  if (!user.permissions.includes("admin:store")) {
    return c.json({ error: "Forbidden" }, 403);
  }
  await next();
});
```

### Management API client vs SPA client
| Feature               | Management API Client          | SPA Client                     |
|-----------------------|---------------------------------|---------------------------------|
| **Purpose**           | Script/Backend API access       | Frontend authentication         |
| **Auth Flow**         | Client Credentials              | PKCE                            |
| **Used by**           | `deploy-tenant-resources.ts`    | React frontend                  |
| **Token Storage**     | Never in browser                | `localStorage` (HTTP-only)      |
| **Env Vars**          | `AUTH0_MANAGEMENT_*`            | `AUTH0_CLIENT_ID`               |

**Example usage**:
```typescript
// Backend: Using Management API client
const token = await getValidMgmtToken(
  env("AUTH0_DOMAIN"),
  env("AUTH0_MANAGEMENT_API_CLIENT_ID"),
  env("AUTH0_MANAGEMENT_API_CLIENT_SECRET")
);

// Frontend: Using SPA client
const { login } = useAuth0();
await login({
  authorizationParams: {
    audience: import.meta.env.VITE_AUTH0_AUDIENCE,
    scope: "openid profile email read:messages"
  }
});
```

### Login post-action: Permission injection
**Purpose**: The post-action modifies the ID token to include a `permissions` array that matches the Auth0 scopes. This enables frontend permission checks via `import.meta.env.PERMISSIONS`.

**How it works**:
1. User logs in via Auth0
2. Post-action executes after authentication
3. Injects `permissions` claim into ID token:
   ```json
   {
     "permissions": [
       "read:messages",
       "admin:store"
     ]
   }
   ```
4. Frontend accesses via:
   ```tsx
   // React component
   const { permissions } = useUser();
   if (permissions.includes("delete:products")) {
     return <DeleteButton />;
   }
   ```

**Action code location**:
```
scripts/auth0/auth0-code/add-userinfo-to-access-jwt.js
```

**Critical dependency**: Without this action, `hasPermission()` checks in the frontend will always fail. Verify it's installed by checking:
1. Auth0 Dashboard > Actions > Flows > Login
2. Confirm "Add Userinfo to jwt" action is bound to the flow
