## Auth0 Tenant Setup Reference

This script configures a new Auth0 tenant for Fufuni. Run it once per tenant using `npm run auth0:deploy` from the monorepo root.

### Purpose and Execution
The `deploy-tenant-resources.ts` script is a one-shot setup for configuring a new Auth0 tenant. Run it when:
- Setting up a new development environment
- Creating a new production tenant
- Resetting an existing tenant configuration

```bash
npm run auth0:deploy
```

### Configuration Components
The script configures four main components:

1. **SPA Client**: Frontend application with PKCE flow and configured callbacks
2. **API Resource Server**: Backend API with permission scopes
3. **Social Connections**: Google, GitHub, and other social logins
4. **authadmin Role**: Administrative role with full permissions

### Required Environment Variables
The script requires these environment variables (set via `--env-file`):

```env
AUTH0_DOMAIN=your-tenant.auth0.com
AUTH0_MANAGEMENT_API_CLIENT_ID=your_management_client_id
AUTH0_MANAGEMENT_API_CLIENT_SECRET=your_management_client_secret
AUTH0_AUDIENCE=https://api.your-domain.com/
STORE_URL=http://localhost:5173
```

Example `.env` file:
```env
AUTH0_DOMAIN=my-tenant.eu.auth0.com
AUTH0_TENANT=my-tenant
AUTH0_MANAGEMENT_API_CLIENT_ID=abc123
AUTH0_MANAGEMENT_API_CLIENT_SECRET=xyz789
AUTH0_AUDIENCE=https://api.my-domain.com/
STORE_URL=http://localhost:5173
```

### Adding New Permission Scopes
To add a new permission scope:

1. Add to scopes array in `deploy-tenant-resources.ts`:
```typescript
scopes: [
  // existing scopes...
  { value: "new:scope", description: "New permission description" },
],
```

2. Re-run the deploy script:
```bash
npm run auth0:deploy
```

3. Grant to admin role if needed (via Auth0 Dashboard)

4. Use in frontend guards:
```typescript
if (hasPermission("new:scope")) {
  // protected code
}
```

### authadmin Role
The authadmin role grants:
- `admin:store`: Full access to Fufuni admin endpoints
- `auth0:admin:api`: Access to Auth0 Management API

To assign to a user:
1. In Auth0 Dashboard, go to "Users & Roles" > "Roles"
2. Select "authadmin" role
3. Click "Assign Users" and add the user

### Client Types
**Management API Client** vs **SPA Client**:
- Management API Client: Machine-to-machine client used by:
  - The deploy script
  - Backend Management API proxy
  - Never used by frontend applications

- SPA Client: Public client for frontend applications using:
  - Authorization Code + PKCE flow
  - Configured callbacks and origins

### Login Post-Action
The script installs a post-login action that:
1. Enriches the ID token with user permissions array
2. Enables frontend permission checks via `import.meta.env.PERMISSIONS`

This is required for frontend permission guards to work with Auth0 scopes.

Example permission check:
```typescript
import { hasPermission } from "@/auth/permissions";

function AdminPanel() {
  if (!hasPermission("admin:store")) {
    return <div>Access denied</div>;
  }
  return <div>Admin content</div>;
}
```
