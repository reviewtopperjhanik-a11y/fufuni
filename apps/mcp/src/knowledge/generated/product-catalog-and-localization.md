## Product Model

The product model in Fufuni consists of the following fields:

- `id`: UUID (primary key)
- `name`: Product name (base en-US)
- `description`: Product description (base en-US)
- `category_id`: UUID referencing the category
- `base_currency`: ISO 4217 currency code (e.g., "USD")
- `images`: Ordered JSON array of images (see below)
- `tags`: JSON array of strings or object for multilingual tags
- `created_at`: Timestamp
- `updated_at`: Timestamp

### Variant Model

Each product can have multiple variants stored in the `product_variants` table:

- `id`: UUID (primary key)
- `product_id`: UUID referencing the product
- `sku`: Stock keeping unit (string)
- `price_cents`: Price in cents (integer)
- `currency`: ISO 4217 currency code
- `stock_quantity`: Available stock (integer)
- `attributes`: JSON object (e.g., `{ "size": "M", "color": "black" }`)
- `title`: Variant title (e.g., "Black / Medium")
- `weight_g`: Weight in grams
- `dims_cm`: Dimensions in cm as `{ l, w, h }`
- `requires_shipping`: Boolean
- `barcode`: String (nullable)
- `compare_at_price_cents`: Original price in cents (nullable)

### Image Array Structure

Product images are stored as an ordered JSON array in the `images` column:

```typescript
interface ProductImage {
  url: string;
  alt: string;
  isPrimary: boolean;
}

type ProductImages = ProductImage[];
```

Example:
```json
[
  {
    "url": "https://example.com/image1.jpg",
    "alt": "Product front view",
    "isPrimary": true
  },
  {
    "url": "https://example.com/image2.jpg",
    "alt": "Product side view",
    "isPrimary": false
  }
]
```

The thumbnail is determined by the first image with `isPrimary: true`.

## Category Tree

Categories form a hierarchical tree structure using the `parent_id` field:

- `id`: UUID (primary key)
- `parent_id`: UUID referencing parent category (nullable for root categories)
- `slug`: URL-friendly category identifier
- `position`: Integer for sorting within parent

### Creating Nested Categories

To create a nested category structure:

1. Create root categories with `parent_id: null`
2. Create sub-categories with `parent_id` set to the parent category's ID
3. Use `position` to control display order within the same parent

Example category tree:
```
Electronics (parent_id: null)
├── Phones (parent_id: electronics-id)
│   ├── Smartphones (parent_id: phones-id)
│   └── Accessories (parent_id: phones-id)
└── Computers (parent_id: electronics-id)
```


## Localization

Fufuni supports localized product and category data through dedicated tables:

### Database Tables

**product_locales:**
```sql
CREATE TABLE product_locales (
  product_id UUID REFERENCES products(id),
  locale VARCHAR(10),
  name VARCHAR(255),
  description TEXT,
  PRIMARY KEY (product_id, locale)
);
```

**category_locales:**
```sql
CREATE TABLE category_locales (
  category_id UUID REFERENCES categories(id),
  locale VARCHAR(10),
  name VARCHAR(255),
  PRIMARY KEY (category_id, locale)
);
```

### Fallback Logic

When requesting data with a specific locale:
1. Check for translation in the requested locale
2. If not found, fall back to `en-US`
3. If `en-US` not available, return null for localized fields

### Setting Translations

To add or update translations:

```typescript
// Example: Update French translation for a product
await db.insert(product_locales).values({
  product_id: '123e4567-e89b-12d3-a456-426614174000',
  locale: 'fr-FR',
  name: 'Téléphone intelligent',
  description: 'Un téléphone intelligent avec toutes les fonctionnalités.'
});
```

## Variant Management

### Creating Variants

```typescript
// POST /v1/products/:id/variants
const response = await fetch('https://api.example.com/v1/products/123/variants', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer admin-token',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    sku: 'PHONE-BLACK-M',
    price_cents: 69999,
    currency: 'USD',
    stock_quantity: 50,
    attributes: {
      color: 'black',
      size: 'medium'
    },
    title: 'Black / Medium',
    weight_g: 150,
    dims_cm: { l: 15, w: 7, h: 1 },
    requires_shipping: true
  })
});
```

### Updating Variants

```typescript
// PUT /v1/products/:id/variants/:variantId
await fetch('https://api.example.com/v1/products/123/variants/456', {
  method: 'PUT',
  headers: {
    'Authorization': 'Bearer admin-token',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    price_cents: 64999,
    stock_quantity: 45
  })
});
```

### Deleting Variants

```typescript
// DELETE /v1/products/:id/variants/:variantId
await fetch('https://api.example.com/v1/products/123/variants/456', {
  method: 'DELETE',
  headers: {
    'Authorization': 'Bearer admin-token'
  }
});
```

### Attributes JSON Format

Variant attributes are stored as a JSON object with key-value pairs:

```json
{
  "color": "black",
  "size": "medium",
  "material": "cotton"
}
```

## Product Tags

Product tags are stored as a many-to-many relationship in the `product_tags` table:

```sql
CREATE TABLE product_tags (
  product_id UUID REFERENCES products(id),
  tag_id UUID REFERENCES tags(id),
  PRIMARY KEY (product_id, tag_id)
);
```

### Filtering by Tags

To filter products by tags, use the `tags` query parameter with comma-separated tag values:

```
GET /v1/products?tags=sale,new,featured
```

This returns products that have ANY of the specified tags (OR logic).

## Image Array Management

### Image Structure

Each image in the array has:

- `url`: Image URL (required)
- `alt`: Alternative text (required)
- `isPrimary`: Boolean (optional, default false)

### Setting Primary Image

To set a primary image, include `isPrimary: true` in the image object:

```json
{
  "url": "https://example.com/primary.jpg",
  "alt": "Primary product image",
  "isPrimary": true
}
```

### Reordering Images

To reorder images, update the entire `images` array with the new order:

```typescript
// PUT /v1/products/:id
await fetch('https://api.example.com/v1/products/123', {
  method: 'PUT',
  headers: {
    'Authorization': 'Bearer admin-token',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    images: [
      { url: 'new-first.jpg', alt: 'First', isPrimary: true },
      { url: 'new-second.jpg', alt: 'Second' },
      { url: 'new-third.jpg', alt: 'Third' }
    ]
  })
});
```
