## Product Catalog & Localization Reference

### Product Model

Products in Fufuni have the following fields:

```typescript
interface Product {
  id: string; // UUID
  name: string; // Localized
  description: string; // Localized, nullable
  category_id: string; // UUID
  base_currency: string; // ISO 4217 code
  images: ProductImage[]; // Ordered array
  tags: string[]; // Array of tag strings
  created_at: string; // ISO 8601 timestamp
  updated_at: string; // ISO 8601 timestamp
  variants?: Variant[]; // Array of variants
}

interface ProductImage {
  url: string;
  alt: string | null;
  isPrimary: boolean;
}

interface Variant {
  id: string; // UUID
  sku: string;
  price_cents: number;
  currency: string;
  stock_quantity: number;
  attributes: Record<string, string | number>;
  shipping_class_id: string | null;
  variant_type: 'physical' | 'digital' | 'ai_tokens';
  ai_token_units: number | null; // For ai_tokens type
  weight_g: number;
  dims_cm: { l: number; w: number; h: number } | null;
}
```

### Category Tree

Categories form a hierarchical tree structure:

```typescript
interface Category {
  id: string; // UUID
  parent_id: string | null; // UUID of parent category, null for root
  slug: string; // URL-friendly identifier
  name: string; // Localized
}
```

To create nested categories:
1. Create parent category first
2. When creating child category, set `parent_id` to the parent's ID
3. The full tree can be fetched via `GET /v1/categories`


### Localization

Localized content is stored in separate tables:

```sql
-- product_locales table
CREATE TABLE product_locales (
  product_id TEXT NOT NULL,
  locale TEXT NOT NULL,
  name TEXT NOT NULL,
  description TEXT,
  PRIMARY KEY (product_id, locale),
  FOREIGN KEY (product_id) REFERENCES products(id)
);

-- category_locales table
CREATE TABLE category_locales (
  category_id TEXT NOT NULL,
  locale TEXT NOT NULL,
  name TEXT NOT NULL,
  PRIMARY KEY (category_id, locale),
  FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

Fallback logic:
1. Check for content in requested locale (e.g., fr-FR)
2. If not found, fall back to base locale (en-US)
3. If no base locale content exists, return null

To set translations:
```typescript
// Example: Setting French translation for a product
await db.execute(
  'INSERT INTO product_locales (product_id, locale, name, description) VALUES (?, ?, ?, ?)',
  [productId, 'fr-FR', 'Nom en français', 'Description en français']
);
```

### Variant Management

Endpoints:
- `GET /v1/products/{id}/variants` - List all variants
- `POST /v1/products/{id}/variants` - Create new variant (admin)
- `PUT /v1/products/{id}/variants/{variantId}` - Update variant (admin)
- `DELETE /v1/products/{id}/variants/{variantId}` - Delete variant (admin)

Creating a variant:
```typescript
interface CreateVariantBody {
  sku: string;
  price_cents: number;
  currency: string;
  stock_quantity: number;
  attributes: Record<string, string | number>;
  // Optional fields:
  shipping_class_id?: string | null;
  variant_type?: 'physical' | 'digital' | 'ai_tokens';
  ai_token_units?: number | null;
  weight_g?: number;
  dims_cm?: { l: number; w: number; h: number } | null;
}

// Example request body
{
  "sku": "PROD-001-BLK-M",
  "price_cents": 2999,
  "currency": "USD",
  "stock_quantity": 100,
  "attributes": {
    "color": "black",
    "size": "M"
  },
  "weight_g": 500,
  "dims_cm": { "l": 30, "w": 20, "h": 5 }
}
```

### Product Tags

Products can have multiple tags stored in a many-to-many relationship:

```sql
CREATE TABLE product_tags (
  product_id TEXT NOT NULL,
  tag TEXT NOT NULL,
  PRIMARY KEY (product_id, tag),
  FOREIGN KEY (product_id) REFERENCES products(id)
);
```

Filtering by tags:
```bash
# Single tag
curl "https://api.example.com/v1/products?tags=sale"

# Multiple tags (OR logic)
curl "https://api.example.com/v1/products?tags=sale,new-arrival"
```

### Image Array

Images are stored as an ordered JSON array in the `products.images` column:

```typescript
interface ProductImage {
  url: string; // Full image URL
  alt: string | null; // Alternative text
  isPrimary: boolean; // Marks primary image
}

type ProductImages = ProductImage[];
```

Example image array:
```json
[
  {
    "url": "https://example.com/images/product1.jpg",
    "alt": "Product image 1",
    "isPrimary": true
  },
  {
    "url": "https://example.com/images/product2.jpg",
    "alt": "Product image 2",
    "isPrimary": false
  }
]
```

To reorder images:
1. Fetch current product data
2. Modify the images array order
3. Update product with new array

The first image with `isPrimary: true` is used as the thumbnail. If no primary is set, the first image is used.
