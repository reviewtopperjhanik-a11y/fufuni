## Theming & Layouts Reference

Fufuni provides two distinct layout components and a comprehensive theming system that integrates with HeroUI. This guide covers layout selection, theme management, CSS variable overrides, and CMS content integration.

### Layout Components

#### DefaultLayout

The primary layout for all standard e-commerce pages. Located at `apps/client/src/layouts/default.tsx`.

Key features:
- Includes Navbar with cart button and search
- Manages CartDrawer state and visibility
- Handles authentication state and token refresh
- Provides footer with company info, legal links, and social media
- Implements theme switching via ThemeSwitcher

Use for:
- Product listing pages
- Category pages
- Standard content pages (about, contact, etc.)
- User account pages

```tsx
import DefaultLayout from "@/layouts/default";

function MyPage() {
  return (
    <DefaultLayout>
      {/* Your page content */}
    </DefaultLayout>
  );
}
```

#### LuxuryLayout

A minimal layout for premium product showcases. Located at `apps/client/src/layouts/luxury.tsx`.

Key features:
- Full-bleed container (no horizontal padding)
- Uses the dark luxury Footer component
- Still includes Navbar and CartDrawer
- Designed for high-impact product presentations

Use for:
- Premium product landing pages
- Editorial content pages
- Full-screen product showcases

```tsx
import LuxuryLayout from "@/layouts/luxury";

function ProductShowcase() {
  return (
    <LuxuryLayout>
      {/* Full-bleed hero content */}
    </LuxuryLayout>
  );
}
```

### Store Theme System

The `StoreThemeProvider` manages theme application across the entire application. Located at `apps/client/src/providers/theme-provider.tsx`.

#### Theme Application Flow

1. On initial load, reads cached theme from localStorage
2. For authenticated users, fetches theme from JWT token metadata
3. Applies theme CSS variables to the document root
4. Listens for theme change events to update the DOM

Supported themes are defined as:

```typescript
export const AVAILABLE_THEMES = ["default", "luxury", "luxury-dark"] as const;
export type ThemeSlug = (typeof AVAILABLE_THEMES)[number];
```

#### Using the Theme Hook

```tsx
import { useStoreTheme } from "@/providers/theme-provider";

function ThemeAwareComponent() {
  const { theme, isLoading, setTheme } = useStoreTheme();

  if (isLoading) return <div>Loading theme...</div>;

  return (
    <div className={`theme-${theme}`}>
      Current theme: {theme}
      <button onClick={() => setTheme("luxury")}>Set Luxury</button>
    </div>
  );
}
```

### Adding New CSS Variables

To extend the theme system with new CSS variables:

1. Add the variable to the store themes database schema
2. Update the theme application logic in `theme-provider.tsx`
3. Use the variable in your components via `var(--your-variable)`

Example:

```css
/* In your global CSS */
:root {
  --color-accent: var(--color-primary);
}
```

### ThemeSwitch vs StoreTheme

- **ThemeSwitch**: Toggles between light/dark color modes by adding/removing classes like `light` or `dark` on the `<html>` element
- **StoreTheme**: Changes the actual theme (color palette, component styles) by applying CSS variables to the document root

```tsx
import { ThemeSwitcher } from "@/components/ui/theme-switcher";
// This only affects light/dark mode, not the store theme
```

### CMS Content System

The CMS content is managed through `cms-content.ts` and provides structured content for various pages.

#### Content Structure

```typescript
export type CmsPageContent = {
  title: string;
  lead: string;
  sections: CmsSection[];
};

export type CmsSection = {
  heading: string;
  body: string;
};
```

#### Fetching Content

```typescript
import { getCmsPage } from "@/config/cms-content";

const content = getCmsPage("about", "en-US");
```

#### Adding New CMS Sections

1. Add the new content type to `CmsContent` in `cms-content.ts`
2. Create an admin editor in the admin/cms page
3. Implement API endpoint to handle content updates
4. Render the new content in appropriate components

```typescript
// Example of extending the CMS content
export interface CmsContent {
  heroBanner: {
    title: string;
    subtitle: string;
    ctaText: string;
    imageUrl: string;
  };
}
```

### HeroUI Color Overrides

The theme system overrides HeroUI's default color variables. The `StoreThemeProvider` applies these variables to the document root, which HeroUI components then use.

To customize HeroUI colors:

1. Define your color variables in the theme CSS
2. Apply them via `StoreThemeProvider`
3. Use HeroUI components as normal - they'll automatically use your theme colors

```css
:root {
  --color-primary: 139 92 246; // violet-500
  --color-primary-foreground: 255 255 255;
}
```
