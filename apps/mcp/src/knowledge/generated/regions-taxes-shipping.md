## Regions

### Data Model
Regions define geographic groupings for tax and shipping calculations. Each region has:

```typescript
interface Region {
  id: string;          // UUID
  name: string;        // e.g., "European Union"
  country_codes: string[]; // ISO 3166-1 alpha-2 (e.g., ["FR", "DE", "IT"])
  currency: string;    // ISO 4217 (e.g., "EUR")
  is_default: boolean; // Fallback for unmatched countries
  tax_inclusive: boolean; // Whether prices include tax by default
}
```

### CRUD Endpoints
All region endpoints require `admin:store` permissions.

#### Create a Region
```typescript
// POST /v1/regions
const createRegion = createRoute({
  method: 'post',
  path: '/',
  request: { body: CreateRegionBody },
  responses: { 201: { content: { 'application/json': { schema: RegionResponse } } } },
});

adminApp.openapi(createRegion, async (c) => {
  const { name, country_codes, currency, is_default } = c.req.valid('json');
  const db = getDb(c.var.db);
  const id = uuid();

  await db.query(
    `INSERT INTO regions (id, name, country_codes, currency, is_default)
     VALUES (?, ?, ?, ?, ?)`,
    [id, name, JSON.stringify(country_codes), currency, is_default ? 1 : 0]
  );

  return c.json({ id, name, country_codes, currency, is_default }, 201);
});
```

#### Country-to-Region Mapping
Country codes are stored as a JSON array in SQLite. To find a region for a country:

```typescript
// Example: Resolve region for country "FR"
const region = await db.query<Region>(
  `SELECT * FROM regions
   WHERE JSON_CONTAINS(country_codes, '"FR"') OR is_default = 1
   ORDER BY is_default ASC LIMIT 1`
);
```

## Tax Rates

### Data Model
```typescript
interface TaxRate {
  id: string;          // UUID
  region_id: string;  // Links to regions.id
```

### Inclusive vs. Exclusive Tax
- **Inclusive (`is_inclusive: true`)**:
  Tax is embedded in the price. Formula: `tax_amount = price × (rate / (1 + rate))`.
  Example: €120 product with 20% VAT → tax = €20, net = €100.

- **Exclusive (`is_inclusive: false`)**:
  Tax is added to the price. Formula: `tax_amount = price × rate`.
  Example: $100 product with 10% GST → tax = $10, total = $110.

## Checkout Integration

### Region Resolution
1. Customer submits billing address with `country_code`.
2. System queries regions:
   ```sql
   SELECT * FROM regions
   WHERE JSON_CONTAINS(country_codes, '"FR"') OR is_default = 1
   ORDER BY is_default ASC LIMIT 1
   ```

### Shipping Auto-Selection
If no method is chosen:
```typescript
const methods = await getShippingMethods(db, region.id, cart.subtotal_cents);
const cheapest = methods.sort((a, b) => a.amount_cents - b.amount_cents)[0];
await db.query(
  `UPDATE carts SET shipping_rate_id = ? WHERE id = ?`,
  [cheapest.id, cartId]
);
```
