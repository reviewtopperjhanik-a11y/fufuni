## Regions, Taxes & Shipping Reference

### Regions

Regions define geographic groupings for shipping and tax purposes. Each region contains:

- `id`: Unique identifier
- `name`: Display name
- `country_codes`: Array of ISO 3166-1 alpha-2 country codes (e.g., `["US", "CA"]`)
- `currency`: ISO 4217 currency code (e.g., `"USD"`)
- `is_default`: Boolean flag for default region

The `country_codes` array maps multiple countries to a single region, allowing unified tax/shipping rules.

**CRUD Endpoints:**
- `GET /regions`: List all regions (paginated)
- `POST /regions`: Create a new region
- `GET /regions/:id`: Get a specific region
- `PUT /regions/:id`: Update a region
- `DELETE /regions/:id`: Delete a region

**Example: Create Region**
```typescript
import { CreateRegionBody } from '../schemas';

const newRegion: CreateRegionBody = {
  name: "North America",
  country_codes: ["US", "CA", "MX"],
  currency: "USD",
  is_default: false
};

// POST /regions with auth headers
```

### Tax Rates

Tax rates are defined per region and specify how taxes are calculated. Key fields:

- `region_id`: Target region
- `rate`: Decimal value (0-1, e.g., 0.2 for 20% tax)
- `label`: Display name (e.g., "VAT", "Sales Tax")
- `is_inclusive`: Whether prices include tax (true) or exclude tax (false)

**Creation Endpoint:**
```typescript
// POST /v1/tax-rates (admin)
const taxRate: CreateTaxRateBody = {
  region_id: "reg_123",
  rate: 0.2, // 20%
  label: "VAT",
  is_inclusive: true
};
```

**Inclusive vs Exclusive Tax:**

When `is_inclusive=true`:
```typescript
// Extract tax from gross price (price includes tax)
const grossPrice = 120; // $1.20 in cents
const taxRate = 0.2; // 20%
const taxAmount = grossPrice - (grossPrice / (1 + taxRate));
// taxAmount = 20 cents ($0.20)
// Net price = 100 cents ($1.00)
```

When `is_inclusive=false`:
```typescript
// Add tax to net price
const netPrice = 100; // $1.00 in cents
const taxRate = 0.2; // 20%
const taxAmount = netPrice * taxRate;
// taxAmount = 20 cents ($0.20)
// Gross price = 120 cents ($1.20)
```

### lib/tax.ts

The core tax calculation function:

```typescript
export function computeTax(
  price: number, // In smallest currency unit (cents)
  rate: number,  // Decimal (0.2 for 20%)
  inclusive: boolean
): number {
  return inclusive
    ? price - (price / (1 + rate))
    : price * rate;
}

// Example usage:
const tax = computeTax(120, 0.2, true); // 20 cents
```

### Shipping Zones

Shipping zones group regions and define available shipping methods. Each zone has:

- `name`: Display name
- `region_ids`: Array of region IDs covered by this zone
- `methods`: Array of shipping methods

Each method includes:
- `carrier`: Carrier name (e.g., "FedEx")
- `service`: Service level (e.g., "Ground")
- `price`: Base price in cents
- `estimated_days`: Delivery estimate
- `free_threshold`: Minimum subtotal (in cents) for free shipping

**Creation Endpoint:**
```typescript
// POST /v1/shipping-zones (admin)
const zone = {
  name: "Domestic",
  region_ids: ["reg_123"],
  methods: [{
    carrier: "USPS",
    service: "Priority",
    price: 499, // $4.99
    estimated_days: "2-3",
    free_threshold: 5000 // Free over $50
  }]
};
```

### Checkout Integration

1. **Region Resolution:**
   - Determined by the customer's billing address country code
   - Matches country code to a region via `country_codes` array

2. **Shipping Method Selection:**
   - If no method is selected, the cheapest eligible method is auto-selected
   - Eligibility is determined by:
     - Region coverage
     - Free-shipping thresholds
     - Shipping class restrictions

**Example Flow:**
```typescript
// During checkout:
const region = findRegionByCountry(billingAddress.country); // e.g., "US" → "reg_123"
const methods = await getShippingMethods(db, region.id, cart.subtotal);
const selectedMethod = methods[0] || null; // Cheapest or null
```
