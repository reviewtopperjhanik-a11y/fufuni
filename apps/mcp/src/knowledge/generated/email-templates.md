### Mailgun Setup

Configure Mailgun by setting these Cloudflare Workers secrets:

```bash
wrangler secret put MAILGUN_API_KEY
wrangler secret put MAILGUN_DOMAIN
wrangler secret put MAILGUN_BASE_URL  # Optional (default: https://api.mailgun.net)
wrangler secret put MAILGUN_USER      # Sender email address
```

### Triggered Emails

Fufuni automatically sends emails for these order events:

| Event          | Trigger Point               | Content |
|----------------|-----------------------------|---------|
| Order Confirmation | Order creation (Stripe webhook) | Order number, total, tracking link |
| Payment Failed  | Order status update         | Payment failure notice |
| Processing      | Order status update         | Processing notification |
| Shipped         | Order status update         | Tracking number/URL |
| Delivered       | Order status update         | Delivery confirmation |
| Refunded        | Order status update         | Refund details |
| Canceled        | Order status update         | Cancellation notice |

Example trigger call:
```typescript
await sendOrderStatusEmail(env, db, orderId, 'shipped');
```

### Template Structure

Templates in `lib/email-templates.ts` return:

```typescript
{ subject: string; html: string; text: string }
```

Example:
```typescript
export function buildOrderConfirmationEmail(params: {
  orderNumber: string;
  orderUrl: string;
  STORE_NAME: string;
  totalcents: number;
  currency: string;
}): { subject: string; html: string; text: string } {
  const total = new Intl.NumberFormat('en-US', {
    style: 'currency',
    currency: params.currency.toUpperCase(),
  }).format(params.totalcents / 100);

  return {
    subject: `Order Confirmation ${params.orderNumber}`,
    html: `<html>...</html>`,
    text: `Thank you for your order!\nOrder: ${params.orderNumber}`
  };
}
```

### Adding a New Template

1. **Create Template Function**: Add to `email-templates.ts`
2. **Add Trigger Call**: In relevant route handler
3. **Extend Event List**: Update `ORDER_EMAIL_EVENTS` in `order-email-settings.ts`
4. **Add Default Template**: Extend `buildDefaultStatusEmail` in `order-email.ts`

Example new event implementation:
```typescript
// 1. Add to email-templates.ts
export function buildCustomEventEmail(params: {
  orderNumber: string;
  customData: string;
}): { subject: string; html: string; text: string } {
  return {
    subject: `Custom Event for Order ${params.orderNumber}`,
    html: `<p>Your custom event: ${params.customData}</p>`,
    text: `Custom event for order ${params.orderNumber}`
  };
}

// 2. Trigger in route
await sendOrderStatusEmail(env, db, orderId, 'custom_event');
```

### Local Development

When `MAILGUN_API_KEY` is unset:
- Email sending is silently skipped (no errors)
- Database records are updated normally
- Allows testing without Mailgun credentials

Local behavior example:
```typescript
if (!env.MAILGUN_API_KEY) {
  console.log('Skipping email - no Mailgun API key');
  return { success: true };
}
```
