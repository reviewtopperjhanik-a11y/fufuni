## Cloudflare Worker Bindings

Access environment bindings in Hono route handlers via `c.env`. All bindings are typed via `worker-configuration.d.ts`:

```typescript
// apps/merchant/src/routes/products.ts
import { Hono } from 'hono'
import { z } from 'zod'
import { zValidator } from '@hono/zod-validator'

const app = new Hono()

// Access bindings in route handler
app.get('/products', async (c) => {
  const cache = c.env.KV_CACHE
  const images = c.env.IMAGES
  const merchantDO = c.env.MERCHANT

  // Use KV cache
  const cached = await cache.get('products:featured')
  if (cached) return c.json(JSON.parse(cached))

  // Access R2 bucket
  const imageList = await images.list()

  // Call Durable Object
  const stub = merchantDO.get(merchantDO.idFromName('primary'))
  const result = await stub.fetch(c.req.raw)

  return result
})
```

## Durable Object Pattern

Fufuni uses a single `MerchantDO` instance for all stateful operations:

```typescript
// apps/merchant/src/do.ts
export class MerchantDO {
  async fetch(request: Request): Promise<Response> {
    // Handle requests to the DO
  }

  // Custom methods accessible via stub.run()
  async query(sql: string, params?: any[]): Promise<any> {
    return this.ctx.storage.sql.query(sql, params)
  }
}
```

Get the Durable Object stub and call methods:

```typescript
// In a route handler
const stub = c.env.MERCHANT.get(c.env.MERCHANT.idFromName('primary'))

// Call fetch (HTTP interface)
const response = await stub.fetch(new Request('http://do/query'))

// Or call custom methods via run()
const result = await stub.run('query', 'SELECT * FROM products')
```

## KV Cache Middleware

The `kvCacheMiddleware` caches GET responses with different TTLs:

```typescript
// apps/merchant/src/middleware/kv-cache.ts
export function kvCacheMiddleware() {
  return async (c: Context, next: Next) => {
    if (c.req.method !== 'GET') return next()

    const cacheKey = `cache:${c.req.url}`
    const cached = await c.env.KV_CACHE.get(cacheKey)

    if (cached) {
      return new Response(cached, {
        headers: { 'Content-Type': 'application/json' }
      })
    }

    const response = await next()
    if (response.status === 200) {
      const ttl = getTTL(c.req.url) // Different TTLs per route
      await c.env.KV_CACHE.put(cacheKey, await response.text(), { expirationTtl: ttl })
    }
    return response
  }
}
```

Cache TTLs are configurable via env vars:
- `KV_CACHE_SEARCH_TTL_SECONDS` (default 300)
- `KV_CACHE_REVIEWS_TTL_SECONDS` (default 600)
- `KV_CACHE_DEFAULT_TTL_SECONDS` (default 3600)

## R2 Storage

Product images are stored in the `IMAGES` R2 bucket:

```typescript
// apps/merchant/src/routes/images.ts
app.post('/images/upload', async (c) => {
  const formData = await c.req.formData()
  const file = formData.get('image') as File

  // Upload to R2
  await c.env.IMAGES.put(file.name, await file.arrayBuffer())

  // Return public URL
  return c.json({
    url: `${c.env.IMAGES_URL}/${file.name}`
  })
})
```

Images are served via the `IMAGES_URL` binding configured in wrangler.jsonc.

## Secrets Management

All secrets are managed via GitHub Secrets and .env:

```bash
# Required Mailgun secrets (Wrangler secrets)
MAILGUN_API_KEY=your_api_key
MAILGUN_DOMAIN=your.domain.com
MAILGUN_USER=noreply@your.domain.com
MAILGUN_BASE_URL=https://api.mailgun.net
```

Secrets are automatically loaded from .env in development and from GitHub Secrets in CI.

## Adding New Bindings

To add a new binding:

1. Update `wrangler.jsonc`:
```json
{
  "vars": {
    "NEW_VARIABLE": ""
  }
}
```

2. Update `worker-configuration.d.ts`:
```typescript
interface Env {
  NEW_VARIABLE: string;
}
```

3. Update the `Env` type in your application code.

## CI/CD Flow

Environment variables map 1:1 to GitHub Secrets. The `create-env-artifact.yaml` workflow:

1. Creates `.env` from GitHub Secrets
2. Generates `wrangler.jsonc` using `scripts/generate-wrangler-jsonc.py`
3. Encrypts artifacts for deployment

To expose variables to the frontend, add to `vite.config.ts`:

```typescript
// apps/client/vite.config.ts
define: {
  'import.meta.env.VARIABLE_NAME': JSON.stringify(process.env.VARIABLE_NAME)
}
```
