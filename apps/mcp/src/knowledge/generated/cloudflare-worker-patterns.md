### Accessing Bindings in Route Handlers

All Cloudflare bindings are available via the Hono context object `c.env`. The `Env` interface provides TypeScript support for these bindings.

```typescript
// apps/merchant/src/routes/products.ts
import { Hono } from 'hono'
import type { Env } from '../index'

const app = new Hono<{ Bindings: Env }>()

app.get('/products', async (c) => {
  // Access Durable Object binding
  const merchantId = c.env.MERCHANT.idFromName('default')
  const merchantStub = c.env.MERCHANT.get(merchantId)

  // Access R2 bucket
  const image = await c.env.IMAGES.get('product123.jpg')

  // Access KV cache
  const cachedData = await c.env.KV_CACHE.get('cache-key')

  return c.json({ message: 'Bindings accessed successfully' })
})
```

### The Durable Object Pattern

Fufuni uses a single Durable Object instance for all merchant data to ensure strong consistency and simplify state management.

**Why single instance?**
- Avoids distributed coordination complexity
- Provides linearizable consistency for critical operations
- Simplifies data access patterns

**Getting the stub:**

```typescript
// Get Durable Object stub for the default merchant
const merchantId = c.env.MERCHANT.idFromName('default')
const merchantStub = c.env.MERCHANT.get(merchantId)
```

**Calling methods:**

```typescript
// Query method (HTTP-based)
const products = await merchantStub.fetch('https://do/products', {
  method: 'POST',
  body: JSON.stringify({ query: '{ products { id name price } }' })
})

// Run method (for custom operations)
const result = await merchantStub.fetch('https://do/run-inventory-update', {
  method: 'POST',
  body: JSON.stringify({ productId: '123', quantity: 5 })
})
```

### KV Cache Middleware

The `kvCacheMiddleware` automatically caches GET responses in KV before hitting the Durable Object.

**Cache behavior:**
- Key format: `cache:<full-url>`
- Bypasses cache for non-GET methods
- Bypasses cache for admin JWTs (`Authorization: Bearer pk_*`)

**Manual cache invalidation:**

```typescript
// Invalidate all product cache keys
const keys = await c.env.KV_CACHE.list({ prefix: 'cache:*/v1/products' })
for (const key of keys.keys) {
  await c.env.KV_CACHE.delete(key.name)
}
```

**Cache TTL configuration:**
```bash
# Environment variables controlling cache TTL
KV_CACHE_SEARCH_TTL_SECONDS=300    # 5 minutes for search
KV_CACHE_REVIEWS_TTL_SECONDS=600   # 10 minutes for reviews
KV_CACHE_DEFAULT_TTL_SECONDS=3600  # 1 hour default
```

### R2 Product Image Storage

Product images are stored in R2 and served directly from the edge.

**Uploading images:**

```typescript
// apps/merchant/src/routes/images.ts
app.post('/images', async (c) => {
  const formData = await c.req.formData()
  const file = formData.get('image') as File

  await c.env.IMAGES.put(file.name, await file.arrayBuffer(), {
    httpMetadata: { contentType: file.type }
  })

  return c.json({ success: true })
})
```

**Serving images:**

```typescript
// apps/merchant/src/routes/images.ts
app.get('/images/:filename', async (c) => {
  const object = await c.env.IMAGES.get(c.req.param('filename'))
  if (!object) return new Response('Not found', { status: 404 })

  return new Response(object.body, {
    headers: {
      'Content-Type': object.httpMetadata?.contentType || 'application/octet-stream',
      'Cache-Control': 'public, max-age=31536000, immutable'
    }
  })
})
```

### Secrets Management

**Wrangler secrets vs .env:**
- All sensitive values must be in Wrangler secrets
- Non-sensitive configuration can use .env
- Every .env variable must have a matching GitHub secret

**Mailgun secrets:**
```bash
MAILGUN_API_KEY      # API key for Mailgun
MAILGUN_DOMAIN       # Your Mailgun domain
MAILGUN_BASE_URL     # Default: https://api.mailgun.net
MAILGUN_USER         # Sender email address
```

**Email behavior:** Transactions silently skip email sending if `MAILGUN_API_KEY` is not configured.

### Adding New Bindings

1. Update `wrangler.jsonc`:
```json
{
  "kv_namespaces": [
    { "binding": "NEW_CACHE", "id": "new-id" }
  ]
}
```

2. Update `worker-configuration.d.ts`:
```typescript
interface Env {
  NEW_CACHE: KVNamespace
}
```

3. Use in your code:
```typescript
const data = await c.env.NEW_CACHE.get('key')
```

### CI/CD Process

**Environment variables flow:**
1. .env → GitHub secrets (1:1 mapping)
2. `create-env-artifact.yaml` generates encrypted artifact
3. Deploy jobs decrypt and use the artifact

**Exposing variables to frontend:**
Update `vite.config.ts` define block:

```javascript
// apps/client/vite.config.ts
export default defineConfig({
  define: {
    'import.meta.env.STRIPE_PUBLISHABLE_KEY': JSON.stringify(process.env.STRIPE_PUBLISHABLE_KEY),
    'import.meta.env.PERMISSIONS': JSON.stringify([
      process.env.ADMIN_AUTH0_PERMISSION,
      process.env.ADMIN_STORE_PERMISSION
      // ... other permissions
    ].filter(Boolean))
  }
})
```

**Deployment commands:**
```bash
# Local development
npm run dev:env

# Stripe webhook listener (separate terminal)
npm run stripe:listen

# Production build
npm run build:env
```
