## Outbound Webhooks Reference

### Supported Events
Outbound webhooks notify external systems about domain events. Supported events:

```typescript
const VALID_EVENTS = [
  'order.created',
  'order.updated',
  'order.shipped',
  'order.refunded',
  'inventory.low',
  'order.*',    // Wildcard for all order events
  '*'           // Wildcard for all events
] as const;
```

Trigger points:
- `order.created`: New order placed
- `order.updated`: Order status change
- `order.shipped`: Order marked as shipped
- `order.refunded`: Order refund processed
- `inventory.low`: Stock drops below threshold

### Delivery Mechanics
Webhooks are delivered asynchronously with retry logic:
- Initial attempt immediately after event
- Up to 3 retry attempts with exponential backoff (1s, 4s, 16s delays)
- Delivery statuses: `pending`, `success`, `failed`

```typescript
// From lib/webhooks.ts
const MAX_ATTEMPTS = 3;

// Retry schedule:
for (let attempt = 1; attempt <= MAX_ATTEMPTS; attempt++) {
  try {
    // Attempt delivery
  } catch (err) {
    // On failure, wait before retrying
    await new Promise((r) => setTimeout(r, Math.pow(2, attempt) * 1000));
  }
}
```

### HMAC-SHA256 Signature
Each delivery includes a signature header computed as:

```typescript
async function signPayload(payload: string, secret: string): Promise<string> {
  const encoder = new TextEncoder();
  const key = await crypto.subtle.importKey(
    'raw',
    encoder.encode(secret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign']
  );
  const signature = await crypto.subtle.sign('HMAC', key, encoder.encode(payload));
  return Array.from(new Uint8Array(signature))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('');
}
```

The signature is sent in the `X-Fufuni-Signature` header.

### Signature Verification (Node.js)
Consumers should verify signatures:

```typescript
import crypto from 'crypto';

function verifyWebhook(req: Request, secret: string): boolean {
  const payload = JSON.stringify(req.body);
  const theirSignature = req.headers['x-fufuni-signature'] as string;

  const hmac = crypto.createHmac('sha256', secret);
  const ourSignature = hmac.update(payload).digest('hex');

  return theirSignature === ourSignature;
}

// Express middleware example:
app.post('/webhook', (req, res) => {
  if (!verifyWebhook(req, process.env.FUFUNI_WEBHOOK_SECRET)) {
    return res.status(401).send('Invalid signature');
  }
  // Process webhook
});
```

```typescript
// POST /v1/webhooks/outbound/{id}/deliveries/{deliveryId}/retry
// No request body required
```

### Inbound vs Outbound Webhooks

| Feature          | Outbound Webhooks                     | Inbound Webhooks (Stripe)            |
|------------------|---------------------------------------|--------------------------------------|
| Purpose          | Notify external systems about events  | Receive notifications from Stripe    |
| Endpoint         | POST /v1/webhooks/outbound            | POST /v1/webhooks/stripe             |
| Direction        | Your store → external service         | Stripe → your store                  |
| Authentication   | HMAC signature                       | Stripe signature                     |
| Configuration    | Admin API                            | Stripe dashboard + your store config |
