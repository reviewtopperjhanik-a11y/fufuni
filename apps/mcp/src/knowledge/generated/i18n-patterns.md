## Internationalisation (i18n) Reference

### Supported Locales
Fufuni supports 6 locales, with translation files stored in `apps/client/src/locales/base/`:

| Locale Code | Language Name | Direction | File Path                          |
|-------------|---------------|-----------|------------------------------------|
| en-US       | English       | LTR       | `apps/client/src/locales/base/en-US.json` |
| fr-FR       | Français      | LTR       | `apps/client/src/locales/base/fr-FR.json` |
| es-ES       | Español       | LTR       | `apps/client/src/locales/base/es-ES.json` |
| zh-CN       | 中文          | LTR       | `apps/client/src/locales/base/zh-CN.json` |
| ar-SA       | العربية      | RTL       | `apps/client/src/locales/base/ar-SA.json` |
| he-IL       | עברית        | RTL       | `apps/client/src/locales/base/he-IL.json` |

**Note:** `en-US` is the master language and fallback. All new keys must first be added to `en-US.json`.

### Adding a New Translation Key

#### 1. Edit the master file
Add the new key to `en-US.json` using **kebab-case** and descriptive naming:

```json
// apps/client/src/locales/base/en-US.json
{
  "product-tags-heading": "Product Tags",
  "product-tags-empty": "No tags assigned yet",
  "product-tags-add": "Add Tag"
}
```

#### 2. Add translations to other locales
Add the same key to all other locale files with appropriate translations:

```json
// apps/client/src/locales/base/fr-FR.json
{
  "product-tags-heading": "Étiquettes de Produit",
  "product-tags-empty": "Aucune étiquette attribuée pour l'instant",
  "product-tags-add": "Ajouter une étiquette"
}
```

#### 3. Interpolation syntax
For dynamic values, use **Mustache-style** placeholders:

```json
// en-US.json
{
  "product-tags-count": "{{count}} tag",
  "product-tags-count_plural": "{{count}} tags"
}
```

**Rules:**
- Keys must be **flat** (no nesting)
- Use `-` for word separation (kebab-case)
- Plural forms use `_plural` suffix
- Interpolation uses `{{variableName}}`

### Using Translations in Components

#### Basic usage with `useTranslation`
```tsx
// apps/client/src/components/product-tags.tsx
import { useTranslation } from "react-i18next";

export function ProductTags() {
  const { t } = useTranslation("base"); // "base" is the namespace

  return (
    <div className="space-y-2">
      <h3 className="text-lg font-medium">{t("product-tags-heading")}</h3>
      <p className="text-sm text-gray-500">
        {t("product-tags-empty")}
      </p>
      <button className="btn btn-sm btn-primary">
        {t("product-tags-add")}
      </button>
    </div>
  );
}
```

#### Pluralization and interpolation
```tsx
function TagCount({ count }: { count: number }) {
  const { t } = useTranslation("base");

  return (
    <span>
      {t(count === 1 ? "product-tags-count" : "product-tags-count_plural", { count })}
    </span>
  );
}
```

**Output examples:**
- `1 tag` (when count=1)
- `5 tags` (when count=5)

### RTL Language Handling
Right-to-left (RTL) languages (`ar-SA`, `he-IL`) automatically apply directional styles:

#### 1. Language configuration
RTL is declared in `i18n.ts`:
```typescript
// apps/client/src/i18n.ts
export const availableLanguages: AvailableLanguage[] = [
  { code: "en-US", nativeName: "English", isRTL: false },
  { code: "ar-SA", nativeName: "العربية", isRTL: true }, // <-- RTL flag
  { code: "he-IL", nativeName: "עברית", isRTL: true }  // <-- RTL flag
];
```

#### 2. Automatic RTL application
The root layout component (`apps/client/src/layouts/main.tsx`) applies RTL classes when needed:

```tsx
import { useTranslation } from "react-i18next";

export function MainLayout({ children }: { children: React.ReactNode }) {
  const { i18n } = useTranslation();
  const isRTL = i18n.dir(i18n.language) === "rtl";

  return (
    <div className={isRTL ? "rtl" : "ltr"}>
      {children}
    </div>
  );
}
```

#### 3. RTL-specific styles
Add directional styles in your Tailwind config:

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      screens: {
        'rtl': { 'raw': '(dir: rtl)' }, // Target RTL contexts
      }
    }
  }
}
```

**Usage in components:**
```tsx
<div className="flex rtl:flex-row-reverse">
  {/* Content will reverse order in RTL */}
</div>
```

### Complete Example: Adding Product Tags Feature

#### 1. Add translation keys
```json
// en-US.json
{
  "product-tags-heading": "Product Tags",
  "product-tags-empty": "No tags assigned yet. {{link}} to add some.",
  "product-tags-add": "Add Tag",
  "product-tags-link-text": "Click here"
}
```

```json
// fr-FR.json
{
  "product-tags-heading": "Étiquettes de Produit",
  "product-tags-empty": "Aucune étiquette attribuée. {{link}} pour en ajouter.",
  "product-tags-add": "Ajouter une étiquette",
  "product-tags-link-text": "Cliquez ici"
}
```

#### 2. Create the component
```tsx
// apps/client/src/components/product-tags.tsx
import { useTranslation } from "react-i18next";
import { Link } from "@tanstack/react-router";

export function ProductTags({ tagCount = 0 }: { tagCount?: number }) {
  const { t } = useTranslation("base");

  return (
    <div className="card">
      <div className="flex items-center justify-between">
        <h3 className="card-title">{t("product-tags-heading")}</h3>
        <Link
          to="/admin/products/$id/tags"
          className="btn btn-sm btn-primary"
        >
          {t("product-tags-add")}
        </Link>
      </div>

      <div className="card-content">
        {tagCount === 0 ? (
          <p className="text-sm text-gray-500">
            {t("product-tags-empty", {
              link: (
                <Link to="/admin/products/$id/tags" className="font-medium text-primary">
                  {t("product-tags-link-text")}
                </Link>
              ),
              interpolation: { escapeValue: false } // Allow HTML in translation
            })}
          </p>
        ) : (
          <div className="flex flex-wrap gap-2">
            {/* Render tags here */}
          </div>
        )}
      </div>
    </div>
  );
}
```

#### 3. Use the component
```tsx
// apps/client/src/routes/admin/products/$id.tsx
import { ProductTags } from "@/components/product-tags";

export function ProductDetail() {
  return (
    <div className="space-y-6">
      {/* Other product sections */}
      <ProductTags tagCount={product.tags.length} />
    </div>
  );
}
```

#### 4. Add RTL-specific adjustments
```tsx
// In your component
<div className={cn(
  "flex items-center gap-2",
  isRTL ? "flex-row-reverse" : "flex-row"
)}>
  {t("product-tags-add")}
  <IconPlus className="h-4 w-4" />
</div>
```

**Key points in this example:**
1. All translation keys follow kebab-case convention
2. Complex interpolations use React nodes with `escapeValue: false`
3. RTL layouts automatically adjust via the `isRTL` check
4. The component is fully localized for all 6 languages
5. Pluralization is handled via separate keys when needed

### Handling Missing Translations
When a translation key is missing in the current language, the system will:
1. Fall back to the default language (`en-US`)
2. Log a warning in development mode
3. Show the key itself in production if no fallback exists (e.g., `"missing-key"`)

**Best practice:** Always test your UI in all supported languages during development.
