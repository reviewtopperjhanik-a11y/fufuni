## ## Cloudflare AI Gateway — Unified Access

### ## Overview
Cloudflare AI Gateway provides a unified interface to multiple AI providers (Anthropic, Groq, Gemini, Mistral, OpenRouter) with built-in observability, logging, caching, and rate limiting. Fufuni uses two gateway paths:

1. **Compat path** (`/compat`): OpenAI-compatible endpoint for chat/completion models (all providers)
2. **Native path**: Gemini-specific `embedContent` endpoint for embeddings (256 dimensions, `gemini-embedding-2-preview`)

The gateway enables:
- Single API key rotation point (Cloudflare)
- Per-request logging and analytics
- Caching of identical prompts
- Rate limiting across all providers
- Model-agnostic client code

### ## Encryption
AI credentials are stored encrypted in `ai.json.enc` using OpenSSL:

```bash
# Encrypt ai.json → ai.json.enc
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"${CRYPTOKEN}"
```

#### `decryptAiConfig()` Mechanics
```typescript
// apps/merchant/src/lib/ai-enc.ts
export async function decryptAiConfig(
  base64Ciphertext: string,
  password: string
): Promise<AiConfig> {
  // 1. Base64 decode → raw bytes
  const raw = Uint8Array.from(atob(base64Ciphertext.trim()), c => c.charCodeAt(0));

  // 2. Verify OpenSSL "Salted__" header
  if (new TextDecoder().decode(raw.slice(0, 8)) !== 'Salted__') {
    throw new Error('Invalid OpenSSL header');
  }

  // 3. Extract salt (bytes 8–15) and ciphertext (bytes 16–end)
  const salt = raw.slice(8, 16);
  const ciphertext = raw.slice(16);

  // 4. PBKDF2-SHA256 → 48 bytes (32 key + 16 IV)
  const derived = new Uint8Array(
    await crypto.subtle.deriveBits(
      { name: 'PBKDF2', hash: 'SHA-256', salt, iterations: 100_000 },
      await crypto.subtle.importKey('raw', new TextEncoder().encode(password), 'PBKDF2', false, ['deriveBits']),
      384
    )
  );

  // 5. AES-256-CBC decrypt
  const plaintext = await crypto.subtle.decrypt(
    { name: 'AES-CBC', iv: derived.slice(32, 48) },
    await crypto.subtle.importKey('raw', derived.slice(0, 32), 'AES-CBC', false, ['decrypt']),
    ciphertext
  );

  return JSON.parse(new TextDecoder().decode(plaintext));
}
```

**CRYPTOKEN**: Wrangler secret used as the decryption password. Set in `wrangler.toml`:
```toml
[vars]
CRYPTOKEN = "@ai-cryptoken"
```

export function resolveProviderEndpoint(
  provider: AiProvider,
  aigToken: string | undefined
): { endpoint: string; useGateway: boolean } {
  if (aigToken && provider.gatewayEndpoint) {
    return { endpoint: provider.gatewayEndpoint, useGateway: true };
  }
  return { endpoint: provider.endpoint, useGateway: false };

### ## Model ID Prefixing
Gateway-routed models require provider-specific prefixes:

```typescript
// apps/merchant/src/lib/ai-enc.ts
export function resolveModelId(
  modelId: string,
  provider: AiProvider,
  useGateway: boolean
): string {
  if (useGateway && provider.gatewayModelPrefix) {
    const prefix = `${provider.gatewayModelPrefix}/`;
    if (modelId.startsWith(prefix)) return modelId; // Avoid double-prefixing
    return `${provider.gatewayModelPrefix}/${modelId}`;
  }
  return modelId;
}
```

### ## CORS Limitation
**Problem**: Cloudflare AI Gateway with "Authenticated Gateway" enabled returns `401 Unauthorized` on the CORS preflight `OPTIONS` request because the browser cannot send the `cf-aig-authorization` header during preflight.

**Workaround**: Set `DISABLE_CLOUDFLARE_AIG=true` in `.env` to bypass gateway routing in the frontend:

```typescript
// apps/client/src/utils/ai-client.ts
if (aiParams.cloudflareAigUrl && aiParams.cloudflareAigToken && !import.meta.env.DISABLE_CLOUDFLARE_AIG) {
  // Use gateway
} else {
  // Call provider directly
}
```

**Expected Fix**: Cloudflare is expected to implement a CORS preflight bypass for authenticated gateways.

### ## Known Pitfalls
1. **`usage` Field Must Be Set**
   - Bug: Embedding models (e.g., `gemini-embedding-001`) were selected as chat models because `usage` was omitted (defaults to `"chat"`).
   - Fix: Always set `usage: "embedding"` on embedding models.

2. **Field Name Mismatch**
   - `AiParams` interface fields must match `/v1/ai/parameters` response exactly:
     ```typescript
     // Correct
     interface AiParams {
       cloudflareAigToken?: string;  // Matches backend
       cloudflareAigUrl?: string;    // Matches backend
     }
     ```

3. **Gateway Model Prefixing**
   - Models must be prefixed when routed through the gateway (e.g., `groq/llama-3.3-70b-versatile`). `resolveModelId()` handles this automatically.

4. **Embedding Dimensions**
   - Gemini `gemini-embedding-2-preview` uses `256` dimensions by default. Set `defaultDimensions: 256` in `ai.json` to avoid runtime errors.
