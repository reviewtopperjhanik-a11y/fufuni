## Cloudflare AI Gateway — Unified Access

The Cloudflare AI Gateway provides a unified interface for accessing multiple AI providers through a single endpoint. It offers several benefits:

1. **Observability**: Centralized logging and monitoring of all AI requests
2. **Caching**: Reduced latency and cost by caching responses
3. **Rate limiting**: Protection against API abuse
4. **Authentication**: Single point of control for API keys
5. **Model management**: Consistent interface across different providers

The gateway supports two access paths:

1. **Compatibility mode**: All providers are accessed through a single OpenAI-compatible endpoint
2. **Native mode**: Specialized paths for certain operations (like Gemini embeddings)

## Encryption

The ai.json file is encrypted using AES-256-CBC with PBKDF2 key derivation:

```bash
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"${CRYPTOKEN}"
```

The decryption process in `decryptAiConfig()`:

```typescript
export async function decryptAiConfig(
  base64Ciphertext: string,
  password: string,
): Promise<AiConfig> {
  // 1. base64 decode → raw bytes
  const raw = Uint8Array.from(atob(base64Ciphertext.trim()), c => c.charCodeAt(0));

  // 2. Verify OpenSSL "Salted__" magic header (bytes 0–7)
  if (new TextDecoder().decode(raw.slice(0, 8)) !== 'Salted__') {
    throw new Error('ai.json.enc: invalid format — expected OpenSSL "Salted__" header.');
  }

  const salt = raw.slice(8, 16);       // bytes 8–15
  const ciphertext = raw.slice(16);    // bytes 16–end

  // 3. PBKDF2-SHA256 → 48 bytes (32 key + 16 IV), matching -pbkdf2 -iter 100000
  const pwBytes = new TextEncoder().encode(password);
  const baseKey = await crypto.subtle.importKey('raw', pwBytes, 'PBKDF2', false, ['deriveBits']);
  const derived = new Uint8Array(
    await crypto.subtle.deriveBits(
      { name: 'PBKDF2', hash: 'SHA-256', salt, iterations: 100_000 },
      baseKey,
      384, // 48 bytes × 8 bits
    ),
  );

  // 4. AES-256-CBC decrypt
  const aesKey = await crypto.subtle.importKey(
    'raw', derived.slice(0, 32), 'AES-CBC', false, ['decrypt'],
  );
  const plaintext = await crypto.subtle.decrypt(
    { name: 'AES-CBC', iv: derived.slice(32, 48) },
    aesKey,
    ciphertext,
  );

  return JSON.parse(new TextDecoder().decode(plaintext)) as AiConfig;
}
```

## Gateway Authentication

The gateway requires authentication via the `cf-aig-authorization` header:

```typescript
// In every request to the gateway
headers: {
  ...(aiParams.cloudflareAigToken ? { "cf-aig-authorization": `Bearer ${aiParams.cloudflareAigToken}` } : {}),
}
```

The `resolveProviderEndpoint()` function determines whether to use the gateway:

```typescript
export function resolveProviderEndpoint(
  provider: AiProvider,
  aigToken: string | undefined,
): { endpoint: string; useGateway: boolean } {
  if (aigToken && provider.gatewayEndpoint) {
    return { endpoint: provider.gatewayEndpoint, useGateway: true };
  }
  return { endpoint: provider.endpoint, useGateway: false };
}
```

## Model ID Prefixing

The `resolveModelId()` function handles model ID prefixing:

```typescript
export function resolveModelId(
  modelId: string,
  provider: AiProvider,
  useGateway: boolean,
): string {
  if (useGateway && provider.gatewayModelPrefix) {
    // Avoid double-prefixing if the model ID already contains a slash
    if (modelId.includes('/')) return modelId;
    return `${provider.gatewayModelPrefix}/${modelId}`;
  }
  return modelId;
}
```

Examples:
- Groq: "llama-3.3-70b-versatile" → "groq/llama-3.3-70b-versatile"
- Anthropic: "claude-haiku-4-5" → "anthropic/claude-haiku-4-5"
- Gemini: "gemini-3-flash-preview" → "google-ai-studio/gemini-3-flash-preview"

## CORS Limitations


The `DISABLE_CLOUDFLARE_AIG` flag is a temporary workaround until Cloudflare fixes the CORS preflight issue.

## Known Pitfalls

1. **Usage field requirement**: All models must have the `usage` field set to either "chat" or "embedding". Omitting this field can cause embedding models to be selected as chat models.

2. **Field name matching**: The `AiParams` interface field names must exactly match the `/v1/ai/parameters` response fields. Any mismatch will cause runtime errors.

3. **Gateway vs direct routing**: The `resolveProviderEndpoint()` function must be called before making any requests to determine the correct endpoint and whether to use the gateway.

4. **Model ID prefixing**: The `resolveModelId()` function must be called before sending the model ID to the gateway to ensure proper prefixing.

5. **CORS restrictions**: The inability to send custom headers in CORS preflight requests means direct browser-to-gateway calls are impossible without the `DISABLE_CLOUDFLARE_AIG` workaround.
