## Cloudflare AI Gateway — Unified Access in Fufuni

Fufuni uses **Cloudflare AI Gateway** as a unified entry point for all AI providers.
The gateway provides observability, logging, caching, and rate-limiting without changing the provider-specific SDK logic.
All AI calls flow through one of two paths:

1. **Compat path** (OpenAI-compatible)
   `POST https://gateway.ai.cloudflare.com/v1/{account}/{gateway}/compat`
   Accepts all providers in OpenAI format.
   Model IDs are prefixed: `groq/llama-3.3-70b-versatile`, `anthropic/claude-haiku-4-5`, `google-ai-studio/gemini-3-flash-preview`.

2. **Native path** (Gemini embeddings only)
   `POST https://gateway.ai.cloudflare.com/v1/{account}/{gateway}/google-ai-studio/v1beta/models/{model}:embedContent`
   Uses the native `embedContent` endpoint with `dimensions=256`.

## 2. Encrypting credentials with `ai.json.enc`

```bash
# From the repository root
CRYPTOKEN="your-32-byte-secret" \
  openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json \
  -out ai.json.enc \
  -pass pass:"${CRYPTOKEN}"
```

- **Never commit** `ai.json` (plaintext).
- **Commit** `ai.json.enc` (encrypted).
- **CRYPTOKEN** is stored as a Wrangler secret (`wrangler secret put CRYPTOKEN`).

Decryption in memory (works in Node.js ≥ 18 and Cloudflare Workers):

```typescript
// apps/merchant/src/lib/ai-enc.ts
export async function decryptAiConfig(
  base64Ciphertext: string,
  password: string,
): Promise<AiConfig> {
  // 1. base64 decode → raw bytes
  const raw = Uint8Array.from(atob(base64Ciphertext.trim()), c => c.charCodeAt(0));
  // 2. Verify OpenSSL "Salted__" header
  if (new TextDecoder().decode(raw.slice(0, 8)) !== 'Salted__') {
    throw new Error('Invalid OpenSSL format');
  }
  const salt = raw.slice(8, 16);
  const ciphertext = raw.slice(16);
  // 3. PBKDF2-SHA256 → 48 bytes (32 key + 16 IV)
  const pwBytes = new TextEncoder().encode(password);
  const baseKey = await crypto.subtle.importKey('raw', pwBytes, 'PBKDF2', false, ['deriveBits']);
  const derived = new Uint8Array(
    await crypto.subtle.deriveBits(
      { name: 'PBKDF2', hash: 'SHA-256', salt, iterations: 100_000 },
      baseKey,
      384,
    ),
  );
  // 4. AES-256-CBC decrypt
  const aesKey = await crypto.subtle.importKey(
    'raw', derived.slice(0, 32), 'AES-CBC', false, ['decrypt'],
  );
  const plaintext = await crypto.subtle.decrypt(
    { name: 'AES-CBC', iv: derived.slice(32, 48) },
    aesKey,
    ciphertext,
  );
  return JSON.parse(new TextDecoder().decode(plaintext)) as AiConfig;
}
```

## 3. Gateway authentication and endpoint selection

```typescript
// apps/merchant/src/lib/ai-enc.ts
export function resolveProviderEndpoint(
  provider: AiProvider,
  aigToken: string | undefined,
): { endpoint: string; useGateway: boolean } {
  if (aigToken && provider.gatewayEndpoint) {
    return { endpoint: provider.gatewayEndpoint, useGateway: true };
  }
  return { endpoint: provider.endpoint, useGateway: false };
}

export function resolveModelId(
  modelId: string,
  provider: AiProvider,
  useGateway: boolean,
): string {
  if (useGateway && provider.gatewayModelPrefix) {
    if (modelId.includes('/')) return modelId; // avoid double-prefixing
    return `${provider.gatewayModelPrefix}/${modelId}`;
  }
  return modelId;
}
```

| Model ID | Provider | useGateway | Result |

| `gemini-3-flash-preview` | Google | `true` | `google-ai-studio/gemini-3-flash-preview` |
