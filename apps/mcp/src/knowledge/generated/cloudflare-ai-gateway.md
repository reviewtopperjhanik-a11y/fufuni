## Cloudflare AI Gateway — Unified Access

### Overview

Cloudflare AI Gateway provides centralized observability, logging, caching, and rate limiting for all AI provider calls. Fufuni supports two integration paths:

- **Compat path**: OpenAI-compatible endpoint for all providers (Groq, Anthropic, etc.)
- **Native path**: Gemini-specific embedContent endpoint for vector generation

### ai.json Schema


### Encryption

Plaintext `ai.json` is encrypted using OpenSSL:

```bash
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"${CRYPTOKEN}"
```

Decryption in Workers uses Web Crypto API:

```typescript
// apps/merchant/src/lib/ai-enc.ts
export async function decryptAiConfig(
  base64Ciphertext: string,
  password: string,
): Promise<AiConfig> {
  // 1. Base64 decode
  const raw = Uint8Array.from(atob(base64Ciphertext), c => c.charCodeAt(0));
  
  // 2. Verify OpenSSL "Salted__" header
  if (new TextDecoder().decode(raw.slice(0, 8)) !== 'Salted__') {
    throw new Error('Invalid format');
  }

  // 3. PBKDF2-SHA256 (100k iterations)
  const pwBytes = new TextEncoder().encode(password);
  const derived = new Uint8Array(await crypto.subtle.deriveBits(
    { name: 'PBKDF2', hash: 'SHA-256', salt: raw.slice(8,16), iterations: 100_000 },
    await crypto.subtle.importKey('raw', pwBytes, 'PBKDF2', false, ['deriveBits']),
    384,
  ));

  // 4. AES-256-CBC decrypt
  return JSON.parse(new TextDecoder().decode(
    await crypto.subtle.decrypt(
      { name: 'AES-CBC', iv: derived.slice(32) },
      await crypto.subtle.importKey('raw', derived.slice(0,32), 'AES-CBC', false, ['decrypt']),
      raw.slice(16)
    )
  ));
}
```

### Gateway Authentication

Requests require the `cf-aig-authorization` header. Routing logic:

```typescript
// apps/merchant/src/lib/ai-enc.ts
export function resolveProviderEndpoint(
  provider: AiProvider,
  aigToken: string | undefined,
): { endpoint: string; useGateway: boolean } {
  if (aigToken && provider.gatewayEndpoint) {
    return { endpoint: provider.gatewayEndpoint, useGateway: true };
  }
  return { endpoint: provider.endpoint, useGateway: false };
}
```

### Model ID Prefixing

Gateway requests require provider-specific model prefixes:

```typescript
// apps/merchant/src/lib/ai-enc.ts
export function resolveModelId(
  modelId: string,
  provider: AiProvider,
  useGateway: boolean,
): string {
  if (useGateway && provider.gatewayModelPrefix) {
    const prefix = `${provider.gatewayModelPrefix}/`;
    return modelId.startsWith(prefix) ? modelId : `${prefix}${modelId}`;
  }
  return modelId;
}
```

Examples:
- Groq: `llama-3.3-70b-versatile` → `groq/llama-3.3-70b-versatile`
- Anthropic: `claude-haiku-4-5` → `anthropic/claude-haiku-4-5`
- Gemini: `gemini-3-flash-preview` → `google-ai-studio/gemini-3-flash-preview`

### CORS Limitation

**Problem**: Browser-to-gateway calls fail due to 401 on OPTIONS preflight. No JavaScript workaround exists.

**Interim solution**: Set `DISABLE_CLOUDFLARE_AIG=true` in `.env`:

```typescript
// vite.config.ts
define: {
  'import.meta.env.DISABLE_CLOUDFLARE_AIG': JSON.stringify(process.env.DISABLE_CLOUDFLARE_AIG === 'true')
}
```

This forces direct provider calls until Cloudflare resolves the CORS issue.

### Known Pitfalls

1. **Model usage filtering**: Always set `usage: "chat"` or `usage: "embedding"` on models. Without this, `selectModels()` might select an embedding model for chat completion.

2. **AiParams field names**: Frontend `AiParams` must match `/v1/ai/parameters` response exactly — any mismatch breaks the gateway integration.

3. **CORS workaround**: The `DISABLE_CLOUDFLARE_AIG` flag is temporary. Monitor Cloudflare's changelog for CORS fixes.

4. **Token rotation**: Rotate `CLOUDFLARE_AIG_TOKEN` separately from provider API keys, as it applies to all gateway traffic.
