## Unified AI Gateway Architecture

The Fufuni framework utilizes the **Cloudflare AI Gateway** as a central proxy for all Large Language Model (LLM) interactions. This architecture provides four primary benefits:
1.  **Observability**: Centralized logging and cost tracking across different providers (Groq, Anthropic, Gemini).
2.  **Caching**: Request-level caching to reduce latency and API costs for repetitive tasks like translations.
3.  **Unified Protocol**: The Gateway provides a `compat` endpoint that accepts OpenAI-formatted requests for all supported providers.
4.  **Security**: API keys remain protected behind the `cf-aig-authorization` header, allowing for authenticated gateway access.

Fufuni supports two distinct paths through the gateway:
-   **OpenAI Compatibility Path**: Used for chat completions (Anthropic, Groq, Mistral).
-   **Native Gemini Path**: Used specifically for embeddings via the `google-ai-studio` provider, bypassing the compat layer to support native Google AI Studio features.

### Model Selection and Usage Field
The `usage` field is mandatory. A common pitfall is omitting this field, causing the `selectModels()` utility to treat an embedding model as a chat model because it has a higher priority (1). Always explicitly filter by usage:

```typescript
import { selectModels, type AiConfig } from '../lib/ai-enc';

export function getBestChatModel(config: AiConfig) {
  // CORRECT: Filter by usage="chat"
  const candidates = selectModels(config, { usage: 'chat' });
  return candidates[0]; // Returns the highest priority (lowest number) chat model
}
```

## Encryption and Runtime Decryption

To protect API credentials, `ai.json` is encrypted using OpenSSL and stored as `ai.json.enc`. The `CRYPTOKEN` environment variable serves as the decryption key.

### Encryption Command
```bash

openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"${CRYPTOKEN}"
```

## Gateway Authentication and Model Prefixing

When routing through the Cloudflare AI Gateway, two modifications are required:
1.  **Authentication**: The `cf-aig-authorization` header must be sent with the Cloudflare Gateway token.
2.  **Model IDs**: Models must be prefixed with the provider slug (e.g., `groq/` or `anthropic/`) when using the `compat` endpoint.

### Resolution Logic
Fufuni provides helpers to automate this logic based on the presence of the `CLOUDFLARE_AIG_TOKEN`.

```typescript
import { resolveProviderEndpoint, resolveModelId, type AiProvider } from './ai-enc';

const provider: AiProvider = config.providers.groq;
const aigToken = env.CLOUDFLARE_AIG_TOKEN;

// 1. Determine the endpoint
const { endpoint, useGateway } = resolveProviderEndpoint(provider, aigToken);
// If token exists, returns gatewayEndpoint; else returns direct endpoint

// 2. Prepare the model ID
const modelId = resolveModelId("llama-3.3-70b-versatile", provider, useGateway);
// Returns "groq/llama-3.3-70b-versatile" if useGateway is true
```

## Backend: The Merchant Worker `/parameters` Route

The Merchant Worker exposes an endpoint that provides the frontend with the current optimal AI configuration. This route handles the priority-based selection and rotation of non-expired keys.

```typescript
// apps/merchant/src/routes/ai.ts
adminApp.openapi(aiParamsRoute, async (c) => {
  const config = await loadConfig(c.env);
  if (!config) throw new ApiError('not_configured', 503);

  const candidates = selectModels(config, { usage: 'chat' });
  
  for (const { providerKey, provider, model } of candidates) {
    const validKeys = provider.keys.filter(k => k.type !== 'expired');
    if (validKeys.length === 0) continue;

    const keyObj = validKeys[Math.floor(Math.random() * validKeys.length)];

    return c.json({
      providerName: providerKey,
      apiKey: keyObj.key,
      model: model.id,
      url: provider.endpoint,
      // Only include gateway info if the worker has the secret
      cloudflareAigToken: c.env.CLOUDFLARE_AIG_TOKEN || undefined,
      cloudflareAigUrl: provider.gatewayEndpoint || undefined,
    }, 200);
  }
  
  throw new ApiError('no_valid_keys', 503);
});
```

## Frontend Integration (`ai-client.ts`)

The frontend client consumes the `/parameters` response directly. It is designed to be "gateway-aware," automatically switching to the OpenAI compatibility format if gateway URLs are provided.

### The CORS Limitation Pitfall
**IMPORTANT**: Cloudflare AI Gateway currently does not support "Authenticated Gateway" (using `cf-aig-authorization`) for direct browser-to-gateway requests. The browser's CORS preflight (`OPTIONS`) request fails with a `401 Unauthorized` because custom headers cannot be sent during preflight.

To work around this, Fufuni uses the `DISABLE_CLOUDFLARE_AIG` flag.

```typescript
// apps/client/src/utils/ai-client.ts
export async function analyzeReviewWithAi(review: ReviewInput, aiParams: AiParams) {
  // Check build-time flag to bypass gateway if CORS issues persist
  const useGateway = !!(
    aiParams.cloudflareAigUrl && 
    aiParams.cloudflareAigToken && 
    !import.meta.env.DISABLE_CLOUDFLARE_AIG
  );

  const effectiveUrl = useGateway ? aiParams.cloudflareAigUrl! : aiParams.url;
  const authHeader = {
    Authorization: `Bearer ${aiParams.apiKey}`,
    ...(useGateway ? { "cf-aig-authorization": `Bearer ${aiParams.cloudflareAigToken}` } : {})
  };

  // ... fetch call ...
}
```

The Model Context Protocol (MCP) server uses the gateway for two main tasks: generating static knowledge during build-time and performing semantic vector searches at runtime.

```typescript
export async function generateEmbedding(text: string, opts: EmbeddingOptions) {

      },
      body: JSON.stringify({
        content: { parts: [{ text }] },
        outputDimensionality: vectorDimension
      })
    });

  }
}
```

## Key Configuration Pitfalls

| Pitfall | Consequence | Fix |
| :--- | :--- | :--- |
| **Missing `usage` field** | Embedding models might be used for chat. | Always set `usage: "chat"` or `usage: "embedding"`. |
| **Invalid Gateway URL** | Gateway returns 404 or protocol errors. | Ensure `gatewayEndpoint` ends with `/compat` for non-Gemini providers. |
| **CORS Preflight Fail** | Browser console shows 401 on OPTIONS. | Set `DISABLE_CLOUDFLARE_AIG=true` in the frontend `.env`. |
| **Wrong Dimension** | Vector search returns garbage or crashes. | Ensure `defaultDimensions` in `ai.json` matches the build-time `VECTOR_DIM`. |
| **Expired Keys** | `ai:parameters` returns 503. | Use the `type: "expired"` flag in `ai.json` to exclude dead keys from the pool. |
