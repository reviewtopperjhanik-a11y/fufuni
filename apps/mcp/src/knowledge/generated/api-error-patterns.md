## API Error Handling Reference

### **Verified facts**
- All backend routes **must** throw `ApiError` (never plain `Error` or HTTP exceptions).
- The global error handler in `apps/merchant/src/app.ts` converts `ApiError` into:
  ```json
  {
    "error": {
      "code": "not_found",
      "message": "Product not found",
      "details": { "id": 123 }
    }
  }
  ```
- Frontend errors from `useSecuredApi()` are normalized into `ApiErrorResponse` objects with:
  - `status`: HTTP status code (number)
  - `code`: Machine-readable error code (string)
  - `message`: User-facing message (string)
  - `details`: Optional object with additional context

## ApiError Static Helpers

| Method                     | HTTP Status | Use Case                                                                 |
|----------------------------|-------------|--------------------------------------------------------------------------|
| `unauthorized()`           | 401         | Missing/invalid auth token or API key.                                  |
| `forbidden()`              | 403         | Authenticated but lacks required permissions.                           |
| `notFound()`               | 404         | Resource does not exist (e.g., product, order).                        |
| `invalidRequest()`         | 400         | Validation failed (e.g., missing fields, invalid format).              |
| `badRequest()`             | 400         | Alias of `invalidRequest()` (legacy compatibility).                     |
| `conflict()`               | 409         | Duplicate resource (e.g., SKU already exists) or optimistic lock fail. |
| `insufficientInventory()`  | 409         | Stock check failed during checkout.                                     |
| `stripeError()`            | 502         | Stripe API failure (e.g., card declined).                               |
| `internalServerError()`    | 500         | Unhandled exception or database failure.                                |

## Hono JSON Response Format

When an `ApiError` is thrown, Hono’s global error handler serializes it into:

```typescript
{
  error: {
    code: string;      // Machine-readable (e.g., "not_found")
    message: string;   // User-facing (e.g., "Product not found")
    details?: object;  // Optional context (e.g., { field: "email" })
  }
}
```

```http
HTTP/1.1 404 Not Found

{
```

## Backend Usage Examples

### 1. **Resource Not Found (404)**

```typescript
import { ApiError } from '@/types';

// In a Hono route handler:
app.get('/products/:id', async (c) => {
  const product = await c.var.db.query<Product>(
```

## Frontend Error Handling

Errors from `useSecuredApi()` are typed as `ApiErrorResponse`:

```typescript
import { useSecuredApi } from '@/hooks/use-secured-api';

type ApiErrorResponse = {
  status: number;
  code: string;
  message: string;
  details?: Record<string, unknown>;
};

// Example: Handling a 404 in a React component
const { data, error, isLoading } = useSecuredApi<Product>({
  endpoint: `/products/${id}`,
});

if (error) {
  switch (error.code) {
    case 'not_found':
      return <div>Product not found. <Link to="/shop">Browse our catalog</Link></div>;
    case 'unauthorized':
      return <div>Please <Link to="/login">log in</Link> to view this product.</div>;
    case 'invalid_request':
      return (
        <Alert variant="destructive">
          {error.message}
          {error.details?.field && (
            <div className="mt-2 text-sm">
              Field: <code>{error.details.field}</code>
            </div>
          )}
        </Alert>
      );
    default:
      return <Alert variant="destructive">Something went wrong. Please try again.</Alert>;
  }
}
```

### **Displaying Field-Specific Errors (Forms)**
```typescript
const { mutate, error } = useSecuredApi({
  endpoint: '/checkout',
  method: 'POST',
});

const handleSubmit = (formData: CheckoutForm) => {
  mutate(formData, {
    onError: (err) => {
      if (err.code === 'invalid_request' && err.details?.field) {
        // Focus the invalid field
        const field = err.details.field as keyof CheckoutForm;
        form.setFocus(field);
        form.setError(field, { message: err.message });
      }
    },
  });
};
```

### **Global Error Boundary (React 19)**
```typescript
import { ErrorBoundary } from 'react-error-boundary';

function ApiErrorFallback({ error }: { error: ApiErrorResponse }) {
  return (
    <div className="p-4 bg-red-50 rounded-lg">
      <h3 className="font-bold">{error.code.replace('_', ' ')}</h3>
      <p>{error.message}</p>
      {error.details && (
        <pre className="mt-2 text-xs bg-gray-100 p-2 rounded">
          {JSON.stringify(error.details, null, 2)}
        </pre>
      )}
    </div>
  );
}

// Usage
<ErrorBoundary FallbackComponent={ApiErrorFallback}>
  <CheckoutForm />
</ErrorBoundary>
```
