## React Router Setup

Routes are declared in `apps/client/src/app.tsx` using React Router v6. The app uses a **flat route hierarchy** with protected routes wrapped in either `AuthenticationGuard` (requires login) or `AuthenticationGuardWithPermission` (requires login + specific Auth0 permission).

### Key Patterns
1. **Public vs Protected Routes**
   Public routes (e.g., `/`, `/product/:id`) are declared without guards. Protected routes wrap their `element` in a guard component.

2. **Nested Layouts**
   The account section (`/account/*`) uses a nested layout (`AccountLayout`) with child routes for sub-pages.

3. **Suspense + Loading States**
   The entire `<Routes>` block is wrapped in `<Suspense fallback={<SiteLoading />}>`. Individual pages can also use `React.lazy` for code-splitting.

### Example: Adding a Protected Route
```tsx
// apps/client/src/app.tsx
import { Route } from "react-router-dom";
import { AuthenticationGuardWithPermission } from "./authentication";
import MyNewPage from "./pages/my-new-page";

// Inside the <Routes> block:
<Route
  element={
    <AuthenticationGuardWithPermission permission="admin:store">
      <MyNewPage />
    </AuthenticationGuardWithPermission>
  }
  path="/admin/my-new-page"
/>
```

### Guard Components
| Component                          | Purpose                                                                 |
|------------------------------------|-------------------------------------------------------------------------|
| `AuthenticationGuard`               | Requires login (any authenticated user).                               |
| `AuthenticationGuardWithPermission`| Requires login + specific Auth0 permission (e.g., `"admin:store"`).     |

Both guards accept a `component` prop (React element) or render children directly:
```tsx
// Option 1: component prop
<AuthenticationGuard component={<AdminPage />} />

// Option 2: children
<AuthenticationGuard>
  <AdminPage />
</AuthenticationGuard>
```

## Navbar Auto-Visibility by Permissions

The navbar (`apps/client/src/components/navbar.tsx`) dynamically filters items based on:
1. **Public Items** (`permissions: []`): Always visible.
2. **Admin Items** (`permissions: ["admin:store"]`): Hidden unless:
   - User is authenticated **and**
   - User has the `"admin:store"` Auth0 permission.

### Implementation Details
1. **Public Items Rendering**
   ```tsx
   {siteConfig().navItems
     .filter(item => !item.permissions || item.permissions.length === 0)
     .map((item) => (
       <RouterLink key={item.href} to={item.href}>
         {item.label}
       </RouterLink>
     ))}
   ```

2. **Admin Dropdown**
   Wrapped in `<AuthenticationGuardWithPermission>` and only renders items where `permissions` includes `"admin:store"`:
   ```tsx
   <AuthenticationGuardWithPermission permission="admin:store">
     <Dropdown>
       <Dropdown.Trigger>{t("nav-admin")}</Dropdown.Trigger>
       <Dropdown.Menu>
         {siteConfig().navItems
           .filter(item => item.permissions?.includes("admin:store"))
           .map((item) => (
             <Dropdown.Item key={item.href} onPress={() => navigate(item.href)}>
               {item.label}
             </Dropdown.Item>
           ))}
       </Dropdown.Menu>
     </Dropdown>
   </AuthenticationGuardWithPermission>
   ```

3. **Mobile Menu**
   Mirrors the desktop logic but uses `navMenuItems` (a subset of `navItems`):
   ```tsx
   {siteConfig().navMenuItems.map((item) =>
     item.permissions?.length ? (
       <AuthenticationGuardWithPermission permission={item.permissions[0]}>
         <RouterLink to={item.href}>{item.label}</RouterLink>
       </AuthenticationGuardWithPermission>
     ) : (
       <RouterLink to={item.href}>{item.label}</RouterLink>
     )
   )}
   ```

## ThemeSwitch: Dark/Light Mode

The `ThemeSwitch` component (`apps/client/src/shared/ui/navigation/theme-switch.tsx`) is pre-wired in the navbar and:
1. Toggles between **light/dark/system** themes.
2. Persists the user’s preference to `localStorage` (key: `fufuni-theme`).
3. Syncs with the `StoreThemeProvider` (which loads custom themes from the `store_themes` DB table).

### Usage
```tsx
import { ThemeSwitch } from "@/shared/ui/navigation/theme-switch";

// Render anywhere (already included in Navbar)
<ThemeSwitch />
```

### How It Works
1. **Provider Setup** (`provider.tsx`):
   ```tsx
   <StoreThemeProvider>
     {/* App */}
   </StoreThemeProvider>
   ```
2. **Theme Storage**:
   - User selection → `localStorage`.
   - Custom themes → `store_themes` SQLite table (fetched on app load).

## Worked Example: Adding a "Product Tags" Admin Page

### 1. Create the Page Component
```tsx
// apps/client/src/pages/admin/tags.page.tsx
import { useSeoMeta } from "@/hooks/use-seo-meta";
import { AdminLayout } from "@/layouts/admin-layout";
import { Button, Table, Input } from "@heroui/react";
import { useState } from "react";
import { useTranslation } from "react-i18next";

export default function ProductTagsPage() {
  const { t } = useTranslation();
  const [tags, setTags] = useState([
    { id: "1", name: "Sale", slug: "sale" },
    { id: "2", name: "New", slug: "new" },
  ]);
  const [newTag, setNewTag] = useState("");

  useSeoMeta({
    title: "Product Tags | Admin",
    description: "Manage product tags.",
  });

  const addTag = () => {
    if (!newTag.trim()) return;
    setTags([...tags, { id: Date.now().toString(), name: newTag, slug: newTag.toLowerCase() }]);
    setNewTag("");
  };

  return (
    <AdminLayout>
      <div className="flex justify-between items-center mb-6">
        <h1 className="text-2xl font-bold">{t("admin-tags-title")}</h1>
        <div className="flex gap-2">
          <Input
            value={newTag}
            onChange={(e) => setNewTag(e.target.value)}
            placeholder={t("add-tag-placeholder")}
            onKeyDown={(e) => e.key === "Enter" && addTag()}
          />
          <Button onPress={addTag}>{t("add")}</Button>
        </div>
      </div>
      <Table>
        <Table.Header>
          <Table.Column>{t("name")}</Table.Column>
          <Table.Column>{t("slug")}</Table.Column>
          <Table.Column>{t("actions")}</Table.Column>
        </Table.Header>
        <Table.Body>
          {tags.map((tag) => (
            <Table.Row key={tag.id}>
              <Table.Cell>{tag.name}</Table.Cell>
              <Table.Cell>{tag.slug}</Table.Cell>
              <Table.Cell>
                <Button size="sm" variant="ghost">
                  {t("edit")}
                </Button>
              </Table.Cell>
            </Table.Row>
          ))}
        </Table.Body>
      </Table>
    </AdminLayout>
  );
}
```
