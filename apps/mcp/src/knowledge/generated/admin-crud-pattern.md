## Admin CRUD Pattern Guide

### The Three-Component Pattern

The Fufuni admin interface follows a consistent three-component pattern for all CRUD operations:

1. **AdminCrudLayout** - Outer shell with header, filters, and table structure
2. **useAdminCrud()** - Hook managing state and API interactions
3. **RowActions** - Standardized row-level action buttons

These components compose together to create a uniform admin experience:

```tsx
// Typical admin page structure
function AdminProductsPage() {
  const crud = useAdminCrud<Product>({ /* options */ });

  return (
    <AdminCrudLayout
      title="Products"
      addLabel="Add Product"
      onAdd={crud.openCreate}
      globalFilter={crud.globalFilter}
      onGlobalFilterChange={crud.setGlobalFilter}
      statusFilter={crud.statusFilter}
      onStatusFilterChange={crud.setStatusFilter}
    >
      {/* Table with RowActions in each row */}
      {crud.displayedItems.map(item => (
        <tr key={item.id}>
          {/* ... cells ... */}
          <td>
            <RowActions
              onEdit={() => crud.openEdit(item)}
              onDelete={() => crud.remove(item.id)}
            />
          </td>
        </tr>
      ))}

      {/* Create/Edit Modal */}
      <ProductModal
        isOpen={crud.isModalOpen}
        onClose={crud.closeModal}
        item={crud.editingItem}
        isEditMode={crud.isEditMode}
      />
    </AdminCrudLayout>
  );
}
```

### useAdminCrud() Hook

The `useAdminCrud<T>()` hook centralizes all CRUD state management. It requires a generic type parameter extending `HasIdAndStatus`:

```typescript
interface UseAdminCrudOptions<T extends HasIdAndStatus> {
  filterFn: (item: T, term: string) => boolean;
}

interface UseAdminCrudResult<T extends HasIdAndStatus> {
  // List state
  items: T[];
  setItems: Dispatch<SetStateAction<T[]>>;
  displayedItems: T[];

  // Filter state
  globalFilter: string;
  setGlobalFilter: (value: string) => void;
  statusFilter: string;
  setStatusFilter: (value: string) => void;

  // Modal state
  isModalOpen: boolean;
  setIsModalOpen: Dispatch<SetStateAction<boolean>>;
  isEditMode: boolean;
  editingItem: T | null;

  // Modal helpers
  openCreate: () => void;
  openEdit: (item: T) => void;
  closeModal: () => void;
}
```

Key features:
- Automatically filters items based on global search and status filters
- Manages modal state for create/edit operations
- Tracks the currently edited item

### Modal Pattern

The same modal handles both create and edit operations:

```tsx
function TagModal({ isOpen, onClose, item, isEditMode }) {
  const { register, handleSubmit } = useForm({
    values: isEditMode ? item : { name: '', status: 'active' }
  });

  const onSubmit = (data) => {
    isEditMode ? updateTag(item.id, data) : createTag(data);
    onClose();
  };

  return (
    <Modal isOpen={isOpen} onClose={onClose}>
      <Modal.Header>
        {isEditMode ? 'Edit Tag' : 'Create New Tag'}
      </Modal.Header>
      <form onSubmit={handleSubmit(onSubmit)}>
        {/* Form fields */}
      </form>
    </Modal>
  );
}
```

Key distinctions:
- `isEditMode` determines form title and initial values
- `editingItem` provides data for edit operations
- Same form structure used for both operations

### Form Validation

All forms use react-hook-form with Zod validation:

```tsx
import { zodResolver } from '@hookform/resolvers/zod';
import * as z from 'zod';

const tagSchema = z.object({
  name: z.string().min(2).max(50),
  status: z.enum(['active', 'inactive'])
});

function TagForm() {
  const { register, handleSubmit, formState: { errors } } = useForm({
    resolver: zodResolver(tagSchema)
  });

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <TextField error={errors.name}>
        <Label>Tag Name</Label>
        <Input {...register('name')} />
      </TextField>
      {/* Other fields */}
    </form>
  );
}
```

### Complete ProductTags Example

Here's a full implementation of a product tags admin page:

```tsx
// apps/client/src/pages/admin/product-tags.tsx
import { useAdminCrud } from '@/hooks/use-admin-crud';
import { AdminCrudLayout } from '@/shared/ui/admin/admin-crud-layout';
import { RowActions } from '@/shared/ui/admin/row-actions';
import { api } from '@/lib/api';

interface ProductTag extends HasIdAndStatus {
  name: string;
  slug: string;
}

export function AdminProductTagsPage() {
  const crud = useAdminCrud<ProductTag>({
    filterFn: (tag, term) =>
      tag.name.toLowerCase().includes(term) ||
      tag.slug.toLowerCase().includes(term)
  });

  const fetchTags = async () => {
    const tags = await api.productTags.list();
    crud.setItems(tags);
  };

  useEffect(() => {
    fetchTags();
  }, []);

  const createTag = async (data) => {
    await api.productTags.create(data);
    await fetchTags();
  };

  const updateTag = async (id, data) => {
    await api.productTags.update(id, data);
    await fetchTags();
  };

  const removeTag = async (id) => {
    await api.productTags.delete(id);
    await fetchTags();
  };

  return (
    <AdminCrudLayout
      title="Product Tags"
      addLabel="Add Tag"
      onAdd={crud.openCreate}
      globalFilter={crud.globalFilter}
      onGlobalFilterChange={crud.setGlobalFilter}
      statusFilter={crud.statusFilter}
      onStatusFilterChange={crud.setStatusFilter}
    >
      <table className="w-full">
        <thead>
          <tr>
            <th>Name</th>
            <th>Slug</th>
            <th>Status</th>
            <th>Actions</th>
          </tr>
        </thead>
        <tbody>
          {crud.displayedItems.map(tag => (
            <tr key={tag.id}>
              <td>{tag.name}</td>
              <td>{tag.slug}</td>
              <td>{tag.status}</td>
              <td>
                <RowActions
                  onEdit={() => crud.openEdit(tag)}
                  onDelete={() => removeTag(tag.id)}
                  deleteConfirmMessage="Delete this tag?"
                />
              </td>
            </tr>
          ))}
        </tbody>
      </table>

      <TagModal
        isOpen={crud.isModalOpen}
        onClose={crud.closeModal}
        item={crud.editingItem}
        isEditMode={crud.isEditMode}
        onSubmit={crud.isEditMode ? updateTag : createTag}
      />
    </AdminCrudLayout>
  );
}
```
