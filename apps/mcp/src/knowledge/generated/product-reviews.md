## Product Reviews Reference

### Review Data Model

The `product_reviews` table stores all review data with these fields:

```typescript
interface ProductReview {
  id: string; // UUID
  product_id: string; // UUID, references products.id
  customer_id: string; // UUID, references customers.id
  rating: number; // 1-5
  title: string | null;
  body: string | null;
  status: 'pending' | 'approved' | 'rejected';
  ai_moderation_result: object | null; // JSON stored as text
  created_at: string; // ISO timestamp
}
```

Example SQL schema:
```sql
CREATE TABLE product_reviews (
  id TEXT PRIMARY KEY,
  product_id TEXT NOT NULL REFERENCES products(id),
  customer_id TEXT NOT NULL REFERENCES customers(id),
  rating INTEGER NOT NULL CHECK (rating BETWEEN 1 AND 5),
  title TEXT,
  body TEXT,
  status TEXT NOT NULL CHECK (status IN ('pending', 'approved', 'rejected')),
  ai_moderation_result TEXT,
  created_at TEXT NOT NULL
);
```

### Rating Aggregates

The `products` table stores computed columns:

```sql
-- Columns definition
avg_rating DECIMAL(3,2) GENERATED ALWAYS AS (
  (SELECT AVG(rating) FROM product_reviews WHERE product_id = id AND status = 'approved')
) STORED,

review_count INTEGER GENERATED ALWAYS AS (
  (SELECT COUNT(*) FROM product_reviews WHERE product_id = id AND status = 'approved')
) STORED
```

Updates trigger on status changes:

```typescript
// After PATCH /v1/reviews/:id/status
await db.execute(`
  UPDATE products
  SET avg_rating = (SELECT AVG(rating) FROM product_reviews WHERE product_id = ? AND status = 'approved'),
      review_count = (SELECT COUNT(*) FROM product_reviews WHERE product_id = ? AND status = 'approved')
  WHERE id = ?
`, [productId, productId, productId]);
```
