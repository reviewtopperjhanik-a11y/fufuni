## Review data model

The `product_reviews` table stores all review data with these columns:

```sql
CREATE TABLE product_reviews (
  id              TEXT PRIMARY KEY DEFAULT (uuid()),
  product_id      TEXT NOT NULL REFERENCES products(id) ON DELETE CASCADE,
  customer_id     TEXT REFERENCES customers(id) ON DELETE SET NULL,
  rating          INTEGER NOT NULL CHECK (rating BETWEEN 1 AND 5),
  title           TEXT,
  body            TEXT,
  status          TEXT NOT NULL CHECK (status IN ('pending', 'approved', 'rejected')),
  ai_moderation_result JSONB,
  created_at      TEXT NOT NULL DEFAULT (datetime('now')),
  -- Computed fields
  is_verified_purchase INTEGER GENERATED ALWAYS AS (
    (SELECT COUNT(*) FROM order_items
     WHERE order_items.product_id = product_reviews.product_id
     AND order_items.order_id IN (
       SELECT id FROM orders WHERE orders.customer_id = product_reviews.customer_id
     )) > 0
  ) STORED,
  helpful_count   INTEGER NOT NULL DEFAULT 0
);
```

**Status values**:
- `pending`: Newly submitted, awaiting admin approval
- `approved`: Visible on product pages
- `rejected`: Hidden from public views

## Public endpoints

### Submit a review
**POST** `/v1/products/:productId/reviews`
Requires customer authentication.

```typescript
// Example request
await fetch(`${apiBase}/v1/products/123e4567-e89b-12d3-a456-426614174000/reviews`, {
  method: 'POST',
  headers: { 'Authorization': 'Bearer ...' },
  body: JSON.stringify({
    rating: 5,
    title: 'Great product!',
    body: 'Works exactly as described.'
  })
});
```

**Response**:
- `201 Created` on success
- `409 Conflict` if customer already reviewed this product
- `400 Bad Request` if rating is outside 1-5 range

## AI moderation integration

AI analysis runs when:
1. Admin opens the reviews page
2. For each pending review, `moderateReview()` is called
3. Results are stored in `ai_moderation_result` column

**UI display**:

## Rating aggregates

The `products` table includes computed columns:

```sql
ALTER TABLE products ADD COLUMN avg_rating REAL GENERATED ALWAYS AS (
  (SELECT AVG(rating) FROM product_reviews
   WHERE product_reviews.product_id = products.id AND status = 'approved')
) STORED;

ALTER TABLE products ADD COLUMN review_count INTEGER GENERATED ALWAYS AS (
  (SELECT COUNT(*) FROM product_reviews
   WHERE product_reviews.product_id = products.id AND status = 'approved')
) STORED;
```

**Update trigger**:
```typescript
// After PATCH /v1/reviews/:id/status
await db.prepare(`
  UPDATE products SET
    avg_rating = (SELECT AVG(rating) FROM product_reviews
                  WHERE product_id = ? AND status = 'approved'),
    review_count = (SELECT COUNT(*) FROM product_reviews
                    WHERE product_id = ? AND status = 'approved')
  WHERE id = ?
`).run(productId, productId, productId);
```
