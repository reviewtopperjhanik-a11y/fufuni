## Analytics API Architecture

Fufuni provides a suite of analytics endpoints under the `/v1/analytics` prefix. These routes are protected by `authMiddleware` and `adminOnly` guards, ensuring that only authenticated administrators can access store performance data. Unlike platforms that rely on third-party tracking services, Fufuni computes all metrics on-demand directly from the Durable Object's SQLite database.

### Core Endpoints

The API is structured to provide granular data for different aspects of the store. Every endpoint follows the same pattern for filtering and currency normalization.

| Method | Path | Description |
| :--- | :--- | :--- |
| `GET` | `/v1/analytics/revenue` | Total revenue, revenue by day, and revenue by product. |
| `GET` | `/v1/analytics/orders` | Volume metrics and breakdown by fulfillment status. |
| `GET` | `/v1/analytics/customers` | New vs. returning customer counts and retention rates. |
| `GET` | `/v1/analytics/products/top` | Ranking of top 10 products by generated revenue. |
| `GET` | `/v1/analytics/funnel` | Checkout conversion steps from cart to completion. |

## Date Range and Filtering

All analytics endpoints accept `from` and `to` query parameters as ISO-8601 strings. If omitted, the default range is usually the last 30 days. Because Fufuni uses SQLite within a Cloudflare Worker, date filtering is performed using the `strftime` or `datetime` functions.

### SQL Implementation for Periods

When querying the SQLite database, the parameters are interpolated into the `WHERE` clause. It is critical to use indices on the `created_at` columns to maintain performance as the order history grows.

```typescript
// Inside the Hono handler
const { from, to } = c.req.valid('query');

const startDate = from || new Date(Date.now() - 30 * 24 * 60 * 60 * 1000).toISOString();
const endDate = to || new Date().toISOString();

const revenueData = await db.query<{ date: string; amount: number }>(
  `SELECT 
     strftime('%Y-%m-%d', created_at) as date,
     SUM(total_cents) as amount
   FROM orders
   WHERE created_at BETWEEN ? AND ?
     AND status NOT IN ('cancelled', 'refunded')
   GROUP BY date
   ORDER BY date ASC`,
  [startDate, endDate]
);
```

## Currency and Monetary Values

Fufuni handles all monetary values in the **smallest unit** (cents/sub-units) for the requested currency. The `?currency=XYZ` parameter ensures that the analytics engine performs necessary conversions if the store supports multi-currency transactions.

## Revenue and Product Performance

The `/v1/analytics/products/top` endpoint ranks products by revenue generated within the specified timeframe. This requires joining the `orders`, `order_items`, and `products` tables.

### Top Products Query

The ranking is computed by summing the line item totals for paid orders.

```sql
SELECT 
    p.id as product_id,
    p.title as product_title,
    SUM(oi.quantity) as units_sold,
    SUM(oi.price_cents * oi.quantity) as revenue_cents
FROM order_items oi
JOIN orders o ON oi.order_id = o.id
JOIN products p ON oi.product_id = p.id
WHERE o.status IN ('paid', 'processing', 'shipped', 'delivered')
  AND o.created_at BETWEEN ? AND ?
GROUP BY p.id
ORDER BY revenue_cents DESC
LIMIT 10;
```

## Customer Metrics and Retention

The `/v1/analytics/customers` endpoint provides insight into the growth of the customer base.

### Retention Logic
- **New In Period**: Customers whose first order occurred within the `from`/`to` range.
- **Returning Rate**: The percentage of customers who placed an order in the current period and had at least one order prior to the `from` date.

```typescript
// Example response structure for /v1/analytics/customers
const customerStats = {
  total: 1250,        // Total unique customers in DB
  newInPeriod: 45,    // First order was in this range
  returningRate: 0.15 // 15% of customers in this period were repeat buyers
};
```

## Checkout Funnel Analysis

The funnel tracks the efficiency of the checkout flow. It measures four distinct stages:
1. **Cart Created**: A session where at least one item was added.
2. **Checkout Started**: The user reached the shipping/billing information page.
3. **Checkout Completed**: A successful transaction (Order created with 'paid' status).
4. **Conversion Rate**: `(Checkout Completed / Cart Created) * 100`.

```typescript
const { data: funnel } = useQuery({
  queryKey: ["analytics-funnel", period],
  queryFn: () => getJson(`${apiBase}/v1/analytics/funnel?from=${from}&to=${to}`)
});

// Rendering with HeroUI Progress or custom bars
```

## Performance and Indexing

Because analytics are computed on-demand from the SQLite database, query execution time can increase linearly with the number of orders. To keep the Admin Dashboard responsive (under 200ms), the following indexes are mandatory in the Fufuni migrations:

```sql
-- Essential for date-range filtering
CREATE INDEX IF NOT EXISTS idx_orders_created_at ON orders(created_at);

-- Essential for product-based revenue reports
CREATE INDEX IF NOT EXISTS idx_order_items_product_id ON order_items(product_id);

-- Essential for customer retention queries
CREATE INDEX IF NOT EXISTS idx_orders_customer_id_created ON orders(customer_id, created_at);
```
