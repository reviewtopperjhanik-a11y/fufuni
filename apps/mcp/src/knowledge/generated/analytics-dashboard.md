## Analytics Dashboard Reference

### Endpoints

All analytics endpoints are under `/v1/analytics` and require admin authentication. Each endpoint accepts the following query parameters:

- `from`: ISO date string (e.g., `2023-01-01`)
- `to`: ISO date string (e.g., `2023-12-31`)
- `currency`: 3-letter currency code (e.g., `EUR`)

Default date range is the last 30 days if `from` and `to` are omitted.

#### Revenue

```typescript
// GET /v1/analytics/revenue
interface RevenueResponse {
  total: number; // Total revenue in cents
  byDay: Array<{
    date: string; // ISO date

  }>;
  byProduct: Array<{
    productId: string;
    name: string;
    amount: number; // Revenue in cents for this product

```

### Date Range Handling

All endpoints accept `from` and `to` parameters as ISO date strings. If omitted, the default range is the last 30 days.

Example request:
```bash
GET /v1/analytics/revenue?from=2023-01-01&to=2023-01-31&currency=EUR
```

### Currency Handling

All monetary values are returned in the smallest currency unit (e.g., cents for EUR). Specify the currency using the `currency` parameter. If omitted, the store's default currency is used.

### Revenue Chart

The revenue chart uses data from the `/revenue` endpoint. The `byDay` array provides daily revenue totals, suitable for time-series charts. The `byProduct` array shows revenue distribution across products.

### Orders by Status

The orders by status chart uses data from the `/orders` endpoint. The `byStatus` object contains counts for each order status. `avgOrderValue` is calculated as total revenue divided by total orders.

### Customer Metrics

The `returningRate` in the customers response is the percentage of orders placed by customers who had previously placed an order.

### Top Products

Products are ranked by total revenue in the specified date range. The top 10 products are returned.

### Checkout Funnel

The funnel shows the conversion path:
1. `cartCreated`: Number of carts created
2. `checkoutStarted`: Number of users who began checkout
3. `checkoutCompleted`: Number of completed purchases
4. `conversionRate`: Percentage of carts that resulted in a purchase

### Performance Considerations

Analytics are computed on-demand using SQL queries. For stores with large order volumes, ensure the following database indexes exist:

```sql
CREATE INDEX idx_orders_created_at ON orders(created_at);
CREATE INDEX idx_order_items_product_id ON order_items(product_id);
```

The analytics system does not use pre-aggregation. For optimal performance with large datasets, consider adding these indexes during database setup.
