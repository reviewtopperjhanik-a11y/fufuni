### Running E2E Tests
**Prerequisites**:
- Dev server running (`npm run dev` from monorepo root)
- `.env` file with `VITE_APP_URL` (defaults to `http://localhost:5173`)
- Optional: `PLAYWRIGHT_API_BASE_URL` for worker API tests (e.g., `http://localhost:8787`)

**Command**:
```bash
npm run e2e
```

**Targeted runs**:
```bash
# Run only public tests
npx playwright test --project=public-chromium

# Run only admin tests
npx playwright test --project=auth-admin

# Run a specific spec
npx playwright test e2e/tests/auth/checkout.spec.ts
```

### Auth State Setup
Setup scripts validate pre-exported storage states from real Auth0 sessions. They **do not** perform live logins.

#### How Fixtures Are Created
1. Manually log in via Auth0 Universal Login (hosted page) with test credentials
2. Export storage state using Playwright's `browserContext.storageState()`
3. Save as `storage-state-user.json` or `storage-state-admin.json`

#### Setup Scripts
**`user.setup.ts`**:
```typescript
import { test as setup, expect } from "@playwright/test";
import * as fs from "fs";
import * as path from "path";

const FIXTURE_PATH = path.join(__dirname, "../../fixtures/storage-state-user.json");

setup("validate user storage state exists", async () => {
  const exists = fs.existsSync(FIXTURE_PATH);
  expect(exists).toBe(true);

  const raw = fs.readFileSync(FIXTURE_PATH, "utf-8");
  const state = JSON.parse(raw);
  expect(state.origins[0].localStorage.some(
    (e: { name: string }) => e.name.startsWith("@@auth0spajs@@")
  )).toBe(true);
});
```

**Credentials**:
Loaded from `.env` (root):
```env
E2E_USER_EMAIL=test-user@fufuni.example
E2E_USER_PASSWORD=correct-horse-battery-staple
E2E_ADMIN_EMAIL=admin@fufuni.example
E2E_ADMIN_PASSWORD=admin-password-123
```
*Note*: These are **not** committed to Git.

### Writing a New Spec
#### 1. Storage State Selection
Use the `test.use()` override to specify auth requirements:
```typescript
// For admin-only tests
test.use({ storageState: "./fixtures/storage-state-admin.json" });
```

#### 2. BaseURL Handling
The base URL is auto-injected from `playwright.config.ts`:
```typescript
test("Loads homepage", async ({ page }) => {
  await page.goto("/"); // Resolves to VITE_APP_URL
});
```

#### 3. Page Object Pattern
Fufuni uses **inline page objects** (no separate classes). Example from `checkout.spec.ts`:
```typescript
async function addFirstProductToCart(page: import("@playwright/test").Page) {
  await page.goto("/");
  const addBtn = page.getByRole("button", { name: /ajouter au panier/i }).first();
  await addBtn.click();
}
```

#### 4. Worker API Tests
Use `playwrightRequest` for direct API calls:
```typescript
test("Worker API returns 400 without body", async ({ request }) => {
  const resp = await request.post("/ucp/v1/checkout-sessions", { data: {} });
  expect([400, 401, 403, 422]).toContain(resp.status());
});
```

```typescript
    await expect(page.getByRole("main")).toBeVisible();
  }
});
```

### Cleanup Discipline
Admin tests **must** delete created data. Use timestamp-based handles to avoid collisions:
```typescript
const TEST_HANDLE = `playwright-test-${Date.now()}`;

// After test:
await page.locator('[title="Supprimer"] button').click();
await page.getByRole("button", { name: /supprimer/i }).click();
```

**Force-reload after mutations** to bypass KV cache:
```typescript
await page.reload();
await page.waitForLoadState("networkidle");
```

### CI Integration
**When E2E Runs**:
- On every PR merge to `main`
- Nightly on `main` branch (cron job)

**Env Vars in CI**:
Injected via GitHub Actions secrets:
```yaml
env:
  PLAYWRIGHT_BASE_URL: ${{ secrets.PLAYWRIGHT_BASE_URL }}
  PLAYWRIGHT_API_BASE_URL: ${{ secrets.PLAYWRIGHT_API_BASE_URL }}
  E2E_USER_EMAIL: ${{ secrets.E2E_USER_EMAIL }}
  E2E_USER_PASSWORD: ${{ secrets.E2E_USER_PASSWORD }}
```

**CI-Specific Config** (`playwright.config.ts`):
```typescript
export default defineConfig({
  retries: process.env.CI ? 2 : 0,
  workers: process.env.CI ? 2 : 1,
  forbidOnly: !!process.env.CI,
  reporter: process.env.CI ? ["github", "list"] : ["html", "list"],
});
```
