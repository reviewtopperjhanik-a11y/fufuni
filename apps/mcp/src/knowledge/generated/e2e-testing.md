## Project Structure

The E2E test suite is organized in the `e2e/` directory with the following structure:

```
e2e/
├── tests/
│   ├── public/          # Tests for anonymous users
│   ├── auth/            # Tests for authenticated users
│   ├── admin/           # Tests for admin users
│   └── setup/           # Setup scripts for auth states
├── fixtures/            # Storage state fixtures
└── playwright.config.ts  # Playwright configuration
```

The framework uses three authentication states:
1. **Anonymous** (public tests): No storage state fixture
2. **Authenticated user**: `storage-state-user.json`
3. **Admin user**: `storage-state-admin.json`

Fixtures are generated by setup scripts and stored in `e2e/fixtures/`.

## Running E2E Tests

To execute the test suite:

```bash
npm run e2e
```

**Prerequisites:**
- Development server must be running (`npm run dev`)
- Environment variables configured (see below)
- Playwright browsers installed (`npx playwright install`)

Required environment variables (in `.env` at monorepo root):
```env
E2E_USER_EMAIL=test@example.com
E2E_USER_PASSWORD=securepassword
E2E_ADMIN_EMAIL=admin@example.com
E2E_ADMIN_PASSWORD=adminpassword
```

## Authentication Setup

Setup scripts (`setup/user.setup.ts` and `setup/admin.setup.ts`) validate storage state fixtures. These fixtures are created by:

1. Manually logging into Auth0 Universal Login page with test credentials
2. Exporting the storage state using Playwright's `context.storageState()`
3. Saving to `e2e/fixtures/` as JSON files

Example setup validation:
```typescript
// e2e/tests/setup/user.setup.ts
import { test as setup, expect } from "@playwright/test";
import * as fs from "fs";
import * as path from "path";

const FIXTURE_PATH = path.join(__dirname, "../../fixtures/storage-state-user.json");

setup("validate user storage state exists", async () => {
  const exists = fs.existsSync(FIXTURE_PATH);
  expect(exists).toBe(true);
  const raw = fs.readFileSync(FIXTURE_PATH, "utf-8");
  const state = JSON.parse(raw);
  expect(state.origins[0].localStorage.some(
    (e: { name: string }) => e.name.startsWith("@@auth0spajs@@")
  )).toBe(true);
});
```

## Writing New Specs

To add a new test specification:

1. Create file in appropriate category folder:
   - `e2e/tests/public/` for anonymous tests
   - `e2e/tests/auth/` for authenticated user tests
   - `e2e/tests/admin/` for admin tests

2. Import the required storage state:
```typescript
// For authenticated tests
test.use({ storageState: "./fixtures/storage-state-user.json" });
```

3. Use the base URL from config:
```typescript
import { test, expect } from "@playwright/test";

test("Example test", async ({ page }) => {
  await page.goto("/"); // Uses baseURL from playwright.config.ts
  await expect(page).toHaveTitle(/Fufuni/i);
});
```

## Test Categories Conventions

### Public Tests (Anonymous)
- Location: `e2e/tests/public/`
- Storage state: None (anonymous)
- Example: Navigation tests
```typescript
test("Homepage loads successfully", async ({ page }) => {
  await page.goto("/");
  await expect(page).toHaveTitle(/Fufuni/i);
});
```

### Auth Tests (User)
- Location: `e2e/tests/auth/`
- Storage state: `storage-state-user.json`
- Example: Checkout flow
```typescript
test.describe("Checkout — utilisateur authentifié", () => {
  test.beforeEach(async ({ page }) => {
    await addFirstProductToCart(page);
  });

  test("Le checkout redirige vers Stripe Checkout", async ({ page }) => {
    await page.getByRole("button", { name: /ouvrir le panier/i }).click();
    await page.getByRole("button", { name: /commander/i }).click();
    await expect(page).toHaveURL(/checkout\.stripe\.com/);
  });
});
```

### Admin Tests
- Location: `e2e/tests/admin/`
- Storage state: `storage-state-admin.json`
- Convention: Each test cleans up created data
```typescript
test("Supprimer la catégorie de test", async ({ page }) => {
  await page.goto("/admin/categories");
  const row = page.getByRole("row").filter({ hasText: TEST_NAME });
  await row.locator('[title="Supprimer"] button').click();
  await page.getByRole("button", { name: /supprimer/i }).click();
  await expect(page.getByRole("rowheader", { name: new RegExp(TEST_NAME) })).not.toBeVisible();
});
```

## Cleanup Discipline

Admin tests follow strict cleanup protocols:
1. Create unique test data with timestamps
2. Delete created items at test end
3. Reload pages to bypass cache

Example pattern:
```typescript
const TEST_HANDLE = `playwright-test-${Date.now()}`;

test("Créer une catégorie de test", async ({ page }) => {
  // ... creation logic
});

test("Supprimer la catégorie de test", async ({ page }) => {
  // ... deletion logic using TEST_HANDLE
});
```

## CI Integration

In CI environments:
- Tests run with `PLAYWRIGHT_ENV=ci`
- Environment variables are injected from CI secrets
- Configuration adjusts for CI:
  - Retries: 2
  - Workers: 2
  - No video capture (only on failure)

Key CI environment variables:
```env
PLAYWRIGHT_BASE_URL=https://ci-preview-url.com
PLAYWRIGHT_API_BASE_URL=https://api-ci-url.com
```
