## AI-Assisted Features Reference

## Architecture

AI calls are made directly from the browser to avoid backend inference latency. The merchant backend only provides credential management via GET `/v1/ai/parameters`, which returns decrypted API keys to authenticated users. This design minimizes roundtrips and keeps AI processing off the critical path.

```typescript
// Client-side direct call example
const { apiKey, model, url } = await fetchAiParams();
const result = await moderateReview(
  { id: "rev_123", rating: 4, body: "Great product!" },
  apiKey,
  model,
  url
);
```

## Credential Storage

AI credentials are stored encrypted in the `ai_settings` table using AES-256-CBC encryption with PBKDF2 key derivation (100,000 iterations). The encryption key is the `ENCRYPTION_KEY` Wrangler secret.

```typescript
// Encryption format (OpenSSL command)
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"${CRYPTOKEN}"
```

## GET /v1/ai/parameters

Authenticated admin users (with `ai:api` permission) can fetch decrypted credentials. The endpoint returns:

```typescript
interface AiParams {
  apiKey: string;
  model: string;
  url: string;
  cloudflareAigToken?: string;
  cloudflareAigUrl?: string;
}
```

Example request:
```typescript
const response = await fetch('/v1/ai/parameters', {
  headers: { Authorization: 'Bearer YOUR_ADMIN_TOKEN' }
});
const { apiKey, model, url } = await response.json();
```

## Review Moderation

The admin reviews page calls `moderateReview()` before displaying approve/reject buttons. It returns `{ safe: boolean, reason?: string }` which the UI uses to:
- Show/hide moderation controls
- Display warning messages
- Pre-select action (approve/reject)

```typescript
// Admin UI integration
const moderation = await moderateReview(reviewData);
if (!moderation.safe) {
  showWarning(`Recommended: Reject (${moderation.reason})`);
}
```

## Auto-Translation

The product form calls `autoTranslate()` to pre-fill localized fields. Workflow:
1. Base language (en-US) content is sent to AI
2. Translations populate all other locale fields
3. Fallback: When AI isn't configured, translate buttons are hidden

```typescript
// Product form integration
const locales = ['fr-FR', 'de-DE', 'es-ES'];
for (const locale of locales) {
  descriptionFields[locale] = await autoTranslate(
    baseDescription,
    locale,
    ...aiParams
  );
}
```

## Graceful Degradation

When AI isn't configured:
- Auto-translate buttons are hidden
- Review moderation silently skips AI checks
- All features remain functional with manual workflows

```typescript
// Fallback UI logic
if (!aiConfigured) {
  translateButton.style.display = 'none';
  // Manual moderation still works
}
```
