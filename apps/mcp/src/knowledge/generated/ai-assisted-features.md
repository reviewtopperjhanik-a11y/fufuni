## AI-Assisted Features Reference

Fufuni uses client-side AI calls for translation and review moderation. AI requests originate from the browser, not the backend, to reduce server load and latency.

## Architecture

AI inference runs in the user's browser via direct calls to third-party AI providers. The backend only serves encrypted credentials and configuration.

**Key design choices:**
- **Client-side requests**: The frontend fetches credentials then calls AI APIs directly
- **Provider-agnostic**: Supports OpenAI, Groq, Anthropic via a common interface
- **Encrypted storage**: Credentials are encrypted at rest using AES-256-CBC

## Credential Storage

AI credentials are stored encrypted in the database:

```typescript
// Stored in ai_settings table (encrypted)
interface AiConfig {
  version: number;
  providers: Record<string, {
    protocol: 'openai' | 'anthropic' | 'gemini';
    endpoint: string;
    keys: Array<{ key: string; owner?: string }>;
    models: Array<{ id: string; priority: number }>;
  }>;
}
```

Encryption uses the `CRYPTOKEN` Wrangler secret with 100,000 PBKDF2 iterations:

```bash
# Encryption format (compatible with OpenSSL)
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"${CRYPTOKEN}"
```

## GET /v1/ai/parameters

Returns decrypted AI credentials to authenticated admin users.

**Endpoint**: `GET /v1/ai/parameters`
**Permission**: `ai:api`
**Response**:
```typescript
interface AiParams {
  apiKey: string;       // Decrypted API key
  model: string;        // Model ID (e.g., "gpt-4o")
  url: string;          // Base URL (e.g., "https://api.groq.com/openai/v1")
  cloudflareAigToken?: string; // Optional gateway token
  cloudflareAigUrl?: string;   // Optional gateway URL
}
```

Example usage:
```typescript
const response = await fetch('/v1/ai/parameters', {
  headers: { Authorization: `Bearer ${adminToken}` }
});
const { apiKey, model, url } = await response.json();
```

## Review Moderation Flow

1. Admin loads reviews page → Frontend fetches AI credentials
2. For each review, calls `analyzeReviewWithAi()`
3. UI displays recommendation with reason

**UI Integration**:
```typescript
const moderate = async (reviewId) => {
  const result = await analyzeReviewWithAi(review, aiParams);
  if (result.recommendation === "approve") {
    approveButton.classList.remove("hidden");
  } else {
    rejectButton.classList.remove("hidden");
    reasonElement.textContent = result.reason;
  }
};
```

## Auto-Translation Workflow

1. Admin opens product form with base locale content
2. Clicks "Translate all" → Frontend batches requests
3. AI translates to all configured locales (en-US → fr-FR, de-DE, etc.)
4. Pre-fills form fields with results

**Fallback behavior**: When AI isn't configured, translation buttons are hidden.

## Graceful Degradation

When AI isn't configured:
- Translation buttons are hidden in the admin UI
- Review moderation silently skips AI check (defaults to manual approval)
- No client-side errors — features remain usable without AI
