## AI-Assisted Features Reference

### Architecture: Client-Side AI Calls
Fufuni makes AI API calls **directly from the browser** (not via backend inference) for:
1. **Reduced latency**: Avoids an extra round-trip to the Worker.
2. **Cost control**: The merchant’s AI API key is used directly, so usage is billed to their account.
3. **Flexibility**: Supports any OpenAI-compatible provider (Groq, Anthropic, etc.) without backend changes.

**Flow**:
1. Admin fetches decrypted credentials via `GET /v1/ai/parameters` (requires `ai:api` permission).
2. Browser calls the AI provider directly using `ai-client.ts` utilities.
3. Responses are processed client-side (e.g., auto-filling translation fields).

---

### Credential Storage and Encryption
Credentials are stored in the `ai_settings` table (SQLite via Durable Objects) as an **encrypted blob** (`ai.json.enc`).
Encryption uses OpenSSL-compatible AES-256-CBC with:
- **Key**: The `ENCRYPTION_KEY` Wrangler secret (set via `wrangler secret put ENCRYPTION_KEY`).
- **Format**: Base64-encoded OpenSSL output (includes `Salted__` header).
- **Decryption**: Handled by `lib/ai-enc.ts` using the Web Crypto API (works in Workers + Node.js).

**Example `ai.json` (before encryption)**:
```json
{
  "version": 1,
  "providers": {
    "groq": {
      "protocol": "openai",
      "endpoint": "https://api.groq.com/openai/v1",
      "keys": [
        { "key": "gsk_...", "type": "paid" }
      ],
      "models": [
        {
          "id": "llama-3.3-70b-versatile",
          "contextWindow": 8192,
          "maxOutputTokens": 4096,
          "priority": 1
        }
      ]
    }
  }
}
```

**Encrypting the file**:
```bash
openssl enc -aes-256-cbc -a -pbkdf2 -iter 100000 -salt \
  -in ai.json -out ai.json.enc -pass pass:"$(printenv ENCRYPTION_KEY)"
```

**Decryption in code**:
```typescript
import { decryptAiConfig } from '../lib/ai-enc';

const config = await decryptAiConfig(encryptedBlob, env.ENCRYPTION_KEY);
```

### `GET /v1/ai/parameters`
**Purpose**: Fetches decrypted AI credentials for client-side use.
**Authentication**: Requires `ai:api` permission (granted to admins via `aiAccessOnly` middleware).
**Response**:
```typescript
interface AiParams {
  apiKey: string;          // Decrypted API key (randomly selected from pool)
  model: string;           // Model ID (e.g., "llama-3.3-70b-versatile")
  url: string;             // Base URL (e.g., "https://api.groq.com/openai/v1")
  provider?: string;       // Auto-detected provider ("openai"|"groq"|"anthropic")
  cloudflareAigToken?: string;  // Present if using Cloudflare AI Gateway
  cloudflareAigUrl?: string;    // Gateway endpoint (overrides `url`)
}
```

**Example call**:
```typescript
// In a React component (admin context)
const { data: aiParams } = useSWR('/v1/ai/parameters', fetcher);
if (aiParams) {
  await translateWithAi("Hello", "fr-FR", aiParams);
}
```

**Key behaviors**:
- **Key rotation**: Randomly selects a key from the pool (load balancing).
- **Fallback**: Uses legacy `AI_API_KEY`/`AI_MODEL` env vars if no encrypted config exists.
- **Gateway support**: Routes through Cloudflare AI Gateway when `cloudflareAigUrl` is set.

### `ai-client.ts` Exports
#### 1. `translateWithAi()`
Translates text/HTML to a target locale using the merchant’s AI provider.

**Signature**:
```typescript
async function translateWithAi(
  sourceContent: string,      // Text or HTML to translate
  targetLanguage: string,     // BCP-47 code (e.g., "fr-FR")
  aiParams: AiParams,         // From GET /v1/ai/parameters
  isHtml = true,              // Set false for plain text (e.g., product titles)
  options?: {
    maxTokens?: number;       // Override default token limit
    contentType?: "product_description" | "email_template";  // Adjusts prompt
  }
): Promise<TranslationResult>
```

**Example: Product Description**:
```typescript
const { success, content } = await translateWithAi(
  '<h1>Premium Widget</h1><p>Durable and stylish.</p>',
  'de-DE',
  aiParams,
  true,
  { contentType: 'product_description' }
);
if (success) {
  setTranslatedContent(content!);  // "<h1>Premium-Widget</h1><p>Langlebig und stilvoll.</p>"
}
```

**Prompt rules**:
- **HTML mode**: Preserves all tags/placeholders (e.g., `TMPLVAR0` in emails).
- **Email templates**: Forces formal register (e.g., "vous" in French).
- **Plain text**: Strips all HTML tags.

#### 2. `analyzeReviewWithAi()`
Moderates a product review for spam/offensive content.

**Signature**:
```typescript
async function analyzeReviewWithAi(
  review: {
    id: string;
    rating: number;
    title?: string | null;
    body?: string | null;
    author_name?: string | null;
  },
  aiParams: AiParams
): Promise<ReviewAnalysisResult>
```

**Example**:
```typescript
const { success, recommendation, reason } = await analyzeReviewWithAi(
  {
    id: "rev_123",
    rating: 1,
    title: "Scam!",
    body: "This product is fake. Do not buy.",
    author_name: "Angry Customer"
  },
  aiParams
);
// => { success: true, recommendation: "reject", reason: "Potential defamation" }
```

**UI Integration**:
- Called in the **admin reviews table** before rendering actions.
- **Approved reviews**: Show "Approve" button.
- **Rejected reviews**: Show "Reject" button + reason tooltip.
- **Error**: Falls back to manual moderation (no AI block).

#### 3. `analyzeReviewsBatchWithAi()`
Processes multiple reviews in parallel (5 concurrent requests max).

**Signature**:
```typescript
async function analyzeReviewsBatchWithAi(
  reviews: ReviewInput[],
  aiParams: AiParams,
  onProgress?: (done: number, total: number) => void
): Promise<Map<string, ReviewAnalysisResult>>
```

**Example**:
```typescript
const results = await analyzeReviewsBatchWithAi(
  pendingReviews,
  aiParams,
  (done, total) => setProgress(`${done}/${total}`)
);
```

### Review Moderation Workflow
1. **Trigger**: Admin opens the "Pending Reviews" page.
2. **AI Check**: For each review, call `analyzeReviewWithAi()`.
3. **UI Actions**:
   - **Safe (`"approve"`)**: Show green "Approve" button.
   - **Unsafe (`"reject"`)**: Show red "Reject" button + reason.
   - **Error**: Show manual moderation controls (no AI dependency).

**Prompt Template**:
```text
You are a content moderator for an e-commerce platform.
Analyze the following review and respond with JSON ONLY:
{"recommendation":"approve","reason":"..."}
or
{"recommendation":"reject","reason":"..."}
```

**Rejection Criteria**:
- Spam (e.g., "Check out my website!")
- Offensive language
- Personal data (e.g., phone numbers)
- Off-topic (e.g., political rants)

### Auto-Translation Workflow
1. **Trigger**: Admin edits a product’s base language (e.g., `en-US`) fields.
2. **Target Locales**: Auto-fills **all other enabled locales** (e.g., `fr-FR`, `de-DE`).
3. **Fallback**:
   - If AI is not configured, hide the "Auto-Translate" button.
   - If the AI call fails, show the error and keep existing translations.

**Example Flow**:
```typescript
// In ProductForm.tsx
const handleAutoTranslate = async () => {
  const { success, content } = await translateWithAi(
    product.description_en,
    'fr-FR',
    aiParams,
    true,
    { contentType: 'product_description' }
  );
  if (success) {
    form.setValue('description_fr', content!);
  }
};
```

**Token Budgeting**:
- Uses `getModelBudget()` to calculate max input size based on the model’s context window.
- Defaults: 2048 tokens for Groq, 4096 for others.

### Admin Setup Endpoints
#### 1. `POST /v1/ai/config`
Uploads an encrypted `ai.json.enc` file to Cloudflare KV.

**Request**:

**Example**:

```bash
curl -X POST /v1/ai/config \

  -H "Content-Type: application/json" \
```

### Graceful Degradation
| Scenario               | Behavior                                                                 |
|------------------------|--------------------------------------------------------------------------|
| No AI config           | Hide auto-translate buttons; skip review moderation.                     |
| Decryption fails       | Fall back to `AI_API_KEY`/`AI_MODEL` env vars.                           |
| AI API error           | Show user-friendly error; allow manual action (e.g., translate manually). |
| Rate-limited           | Retry with exponential backoff (max 3 attempts).                        |
| Cloudflare Gateway down | Fall back to direct provider calls.                                     |

**Example: Disabled State**:
```typescript
// In ReviewModeration.tsx
if (!aiParams) {
  return <Alert>AI moderation disabled. Moderate reviews manually.</Alert>;
}
```

### Provider-Specific Notes
- **Cloudflare AI Gateway**:
  - Requires `CLOUDFLARE_AIG_TOKEN` env var.
  - Models are prefixed with provider slugs (e.g., `groq/llama-3.3-70b-versatile`).
- **Anthropic**:
  - Uses `x-api-key` header (not `Authorization`).
  - Requires `anthropic-version: 2023-06-01`.
- **Groq/OpenAI**:
  - Uses standard `/v1/chat/completions` endpoint.
  - Supports `max_tokens` override for large translations.
